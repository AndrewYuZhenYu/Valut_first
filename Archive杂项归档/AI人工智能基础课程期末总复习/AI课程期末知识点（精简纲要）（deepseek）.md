# 第一章：人工智能概述

## 一、人工智能定义

**人工智能（Artificial Intelligence, AI）** 是研究、开发用于模拟、延伸和扩展人类智能的理论、方法、技术及应用系统的前沿交叉学科。

### 1. 人工智能的三种类型

| 类型 | 名称 | 特点 | 现状 |
|------|------|------|------|
| ANI | 弱人工智能 | 执行特定任务，缺乏跨领域泛化能力 | 已广泛应用 |
| AGI | 强人工智能 | 具备人类通用认知能力，可适配无限任务 | 理论研究阶段 |
| SI | 超人工智能 | 所有领域超越最聪明人类 | 理论层面，争议较大 |

### 2. 图灵测试（1950）

- **提出者**：艾伦·图灵
- **核心思想**：用“行为等价”替代“本质等同”，将抽象的思考能力转化为可验证实验
- **意义**：首次为机器智能赋予可量化、可验证的科学属性

### 3. 达特茅斯会议（1956）

- **历史意义**：
  - 麦卡锡首次明确“Artificial Intelligence”术语
  - 定义AI研究三大早期目标：模拟推理、语言理解、学习能力
  - 凝聚学术共同体

---

## 二、技术流派

| 流派 | 核心假设 | 实现核心 | 典型应用 | 局限 |
|------|----------|----------|----------|------|
| **符号主义** | 智能是符号的逻辑运算 | 知识表示与逻辑推理 | 专家系统、数学证明 | 知识获取瓶颈 |
| **联结主义** | 智能是神经网络的权重学习 | 人工神经网络与反向传播 | 图像识别、语音助手 | 黑箱、算力依赖 |
| **行为主义** | 智能是行为的环境适应 | 感知-动作循环与强化学习 | 机器人、自动驾驶 | 无法处理抽象任务 |

### 各流派代表成果

- **符号主义**：IBM DeepBlue（1997年击败国际象棋冠军卡斯帕罗夫）
- **联结主义**：AlphaFold（获2024年诺贝尔化学奖）
- **行为主义**：波士顿动力Atlas机器人

## 三、发展历程

### 第一次浪潮（1956-1970s）

**标志性成果**：
- 逻辑定理机（纽厄尔、西蒙）
- 感知机（罗森布拉特，1958）
- 国际跳棋程序（塞缪尔，首次提出“机器学习”概念）
- ELIZA聊天机器人（1966）
- 吴方法（几何定理机器证明）

**衰落原因**：单层感知机无法解决非线性问题、计算复杂度约束、经费削减

### 第二次浪潮（1970s-1980s）

**核心成果**：专家系统（DENDRAL、MYCIN、XCON）

**机器学习发展**：
- 反向传播算法（辛顿等，1986）
- 统计学习（核方法、集成学习）

**衰落原因**：第五代计算机未达成商业目标

### 第三次浪潮（2006至今）

**三驾马车**：算法、算力、数据

**里程碑成果**：
- AlexNet（2012）→ 深度学习时代
- AlphaGo（2016）→ 4:1击败李世石
- BERT、GPT系列 → 大语言模型时代

**核心规律**：
- **缩放律（Scaling Law）**：参数规模增加，实现相同性能所需数据量减少
- **涌现效应（Emergent Abilities）**：参数超阈值后，自主产生高阶能力

# 第二章：算力与计算系统

## 一、计算机与计算系统

### 1. 图灵机（1936）

- **提出者**：艾伦·图灵
- **组成**：无限长纸带、读写头、内部状态寄存器、控制规则表
- **核心贡献**：证明通用计算的可能性

### 2. 冯·诺依曼结构（1945）

**核心思想**：
- 存储程序原理（程序与数据共同存储）
- 五大核心部件：运算器、控制器、存储器、输入设备、输出设备
- 采用二进制

### 3. 硬件系统组成

| 部件 | 功能 |
|------|------|
| CPU（运算器+控制器） | 执行计算、控制协调 |
| 存储器 | 内存（临时）、外存（永久） |
| 总线 | 数据总线、地址总线、控制总线 |
| 专用芯片 | GPU、NPU、TPU |

### 4. 软件系统

| 类型 | 功能 | 示例 |
|------|------|------|
| 系统软件 | 管理硬件、提供运行环境 | 操作系统、DBMS、编译器 |
| 应用软件 | 满足特定场景需求 | 办公软件、即时通讯、CAD |

---

## 二、算力与计算系统

### 1. 算力的基本要素

**定义**：计算系统在单位时间内处理数据、执行运算任务的能力

**核心指标**：
- **FLOPS**（每秒浮点运算次数）：GFLOPS、TFLOPS、EFLOPS
- 辅助指标：整数运算速度、内存带宽、数据吞吐量

### 2. 算力三大分类

| 类型 | 面向任务 | 载体 |
|------|----------|------|
| 基础算力 | 日常办公、网页浏览 | 个人计算机、普通服务器 |
| 智能算力 | AI训练与推理 | GPU、TPU、ASIC |
| 超算算力 | 科学研究、国防工程 | 超级计算机集群 |

## 二、知识表示

### 1. DIKW模型

| 层级 | 含义 |
|------|------|
| Data（数据） | 原始记录，无上下文 |
| Information（信息） | 加工后有意义的记录 |
| Knowledge（知识） | 提炼的规律与规则 |
| Wisdom（智慧） | 运用知识解决问题 |

### 2. 知识分类

- **陈述性知识**：事实性知识（如“北京是首都”）
- **过程性知识**：如何做某事（如“红灯停”）
- **启发性知识**：经验法则（如老中医诊断）

### 3. 产生式规则

**基本形式**：`IF P THEN Q`

**不确定性扩展**：引入可信度CF或概率P

**推理过程**：
1. 规则匹配（前件匹配）
2. 冲突消解（优先级、可信度、具体性、数据排序）

**优势**：贴近人类思维、模块化、可解释
**局限**：知识获取效率低、规则爆炸、不适合复杂关系

### 4. 专家系统

**核心组成**：
- 知识库：存储专业知识
- 推理机：执行推理
- 综合数据库：存储事实
- 解释器：解释推理过程
- 人机交互界面

**优势**：高效持久、可复制、一致客观、可解释
**局限**：知识获取瓶颈、缺乏学习能力、领域狭窄、维护成本高

# 第四章：机器学习

### 4. 机器学习三大范式

|------|----------|----------|----------|

| **无监督学习** | 无标签 | 聚类、降维 | K-means、DBSCAN、PCA |

2. 数据与环境准备

4. 模型训练与优化
5. 模型评估与应用

## 二、有监督学习

### 1. 线性回归

**一元线性回归**：y = wx + b

**损失函数**：均方误差（MSE）
\[
J(w,b) = \frac{1}{N}\sum_{i=1}^{N}(wx_i + b - y_i)^2
\]

**参数求解**：最小二乘法（求偏导=0）

**多元线性回归**：\(\hat{y} = w^Tx + b\)

**正则化方法**：
- 岭回归：L2正则化
- Lasso回归：L1正则化
- Elastic net：L1+L2

### 2. 逻辑回归

**核心**：线性回归输出通过Sigmoid函数映射到(0,1)

\[
\hat{y} = \sigma(w^Tx + b) = \frac{1}{1+e^{-(w^Tx+b)}}
\]

**损失函数**：交叉熵损失

\[
L(\hat{y},y) = -[y\log\hat{y} + (1-y)\log(1-\hat{y})]
\]

**优化方法**：梯度下降法

### 3. K近邻（KNN）

**核心思想**：物以类聚，人以群分

**关键要素**：
- K值选择（交叉验证）
- 距离度量（欧氏距离、曼哈顿距离、闵可夫斯基距离）

**KD树**：加速KNN查询的二叉树结构

**局限**：效率低、维度灾难、类别不平衡敏感

### 4. 决策树

**核心**：基于树结构进行决策

**划分准则**：

| 准则 | 公式 | 特点 |
|------|------|------|
| 信息增益 | Gain = Ent(D) - Σ权重×Ent(Dᵛ) | ID3，偏好取值多的属性 |
| 增益率 | Gain_ratio = Gain/IV | C4.5，偏好取值少的属性 |
| 基尼指数 | Gini = 1 - Σpₖ² | CART，越小纯度越高 |

**剪枝**：
- 预剪枝：生成过程中剪枝（有欠拟合风险）
- 后剪枝：生成完整树后剪枝（时间开销大）

**集成学习**：

| 方法 | 思想 | 代表 |
|------|------|------|
| Bagging | 并行训练，投票/平均 | 随机森林 |
| Boosting | 串行训练，修正前模型错误 | AdaBoost、GBDT、XGBoost |

### 5. 支持向量机（SVM）

**核心思想**：最大化分类间隔

**关键概念**：
- 支持向量：距离决策平面最近的样本点
- 间隔 = 2/||w||

**三种类型**：
- 硬间隔SVM：线性可分
- 软间隔SVM：引入松弛变量ξₖ
- 核SVM：映射到高维空间（核技巧）

## 三、无监督学习

### 1. K-means聚类

**目标**：最小化样本到所属簇中心的距离平方和

**算法流程**：
1. 随机初始化K个中心点
2. 分配样本到最近中心点
3. 更新中心点为簇均值
4. 重复2-3直到收敛

**肘方法**：用目标函数曲线拐点确定K值

**缺点**：对非凸数据集表现差、对初始值敏感、可能陷入局部最优

### 2. DBSCAN密度聚类

**核心概念**：
- ε-邻域：距离≤ε的样本集合
- 核心对象：ε-邻域内样本数≥MinPts
- 密度直达、密度可达、密度相连

**优势**：可处理非凸数据集、自动确定簇数、可识别噪声点

**参数选择**：$k-距离曲线确定ε$，$MinPts≥D+1$

### 3. 主成分分析（PCA）

**核心思想**：将数据向方差最大方向投影

**算法步骤**：
1. 中心化处理
2. 计算协方差矩阵$\large Σ = \frac{1}{(n-1)}XᵀX$
3. 特征值分解
4. 取前l个最大特征值对应的特征向量组成映射矩阵W
5. 投影：Y = XW

**应用**：数据降维、可视化、特征人脸（Eigenface）

## 四、强化学习

### 1. 核心要素

| 要素 | 含义 |
|------|------|
| 智能体（Agent） | 学习决策的主体 |
| 环境（Environment） | 智能体所处的外部场景 |
| 状态（State） | 环境当前描述 |
| 动作（Action） | 智能体可执行的操作 |
| 奖励（Reward） | 环境对动作的反馈 |

### 2. 马尔可夫决策过程（MDP）

**五元组**：(S, A, {Pₛₐ}, γ, R)

- S：状态集合
- A：动作集合
- Pₛₐ：状态转移概率
- γ：折扣因子（0~1）
- R：奖励函数

### 3. 无模型强化学习

直接从经验中学习价值函数和最优策略，无需构建MDP模型

### 4. Actor-Critic算法

| 组件 | 功能 |
|------|------|
| Actor（演员） | 策略网络πθ(a\|s)，负责决策 |
| Critic（评论家） | 价值网络VΦ(s)，负责评估 |

**核心公式**：
- TD误差：δ = r + γVΦ(s') - VΦ(s)
- 更新演员：θ ← θ + αθ·δ·∇θlnπθ(a\|s)
- 更新评论家：φ ← φ + αφ·δ·∇φVΦ(s)

**优势**：降低方差、实时反馈、灵活
**经典变种**：A2C、A3C、DDPG

# 第五章：深度学习

## 一、人工神经网络

### 1. M-P神经元模型（1943）

- 输入加权和 + 偏置 → 激活函数 → 输出
- 激活函数：阶跃函数、Sigmoid、ReLU

### 2. 前馈神经网络（MLP）

**结构**：输入层 + 隐藏层 + 输出层

**信息传递**：
\[
z^{(l)} = W^{(l)}a^{(l-1)} + b^{(l)}
\]
\[
a^{(l)} = f_l(z^{(l)})
\]

### 3. 输出单元

| 任务 | 输出单元 | 损失函数 |
|------|----------|----------|
| 回归 | 线性单元 | 均方误差 |
| 二分类 | Sigmoid单元 | 交叉熵 |
| 多分类 | Softmax单元 | 交叉熵 |

### 4. 反向传播算法（BP）

**核心思想**：基于梯度下降，计算损失函数对每个权重的偏导数

**链式法则**：
\[
\frac{\partial L}{\partial w_{hj}} = \delta_j \cdot b_h
\]

**误差项传播**：
\[
\delta^{(l)} = f_l'(z^{(l)}) \odot ((W^{(l+1)})^T \delta^{(l+1)})
\]

### 5. 常见问题与对策

| 问题 | 对策 |
|------|------|
| 过拟合 | 早停、正则化（L1/L2）、Dropout |
| 梯度消失 | ReLU激活函数、批归一化、残差连接 |

---

## 二、卷积神经网络（CNN）

### 1. 设计思想

受生物学感受野机制启发，具有三大特性：
- **局部连接**：每个神经元只连接局部区域
- **权重共享**：同一卷积核参数共享
- **池化**：降维、防止过拟合

### 2. 卷积层

**二维卷积**：
\[
y_{ij} = \sum_{u=1}^{U}\sum_{v=1}^{V} w_{uv}x_{i-u+1,j-v+1}
\]

**输出尺寸计算**：
\[
W_2 = (W_1 - K + 2P)/S + 1
\]

### 3. 池化层

| 类型 | 操作 | 特点 |
|------|------|------|
| 最大池化 | 取区域内最大值 | 提取纹理，保持局部不变性 |
| 平均池化 | 取区域内平均值 | 保留背景信息 |

### 4. 典型架构

**卷积层（特征提取）→ 池化层（降维）→ 全连接层（分类）**

---

## 三、循环神经网络（RNN）

### 1. 核心思想

通过循环结构和隐藏状态，让网络具备“记忆能力”

**关键公式**：
\[
s_t = f(Ux_t + Ws_{t-1})
\]
\[
o_t = g(Vs_t)
\]

### 2. 训练算法：BPTT

沿时间反向传播，将RNN按时间展开为深度前馈网络

### 3. 长程依赖问题

| 问题 | 原因 | 后果 |
|------|------|------|
| 梯度消失 | 连乘W，特征值<1 | 无法学习早期信息 |
| 梯度爆炸 | 连乘W，特征值>1 | 训练不稳定 |

### 4. LSTM（长短期记忆网络）

**核心创新**：细胞状态（线性信息通道）+ 三门控机制

| 门控 | 功能 |
|------|------|
| 遗忘门（fₜ） | 决定丢弃哪些历史信息 |
| 输入门（iₜ） | 决定存入哪些当前信息 |
| 输出门（oₜ） | 决定输出哪些记忆 |

**状态更新**：
\[
c_t = f_t \odot c_{t-1} + i_t \odot \tilde{c}_t
\]
\[
s_t = o_t \odot \tanh(c_t)
\]

### 5. GRU（门控循环单元）

LSTM的简化版：合并遗忘门与输入门为更新门，合并细胞状态与隐藏状态

| 门控 | 功能 |
|------|------|
| 重置门（rₜ） | 决定历史信息影响程度 |
| 更新门（zₜ） | 兼顾遗忘与更新 |

### 6. 双向RNN（BRNN）

正向RNN + 反向RNN + 输出融合层，可同时利用“过去”和“未来”上下文

**局限**：无法用于实时任务（需要完整序列）

---

## 四、Transformer

### 1. 核心创新

**三大支柱**：
- **自注意力机制**：直接建模任意元素间依赖
- **并行计算**：打破时序依赖
- **位置编码**：注入位置信息

### 2. 自注意力机制

**Q、K、V的含义**：
- Q（Query）：当前词在寻找什么信息
- K（Key）：其他词能提供什么类型信息
- V（Value）：其他词的具体信息内容

**计算公式**：

$Attention(Q,K,V) = softmax\left(\frac{QK^T}{\sqrt{d_k}}\right)V$


### 3. 多头注意力

- 将Q、K、V投影到h个子空间
- 并行计算h次注意力
- 拼接后线性变换

### 4. 位置编码

由于自注意力机制本身是“无序的”，需要注入位置信息

### 5. Transformer架构

**编码器**：N个相同层（多头注意力 + 前馈网络 + 残差连接 + 层归一化）

**解码器**：N个相同层（掩码多头注意力 + 编码器-解码器注意力 + 前馈网络）

### 6. 与RNN对比

| 维度 | RNN | Transformer |
|------|-----|-------------|
| 计算模式 | 串行 O(n) | 并行 O(n²) |
| 长程依赖 | 易衰减 | 直接建模 |
| 实际速度 | 慢 | 快（利用GPU） |

---

## 五、深度生成网络

### 1. 判别模型 vs 生成模型

| 维度  | 判别模型    | 生成模型  |
| --- | ------- | ----- |
| 任务  | 分类/预测   | 创造新样本 |
| 建模  | P(Y\|X) | P(X)  |
| 比喻  | 法官      | 模仿者   |

### 2. 自编码器（AE）

**结构**：编码器（压缩）→ 瓶颈层 → 解码器（重构）

**训练目标**：最小化重构误差（MSE或交叉熵）

**应用**：数据降维、图像去噪、异常检测

### 3. 变分自编码器（VAE）

**改进**：对潜在向量施加约束，使其服从标准高斯分布

**优势**：潜在空间连续平滑，可随机采样生成新样本

### 4. 生成对抗网络（GAN）

**核心思想**：生成器（伪造者）与判别器（鉴赏家）博弈对抗

**训练过程**：
1. 固定G，训练D（提升区分能力）
2. 固定D，训练G（提升欺骗能力）

**挑战**：模式崩溃、训练不稳定

**解决方案**：WGAN、DCGAN、CycleGAN、Conditional GAN

### 5. 扩散模型（Diffusion Model）

**核心思想**：前向扩散（逐步破坏数据）+ 反向去噪（逐步恢复）

**优势**：
- 训练目标明确（预测噪声）
- 过程稳定，几乎无模式崩溃
- 生成质量超越GAN

**代表应用**：DALL-E 2、Midjourney、Stable Diffusion

# 第六章：大模型技术

## 一、大模型概述

### 1. 定义

> 海量数据 + 大规模算力 + 先进算法，参数庞大、泛化能力强、接近通用智能的人工智能系统

### 2. 核心特征

- **大**：不仅是参数规模，更是能力边界的突破
- **涌现能力**：参数达特定阈值后，自主具备零样本学习、逻辑推理等能力
- **从“专用模型”到“通用平台”的跃迁**

### 3. 与传统小模型对比

| 维度 | 传统小模型 | 大模型 |
|------|------------|--------|
| 数据 | “小而精”的标注数据 | “大而广”的无标注数据 |
| 任务适配 | 一模一用（需重训练） | 一模多用（提示/微调） |
| 泛化能力 | 弱 | 强 |
| 规模算力 | 百万级参数 | 亿万级参数 |

### 4. 三大要素

| 要素 | 说明 |
|------|------|
| 海量数据 | 万亿级Token或亿级样本 |
| 超强算力 | 数千甚至上万个GPU集群 |
| 先进算法 | Transformer架构 |

### 5. 训练范式

**Step 1：预训练（通识教育）**
- 目标：学习通用知识和规律
- 方法：海量无标注数据自监督学习

**Step 2：微调（专业训练）**
- 目标：适配特定场景任务
- 方法：少量标注领域数据训练

### 6. 三大架构类型

| 架构 | 特点 | 擅长 | 代表 |
|------|------|------|------|
| 解码器（生成家） | 单向注意力，逐字生成 | 写文章、写代码 | GPT系列 |
| 编码器（理解家） | 双向注意力，通读全文 | 分类、情感分析 | BERT系列 |
| 双编码器（连接家） | 跨模态对齐 | 以文搜图 | CLIP |

---

## 二、大语言模型

### 1. BERT系列（理解派）

**核心突破**：首次将Transformer双向注意力机制全面应用于预训练

**“三层大脑”结构**：
1. 嵌入层：文字→数字“身份证”（词嵌入+段嵌入+位置嵌入）
2. 编码器层：12/24层Transformer编码器堆叠
3. 输出层：任务适配器

**预训练任务**：
- **MLM（掩码语言建模）**：完形填空，学习双向上下文
- **NSP（下句预测）**：学习句子间逻辑关系

### 2. GPT系列（生成派）

**核心任务**：自回归语言建模（预测下一个词）

**发展历程**：

| 版本 | 年份 | 参数 | 核心突破 |
|------|------|------|----------|
| GPT-1 | 2018 | 1.17亿 | 验证Transformer解码器可行性 |
| GPT-2 | 2019 | 15亿 | 零样本学习能力 |
| GPT-3 | 2020 | 1750亿 | 涌现能力、少样本学习 |
| GPT-3.5 | 2022 | - | RLHF人类对齐 |
| GPT-4 | 2023 | - | 多模态输入（文本+图像） |

### 3. RLHF（人类反馈强化学习）

**目标**：让模型生成内容更贴合人类意图、逻辑和价值观

**简化流程**：预训练模型 → 奖励建模 → 强化学习微调

---

## 三、视觉大模型

### 1. ViT（视觉Transformer）

**核心思想**：将图像分割为固定大小的Patches（补丁块），转化为序列后输入Transformer

**步骤**：
1. 图像分块（如224×224→196个16×16小块）
2. 展平与嵌入
3. 添加位置编码

### 2. SAM（Segment Anything Model）

**核心能力**：无需微调，分割任意类型目标

**交互方式**：点、框、文本等多种提示

**三段式架构**：
- 图像编码器（ViT重型骨干，一次计算多次复用）
- 提示编码器（异构输入→统一特征）
- 掩码解码器（轻量高效，实时交互）

**训练数据**：SA-1B数据集（1100万图像，10亿+掩码）

---

## 四、多模态大模型

### 1. 核心概念

**模态**：人与世界交互的“通道”

**关键步骤**：
1. **对齐**：给不同模态打上相同“身份证”
2. **统一表征**：不同模态映射到同一语义空间

### 2. GPT-4V

**核心能力**：
- 看图说话：精准描述图片细节
- 视觉推理：解释图表、理解幽默
- 空间感知：定位物体位置

**输入处理**：图像预处理 → 视觉特征提取 → 特征融合 → 跨模态注意力

### 3. 视频生成大模型（Sora）

**核心突破**：文本指令驱动高质量视频生成（60秒1080p）

**核心技术**：
- 时空潜在补丁（视频压缩+时空切分）
- 扩散Transformer
- 文本-视频对比学习

**关键能力**：
- 物理连贯性（3D形态、运动逻辑）
- 长时高清生成

**局限**：物理逻辑偏差、细节把控不足、算力要求高

### 4. 伦理警示

- **深度伪造风险**：虚假新闻、身份伪造
- **识别方法**：寻找物理破绽、检查元数据（C2PA）、关注水印、AI鉴伪

## 五、大模型应用技术

### 1. 三大支柱

| 技术 | 作用 |
|------|------|
| 提示词工程 | 低成本高效交互，引导模型输出 |
| 大模型微调 | 垂直场景深度适配 |
| 大模型评测 | 保障应用效果可控 |

### 2. 提示词工程

| 方法 | 核心 | 适用场景 |
|------|------|----------|
| 零样本提示 | 清晰完整指令 | 简单任务 |
| 少样本提示 | 提供2-3个示例 | 复杂/格式特殊任务 |
| RAG | 检索+生成 | 知识更新、减少幻觉 |
| APE | AI自动生成优化提示 | 开发者规模化应用 |

### 3. 大模型微调

| 方法 | 操作 | 优势 | 挑战 |
|------|------|------|------|
| 全参数微调 | 优化所有参数 | 效果天花板最高 | 算力成本高、灾难性遗忘 |
| PEFT | 优化1%-10%参数 | 成本低、避免遗忘 | 极端场景精度略低 |

**PEFT主流方法**：
- **LoRA**：在关键层旁挂载低秩矩阵（“外挂技能卡”）
- **Adapter**：层间插入小型模块（“内置插件”）
- **Prefix Tuning**：输入层添加可学习前缀向量（“魔法咒语”）

### 4. 大模型评测

**四大维度**：

| 维度 | 评测内容 |
|------|----------|
| 知识与能力 | 知识储备、任务执行能力 |
| 对齐评测 | 目标对齐、价值对齐 |
| 安全评测 | 内容安全、隐私安全、合规安全 |
| 行业适配 | 行业知识、行业任务、场景实战 |

**四大核心原则**：
1. 确保评测数据代表性
2. 平衡客观量化与主观定性
3. 重视动态评测与持续迭代
4. 坚守伦理与合规底线
