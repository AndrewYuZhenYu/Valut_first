# 第四版图片质量与归档说明

- 插图总数：65 张，各有 PNG 主图与不依赖设备字体的矢量轮廓 SVG。
- 重新排版：按每幅图实际视觉边界压缩画布高度，不再统一使用 1500×820。
- 文字：所有标题及各级标注已放大，并对文本越界风险进行了宽度限制。
- 防乱码：最终 SVG 中所有文字均转换成矢量字形路径，不再依赖读者设备的字体；PNG 从同一份矢量 PDF 原生渲染。
- 清晰度：PNG 约按每 SVG 坐标单位 2.6 像素导出；SVG 是可无限缩放的矢量格式。
- 维护：editable_svg_sources 保存了可继续修改文字的矢量源文件，但跨平台显示以 images 内的轮廓 SVG 和 PNG 为准。
- 图片和正文的引用关系保持不变。按原规范将唯一名称的资源目录放入 Obsidian Vault 的 Assets/ 下。
- 自动验收包括：65 张原图完整生成、SVG/XML 解析、PNG 解码、文本路径化、Markdown 图片引用完整性。未直接访问用户本地 Obsidian 配置。

- 二次版式紧凑化：识别主体内部真正无绘制内容的长空白区，仅当所有几何元素可安全分组移动时进行二次压缩，避免拉伸或截断箭头。
