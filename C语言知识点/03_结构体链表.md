## 第一章：为什么我们需要链表？

### 1.1 回顾数组 —— 我们熟悉的老朋友

在学链表之前，我们先看看C语言里我们已经掌握的工具——数组。

假设你要管理一个班级的学生成绩，你可能会这样写：

```c
int scoreA[5] = {78, 85, 92, 88, 76};
```

数组用起来很方便，你想访问第3个成绩，写 `scoreA[2]` 就行了。但是，数组有两个让我们头疼的问题：

**问题一：数组的大小是固定的**

当你写下 `int scoreA[5]` 的时候，你就告诉电脑："给我5个连续的格子放成绩"。如果后来班级来了第6个学生，你就没地方放了。你可能会想："那我就写大一点，`int scoreA[1000]`！" 但这样会造成巨大的浪费，就像你为了偶尔来一个客人，常年租着一个能坐1000人的大宴会厅。

**问题二：插入和删除非常麻烦**

假设数组里存的是 `[78, 85, 92, 88, 76]`，现在你想在 `85` 和 `92` 之间插入一个 `89`。你需要：
1. 先把 `92` 往后挪一个位置
2. 再把 `88` 往后挪一个位置
3. 再把 `76` 往后挪一个位置
4. 最后把 `89` 放进空出来的位置

如果数组有10000个元素，你在开头插入一个数据，就要移动10000次，太慢了！

### 1.2 链表的解决思路 —— "各找各妈" 的存储方式

链表换了一种思路：我们不再要求数据在内存里"排排坐"，而是让每个数据自己带一个"地址标签"，告诉下一个数据在哪里。

想象一下寻宝游戏：
- 你在树下找到第一张纸条，上面写着："宝藏是金币，下一个线索在花坛下面"
- 你跑到花坛，找到第二张纸条："宝藏是银币，下一个线索在假山后面"
- 你跑到假山，找到第三张纸条："宝藏是钻石，这里就是终点"

这些纸条就是链表的"节点"。每张纸条都包含：
1. 它自己的数据（宝藏是什么）
2. 下一个纸条的位置（线索指向哪里）

**这就是链表的核心思想：数据分散存储，每个数据都知道下一个数据在哪里。**

## 第二章：链表的基石 —— 节点（Node）

### 2.1 什么是节点？

在链表中，我们管每一个"纸条"叫做一个**节点（Node）**。

每个节点都包含两个部分：
- **数据域**：存放实际的数据（比如成绩、名字、年龄等）
- **指针域**：存放下一个节点的地址

### 2.2 用结构体定义节点

在C语言中，我们用 `struct`（结构体）来定义节点。结构体可以把多个不同类型的数据组合在一起。

我们用一个生活中的例子来学习：**水果店里的水果清单**。每个节点代表一种水果，包含水果的名字和价格，以及指向下一个水果的指针。

```c
// 定义一个水果节点
// 每个节点代表一种水果
struct FruitNode {
    char nameA[30];          // 水果的名字，比如 "Apple"
    float priceA;            // 水果的价格，比如 5.5
    struct FruitNode *nextA; // 指向下一个水果节点的指针
};
```

请你盯着这个结构体看10秒钟。最关键的是第三行：`struct FruitNode *nextA;`

这行代码的意思是：在 `FruitNode` 这个结构体里面，有一个成员变量叫 `nextA`，它的类型是"指向 `FruitNode` 类型结构体的指针"。

通俗点说：每个水果节点都知道"下一个水果节点"住在哪里（内存地址）。

### 2.3 关于指针的快速复习

如果你对指针还不太熟悉，我们用最朴素的方式解释一下：

- 每个变量都住在内存里，有一个地址（就像你家有个门牌号）
- 指针就是一个"存地址"的变量
- `int *p` 表示：p 是一个指针，它指向一个 int 类型的数据
- `struct FruitNode *nextA` 表示：nextA 是一个指针，它指向一个 FruitNode 类型的数据

**关键理解：** `nextA` 本身是一个变量，它存储的值是"下一个节点的地址"。这就是把节点串联起来的"绳子"。

### 2.4 节点的图示

想象三个水果节点在内存中的样子：

```
节点1 (Apple)               节点2 (Banana)              节点3 (Cherry)
+------------------+        +------------------+        +------------------+
| nameA = "Apple"  |        | nameA = "Banana" |        | nameA = "Cherry" |
| priceA = 5.5     |        | priceA = 3.2     |        | priceA = 8.0     |
| nextA = 地址2 ---|------->| nextA = 地址3 ---|------->| nextA = NULL     |
+------------------+        +------------------+        +------------------+
                                                                  |
                                                                  v
                                                           (这是终点)
```

注意最后一个节点的 `nextA` 是 `NULL`，这表示链表的结束。`NULL` 就是一个特殊的地址值，代表"哪里也不指向"。

## 第三章：创建节点的工具 —— 动态内存分配

### 3.1 为什么需要动态内存分配？

你可能已经习惯了这样创建变量：
```c
int numA = 10;
struct FruitNode nodeA;
```

这种创建方式叫"静态分配"，变量在程序运行前就分配好了空间，而且在函数结束时会被自动销毁。

但是，链表需要在程序运行的过程中**随时**创建新的节点，我们不知道会有多少个节点，也不知道什么时候需要创建。所以我们需要"动态分配"。

### 3.2 malloc 函数 —— 向系统申请内存

`malloc` 是 C 语言标准库中的一个函数，它的全称是 "memory allocation"（内存分配）。它的作用是：从系统的堆内存中申请一块指定大小的空间，并返回这块空间的起始地址。

使用 `malloc` 需要包含头文件：`#include <stdlib.h>`

基本用法：
```c
// 申请一块能存放一个 FruitNode 结构体的内存
// sizeof(struct FruitNode) 计算出一个 FruitNode 需要多少字节
// (struct FruitNode*) 是把返回的地址转换成"指向 FruitNode 的指针"类型
struct FruitNode *newNodeA = (struct FruitNode*)malloc(sizeof(struct FruitNode));
```

**我们拆解一下这行代码：**

| 部分 | 含义 |
|------|------|
| `sizeof(struct FruitNode)` | 计算一个水果节点占多少字节 |
| `malloc(...)` | 向系统申请这么多字节的内存 |
| `(struct FruitNode*)` | 把返回的地址转换成正确的指针类型 |
| `struct FruitNode *newNodeA` | 声明一个指针变量，用来保存这个地址 |

### 3.3 检查 malloc 是否成功

`malloc` 不一定总能成功。如果系统内存不足，`malloc` 会返回 `NULL`。

所以我们每次使用 `malloc` 之后，**必须**检查返回值：

```c
struct FruitNode *newNodeA = (struct FruitNode*)malloc(sizeof(struct FruitNode));
if (newNodeA == NULL) {
    // 内存分配失败！
    printf("系统内存不足，无法创建新节点！\n");
    // 通常我们会退出程序或者返回错误码
    exit(1); // exit 函数需要 #include <stdlib.h>
}
```

这是一个良好的编程习惯，可以避免程序因访问空指针而崩溃。

### 3.4 free 函数 —— 归还内存

动态分配的内存不会自动释放。当你不再需要一个节点时，必须用 `free` 函数把它归还给系统，否则会造成"内存泄漏"（memory leak）。

```c
free(newNodeA); // newNodeA 指向的内存被释放了
```

**注意：** `free` 之后，`newNodeA` 指针本身还存在，但它指向的内存已经无效了。我们通常会把指针设为 `NULL`，防止不小心使用它。

```c
free(newNodeA);
newNodeA = NULL;
```

## 第四章：第一个链表 —— 从零开始创建

### 4.1 准备工作：创建一个节点的函数

我们先把"创建节点"这个操作封装成一个函数，这样后面会方便很多。

这个函数的功能是：
1. 接收水果的名字和价格
2. 动态分配一个节点
3. 把数据放进节点
4. 返回指向这个节点的指针

```c
#include <stdio.h>
#include <stdlib.h>
#include <string.h>  // 为了使用 strcpy

// 定义水果节点结构体
struct FruitNode {
    char nameA[30];
    float priceA;
    struct FruitNode *nextA;
};

// 函数：创建一个新的水果节点
// 参数：水果名字 nameArg，水果价格 priceArg
// 返回值：指向新节点的指针，如果失败则返回 NULL
struct FruitNode* createFruitNode(char nameArg[], float priceArg) {
    // 第一步：申请内存
    struct FruitNode *newNodeA = (struct FruitNode*)malloc(sizeof(struct FruitNode));
    
    // 第二步：检查是否申请成功
    if (newNodeA == NULL) {
        printf("创建水果节点失败，内存不足！\n");
        return NULL;
    }
    
    // 第三步：填充数据
    // strcpy 是字符串复制函数，把 nameArg 复制到 newNodeA->nameA
    strcpy(newNodeA->nameA, nameArg);
    newNodeA->priceA = priceArg;
    
    // 第四步：指针域初始化为 NULL，表示这个节点目前不指向任何节点
    newNodeA->nextA = NULL;
    
    // 第五步：返回新节点的地址
    return newNodeA;
}
```

**关于 `strcpy` 的说明：** `strcpy` 是 C 标准库中的字符串复制函数，需要包含 `<string.h>`。它的作用是把源字符串复制到目标字符串中。我们这里把参数 `nameArg` 复制到结构体的 `nameA` 中。

### 4.2 手动创建三个节点的链表

现在我们用刚才的 `createFruitNode` 函数来创建三个水果节点，并把它们串联起来。

```c
int main() {
    // 声明三个指针，分别指向三个节点
    struct FruitNode *headA;     // 头节点指针
    struct FruitNode *nodeApple;
    struct FruitNode *nodeBanana;
    struct FruitNode *nodeCherry;
    
    // 第一步：创建三个节点
    nodeApple = createFruitNode("Apple", 5.5);
    nodeBanana = createFruitNode("Banana", 3.2);
    nodeCherry = createFruitNode("Cherry", 8.0);
    
    // 检查节点是否都创建成功了
    if (nodeApple == NULL || nodeBanana == NULL || nodeCherry == NULL) {
        printf("节点创建失败，程序退出\n");
        return 1;
    }
    
    // 第二步：把三个节点串联起来
    // Apple 后面是 Banana
    nodeApple->nextA = nodeBanana;
    // Banana 后面是 Cherry
    nodeBanana->nextA = nodeCherry;
    // Cherry 的 nextA 已经是 NULL，表示链表结束
    
    // 第三步：让 headA 指向第一个节点
    headA = nodeApple;
    
    // 到这里，链表就创建好了！
    // headA ---> Apple ---> Banana ---> Cherry ---> NULL
    
    // 我们会在下一章学习如何遍历这个链表
    
    return 0;
}
```

### 4.3 理解 headA —— 链表的入口

`headA` 是一个指针，它指向链表的第一个节点。我们把 `headA` 叫做"头指针"。

**重要概念：** 我们通过 `headA` 来代表整个链表。只要你知道 `headA` 指向哪里，你就可以顺着 `nextA` 指针找到所有的节点。

如果把链表比作一列火车：
- `headA` 是火车头的地址
- 每个节点是一节车厢
- `nextA` 是连接下一节车厢的挂钩
- `NULL` 是火车的终点

### 4.4 遍历链表 —— 把数据打印出来

"遍历"就是从头到尾走一遍，访问每一个节点。

思路很简单：
1. 从 `headA` 开始
2. 只要当前节点不是 `NULL`，就处理这个节点
3. 然后通过 `nextA` 移动到下一个节点

```c
// 函数：打印链表中的所有水果
// 参数：头节点指针 headPtr
void printFruitList(struct FruitNode *headPtr) {
    // 如果链表为空
    if (headPtr == NULL) {
        printf("水果列表是空的！\n");
        return;
    }
    
    // 创建一个"行走"指针，从头部开始
    struct FruitNode *walker = headPtr;
    int countA = 1;
    
    printf("\n===== 水果列表 =====\n");
    while (walker != NULL) {
        printf("第 %d 种水果：%s，价格：%.2f 元\n", 
               countA, walker->nameA, walker->priceA);
        // 移动到下一个节点
        walker = walker->nextA;
        countA++;
    }
    printf("===================\n");
}
```

**代码详解：**

- `walker` 这个变量名表示"行走的人"，它会在链表中一步一步地移动
- `while (walker != NULL)` 表示：只要还没走到终点，就继续
- `walker = walker->nextA` 是关键的移动步骤，把 `walker` 指向下一个节点
- 最后一个节点的 `nextA` 是 `NULL`，所以循环会正常结束

## 第五章：链表的核心操作 —— 增删改查

现在我们要学习链表最重要的四个操作：**增（插入）**、**删（删除）**、**改（修改）**、**查（查找）**。

我们会把每个操作都封装成函数。注意，这些函数有的需要修改 `headA` 指针本身（比如在头部插入或删除），所以我们需要传递"指向 headA 的指针"，也就是 **二级指针**。

### 5.1 关于二级指针的详细解释

这是一个初学者最容易困惑的地方。我们用例子来说明。

假设你在 `main` 函数中有一个指针 `headA`，它指向链表的第一个节点。

```c
struct FruitNode *headA = NULL; // headA 是一个指针
```

现在你想在链表的头部插入一个新节点，这意味着你需要**修改 `headA` 的值**，让它指向新的节点。

如果你把 `headA` 传给函数，函数接收的是 `headA` 的**拷贝**，函数内部修改的是拷贝，外面的 `headA` 不会变。

所以我们需要传递 `headA` 的地址（也就是指向 `headA` 的指针），这样函数可以通过这个地址直接修改 `headA`。

```c
// headA 的类型是 struct FruitNode*
// &headA 的类型是 struct FruitNode**
// 所以函数参数是 struct FruitNode **headPtrPtr
```

**记忆技巧：** 如果函数要修改一个 `int` 变量，我们传 `&变量`，函数用 `int *` 接收。同理，如果函数要修改一个指针变量 `headA`，我们传 `&headA`，函数用 `struct FruitNode **` 接收。

### 5.2 插入操作 —— 头部插入

在链表的头部插入一个新节点，让新节点成为链表的第一个。

**步骤：**
1. 创建新节点
2. 新节点的 `nextA` 指向原来的头节点
3. 头指针指向新节点

```c
// 函数：在链表头部插入一个水果节点
// 参数：headPtrPtr 是指向头指针的指针，nameArg 是水果名，priceArg 是价格
void insertAtHead(struct FruitNode **headPtrPtr, char nameArg[], float priceArg) {
    // 第一步：创建新节点
    struct FruitNode *newNodeA = createFruitNode(nameArg, priceArg);
    if (newNodeA == NULL) {
        return; // 创建失败，直接返回
    }
    
    // 第二步：新节点的 next 指向原来的头节点
    // *headPtrPtr 就是 main 函数里的 headA
    newNodeA->nextA = *headPtrPtr;
    
    // 第三步：头指针指向新节点
    *headPtrPtr = newNodeA;
    
    printf("在头部插入 %s 成功！\n", nameArg);
}
```

**使用示例：**
```c
int main() {
    struct FruitNode *headA = NULL;
    
    // 在头部插入三个水果
    insertAtHead(&headA, "Apple", 5.5);
    insertAtHead(&headA, "Banana", 3.2);
    insertAtHead(&headA, "Cherry", 8.0);
    
    // 现在链表的顺序是：Cherry -> Banana -> Apple
    // 因为每次都在头部插入，最后插入的变成了第一个
    
    printFruitList(headA);
    return 0;
}
```

### 5.3 插入操作 —— 尾部插入

在链表的末尾插入一个新节点。

**步骤：**
1. 创建新节点
2. 如果链表为空，新节点就是头节点
3. 如果链表不为空，找到最后一个节点（`nextA == NULL` 的节点）
4. 最后一个节点的 `nextA` 指向新节点

```c
// 函数：在链表尾部插入一个水果节点
void insertAtTail(struct FruitNode **headPtrPtr, char nameArg[], float priceArg) {
    // 第一步：创建新节点
    struct FruitNode *newNodeA = createFruitNode(nameArg, priceArg);
    if (newNodeA == NULL) {
        return;
    }
    
    // 第二步：如果链表为空
    if (*headPtrPtr == NULL) {
        *headPtrPtr = newNodeA;
        printf("链表为空，%s 成为第一个节点。\n", nameArg);
        return;
    }
    
    // 第三步：找到最后一个节点
    struct FruitNode *walker = *headPtrPtr;
    while (walker->nextA != NULL) {
        walker = walker->nextA;
    }
    // 循环结束后，walker 指向最后一个节点
    
    // 第四步：最后一个节点的 next 指向新节点
    walker->nextA = newNodeA;
    printf("在尾部插入 %s 成功！\n", nameArg);
}
```

**特别注意：** `while (walker->nextA != NULL)` 这个条件，当 `walker->nextA` 是 `NULL` 时，`walker` 就是最后一个节点。我们停在了最后一个节点上，而不是停在 `NULL` 上。

### 5.4 插入操作 —— 在指定节点后面插入

这个操作需要先找到指定的节点，然后在它后面插入新节点。

**步骤：**
1. 创建新节点
2. 从头部开始遍历，查找名字匹配的节点
3. 如果找不到，释放新节点并返回
4. 如果找到了，执行插入：
   - 新节点的 `nextA` 指向目标节点的 `nextA`
   - 目标节点的 `nextA` 指向新节点

```c
// 函数：在指定水果后面插入一个新水果
// 参数：targetName 是目标水果的名字，newName 是新水果的名字
void insertAfterFruit(struct FruitNode **headPtrPtr, char targetName[], 
                      char newName[], float newPrice) {
    // 第一步：创建新节点
    struct FruitNode *newNodeA = createFruitNode(newName, newPrice);
    if (newNodeA == NULL) {
        return;
    }
    
    // 第二步：查找目标节点
    struct FruitNode *walker = *headPtrPtr;
    while (walker != NULL && strcmp(walker->nameA, targetName) != 0) {
        walker = walker->nextA;
    }
    
    // 第三步：判断是否找到了
    if (walker == NULL) {
        printf("没有找到 %s，插入失败！\n", targetName);
        free(newNodeA); // 重要：新节点没有用上，要释放掉
        return;
    }
    
    // 第四步：在 walker 后面插入 newNodeA
    newNodeA->nextA = walker->nextA;
    walker->nextA = newNodeA;
    
    printf("在 %s 后面插入 %s 成功！\n", targetName, newName);
}
```

**关键理解：** 插入操作中，指针赋值的顺序非常重要！
- 先 `newNodeA->nextA = walker->nextA`（新节点先指向后面的节点）
- 再 `walker->nextA = newNodeA`（前面的节点再指向新节点）

如果顺序颠倒了，你会丢失 `walker` 后面的整个链表！

### 5.5 删除操作 —— 删除指定节点

删除节点是链表操作中最需要小心的操作之一。

**步骤：**
1. 检查链表是否为空
2. 如果要删除的是头节点，特殊处理
3. 否则，遍历查找目标节点，同时记录前一个节点
4. 找到后，让前一个节点的 `nextA` 跳过目标节点，直接指向目标节点的 `nextA`
5. 释放目标节点的内存

```c
// 函数：删除指定名字的水果节点
void deleteFruitByName(struct FruitNode **headPtrPtr, char targetName[]) {
    // 第一步：检查链表是否为空
    if (*headPtrPtr == NULL) {
        printf("链表为空，无法删除！\n");
        return;
    }
    
    // 第二步：准备两个指针
    struct FruitNode *currentA = *headPtrPtr;  // 当前节点
    struct FruitNode *prevA = NULL;            // 当前节点的前一个节点
    
    // 第三步：查找目标节点
    while (currentA != NULL && strcmp(currentA->nameA, targetName) != 0) {
        prevA = currentA;
        currentA = currentA->nextA;
    }
    
    // 第四步：如果没找到
    if (currentA == NULL) {
        printf("没有找到 %s，删除失败！\n", targetName);
        return;
    }
    
    // 第五步：找到了，执行删除
    if (prevA == NULL) {
        // 删除的是头节点
        *headPtrPtr = currentA->nextA;
    } else {
        // 删除的是中间或尾部的节点
        prevA->nextA = currentA->nextA;
    }
    
    // 第六步：释放被删除节点的内存
    free(currentA);
    printf("成功删除 %s！\n", targetName);
}
```

**图示理解删除操作：**

删除前：
```
prevA          currentA
  |              |
  v              v
Node1 ----> Node2 ----> Node3
```

执行 `prevA->nextA = currentA->nextA` 后：
```
prevA          currentA
  |              |
  v              v
Node1 ----+  Node2    Node3
          |            ^
          +------------+
```

Node2 被跳过了，然后我们 `free(currentA)`，Node2 的内存被释放。

### 5.6 查找操作 —— 根据条件查找节点

查找操作比较简单，就是遍历链表，找到匹配的节点返回它的指针。

```c
// 函数：根据名字查找水果节点
// 返回值：找到则返回节点指针，没找到返回 NULL
struct FruitNode* findFruitByName(struct FruitNode *headPtr, char targetName[]) {
    struct FruitNode *walker = headPtr;
    
    while (walker != NULL) {
        if (strcmp(walker->nameA, targetName) == 0) {
            return walker; // 找到了，返回指针
        }
        walker = walker->nextA;
    }
    
    return NULL; // 没找到
}
```

### 5.7 修改操作 —— 更新节点的数据

修改操作通常先查找，找到后更新数据。

```c
// 函数：修改水果的价格
// 返回值：1 表示修改成功，0 表示没找到
int updateFruitPrice(struct FruitNode *headPtr, char targetName[], float newPrice) {
    struct FruitNode *foundA = findFruitByName(headPtr, targetName);
    
    if (foundA == NULL) {
        printf("没有找到 %s，修改价格失败！\n", targetName);
        return 0;
    }
    
    foundA->priceA = newPrice;
    printf("%s 的价格已更新为 %.2f 元\n", targetName, newPrice);
    return 1;
}
```

## 第六章：链表的完整示例程序

    int countA = 1;
    
    printf("\n===== 水果列表 =====\n");

        printf("%d. %s - 价格：%.2f 元\n", countA, walker->nameA, walker->priceA);
        walker = walker->nextA;

    }

}

    if (newNodeA == NULL) return;
    
    if (*headPtrPtr == NULL) {
        *headPtrPtr = newNodeA;
        printf("✅ 链表为空，%s 成为第一个节点。\n", nameArg);
        return;
    }
    
    struct FruitNode *walker = *headPtrPtr;
    while (walker->nextA != NULL) {
        walker = walker->nextA;

    walker->nextA = newNodeA;

    struct FruitNode *walker = *headPtrPtr;
    while (walker != NULL && strcmp(walker->nameA, targetName) != 0) {

void deleteFruitByName(struct FruitNode **headPtrPtr, char targetName[]) {

    struct FruitNode *currentA = *headPtrPtr;

        *headPtrPtr = currentA->nextA;
    } else {

// 3.7 查找节点
struct FruitNode* findFruitByName(struct FruitNode *headPtr, char targetName[]) {
    struct FruitNode *walker = headPtr;

            return walker;
        }
        walker = walker->nextA;

    return NULL;

// 3.8 修改节点
int updateFruitPrice(struct FruitNode *headPtr, char targetName[], float newPrice) {

## 第七章：链表的变体 —— 双向链表

前面我们学习的链表叫做"单向链表"，因为每个节点只有一个 `next` 指针，只能从前往后走。

双向链表在每个节点中增加了 `prev` 指针，指向前一个节点，这样我们就可以从后往前走了。

### 7.1 双向链表的节点定义

```c
// 双向链表的节点
// 我们用"书"来举例，每本书有书名和作者
struct BookNode {
    char titleA[50];
    char authorA[30];
    struct BookNode *prevA;   // 指向前一个节点
    struct BookNode *nextA;   // 指向后一个节点
};
```

### 7.2 双向链表的结构

```
NULL <---- Node1 ----> Node2 ----> Node3 ----> NULL
          (prev)      (prev)      (prev)
          (next)      (next)      (next)
```

每个节点有两个指针：
- `prevA` 指向前一个节点
- `nextA` 指向后一个节点
- 头节点的 `prevA` 是 `NULL`
- 尾节点的 `nextA` 是 `NULL`

### 7.3 双向链表的插入（头部插入）

```c
// 双向链表：在头部插入
void insertAtHeadBook(struct BookNode **headPtrPtr, char titleArg[], char authorArg[]) {
    // 创建新节点
    struct BookNode *newNodeA = (struct BookNode*)malloc(sizeof(struct BookNode));
    if (newNodeA == NULL) return;
    
    strcpy(newNodeA->titleA, titleArg);
    strcpy(newNodeA->authorA, authorArg);
    newNodeA->prevA = NULL;
    newNodeA->nextA = NULL;
    
    // 如果链表为空
    if (*headPtrPtr == NULL) {
        *headPtrPtr = newNodeA;
        return;
    }
    
    // 链表不为空
    newNodeA->nextA = *headPtrPtr;   // 新节点指向旧头节点
    (*headPtrPtr)->prevA = newNodeA; // 旧头节点的 prev 指向新节点
    *headPtrPtr = newNodeA;          // 头指针指向新节点
}
```

### 7.4 双向链表的删除

```c
// 双向链表：删除指定书名的节点
void deleteBookByName(struct BookNode **headPtrPtr, char titleArg[]) {
    if (*headPtrPtr == NULL) return;
    
    struct BookNode *currentA = *headPtrPtr;
    
    // 查找目标节点
    while (currentA != NULL && strcmp(currentA->titleA, titleArg) != 0) {
        currentA = currentA->nextA;
    }
    
    if (currentA == NULL) {
        printf("没有找到 %s\n", titleArg);
        return;
    }
    
    // 处理前一个节点
    if (currentA->prevA != NULL) {
        currentA->prevA->nextA = currentA->nextA;
    } else {
        // 删除的是头节点
        *headPtrPtr = currentA->nextA;
    }
    
    // 处理后一个节点
    if (currentA->nextA != NULL) {
        currentA->nextA->prevA = currentA->prevA;
    }
    
    free(currentA);
    printf("成功删除 %s\n", titleArg);
}
```

### 7.5 双向链表的优势与劣势

**优势：**
- 可以从前往后遍历，也可以从后往前遍历
- 删除节点时，不需要知道前一个节点（因为 `prevA` 直接提供了）
- 删除操作更快（不需要额外的遍历来找到前驱节点）

**劣势：**
- 每个节点多了一个指针，占用更多内存
- 插入和删除操作更复杂（需要维护两个指针）

## 第八章：链表的变体 —— 循环链表

循环链表是链表的另一种变体，它的最后一个节点的 `next` 不是 `NULL`，而是指向头节点，形成一个环。

### 8.1 单向循环链表

```c
struct CatNode {
    char nameA[20];
    int ageA;
    struct CatNode *nextA;
};

// 创建循环链表
void createCircularList(struct CatNode **headPtrPtr) {
    struct CatNode *catA = createCatNode("Mimi", 3);
    struct CatNode *catB = createCatNode("Kitty", 2);
    struct CatNode *catC = createCatNode("Bob", 5);
    
    catA->nextA = catB;
    catB->nextA = catC;
    catC->nextA = catA;  // 关键：最后一个指向第一个
    
    *headPtrPtr = catA;
}
```

### 8.2 循环链表的遍历

遍历循环链表时需要注意，不能像普通链表那样用 `NULL` 来判断结束，而是判断是否回到了头节点。

```c
void printCircularList(struct CatNode *headPtr) {
    if (headPtr == NULL) {
        printf("链表为空\n");
        return;
    }
    
    struct CatNode *walker = headPtr;
    do {
        printf("名字：%s，年龄：%d\n", walker->nameA, walker->ageA);
        walker = walker->nextA;
    } while (walker != headPtr);  // 回到头节点就停止
}
```

### 8.3 循环链表的应用场景

循环链表非常适合需要"循环访问"的场景：
- 操作系统的进程调度（轮流分配CPU时间）
- 约瑟夫问题（报数出列问题）
- 循环缓冲区

## 第九章：链表的高级操作

### 9.1 链表的反转

反转链表是一个经典的面试题。我们需要改变每个节点的 `next` 指针方向，让链表倒过来。

**思路：** 我们用三个指针 `prevA`、`currentA`、`nextTempA`，逐个改变节点的指向。

```c
// 函数：反转单向链表
// 返回新的头节点指针
struct FruitNode* reverseFruitList(struct FruitNode *headPtr) {
    struct FruitNode *prevA = NULL;
    struct FruitNode *currentA = headPtr;
    struct FruitNode *nextTempA = NULL;
    
    while (currentA != NULL) {
        nextTempA = currentA->nextA;   // 先保存下一个节点
        currentA->nextA = prevA;        // 反转当前节点的指向
        prevA = currentA;               // 前指针后移
        currentA = nextTempA;           // 当前指针后移
    }
    
    // 循环结束时，prevA 指向原链表的最后一个节点，也就是新链表的头
    return prevA;
}
```

**图解反转过程：**

初始状态：
```
NULL <- prevA    currentA -> Node2 -> Node3 -> NULL
                    |
                   Node1
```

第一步后：
```
NULL <- prevA    currentA -> Node3 -> NULL
                    |
                   Node2 -> Node1 -> NULL
                    |
                   Node1
```

最终：
```
NULL <- Node3 <- Node2 <- Node1
                         |
                        head
```

### 9.2 寻找链表的中间节点

如果不知道链表的长度，如何找到中间的节点？

**方法：快慢指针**
- 慢指针每次走一步
- 快指针每次走两步
- 当快指针到达末尾时，慢指针就在中间位置

```c
// 函数：寻找链表的中间节点
struct FruitNode* findMiddleFruit(struct FruitNode *headPtr) {
    if (headPtr == NULL) {
        return NULL;
    }
    
    struct FruitNode *slowA = headPtr;
    struct FruitNode *fastA = headPtr;
    
    while (fastA != NULL && fastA->nextA != NULL) {
        slowA = slowA->nextA;        // 慢指针走一步
        fastA = fastA->nextA->nextA; // 快指针走两步
    }
    
    return slowA; // 慢指针指向中间节点
}
```

### 9.3 检测链表是否有环

如果链表中有环，遍历时永远不会结束。我们需要检测是否存在环。

**方法：同样使用快慢指针**
- 如果有环，快指针最终会追上慢指针
- 如果没有环，快指针会到达 `NULL`

```c
// 函数：检测链表是否有环
// 返回值：1 表示有环，0 表示没有环
int hasCycle(struct FruitNode *headPtr) {
    if (headPtr == NULL) {
        return 0;
    }
    
    struct FruitNode *slowA = headPtr;
    struct FruitNode *fastA = headPtr;
    
    while (fastA != NULL && fastA->nextA != NULL) {
        slowA = slowA->nextA;
        fastA = fastA->nextA->nextA;
        
        if (slowA == fastA) {
            return 1; // 快慢指针相遇，有环
        }
    }
    
    return 0; // 无环
}
```

### 9.4 合并两个有序链表

假设有两个链表，每个链表中的节点都是按价格从小到大排序的。我们要把它们合并成一个新的有序链表。

```c
// 函数：合并两个有序水果链表
// 返回合并后的链表头指针
struct FruitNode* mergeSortedFruitLists(struct FruitNode *listA, struct FruitNode *listB) {
    // 处理空链表的情况
    if (listA == NULL) return listB;
    if (listB == NULL) return listA;
    
    struct FruitNode *resultHead = NULL;
    struct FruitNode *resultTail = NULL;
    
    // 选择头节点
    if (listA->priceA <= listB->priceA) {
        resultHead = listA;
        listA = listA->nextA;
    } else {
        resultHead = listB;
        listB = listB->nextA;
    }
    resultTail = resultHead;
    
    // 合并剩余节点
    while (listA != NULL && listB != NULL) {
        if (listA->priceA <= listB->priceA) {
            resultTail->nextA = listA;
            listA = listA->nextA;
        } else {
            resultTail->nextA = listB;
            listB = listB->nextA;
        }
        resultTail = resultTail->nextA;
    }
    
    // 连接剩余的节点
    if (listA != NULL) {
        resultTail->nextA = listA;
    } else {
        resultTail->nextA = listB;
    }
    
    return resultHead;
}
```

## 第十章：链表的复杂度分析

### 10.1 时间复杂度（大O表示法）

| 操作 | 单向链表 | 双向链表 | 数组 |
|------|---------|---------|------|
| 访问（按索引） | O(n) | O(n) | O(1) |
| 头部插入 | O(1) | O(1) | O(n) |
| 尾部插入（有尾指针） | O(1) | O(1) | O(1) |
| 尾部插入（无尾指针） | O(n) | O(n) | O(1) |
| 中间插入（已知位置） | O(1) | O(1) | O(n) |
| 删除（已知位置） | O(1) | O(1) | O(n) |
| 查找 | O(n) | O(n) | O(n) |

**解释：**
- O(1) 表示操作时间与数据量无关，是常数时间
- O(n) 表示操作时间与数据量成正比
- 链表的优势在插入和删除，劣势在随机访问

### 10.2 空间复杂度

链表需要为每个节点额外存储一个或多个指针，所以空间开销比数组大。

- 单向链表：每个节点多占用 4 或 8 字节（指针大小）
- 双向链表：每个节点多占用 8 或 16 字节

## 第十一章：链表 vs 数组 —— 如何选择？

### 11.1 对比表格

| 特性 | 数组 | 链表 |
|------|------|------|
| 内存分配 | 连续，一次性分配 | 不连续，每次分配一个节点 |
| 大小 | 固定，无法动态扩展 | 动态，可随时扩展 |
| 内存利用率 | 可能浪费（预分配过大） | 利用率高，按需分配 |
| 随机访问 | O(1)，非常快 | O(n)，需要遍历 |
| 插入/删除 | 慢，需要移动元素 | 快，只需改变指针 |
| 缓存友好性 | 好（连续内存） | 差（分散内存） |
| 实现复杂度 | 简单 | 较复杂 |

### 11.2 什么时候用链表？

1. **需要频繁插入和删除**：比如任务队列、消息队列
2. **数据量不确定**：不知道会有多少个元素
3. **不需要随机访问**：只需要顺序访问
4. **内存紧张**：希望按需分配，避免浪费

### 11.3 什么时候用数组？

1. **需要频繁随机访问**：比如按索引取数据
2. **数据量已知且固定**：比如存储月份的天数
3. **对性能要求极高**：数组缓存友好，访问速度快
4. **实现简单**：代码更简洁

// fruitlist.c

#include <string.h>

// 创建节点
FruitNode* createFruitNode(char nameArg[], float priceArg) {
    FruitNode *newNodeA = (FruitNode*)malloc(sizeof(FruitNode));
    if (newNodeA == NULL) {
        return NULL;
    }
    strcpy(newNodeA->nameA, nameArg);
    newNodeA->priceA = priceArg;
    newNodeA->nextA = NULL;
    return newNodeA;
}

// 打印链表
void printFruitList(FruitNode *headPtr) {
    if (headPtr == NULL) {
        printf("链表为空\n");
        return;
    }
    
    FruitNode *walker = headPtr;
    int countA = 1;
    while (walker != NULL) {
        printf("%d. %s - %.2f\n", countA, walker->nameA, walker->priceA);
        walker = walker->nextA;
        countA++;
    }
}

// ... 其他函数实现（省略，与之前相同）...

// 销毁链表
void destroyFruitList(FruitNode **headPtrPtr) {
    FruitNode *currentA = *headPtrPtr;
    FruitNode *nextTempA;
    
    while (currentA != NULL) {
        nextTempA = currentA->nextA;
        free(currentA);
        currentA = nextTempA;
    }
    *headPtrPtr = NULL;
}

## 第十三章：常见错误与调试技巧

### 13.1 常见错误

**错误 1：忘记初始化 `next` 指针**

```c
// ❌ 错误：newNode->nextA 是随机值
struct FruitNode *newNodeA = (struct FruitNode*)malloc(sizeof(struct FruitNode));
strcpy(newNodeA->nameA, "Apple");

// ✅ 正确：一定要初始化
struct FruitNode *newNodeA = (struct FruitNode*)malloc(sizeof(struct FruitNode));
strcpy(newNodeA->nameA, "Apple");
newNodeA->nextA = NULL;  // 关键！
```

**错误 2：访问 NULL 指针**

```c
// ❌ 错误：如果 headPtr 是 NULL，访问 headPtr->nextA 会崩溃
while (headPtr->nextA != NULL) {
    // ...
}

// ✅ 正确：先检查 headPtr 是否为 NULL
while (headPtr != NULL && headPtr->nextA != NULL) {
    // ...
}
```

**错误 3：插入时顺序颠倒**

```c
// ❌ 错误：先改 walker->nextA，再改 newNode->nextA，会丢失后续节点
walker->nextA = newNodeA;
newNodeA->nextA = walker->nextA; // 这时 walker->nextA 已经是 newNodeA 了

// ✅ 正确：先保存后面的节点
newNodeA->nextA = walker->nextA;
walker->nextA = newNodeA;
```

**错误 4：忘记释放内存**

```c
// ❌ 错误：删除节点时只修改指针，忘记 free
prevA->nextA = currentA->nextA;
// 没有 free(currentA) —— 内存泄漏！

// ✅ 正确
prevA->nextA = currentA->nextA;
free(currentA);
```

**错误 5：使用已经释放的指针**

```c
// ❌ 错误：free 之后继续使用
free(currentA);
printf("%s", currentA->nameA); // 危险！访问已释放的内存

// ✅ 正确：free 后将指针设为 NULL
free(currentA);
currentA = NULL;
```

    struct FruitNode *walkerA = listA;
    struct FruitNode *walkerB = listB;

        if (strcmp(walkerA->nameA, walkerB->nameA) != 0 ||
            walkerA->priceA != walkerB->priceA) {
            return 0;

        walkerA = walkerA->nextA;
        walkerB = walkerB->nextA;

// 使用链表实现栈
struct StackNode {
    int dataA;
    struct StackNode *nextA;
};

void push(struct StackNode **topPtr, int dataArg) {
    struct StackNode *newNodeA = (struct StackNode*)malloc(sizeof(struct StackNode));
    newNodeA->dataA = dataArg;
    newNodeA->nextA = *topPtr;
    *topPtr = newNodeA;
}

int pop(struct StackNode **topPtr) {
    if (*topPtr == NULL) {
        printf("栈为空！\n");
        return -1;
    }
    struct StackNode *toDelete = *topPtr;
    int resultA = toDelete->dataA;
    *topPtr = toDelete->nextA;
    free(toDelete);
    return resultA;
}

int peek(struct StackNode *topPtr) {
    if (topPtr == NULL) return -1;
    return topPtr->dataA;
}
