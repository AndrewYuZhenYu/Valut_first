在C语言中，**动态内存分配（Dynamic Memory Allocation）** 是一项核心技能。它允许程序在运行时根据需要申请或释放内存，而不是在编译时固定死内存大小。

以下是关于动态内存分配的系统性整理：

---

## 1. 为什么需要动态内存分配？

- **灵活性**：在编写代码时，我们往往不知道实际处理的数据量（例如：用户输入了多少个单词）。
    
- **生命周期控制**：局部变量在函数结束时自动销毁，而动态内存的生命周期由程序员手动控制。
    
- **规避栈限制**：栈空间（Stack）通常较小（一般几MB），而堆空间（Heap）理论上可以占用系统大部分可用内存。
    

---

## 2. 核心函数库：`<stdlib.h>`

C语言主要通过以下四个函数进行管理：

### ① malloc (Memory Allocation)

- **功能**：申请指定字节数的连续内存。
    
- **特点**：申请到的内存**不会初始化**（内容是随机的垃圾值）。
    
- **语法**：`void* malloc(size_t size);`
    

### ② calloc (Contiguous Allocation)

- **功能**：为指定数量的元素申请内存。
    
- **特点**：申请后会自动将内存中的每一位**初始化为 0**。
    
- **语法**：`void* calloc(size_t num, size_t size);`
    

### ③ realloc (Re-allocation)

- **功能**：调整之前申请的内存块大小。
    
- **特点**：如果原块后续空间足够，则原地扩容；如果不够，会找新地址拷贝数据并释放旧地址。
    
- **语法**：`void* realloc(void* ptr, size_t new_size);`
    

### ④ free

- **功能**：释放不再使用的内存。
    
- **注意**：释放后建议将指针置为 `NULL`，防止出现“野指针”。
    
- **语法**：`void free(void* ptr);`
    

---

## 3. 内存区域模型

为了理解动态内存，需要知道它在进程内存布局中的位置：

- **栈 (Stack)**：存放局部变量、函数参数。自动分配和释放。
    
- **堆 (Heap)**：动态内存申请的区域。程序员通过指令手动操作。
    

---

## 4. 标准代码模板

编写动态内存分配代码时，必须包含**判空**和**释放**两步：

C

```
#include <stdio.h>
#include <stdlib.h>

int main() {
    int n = 5;
    // 1. 申请内存 (注意要强制类型转换)
    int *arr = (int*)malloc(n * sizeof(int));

    // 2. 检查是否申请成功
    if (arr == NULL) {
        printf("内存分配失败！\n");
        return 1;
    }

    // 3. 使用内存
    for (int i = 0; i < n; i++) arr[i] = i * 10;

    // 4. 释放内存并置空
    free(arr);
    arr = NULL; 

    return 0;
}
```

---

## 5. 常见坑点与禁忌（避坑指南）

|**错误类型**|**后果**|**解决办法**|
|---|---|---|
|**忘记 free**|**内存泄漏 (Memory Leak)**|程序运行久了会耗尽系统内存。|
|**释放后继续使用**|**野指针访问 / 段错误**|`free` 之后立即将指针设为 `NULL`。|
|**重复释放 (Double Free)**|**程序崩溃**|确保每个 `malloc` 只对应一个 `free`。|
|**不检查返回值**|**空指针解引用**|永远要判断 `if (ptr == NULL)`。|
|**越界访问**|**破坏堆结构**|申请了 10 个字节，千万别往第 11 个写数据。|

---

## 6. 进阶：malloc 与 free 的底层逻辑

`malloc` 并不是直接向操作系统要内存，而是通过标准库维护一个**内存池**。当你调用 `free` 时，内存并不会立刻还给操作系统，而是回到内存池中，等待下次 `malloc` 重复利用，以提高性能。
