## 运算符类别详解

### 1. 基本运算符
- **作用**：访问、调用结构
- **特点**：最高优先级，操作对象的结构性访问

### 2. 一元运算符
- **作用**：单操作数运算
- **特点**：右结合，前缀形式

### 3. 算术运算符
- **分级**：
  - 乘除模类（优先级3）：`* / %`
  - 加减类（优先级4）：`+ -`
- **特点**：左结合，数学运算基础

### 4. 移位运算符
- **作用**：位级别的左右移动
- **特点**：介于算术和关系运算之间

### 5. 关系运算符
- **分级**：
  - 大小比较（优先级6）：`< <= > >=`
  - 相等判断（优先级7）：`== !=`
- **特点**：比较操作，返回布尔值

### 6. 位运算符
- **分级**：
  - 位与（优先级8）：`&`
  - 位异或（优先级9）：`^`
  - 位或（优先级10）：`|`
- **特点**：逐位操作，优先级与逻辑运算符分离

### 7. 逻辑运算符
- **分级**：
  - 逻辑与（优先级11）：`&&`
  - 逻辑或（优先级12）：`||`
- **特点**：布尔逻辑，短路求值

### 8. 条件运算符
- **作用**：三目选择运算
- **特点**：唯一的三目运算符，右结合

### 9. 赋值运算符
- **作用**：变量赋值
- **特点**：右结合，优先级很低

### 10. 逗号运算符
- **作用**：顺序求值
- **特点**：最低优先级，从左到右依次求值

## 优先级关键对比（明确高低）

### 类别间优先级顺序：
```
1. 基本运算符 > 2. 一元运算符 > 3. 算术乘除 > 4. 算术加减 > 5. 移位运算符 > 
2. 关系大小比较 > 7. 关系相等判断 > 8. 位与 > 9. 位异或 > 10. 位或 >
3. 逻辑与 > 12. 逻辑或 > 13. 条件运算符 > 14. 赋值运算符 > 15. 逗号运算符
```

### 同类内部分级（明确高低）：
- **算术运算符内**：`* / %`（优先级3） > `+ -`（优先级4）
- **关系运算符内**：`< <= > >=`（优先级6） > `== !=`（优先级7）
- **位运算符内**：`&`（优先级8） > `^`（优先级9） > `|`（优先级10）
- **逻辑运算符内**：`&&`（优先级11） > `||`（优先级12）

### 重要实例验证：
```c
// 算术运算优先级验证
int a = 2 + 3 * 4;      // 乘法优先级高于加法：2 + (3*4) = 14

// 关系和逻辑混合
int b = 5 > 3 && 2 == 2; // 关系>高于==高于&&：(5>3) && (2==2) = 1

// 位运算优先级
int c = 1 & 2 | 3 ^ 4;   // & > ^ > |：((1&2) | 3) ^ 4？实际：(1&2) | (3^4)

// 赋值优先级低
int d = 5;
d += d *= 2;            // *=先于+=：d = d + (d*=2)

// 一元与二元区分
int e = -3 * +4;        // 一元正负号先于乘法：(-3) * (+4) = -12
```
