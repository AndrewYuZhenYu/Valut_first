# Academic English Communication - Course Summary
# 学术英语交流 - 课程要点全整理


## Lecture 1: Identifying Key Issues
## 第一讲：识别关键问题

**Learning Objectives / 课程目标：**
- Know the features of an effective academic presentation.
  了解有效学术演讲的特征。
- Understand the need for an effective academic presentation.
  理解进行有效学术演讲的必要性。
- Distinguish the difference between conversation and academic presentation.
  区分日常对话与学术演讲的不同。

**Key Points / 核心要点：**

**1. Elements of a Good / Bad Presentation / 有效与无效演讲的要素**

| Good Presentation / 优秀演讲 | Bad Presentation / 糟糕演讲 |
|------------------------------|-----------------------------|
| A clear and simply presented message / 信息清晰简洁 | Unclear, cluttered message / 信息混乱冗长 |
| Clear topic / 主题明确 | Vague topic / 主题模糊 |
| Logical structure / 结构逻辑性强 | Loose structure / 结构松散 |
| Confident delivery / 交付方式自信 | Boring delivery (e.g., reading from slides) / 交付方式枯燥 |
| Good eye contact / 良好的眼神交流 | No eye contact / 缺乏眼神交流 |
| Well-designed visuals / 精心设计的幻灯片 | Text-heavy slides / 幻灯片堆满文字 |

**2. Ten Simple Rules for Good Presentations / 优秀演讲的十大黄金法则**

| Rule / 法则 | Explanation / 解释 |
|-------------|-------------------|
| **Rule 1: Talk to the audience** / 面向听众 | Gain eye contact with as many people as possible to add intimacy and comfort. / 与尽可能多的人进行眼神交流，营造亲密舒适感。 |
| **Rule 2: Less is More** / 少即是多 | Provide main messages rather than all details — the audience only remembers a fraction. / 传递核心信息而非所有细节。 |
| **Rule 3: Only talk when you have something to say** / 有话则说 | If you're not well-prepared, don't risk giving a boring talk. The audience's time is precious. / 若无充分准备，不要冒险进行无聊的演讲。 |
| **Rule 4: Make the take-home message persistent** / 让核心信息持久 | If your audience remembers three points a week later, you've done a good job. / 一周后听众若能记住三个要点，你就成功了。 |
| **Rule 5: Be logical** / 逻辑清晰 | Tell a story with a clear beginning, middle, and ending. Direct the audience's attention. / 像讲故事一样组织演讲，引导听众注意力。 |
| **Rule 6: Treat the floor as a stage** / 将讲台视为舞台 | It's a form of entertainment, but stay within your character. / 演讲是一种表演，但要基于自身特点。 |
| **Rule 7: Practice and time your presentation** / 练习并计时 | The more you practice, the less likely you will go off on tangents. / 练习越多，越不易偏离主题。 |
| **Rule 8: Use visuals sparingly but effectively** / 谨慎有效地使用视觉辅助 | Never have more than one slide per minute. Avoid reading the visual unless emphasizing a point. / 每分钟不超过一张幻灯片，除非强调要点，否则不要照读。 |
| **Rule 9: Review audio/video of your presentation** / 回顾自己的录音或录像 | Nothing is more effective than seeing yourself on film. / 观看自己是改进最有效的方式。 |
| **Rule 10: Provide appropriate acknowledgement** / 恰当地表示感谢 | Express gratitude to those who have made contributions. / 对提供帮助的人表达感激。 |

**3. Why Some Presentations Are Boring / 为何有些演讲很无聊**
- They are devoid of stories, examples, and case studies. / 缺乏故事、案例研究。
- There are no pictures and images in the PPT slides. / 幻灯片没有图片。
- They are nothing but a wheelbarrow full of facts thrown at people. / 全是堆砌的事实。

**4. Presentation vs. Conversation / 演讲 vs. 日常对话**

| Dimension / 维度 | Presentation / 演讲 | Conversation / 对话 |
|------------------|---------------------|---------------------|
| Intentionality / 计划性 | More intentional (planning, practice) / 更刻意 | Spontaneous / 更自发 |
| Interactivity / 互动性 | Less interactive (clearly defined roles) / 互动性较低 | Interactive (easy exchange) / 互动性强 |
| Formality / 正式程度 | More formal (standard English, planned gestures, no slang) / 更正式 | Casual (casual language, spontaneous gestures) / 更随意 |
| Space / 空间 | Physical distance / 有物理距离 | Close to partner / 距离近 |
| Role / 角色 | Leader of the group / 团队的领导者 | Conversational partner / 平等的交流伙伴 |
| Attention / 注意力 | Inner-directed / 内在注意状态 | Out-directed / 外向注意状态 |


## Lecture 2: Speaking in an Appropriate Style
## 第二讲：以适当风格演讲

**Learning Objectives / 课程目标：**
- Learn how to overcome stage fright. / 学习如何克服怯场。
- Understand the differences between academic writing and academic speaking styles. / 了解学术写作和学术演讲风格的差异。
- Learn how to speak in an appropriate style. / 学习如何以适当的风格演讲。

**Key Points / 核心要点：**

**1. Overcoming Stage Fright / 克服怯场**

| Symptoms / 症状 | Coping Strategies / 应对策略 |
|-----------------|------------------------------|
| Confusing babble / 语无伦次 | 1. **Good preparation** — the best weapon against speech anxiety. / **充分准备** — 最佳武器。 |
| Speaking too fast / 语速过快 | 2. **Recognize the importance of introductory remarks** — a good start is a boost. Pause, do NOT speak rapidly. / **认识开场白的重要性** — 好的开始是成功的一半。 |
| Stuttering, trembling, sweating / 口吃、颤抖、出汗 | 3. **Visualize your success** — envision yourself delivering with confidence; picture a warm audience. / **想象成功** — 想象自己充满信心地演讲。 |
| Butterflies in the stomach / 胃部不适 | 4. **Practice and learn to relax** — rehearse out loud in front of family/friends or a mirror. / **练习与放松** — 大声排练。 |
| Mind going blank / 大脑空白 | 5. **Realize that no one can see your nervousness** — most nervousness is invisible to the audience. / **无人能看见你的紧张** — 大部分紧张对观众不可见。 |
| | 6. **Don't apologize for being nervous** — controversial: it may lighten tension but also draws unnecessary attention. / **不要为紧张道歉** — 有争议：既能缓解紧张，也可能带来不必要的关注。 |

**2. Academic Writing vs. Academic Speaking Style / 学术写作与演讲风格对比**

| Feature / 特征 | Academic Writing / 学术写作 | Academic Speaking / 学术演讲 |
|----------------|----------------------------|-----------------------------|
| Vocabulary / 词汇 | Longer and more complicated words / 更长、更复杂的词汇 | Shorter and simpler words / 更短、更简单的词汇 |
| Dominant word class / 主要词类 | More **nouns** / 多用**名词** | More **verbs** / 多用**动词** |
| Lexical/Functional ratio / 实词/功能词比例 | Higher proportion of **lexical words** (e.g., 1.4:1) / 实词比例更高 | Higher proportion of **functional words** (e.g., 0.85:1) / 功能词比例更高 |
| Sentence structure / 句式 | More **subordinate clauses** / 多用**从属子句** | More **coordinate clauses** / 多用**并列子句** |

**3. English vs. Chinese Style Comparison / 中英文风格对比**

| Feature / 特征 | English / 英文 | Chinese / 中文 |
|----------------|---------------|---------------|
| Preference / 偏好 | Noun preference (nominalization) / 偏好名词（名词化） | Verb preference (serial verbs) / 偏好动词（连动结构） |
| Sentence style / 句式风格 | Static / 静态 | Dynamic / 动态 |
| Example / 示例 | "The application of this method..." / 应用这种方法... | "应用这种方法..." |

**4. Three Principles of Academic Speaking Style / 学术演讲风格三原则**

1. **Formality / 正式性** — Avoid overly informal style, but don't use complicated written structures. / 避免过于随意的口语风格，但也不要用复杂的书面句式。
2. **Simplicity / 简洁性** — One single concept at a time; avoid cramming too much information. / 每次传递一个核心概念，避免信息过载。
3. **Repetition / 重复性** — "Tell them what you are going to tell them; Tell them; Tell them what you told them." / “告诉他们你要告诉他们什么；告诉他们；告诉他们你告诉了他们什么。”


## Lecture 3: English Phonemes and Pronunciation Skills
## 第三讲：英语音素与发音技巧

**Learning Objectives / 课程目标：**
- Learn English phonemes. / 掌握英语音位/音素。
- Learn consonant clusters, incomplete plosion, nasal & lateral plosion, linking, assimilation, weak forms, word stress, sentence stress, and rhythm. / 学习辅音连缀、不完全爆破、连读、同化、弱读、单词重音、句子重音和节奏。

**Key Points / 核心要点：**

**1. Phonemes / 音素**
- 20 vowels and 28 consonants. / 20个元音和28个辅音。
- Correct pronunciation is the foundation of good spoken English. / 正确发音是良好口语的基础。

**2. Incomplete Plosion / 不完全爆破**
- **Plosive + Plosive / 爆破音+爆破音**: `active`, `blackboard`, `put down`, `take care` — the first plosive is not fully released. / 前一个爆破音只做口型不发出声音。
- **Plosive + Fricative/Affricate / 爆破音+摩擦音/破擦音**: `old friends`, `just think`, `red stars`, `good try`.

**3. Nasal Plosion & Lateral Plosion / 鼻腔爆破与舌侧爆破**
- **/t, d/ + /m, n/**: `good morning`, `not now`, `don't know`.
- **/t, d/ + /l/**: `little`, `battle`, `at least`, `a good leader`.

**4. Linking / 连读**
- **Consonant + Vowel / 辅音+元音**: `come in`, `work out`, `first of all`, `not at all`.
- **r-linking**: `there is`, `here and there`, `for an hour`.
- **Vowel + Vowel / 元音+元音**: `you are`, `go out`, `try again`, `stay up`.

**5. Assimilation / 同化**
- `/s/ + /j/ → /ʃ/`: "Has **your**..." → /hæʒɔː/
- `/t/ + /j/ → /tʃ/`: "**Meet you**" → /miːtʃuː/
- `/d/ + /j/ → /dʒ/`: "**Did you**" → /dɪdʒuː/

**6. Important Weak Forms / 重要弱读形式**
- Many function words are weakened in sentences: / 许多功能词在句子中弱读：
  - `and` → /ənd, ən/
  - `as` → /əz/
  - `at` → /ət/
  - `but` → /bət/
  - `that` → /ðət/
  - `to` → /tu, tə/
  - `was` → /wəz/

**7. Word Stress / 单词重音**
- The stressed syllable is longer; unstressed syllables are very short. / 重读音节更长，非重读音节非常短。
- Practice: `nine` → `ninety` → `ninetieth`; `good` → `better` → `excellent`.

**8. Sentence Stress / 句子重音**
- **Content words** (nouns, main verbs, adjectives, adverbs) are usually **stressed**. / **实词**通常**重读**。
- **Function words** (articles, prepositions, conjunctions, pronouns) are usually **unstressed**. / **功能词**通常**不重读**。
- **Exceptions (stressed)**: demonstratives (this, that), possessives (mine, yours), negatives (not, never), reflexives (myself, himself), interrogatives (who, what, where).

**9. Rhythm / 节奏**
- English is stress-timed — the time between stressed syllables is roughly equal. / 英语是重音计时语言，重读音节之间的时间间隔大致相等。
- Practice patterns: `John's gone.` (OO), `Peter lost.` (O.o), `I'd love to.` (O..)


## Lecture 4: Planning an Academic Presentation
## 第四讲：规划学术演讲

**Learning Objectives / 课程目标：**
- Understand the presentation process. / 了解演讲的流程。
- Establish the presentation objective. / 确定演讲目标。
- Research your audience. / 研究听众。
- Focus on your topic. / 聚焦演讲主题。

**Key Points / 核心要点：**

**1. The Presentation Process / 演讲流程**
1. Establish objectives / 确立目标
2. Research audience / 分析听众
3. Focus on topic / 聚焦主题
4. Organize structure / 组织结构
5. Prepare scripts & visuals / 准备讲稿与视觉辅助
6. Practice delivery / 练习交付

**2. Establishing Objectives / 确立演讲目标**

| Objective / 目标 | Purpose / 目的 |
|------------------|---------------|
| **To Inform** / 告知 | Provide new information the audience hasn't heard before. / 提供听众未曾听过的新信息。 |
| **To Instruct** / 指导 | Teach the audience to do something they couldn't do before. / 教会听众做一件以前不会做的事。 |
| **To Persuade** / 说服 | Convince the audience of a new view or strengthen a belief. / 说服听众接受新观点或坚定信念。 |
| **To Inspire** / 激励 | Fill the audience with motivation, courage, enthusiasm, or creativity. / 激发听众的积极性、勇气、热情或创造力。 |

- **Common objectives of academic presentations**: To inform & To persuade. / 学术演讲常见目标：**告知**和**说服**。
- **Above all: SURPRISE them with something NEW!** / 最重要的是：用**新的**东西给听众带来惊喜！

**3. Researching Your Audience / 研究听众**
- **Purpose**: Select appropriate emphasis; develop useful level of detail; choose appropriate visuals; create a sensitive tone. / 选择合适强调点；开发合适的细节层次；选择恰当的视觉辅助；创造体贴听众的基调。
- **Key questions**: What do they already know? What do they expect? How should I adapt? / 听众已知什么？期望什么？如何调整？

| Audience / 听众 | Adaptation Strategy / 调整策略 |
|-----------------|-------------------------------|
| Biology majors / 生物专业学生 | Avoid literary terms; use scientific analogies. / 避免文学术语，使用科学类比。 |
| Literature majors / 文学专业学生 | Use literary terms freely; focus on depth and analysis. / 自由使用文学术语，注重深度和分析。 |
| Professor / 教授 | Demonstrate depth, critical thinking, awareness of current research. / 体现深度、批判性思维和对最新研究的了解。 |

**4. Focusing on Your Topic / 聚焦主题**

| Broad Topic / 宽泛主题 | Focused Topic / 聚焦主题 |
|------------------------|-------------------------|
| Global Warming / 全球变暖 | How Melting Glaciers in Tibet Are Affecting Water Supply in Southern China / 西藏冰川融化如何影响中国南方供水 |

- **The Deep Dive Rule / “深潜”原则**: "It's better to cover one thing deeply than ten things shallowly." / “宁可深入地讲透一个问题，也不要肤浅地讲十个问题。”

- **Five Questions to Narrow a Topic / 缩小主题的五问法**:
  1. **Time / 时间**: Focus on a specific time period? / 聚焦于某个特定时间段？
  2. **Place / 地点**: Focus on a specific region? / 聚焦于某个特定区域？
  3. **Aspect / 方面**: Focus on one specific angle? / 聚焦于某个特定角度？
  4. **People / 人群**: Focus on a specific group? / 聚焦于某个特定群体？
  5. **Comparison / 比较**: Compare two things? / 对两个事物进行比较？


## Lecture 5: Structuring an Academic Presentation
## 第五讲：构建学术演讲结构

**Learning Objectives / 课程目标：**
- Organize the structure of an academic presentation. / 组织学术演讲的结构。
- Support your ideas effectively. / 有效地支持观点。
- Prepare scripts. / 准备讲稿。

**Key Points / 核心要点：**

**1. The Classic Structure / 经典结构**
- **Introduction / 引言**: Tell them what you are going to tell them. / 告诉他们你要告诉他们什么。
- **Body / 主体**: Tell them. / 告诉他们。
- **Conclusion / 结论**: Tell them what you told them. / 告诉他们你告诉了他们什么。

**2. Structure for a Research Presentation / 报告型演讲结构**

| Section / 部分 | Content / 内容 |
|---------------|---------------|
| **Introduction** / 引言 | Self-introduction, announcing the topic / 自我介绍，宣布主题 |
| **Body** / 主体 | **Why** (background, motivation, literature review) / **为什么**（背景、动机、文献综述）<br>**How** (methodology) / **如何做**（方法论）<br>**What** (results, discussion) / **发现了什么**（研究结果、讨论） |
| **Conclusion** / 结论 | Summarizing the most important points / 总结最重要的观点 |

**3. Structure for an Argumentative Presentation / 论证型演讲结构**

| Section / 部分 | Content / 内容 |
|---------------|---------------|
| **Introduction** / 引言 | Background, position/thesis statement / 背景，阐明立场 |
| **Body** / 主体 | Reason 1 / 论据一<br>Reason 2 / 论据二<br>(Counter-argument) / (反驳论点) |
| **Conclusion** / 结论 | Summarizing the most important points / 总结最重要的观点 |

**4. Supporting Your Ideas / 有效支撑观点**

**The ARS Triangle Principle / ARS三角原则** (Adapted from Johnson and Blair)

| Criterion / 标准 | Question / 问题 |
|------------------|----------------|
| **Acceptability** / 可接受性 | Is the evidence believable? / 证据是否可信？ |
| **Relevance** / 相关性 | Does it directly support the point? / 是否直接支撑论点？ |
| **Sufficiency** / 充分性 | Is there enough? / 是否足够？ |

| Evidence Type / 证据类型 | ARS Check / ARS检验 |
|--------------------------|---------------------|
| "A 2024 study from Beijing Normal University found..." / “2024年北师大研究发现...” | **Passes** — credible source, specific data. / **通过** — 可信来源，具体数据。 |
| "My uncle lost his job because of AI." / “我叔叔因AI失业。” | **Fails** — anecdotal, not sufficient. / **不通过** — 个人轶事，不充分。 |
| "EVs produce zero emissions while driving." / “电动车行驶中零排放。” | **Fails** — incomplete evidence. / **不通过** — 证据片面。 |

**5. The TED Talk Structure / TED演讲经典结构**
1. **Tell a personal story** / 讲述个人故事 → Build emotional connection / 建立情感联系
2. **Introduce a universal problem** / 提出普遍问题 → Create resonance / 引发共鸣
3. **Provide data/research** / 提供数据/研究 → Show it's not an isolated case / 证明非孤例
4. **Offer a solution** / 提供解决方案 → Call to action / 号召行动

**6. Preparing Scripts — The KISS Rule / 准备讲稿——KISS原则**
- **K**eep **I**t **S**hort and **S**imple. / 保持简短简洁。
- Write like you speak. / 写得像你说话一样。
- One idea per sentence. / 每句话一个想法。
- Read aloud to check. / 大声朗读检验。


## Lecture 6: Visual Aids
## 第六讲：视觉辅助

**Learning Objectives / 课程目标：**
- Understand the importance of visual aids. / 理解视觉辅助的重要性。
- Learn different types of visual aids. / 学习不同类型的视觉辅助。
- Learn how to use visual aids effectively. / 学习如何有效使用视觉辅助。

**Key Points / 核心要点：**

**1. Why Use Visual Aids? / 为何使用视觉辅助？**
- Clarify and simplify material. / 澄清和简化材料。
- Emphasize key points. / 强调要点。
- Illustrate complicated points with pictures, sound, or animation. / 通过图片、声音或动画说明复杂要点。
- Help visual learners and non-native English speakers. / 帮助视觉学习者和英语非母语者。
- Add audience participation and engagement. / 增加听众参与度。
- Compress large volumes of data. / 压缩大量数据。
- Serve as an outline for the audience. / 为听众提供结构大纲。

**2. Types of Visual Aids / 视觉辅助的类型**
- **Physical / 实体**: Flip charts, posters, handouts. / 翻页图、海报、讲义。
- **Digital / 电子**: PowerPoint slides, text, images, videos, tables, graphs (line, bar, pie, diagram). / PPT、文字、图片、视频、表格、图表。

**3. 14 Rules for Effective PowerPoint Use / 有效使用PPT的14条规则**

| Rule / 规则 | Description / 描述 |
|-------------|-------------------|
| **1. Use bullet points** / 使用项目符号 | Readability — easy to scan and understand; keeps eyes on you. / 提高可读性，聚焦听众注意力。 |
| **2. Six-by-six rule** / 六乘六法则 | No more than 6 bullet points per slide; no more than 6 words per bullet. / 每页最多6个项目符号，每个最多6个词。 |
| **3. No more than two levels of bullets** / 最多两级项目符号 | Avoid deep hierarchies. / 避免层级过深。 |
| **4. Be grammatical with bullet points** / 项目符号语法平行 | Keep structures consistent. / 保持结构一致。 |
| **5. Use numbers when sequence matters** / 区分数字和项目符号 | Use numbers for ordered lists; bullets for unordered. / 有序或强调数量时用数字。 |
| **6. Use a large and clear font** / 字体足够大且清晰 | Ensure readability from the back of the room. / 确保后排可见。 |
| **7. Don't be too "creative" with colors** / 颜色勿过度创意 | Avoid distracting color combinations. / 避免不协调的颜色。 |
| **8. Use contrasting colors** / 文本与背景使用对比色 | Text and background must contrast for readability. / 提高可读性。 |
| **9. Be conservative with animation** / 保守使用动画 | Use animation only for a clear purpose (e.g., demonstrating a process). / 只为明确目的使用。 |
| **10. Be progressive** / 适时渐进 | Reveal information step by step to avoid overload. / 逐步呈现信息。 |
| **11. Use images where appropriate** / 适当使用图片 | Make data easier to comprehend; visualize trends. / 使数据更易理解。 |
| **12. Ensure graphics are relevant, not decorative** / 图形应相关而非仅装饰 | All visuals should serve a purpose. / 所有视觉元素应有明确目的。 |
| **13. Use simple and clear graphs** / 使用简单清晰的图表 | Avoid over-complicated graphs. / 避免过于复杂的图表。 |

## Lecture 10: Intercultural & Ethical Issues
## 第十讲：跨文化与伦理问题

**Learning Objectives / 课程目标：**
- Understand elements of intercultural communication. / 了解跨文化交际的要素。
- Understand ethnocentrism and stereotypes. / 理解民族中心主义和刻板印象。
- Understand culture shock and adaptation. / 了解文化冲击与适应。
- Understand academic misconduct. / 了解学术不端行为。
- Learn how to avoid plagiarism. / 学习如何避免剽窃。

**Key Points / 核心要点：**

**1. Elements of Intercultural Communication / 跨文化交际要素**
- Beliefs, attitudes, values, and worldviews / 信仰、态度、价值观和世界观
- Language / 语言
- Signs and symbols / 符号和标志
- Context / 语境

**2. Ethnocentrism / 民族中心主义**
- **Definition**: The belief that one's own culture is the best and all other cultures are inferior. / 认为自己的文化最优，其他文化低劣。
- **How it impedes communication**: Leads to narrow identity; unfair comparisons; stereotypes. / 如何阻碍交流：导致狭隘身份认同；不公正比较；刻板印象。
- **How to overcome**: Recognize different ≠ inferior; know more about yourself; develop empathy. / 如何克服：不同不等于低劣；更了解自己；培养同理心。

**3. Stereotypes / 刻板印象**
- **Definition**: Overgeneralization based on limited or inaccurate information. / 基于有限或不准确信息的过度概括。
- **How to overcome**: No two groups are totally different or exactly the same; respond to individuals, not labels. / 如何超越：群体间既有差异也有相似；关注个体而非标签。

**4. Culture Shock / 文化冲击**
- **Definition**: Troublesome feelings (depression, loneliness, confusion, frustration) caused by the loss of familiar cues from home culture. / 因失去原有文化线索而产生的不适感（抑郁、孤独、困惑、沮丧）。
- **How to achieve adaptation**: Commitment to learning; willingness to explore without prejudgment; ability to behave appropriately. / 如何适应：承诺学习；不带偏见探索；具备恰当交往的能力。

**5. Academic Misconduct / 学术不端行为**
- Cheating in exams / 考试作弊
- **Plagiarism** / 剽窃
- Fabrication / 捏造数据
- Concurrent submission / 一稿多投
- Deception in authorship / 署名欺骗

**6. How to Avoid Plagiarism / 如何避免剽窃**

| Practice / 做法 | Correct Method / 正确方法 |
|-----------------|---------------------------|
| **Quoting** / 引用 | Use quotation marks and cite the source. / 加引号并注明出处。 |
| **Paraphrasing** / 转述 | Use your own words and sentence structures, and cite the source. / 使用自己的语言和句式，并注明出处。 |
| **Summarizing** / 总结 | Use your own words and cite the source. / 使用自己的语言，并注明出处。 |
| **Common knowledge** / 公知知识 | No citation needed. / 无需引用。 |
| **Self-plagiarism** / 自我剽窃 | Do not reuse your own previously published work without citation. / 避免重复使用自己已发表的内容。 |
| **Web sources** / 网络来源 | Obtain necessary permission for using others' material. / 使用他人材料需获得许可。 |


## Lecture 11: Emails
## 第十一讲：电子邮件

**Learning Objectives / 课程目标：**
- Learn how to write effective subject lines. / 学习如何写有效的主题行。
- Learn how to write appropriate beginnings. / 学习如何写恰当的开头。
- Learn how to write appropriate endings. / 学习如何写恰当的结尾。
- Learn how to structure the content. / 学习如何组织内容。
- Learn how to decide the level of formality. / 学习如何决定正式程度。

**Key Points / 核心要点：**

**1. Effective Subject Lines / 有效的主题行**
- Be **specific and informative**. / **具体、信息丰富**。
- Give the complete message in the subject line — use **EOM (End Of Message)**. / 在主题行给出完整信息 — 使用 **EOM**。
  - Example: `Oct 10 meeting changed to Oct 17. Same place and time. EOM.`
- Consider a two-part subject line: `Context: Details`. / 考虑两段式主题行。
  - Example: `Paper submission: title of your paper`

**2. Appropriate Beginnings / 恰当的开头**
- Spell the recipient's name correctly. / 正确拼写收件人姓名。
- Use appropriate salutations: / 使用恰当的称谓：
  - `Dear Professor Smith,` / `Dear Dr Smith:` / `Dear John Smith`
  - **Avoid**: `Dear Teacher Wang`, `Hi Professor Smith`, `Dear Smith`
- When unsure of gender/surname: Use the full name: `Dear Stewart James`. / 不确定时写全名。
- When name is unknown: Find the name; or use `Dear Session Organizers`, `To whom it may concern`. / 不认识时查找姓名或使用通用称呼。
- Remind the recipient who you are if previous contact was brief. / 若之前联系不多，提醒对方你是谁。

**3. Appropriate Endings / 恰当的结尾**
- Use standard phrases: `Best regards,` / `I look forward to hearing from you.` / 使用标准短语。
- Avoid literal translations from your own language. / 避免中式直译。
- Avoid using too many standard phrases in sequence. / 避免过多客套话。
- Avoid PSs — they are often not read. / 避免使用PS — 通常不会被阅读。
- Include in your signature: name, position, department, university, email, phone number. / 签名包含必要信息。

**4. Structuring Content / 组织内容**
- Plan your email; consider the recipient's point of view. / 规划邮件；考虑收件人的角度。
- Organize information in logical order; include only what is necessary. / 逻辑顺序；只包含必要信息。
- Keep it short and simple to minimize mistakes. / 保持简短简洁。
- **Avoid ambiguity** — ensure pronouns and modifiers are clear. / **避免歧义** — 确保代词和修饰语指代清晰。

**5. Formality / 正式程度**
- Use a friendly and positive approach when asking for help. / 请求帮助时采用友好积极的方式。
- Using titles (Dr, Professor) may increase willingness to help. / 使用头衔可能让对方更愿意帮助。
- Use apologetic/deferential language: `"Sorry to bother you..."` / `"I wonder if you could..."` / 使用道歉或谦恭语言。

| Level of Formality / 正式程度递进 | Example / 示例 |
|----------------------------------|---------------|
| Most direct / 最直接 | "Revise the manuscript for me." |
| More polite / 更礼貌 | "Could you revise the manuscript for me?" |
| Most polite / 最委婉 | "If it's not a problem for you, could you revise the manuscript for me?" |


## Lecture 12: Letters of Requests & Replies
## 第十二讲：请求信与回复

**Learning Objectives / 课程目标：**
- Decide whether to make one request or several. / 决定是发一个请求还是多个。
- Learn clear layout and organization of requests. / 学习如何清晰布局和组织请求。
- Learn how to increase the chances of getting a reply. / 学习如何提高获得回复的几率。
- Choose appropriate methods for replies. / 为回复选择适当的方法。

**Key Points / 核心要点：**

**1. One Request vs. Multiple Requests / 一个请求还是多个请求**
- If you have one important request, only ask that one thing. / 若有一件重要事项，只问这一件事。
- Fewer options = more likely to get what you want. / 选项少 = 更容易获得想要的回应。
- Multiple requests: the easiest ones get answered; complex ones get ignored. / 多个请求中，最简单的会被先处理，复杂的可能被忽略。

**2. Clear Layout and Organization / 清晰布局与组织**

| Practice / 做法 | Example / 示例 |
|-----------------|---------------|
| **Numbering** / 编号 | "Please can you answer the following questions: 1. ... 2. ... 3. ..." |
| **Mini summary** / 迷你总结 | At the end: "Summary: 1) ... 2) ... 3) ..." / 末尾总结要点。 |

**3. Increasing the Chances of Getting a Reply / 提高获得回复的几率**
- Provide all necessary information — avoid back-and-forth. / 提供所有必要信息，避免来回追问。
- Consider not sending attachments to first-time contacts (may be flagged as spam). / 若无前次接触，考虑不发送附件（可能被当作垃圾邮件）。
- Good layout and organization create a positive impression. / 清晰的布局给收件人留下积极印象。
- **Motivate the recipient**: Show empathy (`I know you are very busy...`) or pay a compliment. / **激励对方回复**：表示体谅（`我知道您很忙...`）或给予赞美。
- **Give deadlines** / 给出截止日期：
  - `within` + plural noun: `within the next two days`
  - `by` + specific time: `by 11 tomorrow morning`
  - `until` + negative verb: `I don't need it until next week.`
  - `before` + time period: `before the end of next week`

**4. Appropriate Methods for Replies / 适当的回复方法**
- Insert your answers within the body of the sender's email. / 将回复插入原邮件正文。
- Insert friendly comments within the sender's text. / 在原邮件中插入友好评论。
- Copy/adapt the sender's English rather than experimenting. / 复制或改编发件人的语言，不要自己创造。|

## Lecture 16: Listening to Academic Lectures and Talks
## 第十六讲：学术听力——讲座与演讲

**Learning Objectives / 课程目标：**
- Discuss different listening situations. / 讨论不同的听力情境。
- Identify factors that influence comprehension. / 识别影响理解能力的因素。
- Learn about macrostructure of lectures and talks. / 了解讲座和演讲的宏观结构。
- Learn about features of lectures in different academic cultures. / 了解不同学术文化中讲座的特点。

**Key Points / 核心要点：**

**1. Factors Influencing Listening / 影响听力的因素**
- Speed of speech / 语速
- Background noise / 背景噪音
- Difficult/specialized vocabulary / 生僻/专业术语
- Dense information / 信息密度
- Lack of background knowledge / 缺乏背景知识
- Lack of interest or attention / 缺乏兴趣或注意力
- Interruptions / 他人打断

**2. Two Additional Listening Problems / 两个额外听力问题**
- **Word boundaries**: It's difficult to know when one word ends and another begins. / **单词边界**：难以分辨词与词之间的界限。
- **Word recognition**: Failing to recognize words you know in written form because they are pronounced differently in natural speech. / **单词识别**：无法识别在书面形式中认识的单词，因其在口语中发音不同。

**3. Solutions / 解决方案**
- Get as much practice listening to natural speech as possible. / 尽可能多地练习听自然口语。
- Be ready to change your mind about your understanding if what you hear doesn't make sense. / 当所听内容不通时，愿意改变对意思的理解。

**4. Macrostructure of Lectures / 讲座的宏观结构**

| Structure / 结构 | Description / 描述 |
|------------------|-------------------|
| **Structure 1** | Suggest alternative methods → Discuss benefits and drawbacks. / 提出不同方法 → 讨论优缺点。 |
| **Structure 2** | State hypothesis → Outline experiment → Look at results → Draw conclusions. / 陈述假设 → 概述实验 → 查看结果 → 得出结论。 |
| **Structure 3** | Present theory → See how it works in practice → Suggest problems. / 提出理论 → 应用于实践 → 指出问题。 |

**5. Chinese vs. UK Lectures / 中英讲座文化差异**

| Feature / 特征 | China / 中国 | UK / 英国 |
|----------------|--------------|-----------|
| Content delivery / 内容交付 | Lectures deliver most course content. / 讲座是课程内容的主要载体。 | Content delivered through lectures AND reading. / 内容不只在讲座中传授。 |
| Interactivity / 互动性 | Low (students listen and take notes). / 低（学生听讲记笔记）。 | High (students ask questions, discuss). / 高（学生提问、讨论）。 |
| Key points / 重点 | Explicitly marked by lecturer. / 被明确标记。 | Students must determine for themselves. / 学生需自行判断。 |
| Reading / 阅读 | One course book. / 通常只有一本教材。 | Extensive reading of multiple books and articles. / 需进行大量阅读。 |

## 第十七讲：记笔记

**Learning Objectives / 课程目标：**
- Discuss reasons for taking notes. / 讨论记笔记的原因。
- Learn principles of effective note-taking. / 学习有效记笔记的原则。
- Learn to use abbreviations and symbols. / 学习使用缩写和符号。
- Discuss advantages and disadvantages of two note-taking systems. / 讨论两种笔记系统的优缺点。
- Practice taking notes from lectures/talks. / 练习从讲座/演讲中记笔记。

**Key Points / 核心要点：**

**1. Reasons for Note-taking / 记笔记的原因**
- Separate important information from non-essential material. / 区分重要与非重要信息。
- Recall important information. / 回忆重要信息。
- Help study for exams or write papers. / 帮助复习备考或撰写论文。
- Minimize personal distractions. / 减少注意力分散。

**2. Principles of Note-taking / 有效记笔记的原则**
- **Selective / 选择性**: Decide what is important. / 决定什么是重要的。
- **Clear / 清晰性**: Ensure relationships between ideas are clearly shown. / 确保笔记逻辑清晰。
- **Brief / 简洁性**: Use abbreviations and symbols. / 使用缩写和符号。

**3. Abbreviations & Symbols / 缩写与符号**

| Abbrev. / 缩写 | Meaning / 含义 | Symbol / 符号 | Meaning / 含义 |
|----------------|---------------|---------------|---------------|
| `infl.` | influence | `↑` | increase, rise |
| `invest.` | investment | `↓` | decrease, drop |
| `recess.` | recession | `→` | leads to, causes |
| `min.` | minimum | `=` | equals |
| `B/P` | blood pressure | `≠` | not, isn't |
| `Rx.` | prescriptions | `>` | greater than |
| | | `<` | less than |
| | | `?` | uncertain |
| | | `!` | certain, proven |

**4. Two Note-taking Systems / 两种笔记系统**

| System / 系统 | Advantages / 优点 | Disadvantages / 缺点 | Best for / 适用场景 |

## Lecture 18: Listening to Introductions
## 第十八讲：学术听力——讲座引言

**Learning Objectives / 课程目标：**
- Learn functions and language of lecture/talk introductions. / 了解讲座/演讲引言的功能和语言。
- Learn how introductions help you understand better. / 学习如何利用引言更好地理解。
- Practice taking notes on introductions. / 练习从引言中记笔记。
- Learn basic rules of word stress. / 学习单词重音的基本规则。

**Key Points / 核心要点：**

**1. Functions of Introductions / 引言的功能**

| Function / 功能 | Example / 示例 |
|-----------------|---------------|
| **Preview content/structure** / 预览内容/结构 | "In today's session, I'm going to talk about the local environment, the role of local government..." |
| **Limit scope** / 限定范围 | "That's not the type of migration I want to look at. What I want to look at is internal migration." |
| **Give background** / 提供背景信息 | "I want to give a very simple introduction to European Union Institutions." |
| **Refer to research** / 提及相关研究 | "Sara Shettleworth has a superb chapter on social learning." |
| **Introduce approaches** / 介绍不同方法 | "There are two themes — a qualitative stream and a quantitative stream." |
| **Refer back to previous lectures** / 回顾之前内容 | "Last term we looked at how accounting systems were different." |
| **Explain personal interest** / 解释个人兴趣 | "I undertook a study in the mid-80s..." |
| **Tell what to write down** / 提示记录与否 | "You'll get a handout, so you don't have to write this down." |

**2. Word Stress Rules / 单词重音规则**

| Rule / 规则 | Example / 示例 |
|------------|---------------|
| **2-syllable nouns/adjectives**: stress on **first syllable** / 双音节名词/形容词：重音在**第一音节** | `TA-ble`, `PRE-tty` (exceptions: `ho-TEL`) |
| **2-syllable verbs/prepositions**: stress on **second syllable** / 双音节动词/介词：重音在**第二音节** | `pre-SENT`, `be-TWEEN` (exceptions: `CON-tact`) |
| **Noun vs. Verb (same spelling)**: noun stress on **first**; verb on **second** / 同形名/动词：名**第一**，动**第二** | `PRE-sent` vs. `pre-SENT` |
| **Ending in `-er`, `-ly`**: stress on **first syllable** / 以`-er`、`-ly`结尾：重音在**第一音节** | `MA-na-ger` |
| **Ending in `-ic`, `-sion`, `-tion`**: stress on **second-to-last syllable** / 以`-ic`等结尾：重音在**倒数第二音节** | `cre-A-tion` |
| **Ending in `-cy`, `-ty`, `-phy`, `-gy`, `-al`**: stress on **third-to-last syllable** / 以`-cy`等结尾：重音在**倒数第三音节** | `de-MO-cra-cy` |
| **Compound nouns**: stress on **first noun** / 复合名词：重音在**第一个名词** | `FOOT-ball` |
| **Compound adjectives/verbs**: stress on **second word** / 复合形容词/动词：重音在**第二个词** | `old-FA-shioned`, `over-USE` |


## Lecture 19: Identifying Key Points & Digressions
## 第十九讲：识别关键点与离题

**Learning Objectives / 课程目标：**
- Practice identifying key points in a lecture. / 练习识别讲座中的关键点。
- Practice signposting and highlighting key points. / 练习使用标记性语言标示关键点。
- Discuss reasons for digressions. / 讨论离题的原因。
- Learn how lectures mark digressions. / 学习讲座中如何标记离题。

**Key Points / 核心要点：**

**1. Importance of Identifying Key Points / 识别关键点的重要性**
- It allows the listener to follow the main thread of the argument. / 帮助跟随演讲者论证的主线。

**2. Signposting Language / 标记性语言**

| Function / 功能 | Examples / 示例 |
|-----------------|-----------------|
| **Transitions** / 过渡 | `Firstly, Secondly, In addition, Another point is...` |
| **Emphasis** / 强调 | `The important point here is...`, `Remember that...`, `I'd like to emphasize...` |
| **Summarizing** / 总结 | `To summarize...`, `In summary...` |
| **Shifting topics** / 转换话题 | `Let's move on to...`, `That's all for...`, `Now we can turn to...` |

**3. Reasons for Digressions / 离题的原因**
- To give a short definition of a new technical term. / 简短定义新术语。
- To give a reference book on the topic. / 推荐参考书目。
- To comment on events happening outside the lecture. / 评论外部事件。
- To comment on the point they are making. / 评论自己的观点。
- To give general information about the case. / 给出案例的一般信息。
- To give a personal anecdote to illustrate a point. / 讲述个人轶事。

**4. Identifying Digressions / 识别离题**
- Lecturers mark digressions through **intonation** and **lexical signals**. / 通过**语调**和**词汇信号**标记。
- Beginning: `Before I go on...` / 开始离题
- Returning: `Anyway...` / 回到正题
- Changes in speed, volume, and pausing may signal digressions. / 语速、音量和停顿的变化可能是信号。


## Lecture 20: Introducing New Terminology
## 第二十讲：引入新术语

**Learning Objectives / 课程目标：**
- Listen to lecturers introducing new terms/concepts. / 聆听不同讲座者如何引入新术语或概念。
- Learn different techniques for introducing new concepts. / 学习引入新概念的不同技巧。
- Practice recognizing unstressed function words. / 练习识别被弱读的功能词。

**Key Points / 核心要点：**

**1. Techniques for Introducing New Terminology / 引入新术语的技巧**

| Technique / 技巧 | Description / 描述 | Example / 示例 |
|------------------|-------------------|---------------|
| **a. Give definitions** / 下定义 | Directly explain the meaning. / 直接解释术语含义。 | "Hire purchase is one way that people can buy something..." |
| **b. Provide extended examples** / 提供扩展例子 | Use multiple specific examples. / 用多个具体例子说明。 | "Say somebody wants a new sofa, but cannot afford to pay one sum of £2,000..." |
| **c. Explain how it works** / 解释运作方式 | Explain the mechanism or process. / 解释原理或过程。 | "The person buying the product pays for it over a period of time..." |
| **d. Contrast with familiar concept** / 对比熟悉概念 | Compare with something the audience already knows. / 与听众已知概念对比。 | "You all know what a loan is. Hire purchase is a sort of loan, but..." |

**2. Weak Forms of Function Words / 功能词的弱读**
- Many function words (conjunctions, articles, prepositions, auxiliary verbs) are **unstressed** and difficult to hear. / 许多功能词通常弱读，难以听清。
- When a function word is **stressed** (for contrast, emphasis, or at the end of a sentence), it uses its **strong form**. / 当功能词被**强调**时（为了对比、强调或位于句末），使用其**强读形式**。

| Word / 词 | Weak Form / 弱读 | Strong Form (Stressed) / 强读 (强调时) | Example / 示例 |
|-----------|-----------------|----------------------------------------|---------------|
| `can` | /kən/ | /kæn/ | "I **can** do it, but I don't want to." |
| `at` | /ət/ | /æt/ | "There were **at** least five errors." |
| `us` | /əs/ | /ʌs/ | "Are they going to interview **us** as well?" |
