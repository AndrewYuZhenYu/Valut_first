# Valut First | 个人知识库

  
  
  

> 系统化学习 · 结构化知识 · 跨学科积累 · 长期主义

## 1. 仓库简介 | Overview

Valut First 是一个基于 Obsidian、Markdown 与 Git 构建的综合性个人知识库，主要用于学科知识整理、专业技能学习、技术经验沉淀及长期知识管理。

本知识库以计算机科学与数学为核心，同时向自然科学、经济学、金融学、语言文化等领域拓展，通过系统化、结构化和可视化的知识组织方式，逐步建立具有广度、深度与实际应用价值的个人知识体系。

仓库不仅承担学习资料的存储与归档功能，更致力于知识的理解、整合、关联、检索与复用。

## 4. 知识库特色 | Features

### 系统化知识整理

以学科体系为基础组织知识内容，注重基本概念、核心原理、知识关联、典型应用与常见问题，避免碎片化的信息堆积。

### 可视化知识表达

通过思维导图、结构示意图、流程图、数学函数图像、原理图及对比表格等形式辅助理解复杂概念与抽象理论。

### 理论与实践结合

在理论知识整理的基础上，结合程序代码、课程实验、典型例题、技术操作与实际应用场景，促进知识向实践能力转化。

### 标准化文档管理

以 Markdown 为主要文档格式，结合 LaTeX 数学公式、代码块、表格、图片资源及 Obsidian 特有的知识组织功能，建立便于长期维护的文档体系。

### 持续更新与版本管理

利用 Git 与 GitHub 记录知识库的更新过程，保留历史版本，使知识内容能够持续迭代、修正与扩充。

## 5. 使用方式 | Getting Started

### 5.1 在线阅读

可以直接通过 GitHub 浏览各学科目录及 Markdown 文档。

由于部分笔记使用 Obsidian 特有的语法、内部链接及图片引用方式，GitHub 上的显示效果可能与原始知识库存在差异。

### 5.2 本地阅读

推荐使用 Obsidian，以获得更加完整的阅读与知识管理体验。

首先克隆仓库：

```
git clone https://github.com/AndrewYuZhenYu/Valut_first.git
```

随后：

1. 安装并打开 [Obsidian](https://obsidian.md/)。
    
2. 选择「打开本地仓库」。
    
3. 选择克隆后的 `Valut_first` 文件夹。
    
4. 浏览、检索或编辑相关知识文档。
    

建议保留完整的 `Assets` 目录，以确保笔记中的图片及其他附件能够正常加载。

### 5.3 获取最新内容

```
git pull origin main
```
