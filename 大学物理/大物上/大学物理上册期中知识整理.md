## 一、质点运动学

### （一）基本概念与定义

#### 1. 质点

- **定义**：具有一定质量的几何点；只有质量而不考虑大小、形状和内部运动的理想模型。
- **适用条件**：物体尺寸远小于运动特征长度时；或物体做纯平动时（各点运动完全相同）。
- **举例**：研究地球绕太阳公转 → 可视为质点；研究地球自转 → 不可视为质点。

#### 2. 参考系与坐标系

- **参考系**：研究物体运动时选定为不动的参照物。
- **坐标系**：原点和轴线固定在参考系上，用于定量描述空间位置。常用：直角坐标系、自然坐标系、柱坐标系、球坐标系。

#### 3. 位置矢量（位矢）

坐标系中由原点引向质点空间位置 P 的有向线段 $\overrightarrow{OP}$，用 $\vec{r}$ 表示。

$$\vec{r} = x\hat{i} + y\hat{j} + z\hat{k}, \qquad |\vec{r}| = \sqrt{x^2 + y^2 + z^2}$$

方向余弦：$\cos\alpha = \dfrac{x}{|\vec{r}|},\quad \cos\beta = \dfrac{y}{|\vec{r}|},\quad \cos\gamma = \dfrac{z}{|\vec{r}|}$

#### 4. 位移与路程

| 物理量 | 性质 | 定义 | 说明 |
|--------|------|------|------|
| 位移 $\Delta\vec{r}$ | 矢量 | $\Delta\vec{r} = \vec{r}_2 - \vec{r}_1$ | 只与始末位置有关，与路径无关 |
| 路程 $\Delta s$ | 标量 | 实际走过的轨迹长度 | 与路径有关 |

> **重要**：一般情况下 $|\Delta\vec{r}| \leq \Delta s$，仅在单向直线运动中取等号。

#### 5. 质点的运动方程

$$\vec{r} = \vec{r}(t) = x(t)\hat{i} + y(t)\hat{j} + z(t)\hat{k}$$

消去参数 $t$ 即得轨迹方程。

#### 6. 瞬时速度

$$\vec{v} = \lim_{\Delta t \to 0}\frac{\Delta\vec{r}}{\Delta t} = \frac{d\vec{r}}{dt} = \frac{dx}{dt}\hat{i} + \frac{dy}{dt}\hat{j} + \frac{dz}{dt}\hat{k}$$

- 速度大小：$|\vec{v}| = \left|\dfrac{d\vec{r}}{dt}\right| = \dfrac{d|\vec{r}|}{dt}$（注意：不等于 $\dfrac{d|\vec{r}|}{dt}$，一般）
- 速度方向：质点运动轨迹在该点的切线方向

> **注意**：$|\vec{v}| = \dfrac{ds}{dt}$（速率等于路程对时间的导数），这与 $\dfrac{d|\vec{r}|}{dt}$ 不同。

#### 7. 瞬时加速度

$$\vec{a} = \frac{d\vec{v}}{dt} = \frac{d^2\vec{r}}{dt^2} = \frac{d^2x}{dt^2}\hat{i} + \frac{d^2y}{dt^2}\hat{j} + \frac{d^2z}{dt^2}\hat{k}$$

> **重要**：$\vec{a}$ 与 $\vec{v}$ 方向无必然联系：
> - 同向 → 加速运动
> - 反向 → 减速运动
> - 垂直 → 速度大小不变、方向改变（匀速圆周运动）

### （二）自然坐标系（切线-法线分解）

以质点轨迹上任一点为原点，切线方向 $\hat{e}_t$、法线方向 $\hat{e}_n$（指向曲率中心）建立局部坐标系。

#### 加速度的切向-法向分解

$$\vec{a} = a_t\hat{e}_t + a_n\hat{e}_n$$

| 分量 | 公式 | 物理意义 |
|------|------|----------|
| 切向加速度 | $a_t = \dfrac{dv}{dt}$ | 改变速度**大小** |
| 法向加速度 | $a_n = \dfrac{v^2}{\rho}$ | 改变速度**方向**，$\rho$ 为曲率半径 |
| 总加速度大小 | $a = \sqrt{a_t^2 + a_n^2}$ | 二者的矢量合成 |

**由运动方程求曲率半径的步骤**：

1. 求 $\vec{v} = d\vec{r}/dt$，$\vec{a} = d\vec{v}/dt$
2. $a_t = \dfrac{|\vec{v}\cdot\vec{a}|}{|\vec{v}|}$（速度与加速度的点积除以速度大小）
3. $a_n = \sqrt{a^2 - a_t^2}$
4. $\rho = \dfrac{v^2}{a_n}$

### （三）圆周运动的角量描述

#### 基本角量

| 物理量  | 符号             | 定义                                                       | 单位       |
| ---- | -------------- | -------------------------------------------------------- | -------- |
| 角位移  | $\Delta\theta$ | 位矢转过的角度                                                  | $rad$    |
| 角速度  | $\omega$       | $\omega = \dfrac{d\theta}{dt}$                           | $rad/s$  |
| 角加速度 | $\alpha$       | $\alpha = \dfrac{d\omega}{dt} = \dfrac{d^2\theta}{dt^2}$ | $rad/s²$ |

#### 线量与角量的关系（半径为 $R$）

$$\Delta s = R\Delta\theta, \qquad v = R\omega, \qquad a_t = R\alpha, \qquad a_n = R\omega^2 = \frac{v^2}{R}$$

#### 匀变速圆周运动（$\alpha$ = 常数）

$$\omega_t = \omega_0 + \alpha t, \qquad \theta = \theta_0 + \omega_0 t + \frac{1}{2}\alpha t^2, \qquad \omega_t^2 = \omega_0^2 + 2\alpha(\theta - \theta_0)$$

#### 角速度矢量

- 大小：$\omega$
- 方向：沿转轴，由右手螺旋定则确定
- 线速度与角速度的关系：$\vec{v} = \vec{\omega}\times\vec{r}$

### （四）质点的相对运动

**速度合成定理**（伽利略变换）：

$$\vec{v}_{绝对} = \vec{v}_{相对} + \vec{v}_{牵连}$$

即：$\vec{v} = \vec{v}' + \vec{u}$

- **绝对运动**：物体相对基本参考系（地面）的运动
- **相对运动**：物体相对动参考系的运动
- **牵连运动**：动参考系相对基本参考系的运动

**加速度合成**（惯性系间）：$\vec{a}' = \vec{a}$（伽利略变换下加速度不变）

> **物理意义**：这正是伽利略相对性原理——牛顿第二定律在所有惯性系中形式相同。

### （五）题型归纳与解题技巧

#### 题型一：由运动方程求速度和加速度

**解题技巧**：对时间求导。已知 $\vec{r} = r(t)$，则 $\vec{v} = \dfrac{d\vec{r}}{dt}$，$\vec{a} = \dfrac{d^2\vec{r}}{dt^2}$。

**例**：已知质点的运动学分量式 $x = 2t$，$y = 6 - 2t^2$（SI），求：
- 轨迹方程：由 $x = 2t$ 得 $t = x/2$，代入 $y = 6 - 2(x/2)^2 = 6 - x^2/2$
- $t = 1$ s 时：$v_x = 2$ m/s，$v_y = -4t|_{t=1} = -4$ m/s，故 $v = 2\sqrt{5}$ m/s
- $a_x = 0$，$a_y = -4$ m/s²，故 $a = 4$ m/s²，方向与 $y$ 轴正方向相反

#### 题型二：由加速度积分求速度与位移

四种常见情形：

1. **已知 $a = a(t)$**：$v - v_0 = \int_0^t a(t)\,dt$
2. **已知 $a = a(x)$**：$a\,dx = v\,dv \Rightarrow \int_{x_0}^x a\,dx = \int_{v_0}^v v\,dv$
3. **已知 $a = a(v)$ 求 $v(t)$**：$dt = dv/a(v) \Rightarrow \int_0^t dt = \int_{v_0}^v \dfrac{dv}{a(v)}$
4. **已知 $a = a(v)$ 求 $v(x)$**：$dx = v\,dv/a(v) \Rightarrow \int_{x_0}^x dx = \int_{v_0}^v \dfrac{v\,dv}{a(v)}$

#### 题型三：求切向/法向加速度和曲率半径

已知运动方程 $\vec{r} = r(t)$：

$$a_t = \frac{dv}{dt}, \qquad a_n = \frac{v^2}{\rho}$$

- 圆周运动：$a_n = v^2/R$（直接用半径）
- 一般曲线运动：$a_n = \sqrt{a^2 - a_t^2}$，再由 $\rho = v^2/a_n$ 求曲率半径

#### 题型四：已知角位置函数求角量

对 $\theta(t)$ 求导得 $\omega(t)$，再求导得 $\alpha(t)$，代入数值即可。

#### 题型五：相对速度问题

先明确研究对象和参考系关系，利用速度合成矢量式求解，必要时画矢量图。

## 二、动量守恒定律

### （一）基本概念与公式

#### 1. 惯性与牛顿第一定律

- **自由质点（孤立质点）**：不受其他物体作用的质点，是理想模型。
- **惯性**：物体保持静止或匀速直线运动状态的特性。
- **牛顿第一定律**：任何物体都保持静止或匀速直线运动状态，直到作用在它上面的力迫使它改变这种状态为止。
- **惯性参考系（惯性系）**：其中孤立质点保持静止或匀速直线运动的参考系。相对惯性系做匀速直线运动的参考系也是惯性系；做加速运动的参考系是非惯性系。

#### 2. 动量

$$\vec{p} = m\vec{v} \qquad \text{（矢量，单位：kg·m·s}^{-1}\text{）}$$

质点系的动量：$\vec{p} = \sum\vec{p}_i = \sum m_i\vec{v}_i$

#### 3. 动量守恒定律

**条件**：系统所受合外力为零（$\vec{F}_{外} = 0$）

$$\vec{p} = \sum\vec{p}_i = \text{恒矢量}$$

**注意事项**：
1. 只适用于惯性系
2. 合外力为零，或某方向分量为零（该方向分量守恒）
3. 内力可以很大（如爆炸、碰撞瞬间），只要合外力远小于内力，可近似认为守恒
4. 内力不改变系统总动量，但改变各质点的动量分配

#### 4. 力的分类

| 力 | 方向 | 公式 | 说明 |
|----|------|------|------|
| 万有引力 | 沿质心连线，吸引 | $f = G\dfrac{m_1m_2}{r^2}$，$G = 6.67\times10^{-11}$ N·m²/kg² | 引力质量 $m_1, m_2$ |
| 重力 | 竖直向下 | $F = mg$ | 地表附近近似 |
| 弹力（弹簧） | 恢复形变方向 | $f = -kx$ | 胡克定律，$k$ 为劲度系数 |
| 滑动摩擦力 | 与相对运动方向相反 | $F_k = \mu_k N$ | $\mu_k$ 为动摩擦因数 |
| 静摩擦力 | 与相对运动趋势方向相反 | $|F_s| \leq \mu_s N$ | $\mu_s > \mu_k$（一般） |
| 液体阻力 | 与相对运动方向相反 | $f_d = kv$ | $k$ 与物体大小、形状及流体性质有关 |

> **补充**：绳中各点张力相等（当绳质量可忽略时）。这是因为对绳上任意小段 $dm$：若 $dm \to 0$，则两端张力差 $\to 0$。

#### 5. 动量定理

$$\vec{F} = \sum\vec{F}_i = \frac{d\vec{p}}{dt}$$

分量形式：

$$I_x = \int_{t_1}^{t_2}F_x\,dt = p_{x2} - p_{x1}$$

$$I_y = \int_{t_1}^{t_2}F_y\,dt = p_{y2} - p_{y1}$$

$$I_z = \int_{t_1}^{t_2}F_z\,dt = p_{z2} - p_{z1}$$

#### 6. 冲量

$$\vec{I} = \int_{t_1}^{t_2}\vec{F}\,dt = \vec{p}_2 - \vec{p}_1$$

- **冲量**：力对时间的积累，是过程量，矢量
- **平均冲力**：$\bar{\vec{F}} = \dfrac{\vec{I}}{t_2 - t_1}$（作用时间极短但导致较大动量变化时使用）

#### 7. 变质量系统

设系统质量 $M$，速度 $\vec{v}$；在 $dt$ 内获得质量 $dM$，其相对系统速度为 $\vec{u}$，则：

$$\vec{F}_{外} + \vec{u}\frac{dM}{dt} = M\frac{d\vec{v}}{dt}$$

其中 $\vec{u}\dfrac{dM}{dt}$ 为系统因质量变化而获得的推力（反推力）。

> **火箭方程**：设喷气速度为 $u$，则火箭推力 $T = u\dfrac{dM}{dt}$（$dM/dt < 0$，推力方向与喷气反向）。

#### 8. 牛顿第二定律

$$\vec{F} = \frac{d\vec{p}}{dt} = m\frac{d\vec{v}}{dt} = m\vec{a}$$

- **使用条件**：质点在远离强引力场的惯性系中做宏观低速运动（经典力学范围）
- **自然坐标系分量**：切向 $F_t = m\dfrac{dv}{dt}$，法向 $F_n = m\dfrac{v^2}{\rho}$

**应用步骤**：
1. 明确研究对象
2. 画受力图（隔离体法）
3. 分析运动状态（速度、加速度方向）
4. 建立坐标系，列方程
5. 求解并讨论

#### 9. 质心运动定理

$$\vec{F}_{外} = M\frac{d\vec{v}_c}{dt} = M\vec{a}_c$$

质心位置：$\vec{r}_c = \dfrac{\sum m_i\vec{r}_i}{\sum m_i}$，质心坐标：$x_c = \dfrac{1}{m}\int x\,dm$，$y_c = \dfrac{1}{m}\int y\,dm$

**性质**：
- 内力不能使质心产生加速度
- 若合外力始终为零，质心做匀速直线运动或保持静止

#### 10. 惯性力与非惯性系

非惯性系：相对惯性系做加速运动的参考系（如加速的电梯、旋转圆盘）。

牛顿定律在非惯性系中不成立，为了在形式上继续使用，引入**惯性力**：

$$\vec{F}_0 = -m\vec{a}_0 \qquad \text{（平移惯性力，相对惯性系做加速平动时）}$$

非惯性系中的运动方程：$\vec{F} + \vec{F}_0 = m\vec{a}'$

**惯性离心力**（相对惯性系匀速转动时）：$\vec{F}_f = -mr\omega^2\hat{e}_r$

**科里奥利力**：$\vec{F}_c = 2m\vec{v}'\times\vec{\omega}$

- 科里奥利力不做功（始终垂直于质点在非惯性系中的速度 $\vec{v}'$）
- 北半球气旋逆时针、南半球气旋顺时针旋转，均由科里奥利力引起

### （二）题型归纳与解题技巧

#### 题型一：动量守恒与动量定理的实际应用

**解题技巧**：
- 动量守恒定律：合外力为零时，$\vec{p} = \sum m_i\vec{v}_i = \text{恒矢量}$
- 动量定理：$\vec{F} = \dfrac{d\vec{p}}{dt}$（即 $\int\vec{F}\,dt = m\Delta\vec{v}$）

**经典例题**：质量 $M$ 的平板车以速度 $v_0$ 沿光滑水平直轨道运动，车上站着质量为 $m$ 的人，初人相对于车静止。若人相对于车以速度 $v_1$ 从车尾向车头行走，则此时车的速度为 $v_甲$。

解：由动量守恒 $(M+m)v_0 = m(v_1 + v_甲) + Mv_甲$，得 $v_甲 = v_0 - \dfrac{m}{M+m}v_1$

#### 题型二：求实际问题中的冲量和冲力

碰撞、撞击过程中，碰撞时间极短，利用 $\vec{I} = \Delta\vec{p}$ 和平均冲力 $\bar{F} = I/\Delta t$ 求解。

**注意**：冲力方向由 $\Delta\vec{p}$ 方向决定，不一定与初速度方向相同。

#### 题型三：物体在变力作用下的运动

分三种情形：
1. $F = F(t)$：$a = F(t)/m$，积分得 $v$ 和 $x$
2. $F = F(x)$：$a = F(x)/m$，利用 $v\,dv = a\,dx$ 积分
3. $F = F(v)$：$a = F(v)/m$，分离变量积分

#### 题型四：求物体的质心

**微元法**：将物体视为由无穷个微元构成，利用积分求解：

$$x_c = \frac{1}{m}\int x\,dm, \qquad y_c = \frac{1}{m}\int y\,dm$$

**例**：均匀半圆形薄板的质心（由对称性知 $x_c = 0$；设密度 $\sigma$，取宽度 $dy$ 的矩形）：

$$dm = 2\sigma\sqrt{R^2-y^2}\,dy, \qquad y_c = \frac{1}{\sigma\pi R^2/2}\int_0^R 2\sigma\sqrt{R^2-y^2}\,y\,dy = \frac{4R}{3\pi}$$

#### 题型五：变质量问题

变质量问题中主体排出或吸附一部分质量，一般用动量定理处理：

$$\vec{F}_{外} + \vec{u}\frac{dM}{dt} = M\frac{d\vec{v}}{dt}$$

#### 题型六：非惯性参考系的应用

两种方法：
1. 在惯性系中，从相对加速度得到相对于惯性系的加速度
2. 在非惯性系中，附加惯性力，用 $\vec{F} + \vec{F}_{惯} = m\vec{a}'$

## 三、能量守恒定律

### （一）基本概念与公式

#### 1. 机械能

- **动能**（从能量角度描写机械运动的状态量）：$E_k = \dfrac{1}{2}mv^2$
- **势能**（保守力做功对应的能量）：
**常见势能表达式**：

| 力      | 势能                                          | 零势能点         |
| ------ | ------------------------------------------- | ------------ |
| 重力     | $E_p = mgh$                                 | $h = 0$      |
| 弹力（弹簧） | $E_p = \dfrac{1}{2}kx^2$                    | $x = 0$      |
| 万有引力   | $E_p = -\dfrac{GMm}{r}$                     | $r = \infty$ |
| 库仑力    | $E_p = \dfrac{q_1q_2}{4\pi\varepsilon_0 r}$ | $r = \infty$ |
- **机械能**：动能与势能之和 $E = E_k + E_p$

#### 2. 能量守恒定律

在一个孤立系统中，无论物质运动的过程如何，该系统的能量都不能被创造，也不能被消灭，只能从一种形式转化为另一种形式，而各种形式的能量总和保持不变：

$$\sum E_i = \text{常数}$$

#### 3. 功

**元功**（力 $\vec{F}$ 与元位移 $d\vec{r}$ 的点积）：

$$dA = \vec{F}\cdot d\vec{r} = F\cos\theta\,|d\vec{r}| = F\cos\theta\,ds$$

**有限路程 $a\to b$ 上的功**：

$$A = \int_a^b \vec{F}\cdot d\vec{r} = \int_a^b F\cos\theta\,ds$$

直角坐标系下：$A = \int_a^b(F_x\,dx + F_y\,dy + F_z\,dz)$

**功的性质**：
- 标量，有正负，无方向
- 具有可加性：合力的功等于各分力的功的代数和
- 是过程量，与运动路径相关（非保守力）或无关（保守力）
- 是相对量，与参考系的选取有关

#### 4. 功率

$$P = \frac{dA}{dt} = \vec{F}\cdot\frac{d\vec{r}}{dt} = \vec{F}\cdot\vec{v}$$

单位：瓦特（W），$1\text{ W} = 1\text{ J·s}^{-1}$

#### 5. 一对力的功

两质点间的作用力与反作用力（一对力）所做功之和：

$$dA = \vec{F}_A\cdot d\vec{r}_A + \vec{F}_B\cdot d\vec{r}_B = \vec{F}_B\cdot d(\vec{r}_B - \vec{r}_A) = \vec{F}_B\cdot d\vec{r}_{BA}$$

**推论**：
- 一对力的功与参考系的选择无关（绝对量）
- 若两质点间没有相对运动，或相对运动方向与力方向垂直，则一对力的功为零

#### 6. 动能定理

**质点动能定理**：质点动能的增量等于合力对质点所做的功：

$$A_{合} = \Delta E_k = \frac{1}{2}mv_2^2 - \frac{1}{2}mv_1^2$$

**质点系动能定理**：系统总动能的增量等于各质点所受全部外力与内力做功的代数和：

$$\Delta E_k = E_k - E_{k0} = A_{外} + A_{内}$$

**注意**：
1. 动能定理只适用于惯性参考系
2. "质点系所受外力做功"的说法没有意义，因为各外力作用于不同质点，各质点的位移不同
3. 内力可以改变系统的总动能，但不改变系统的总动量
4. 功和动能与参考系的选择有关，但动能定理与参考系的选择无关

#### 7. 保守力

**定义**：做功只与始末位置有关，与路径无关的力：

$$\oint \vec{F}\cdot d\vec{r} = 0 \qquad \text{（沿任意闭合路径做功为零）}$$

**常见保守力**：重力、弹力（弹簧弹力）、万有引力、静电力（库仑力）

**常见非保守力**：摩擦力、空气阻力

**常见几种保守力做的功**：

（1）**重力做功**：$A = \int_a^b m\vec{g}\cdot d\vec{r} = \int_{h_0}^h (-mg)\,dh = -(mgh - mgh_0) = mg(h_0 - h)$

（2）**平方反比有心力做功**（万有引力、库仑力，$\vec{F} = -\dfrac{k\hat{e}_r}{r^2}$）：

$$A = \int_{r_0}^r \vec{F}\cdot d\vec{r} = -k\left(-\frac{1}{r}\right)\bigg|_{r_0}^r = k\left(\frac{1}{r} - \frac{1}{r_0}\right)$$

（3）**弹簧弹力做功**：$A = \int_{x_0}^x (-kx)\,dx = -\left(\dfrac{1}{2}kx^2 - \dfrac{1}{2}kx_0^2\right)$

#### 8. 势能

**定义**：保守力做的功等于势能增量的负值（即势能的减少量）：

$$\int_{p_0}^p \vec{F}\cdot d\vec{r} = -(E_p - E_{p_0})$$

**由势能求保守力**（梯度关系）：

$$\vec{F} = -\nabla E_p = -\left(\frac{\partial E_p}{\partial x}\hat{i} + \frac{\partial E_p}{\partial y}\hat{j} + \frac{\partial E_p}{\partial z}\hat{k}\right)$$

**常见势能表达式**：

| 力 | 势能 | 零势能点 |
|----|------|----------|
| 重力 | $E_p = mgh$ | $h = 0$ |
| 弹力（弹簧） | $E_p = \dfrac{1}{2}kx^2$ | $x = 0$ |
| 万有引力 | $E_p = -\dfrac{GMm}{r}$ | $r = \infty$ |
| 库仑力 | $E_p = \dfrac{q_1q_2}{4\pi\varepsilon_0 r}$ | $r = \infty$ |

**注意**：
- 势能只有差值有物理意义，绝对值与零势能点的选取有关
- 势能差值与零势能点选取无关
- 保守力属于系统的内力，势能属于系统共有，不属于某个质点
- 保守力方向是沿着势能减小最快的方向

#### 9. 机械能守恒定律

**质点系功能原理**：质点系所受外力和非保守内力做功的代数和等于系统总机械能的增量：

$$A_{外} + A_{非保守内} = \Delta E_k + \Delta E_p = \Delta E_{机械}$$

**机械能守恒定律**：如果一个系统内只有保守内力做功，其他内力和一切外力都不做功，则系统内各物体的动能和势能可以互相转换，但机械能总值保持不变：

$$E_{k2} + E_{p2} = E_{k1} + E_{p1} = \text{常数}$$

**注意**：
- "只有保守内力做功"意味着：外力不做功 + 非保守内力不做功
- 机械能守恒与参考系有关（在某一惯性系中守恒，在另一惯性系中不一定守恒）
- 避免把保守内力做功 $A_{保}$ 与势能变化 $\Delta E_p$ 重复计算

#### 10. 质心系中的动能定理与功能原理

**柯尼希定理**：质点系的动能等于其轨道动能（质心动能）与内动能（相对质心动能）之和：

$$E_k = \frac{1}{2}mv_c^2 + E_k'$$

#### 碰撞类型拓展

| 类型 | 恢复系数 $e$ | 动能变化 | 特点 |
|------|-------------|----------|------|
| 完全弹性碰撞 | $e = 1$ | 守恒 | 理想情况 |
| 非完全弹性碰撞 | $0 < e < 1$ | 有损失 | 一般情况 |
| 完全非弹性碰撞 | $e = 0$ | 损失最大 | 碰后不分离，速度相同 |

$$e = \frac{v_{2f} - v_{1f}}{v_{1i} - v_{2i}} \qquad \text{（分离速度 / 接近速度）}$$

动量守恒在所有碰撞中成立；机械能守恒仅在完全弹性碰撞中成立。

### （二）题型归纳与解题技巧

#### 题型一：功的计算

**分析**：做功可以根据功的定义或动能定理、功能原理进行计算。
- 变力做功：先计算力作用于质点经元位移所做的元功，然后用积分法得到
- 保守力做功：只需考虑始末位置，用公式计算

#### 题型二：动能定理的应用

$$W = \Delta E_k = \frac{1}{2}mv_2^2 - \frac{1}{2}mv_1^2$$

#### 题型三：机械能守恒定律解决实际问题

**步骤**：
1. 列出哪些力是非保守力（如摩擦力）与外力，分别计算做功
2. 代入功能原理 $A_{外} + A_{非保守内} = \Delta E$
3. 若只有保守内力做功，直接用机械能守恒

## 四、角动量守恒定律

### （一）基本概念与公式

#### 1. 角动量（动量矩）

质点相对参考点 $O$ 的角动量：

$$\vec{L} = \vec{r}\times\vec{p} = \vec{r}\times m\vec{v}$$

**说明**：
- 角动量是矢量，单位：$kg·m²·s⁻¹$
- 角动量对不同参考点一般是不同的
- 大小：$|\vec{L}| = rp\sin\theta = r_\perp mv$（$r_\perp$ 为参考点 $O$ 到动量作用线的垂直距离）
- 方向：垂直于 $\vec{r}$ 和 $\vec{p}$ 所组成的平面，三者成右手螺旋关系

**直角坐标分量式**：

$$\vec{L} = (x\hat{i}+y\hat{j}+z\hat{k})\times(p_x\hat{i}+p_y\hat{j}+p_z\hat{k}) = \begin{vmatrix}\hat{i}&\hat{j}&\hat{k}\\x&y&z\\p_x&p_y&p_z\end{vmatrix}$$

$$L_z = m(xv_y - yv_x) = m\left(x\frac{dy}{dt} - y\frac{dx}{dt}\right)$$

**转动惯量与角动量（绕 $z$ 轴圆周运动）**：

$$L_z = mr^2\omega = J\omega$$

**质点系的角动量**：

$$\vec{L} = \sum_{i=1}^N\vec{L}_i = \sum_i\vec{r}_i\times\vec{p}_i$$

#### 2. 角动量守恒定律

若系统不受系统以外的物体的作用（或合外力矩为零），则系统的角动量保持不变：

$$\vec{L} = \sum\vec{L}_i = \text{恒矢量}$$

**守恒的几种可能情况**：
- 孤立系统
- 对某参考点只受有心力作用的物体（有心力对力心的力矩为零）
- 某轴方向合外力矩为零，则该轴方向角动量分量守恒

#### 3. 力矩

$$\vec{M} = \frac{d\vec{L}}{dt} = \vec{r}\times\vec{F}$$

大小：$|\vec{M}| = |\vec{r}\times\vec{F}| = rF\sin\theta = r_\perp F$（$r_\perp$ 为力臂，即 $O$ 到力作用线的垂直距离）

**说明**：
- 力矩的方向由右手螺旋定则由 $\vec{r}$ 和 $\vec{F}$ 确定
- 参考点不同，力矩不同
- 有心力对力心的力矩恒为零
- 作用力和反作用力的力矩大小相等、方向相反，一对力的力矩之和为零

#### 4. 角动量定理

**质点角动量定理**：作用在质点上的合力对任意固定点的力矩，等于质点对该点的角动量对时间的变化率：

$$\vec{M}_{合} = \frac{d\vec{L}}{dt}$$

微分形式：$\vec{M}_{合} = \dfrac{d\vec{L}}{dt}$

积分形式（角冲量定理）：$\displaystyle\int_{t_1}^{t_2}\vec{M}_{合}\,dt = \vec{L}_2 - \vec{L}_1$

**质点系角动量定理**：

$$\vec{M}_{外} = \frac{d\vec{L}}{dt}, \qquad \int_{t_1}^{t_2}\vec{M}_{外}\,dt = \sum\vec{L}_i - \sum\vec{L}_{i0}$$

**注意**：
- 角动量定理中，角动量和力矩都必须相对于同一参考点
- 力矩是单位时间内传递的角动量的量度，是引起角动量变化的原因
- 系统总角动量的变化与内力矩无关

#### 5. 角动量守恒的条件

对某一固定点，若系统所受外力矩的矢量和为零：

$$\vec{M}_{外} = \frac{d\vec{L}}{dt} = 0 \Rightarrow \vec{L} = \text{恒矢量}$$

**重要区别**：
- 合外力为零 $\nRightarrow$ 合外力矩为零
- 合外力矩为零 $\nRightarrow$ 合外力为零

#### 6. 开普勒定律

**第一定律（轨道定律）**：所有行星沿各自的椭圆轨道绕太阳运动，太阳位于椭圆的一个焦点上。

**第二定律（面积定律）**：对任一行星来说，它与太阳的连线在相等的时间内扫过相等的面积。

$$\frac{dS}{dt} = \frac{1}{2}r\cdot v\sin\theta \cdot \frac{1}{r} \cdot r = \frac{L}{2m} = \text{常数}$$

> 本质：角动量守恒（万有引力为有心力，对力心力矩为零）

**第三定律（周期定律）**：行星绕太阳运动周期的平方正比于其椭圆轨道长半轴的立方：

$$\frac{T^2}{a^3} = \frac{4\pi^2}{GM} = \text{常数}$$

### （二）题型归纳与解题技巧

#### 题型一：角动量与力矩的计算

- 角动量：$\vec{L} = \vec{r}\times m\vec{v}$；大小 $L = rp\sin\theta = r_\perp mv$
- 力矩：$|\vec{M}| = |\vec{r}\times\vec{F}| = r_\perp F$

**微元法计算连续体的力矩**：取质量微元 $dm$，计算 $d\vec{M} = \vec{r}\times d\vec{F}$，积分得总力矩。

#### 题型二：角动量守恒定律的应用

**解题技巧**：
1. 认定研究对象
2. 分析合外力矩是否为零
3. 注意角动量必须对某个固定点（或固定轴）转动

#### 题型三：角动量定理的应用

利用微分形式 $\vec{M} = \dfrac{d\vec{L}}{dt}$ 或积分形式 $\displaystyle\int_{t_1}^{t_2}\vec{M}\,dt = \vec{L}_2 - \vec{L}_1$ 解决问题。

## 五、刚体力学

### （一）基本概念与公式

#### 1. 刚体的运动

**刚体**：在外力作用下形状和大小都不变化的物体（组成物体的所有质点之间的距离始终保持不变）。刚体是理想模型，真正的刚体不存在。

**刚体的平动**：刚体内任意两点的连线，在运动过程中始终保持方向不变。各点运动状态相同，可用质点模型。

**刚体的转动**：刚体上所有的点都绕同一直线做圆周运动，这条直线叫做转轴。
- 定轴转动：转轴固定不动
- 定点转动：刚体绕通过某固定点的瞬时轴转动

**刚体的一般运动**：任何运动都可以分解为平动和转动的叠加（平动+转动的分解不是唯一的，与转轴位置的选择有关）。

#### 2. 刚体的定轴转动

定轴转动时，刚体中每一质元都做圆周运动，单位时间内转过的角位移都相同，角速度大小和方向也都相同。

$$\omega = \frac{d\theta}{dt}（方向沿着轴向，右手螺旋关系）\qquad \alpha = \frac{d\omega}{dt} = \frac{d^2\theta}{dt^2}$$

线量与角量的关系（质元距轴距离为 $r_i$）：

$$v_i = r_i\omega, \qquad a_{it} = r_i\frac{d\omega}{dt} = r_i\alpha, \qquad a_{in} = \frac{v_i^2}{r_i} = r_i\omega^2$$

#### 3. 刚体对定轴的角动量和转动惯量

**刚体对 $z$ 轴的转动惯量**：

$$J_z = \sum_i \Delta m_i r_i^2 = \int r^2\,dm \qquad \text{（单位：kg·m²）}$$

**刚体对 $z$ 轴的角动量**：

$$L_z = J_z\omega$$

**转动惯量的计算**：
- 当刚体由质元构成：$J_z = \sum \Delta m_i r_i^2$
- 当刚体质量连续分布：$J_z = \int r^2\,dm$

**说明**：
- 转动惯量决定于刚体质量及对轴的质量分布
- 同一刚体对不同轴的转动惯量一般不同
- 转动惯量是转动惯性大小的量度
- 刚体对某轴的转动惯量越大，刚体绕该轴转动的角速度就越难改变

**平行轴定理**：若刚体过质心的轴的转动惯量为 $J_c$，则刚体与该轴相距 $d$ 的平行轴 $z$ 的转动惯量为：

$$J_z = J_c + md^2$$

**转动惯量具有可叠加性**：组合体对某定轴的转动惯量等于各刚体对同一轴转动惯量之和。

**常见刚体的转动惯量（过质心的对称轴）**：

| 刚体 | 对称轴 | $J_c$ |
|------|--------|-------|
| 细棒（长 $L$，质量 $m$） | 过中点，垂直棒 | $\dfrac{1}{12}mL^2$ |
| 细棒 | 过端点，垂直棒 | $\dfrac{1}{3}mL^2$ |
| 均质圆盘（半径 $R$） | 中心轴 | $\dfrac{1}{2}mR^2$ |
| 均质球壳（半径 $R$） | 直径 | $\dfrac{2}{3}mR^2$ |
| 均质实心球（半径 $R$） | 直径 | $\dfrac{2}{5}mR^2$ |
| 均质圆环（半径 $R$） | 中心轴 | $mR^2$ |
| 均质圆柱（半径 $R$） | 轴线 | $\dfrac{1}{2}mR^2$ |

#### 4. 刚体定轴转动的角动量定理

$$M_z = \frac{dL_z}{dt} = \frac{d(J_z\omega)}{dt} = J_z\frac{d\omega}{dt} = J_z\alpha$$

积分：$\displaystyle\int_{t_0}^t M_z\,dt = J_z\omega - J_z\omega_0$

**刚体定轴转动定理**：刚体所受对某轴的外力矩之和，等于刚体对该轴的转动惯量与绕该轴角加速度的乘积：

$$M_z = J_z\alpha$$

这是刚体定轴转动的"牛顿第二定律"。类比关系：

| 平动 | 转动 |
|------|------|
| 力 $F$ | 力矩 $M$ |
| 质量 $m$ | 转动惯量 $J$ |
| 加速度 $a$ | 角加速度 $\alpha$ |
| 动量 $p = mv$ | 角动量 $L = J\omega$ |
| 动量定理 $F = dp/dt$ | 角动量定理 $M = dL/dt$ |

**刚体的角动量守恒定律**：若 $M_z = 0$，则 $J\omega = \text{恒量}$。

对定轴刚体：$J$ 不变，故 $\omega$ 不变。

对定轴非刚体：$J$ 可变化，$J\uparrow$ 则 $\omega\downarrow$，$J\downarrow$ 则 $\omega\uparrow$（如花样滑冰运动员收臂加速旋转）。

#### 5. 刚体定轴转动的功和能

**力矩的功**：刚体做定轴转动时，外力的功等于它对定轴力矩与角位移的乘积：

$$dA_t = M_z\,d\varphi$$

**刚体定轴转动的动能定理**：

$$A = \int M_z\,d\varphi = \frac{1}{2}J\omega^2 - \frac{1}{2}J\omega_0^2$$

**刚体转动动能**：

$$E_k = \frac{1}{2}J\omega^2 = \frac{1}{2}\sum\Delta m_i v_i^2$$

**刚体的重力势能**：$E_p = \sum\Delta m_i g h_i = mgh_c$（$h_c$ 为质心高度）

**刚体定轴转动的机械能守恒定律**：若刚体系统的运动过程中只有保守内力做功，则系统机械能守恒。

#### 6. 回转运动（进动）

**陀螺仪的进动**：高速旋转的陀螺，在外力矩（如重力矩）作用下，角动量矢量 $\vec{L}$ 绕外力矩方向旋转，称为进动（岁差运动）。

$$\vec{M} = \frac{d\vec{L}}{dt} \Rightarrow d\vec{L} = \vec{M}\,dt$$

$\vec{M}$ 方向与 $\vec{L}$ 方向垂直，只改变 $\vec{L}$ 的方向不改变其大小，产生进动。

#### 7. 刚体的平面平行运动

刚体的平面平行运动可看作质心平动加上刚体对通过质心且垂直于运动平面的定轴的转动：

$$E_k = \frac{1}{2}mv_c^2 + \frac{1}{2}J_c\omega^2$$

**纯滚动条件**（无滑动滚动）：接触点速度为零，满足：

$$v_c = R\omega$$

### （二）题型归纳与解题技巧

#### 题型一：计算刚体的转动惯量

**方法**：利用积分 $J = \int r^2\,dm$，或利用平行轴定理从已知结果推导。

**技巧**：注意 $r$ 是质元到**转轴**的距离，不是到某点的距离。

#### 题型二：刚体定轴转动相关定律的应用

应用 $M = J\alpha$（转动定律）、$\int M\,dt = \Delta(J\omega)$（角冲量定理）、$\int M\,d\varphi = \Delta(\frac{1}{2}J\omega^2)$（功能定理）。

## 六、流体力学简介

### （一）基本概念与公式

#### 1. 理想流体

流体力学研究流体的宏观运动规律，不涉及内部微观结构。

**流体**：具有流动性的连续介质，是气体和液体的总称（具有流动性，没有固定形状）。

**理想流体**：
- **不可压缩**：流体密度不变
- **无粘性**：流体内部无摩擦力，没有能量损耗

#### 2. 流量

- **流速场**：流速矢量的空间分布
- **定常流动**：流速的空间分布不随时间变化（稳定流动）
- **质量流量**：$\rho v\,dS$（单位时间通过某截面的流体质量）
- **体积流量**：$v\,dS$（单位时间通过某截面的流体体积）

#### 3. 流体的连续性原理

理想流体稳定流动时，通过流管截面上的（体积）流量相等：

$$v_1 S_1 = v_2 S_2 = \text{常数（体积流量守恒）}$$

> 截面积小处流速大；截面积大处流速小。

#### 4. 伯努利方程

惯性系中，理想流体在重力场中作定常流动时，一条流线（或流管）上某点的压强 $P$、流速 $v$ 和高度 $h$ 三个量之间的关系：

$$P + \frac{1}{2}\rho v^2 + \rho g h = \text{常数}$$

**三项物理意义**：

| 项 | 意义 |
|----|------|
| $P$ | 压强（压力势能密度） |
| $\dfrac{1}{2}\rho v^2$ | 动能密度（速度水头） |
| $\rho g h$ | 重力势能密度（高度水头） |

**重要推论**：
1. $v_1 = v_2 = 0$ 时，$p_2 + \rho g h_2 = p_1 + \rho g h_1$（静力学基本方程）
2. $p_1 = p_2$ 时，流速增大与高度减小成正比
3. $h_1 = h_2$ 时，$P + \dfrac{1}{2}\rho v^2 = \text{常数}$，流速大处压强小

**应用举例**：
- **文丘里管（流速计）**：细管处流速大，压强小；粗管处流速小，压强大
- **机翼升力**：上表面弧形，流速大，压强小；下表面平直，流速小，压强大；压差形成升力
- **虹吸管**：液体在管内负压（低于大气压）驱动下流动

### （二）题型：伯努利方程的应用

**解题步骤**：
1. 确定研究流线，选取两个已知量较多的截面
2. 利用连续性方程 $v_1S_1 = v_2S_2$ 建立速度关系
3. 代入伯努利方程 $P + \dfrac{1}{2}\rho v^2 + \rho gh = \text{常数}$ 求解

## 七、狭义相对论

### （一）基本概念与公式

#### 1. 伽利略时空变换

考虑两个相对平动的惯性参考系 $S$、$S'$：

$$\begin{cases}r = r' + ut\\ t = t'\end{cases}$$

速度变换：$\vec{v} = \vec{v}' + \vec{u}$，加速度变换：$a' = a$

**绝对时空观**：
- 时间的绝对性：时间的测量与参考系无关
- 空间的绝对性：在不同参考系中，测量同一物体长度相同

**伽利略相对性原理（力学相对性原理）**：所有惯性系对力学规律都是等价的，不可能通过一个惯性系内部的力学实验和观察来确定该惯性系做匀速运动的速度。

#### 2. 爱因斯坦的两个基本假设

**（1）相对性原理**：物理定律的表达式在所有惯性系中都是相同的，即所有惯性系对于一切物理规律的描述都是等价的。（比伽利略相对性原理更广泛，从力学推广到一切物理规律）

**（2）光速不变原理**：在所有惯性系中，观察者测得的光在真空中沿各方向传播的速度都等于恒定值 $c$，与观察者和光源的运动无关。

> 这两条假设看似矛盾（伽利略变换下光速会叠加），正是洛伦兹变换解决了这一矛盾。$c = 3\times10^8$ m/s。

#### 3. 洛伦兹变换

设 $S'$ 以速度 $u$ 相对 $S$ 沿 $x$ 轴正方向运动，$t = t' = 0$ 时两参考系重合，令：

$$\gamma = \frac{1}{\sqrt{1 - u^2/c^2}} \geq 1$$

**洛伦兹正变换**（$S \to S'$）：

$$\begin{cases}x' = \gamma(x - ut)\\ y' = y\\ z' = z\\ t' = \gamma\left(t - \dfrac{u}{c^2}x\right)\end{cases}$$

**洛伦兹逆变换**（$S' \to S$）：

$$\begin{cases}x = \gamma(x' + ut')\\ y = y'\\ z = z'\\ t = \gamma\left(t' + \dfrac{u}{c^2}x'\right)\end{cases}$$

#### 4. 相对论速度变换

对洛伦兹变换公式进行微分，得速度变换公式：

$$v_x' = \frac{v_x - u}{1 - v_xu/c^2}, \qquad v_y' = \frac{v_y/\gamma}{1 - v_xu/c^2}, \qquad v_z' = \frac{v_z/\gamma}{1 - v_xu/c^2}$$

**说明**：
1. 在质点速度 $v_x$ 平行于 $xx'$ 轴的特殊情况下，$v_x' = \dfrac{v_x - u}{1 - v_xu/c^2}$
2. 令 $v_x = c$，则 $v_x' = c$，正好验证了光速不变原理
3. 当 $v > c$ 时，必有 $v' > c$（不允许超光速）
4. 当 $u \ll c$ 时，退化为伽利略变换

#### 5. 相对论的时空观

**（1）同时的相对性**

在 $S'$ 系的异地同时事件，对 $S$ 系是不同时的事件：

$$\Delta t = t_1 - t_2 = \gamma\left(\Delta t' + \frac{u}{c^2}\Delta x'\right) \neq 0$$

- 异地同时的相对性是光速不变原理的直接结果
- $S'$ 系异地同时事件，对 $S$ 系是不同时的事件
- 当速度远小于光速时，两个惯性系结果相同

**（2）时间延缓（动钟变慢）**

原时（固有时）：在同一地点发生的两个事件之间的时间间隔，用 $\Delta t_0$（或 $\Delta\tau$）表示。

**时间延缓**：$S$ 系记录下的两个事件时间间隔大于 $S'$ 系记录到的固有时：

$$\Delta t = \gamma\Delta t_0 > \Delta t_0$$

- 运动时钟变慢是时间本身的客观特性
- 当 $v \ll c$ 时，$\gamma \approx 1$，$\Delta t \approx \Delta t_0$
- 原时最短（固有时是所有参考系中测得的最小时间间隔）

**（3）长度收缩（洛伦兹收缩）**

原长（固有长度）：物体相对某参考系静止时，两端的空间间隔，也称固有长度 $l_0$。

**长度收缩**：物体沿运动方向的长度比其固有长度短：

$$l = \frac{l_0}{\gamma} = l_0\sqrt{1 - u^2/c^2} < l_0$$

- 长度收缩只发生在运动方向，垂直运动方向的长度不变
- 原长最长（固有长度是所有参考系中测得的最大长度）

#### 6. 相对论动力学基础

**（1）相对论质量（动质量）**

$$m = \frac{m_0}{\sqrt{1 - v^2/c^2}} = \gamma m_0$$

$m_0$ 为物体静止时的质量（静止质量）。当 $v \to c$ 时，$m \to \infty$，说明不可能将有静止质量的物体加速到光速。

**（2）相对论动量**

$$\vec{p} = m\vec{v} = \frac{m_0\vec{v}}{\sqrt{1 - v^2/c^2}}$$

**（3）相对论能量（质能关系）**

$$E = mc^2 = \frac{m_0c^2}{\sqrt{1 - v^2/c^2}}$$

**静止能量**：$E_0 = m_0c^2$

**动能**：$E_k = E - E_0 = (\gamma - 1)m_0c^2$

- 当 $v \ll c$：$E_k \approx \dfrac{1}{2}m_0v^2$（回到经典结果）

**（4）相对论的动量-能量关系**

$$E^2 = p^2c^2 + m_0^2c^4$$

对于光子：$m_0 = 0$，故 $E = pc$，结合 $E = h\nu$，得 $p = h\nu/c = h/\lambda$。

### （二）题型归纳与解题技巧

#### 题型一：理论基础

- 狭义相对论的两个基本假设：相对性原理 + 光速不变原理
- 基本时空变换关系：洛伦兹变换
- 光速不变原理的内容：在所有惯性系中，观察者测得光在真空中沿各方向传播的速度都等于恒定值 $c$

#### 题型二：相对论中线量的计算

利用时间延缓和长度收缩公式，或直接用洛伦兹变换计算。

**关键**：
- 固有时（原时）= 同一参考系同一地点发生两事件的时间间隔（最短）
- 固有长度（原长）= 物体相对静止的参考系中测得的长度（最长）

#### 题型三：相对论动力学问题的计算

利用相对论质量 $m = \gamma m_0$，动量 $p = mv$，能量 $E = mc^2 = \gamma m_0c^2$，以及能量-动量关系 $E^2 = p^2c^2 + m_0^2c^4$。

## 重点公式速查表

### 运动学

$$\vec{v} = \frac{d\vec{r}}{dt}, \qquad \vec{a} = \frac{d\vec{v}}{dt} = \frac{d^2\vec{r}}{dt^2}$$

$$a_t = \frac{dv}{dt}, \qquad a_n = \frac{v^2}{\rho}, \qquad a = \sqrt{a_t^2 + a_n^2}$$

$$\omega = \frac{d\theta}{dt}, \qquad \alpha = \frac{d\omega}{dt}, \qquad v = R\omega, \qquad a_t = R\alpha, \qquad a_n = R\omega^2$$

$$\vec{v}_{绝} = \vec{v}_{相} + \vec{v}_{牵}$$

### 动量守恒

$$\vec{F} = \frac{d\vec{p}}{dt}, \qquad \vec{I} = \int_{t_1}^{t_2}\vec{F}\,dt = \Delta\vec{p}$$

$$\vec{p}_{系} = \sum m_i\vec{v}_i = \text{恒矢量}（合外力为零）$$

$$\vec{F}_{外} + \vec{u}\frac{dM}{dt} = M\frac{d\vec{v}}{dt}（变质量系统）$$

### 能量守恒

$$A = \int_a^b \vec{F}\cdot d\vec{r}, \qquad P = \vec{F}\cdot\vec{v}$$

$$A_{合} = \Delta E_k = \frac{1}{2}mv_2^2 - \frac{1}{2}mv_1^2（动能定理）$$

$$\vec{F} = -\nabla E_p（由势能求保守力）$$

$$A_{外} + A_{非保守内} = \Delta E_{机械}（功能原理）$$

$$E_k + E_p = \text{常数}（机械能守恒，仅保守内力做功）$$

$$E^2 = p^2c^2 + m_0^2c^4, \qquad e = \frac{v_{2f}-v_{1f}}{v_{1i}-v_{2i}}（恢复系数）$$

### 角动量守恒

$$\vec{L} = \vec{r}\times m\vec{v}, \qquad \vec{M} = \vec{r}\times\vec{F} = \frac{d\vec{L}}{dt}$$

$$\vec{L} = \text{恒矢量}（合外力矩为零）$$

$$\frac{dS}{dt} = \frac{L}{2m} = \text{常数}（开普勒第二定律）, \qquad \frac{T^2}{a^3} = \frac{4\pi^2}{GM}（开普勒第三定律）$$

### 刚体力学

$$J_z = \int r^2\,dm, \qquad J = J_c + md^2（平行轴定理）$$

$$M_z = J_z\alpha, \qquad L_z = J_z\omega$$

$$A = \int M_z\,d\varphi = \frac{1}{2}J\omega_2^2 - \frac{1}{2}J\omega_1^2$$

$$E_k = \frac{1}{2}mv_c^2 + \frac{1}{2}J_c\omega^2（平面平行运动）, \qquad v_c = R\omega（纯滚动）$$

### 流体力学

$$v_1S_1 = v_2S_2（连续性方程）$$

$$P + \frac{1}{2}\rho v^2 + \rho gh = \text{常数}（伯努利方程）$$

### 狭义相对论

$$\gamma = \frac{1}{\sqrt{1-u^2/c^2}}, \qquad \Delta t = \gamma\Delta t_0, \qquad l = \frac{l_0}{\gamma}$$

$$m = \gamma m_0, \qquad \vec{p} = m\vec{v} = \frac{m_0\vec{v}}{\sqrt{1-v^2/c^2}}$$

$$E = mc^2 = \gamma m_0c^2, \qquad E_k = (\gamma-1)m_0c^2, \qquad E^2 = p^2c^2 + m_0^2c^4$$

## 常见易错点总结

### 运动学

- **切向加速度为零 $\neq$ 加速度为零**：匀速圆周运动 $a_t = 0$，但 $a_n = v^2/R \neq 0$，总加速度指向圆心。
- **速率的导数 $\neq$ 速度矢量的模**：$\dfrac{d|\vec{r}|}{dt}$ 是位矢模的变化率，$|\vec{v}|$ 是速率，一般 $\dfrac{d|\vec{r}|}{dt} \neq |\vec{v}|$。
- **曲率半径求法**：先求 $a_t$，再用 $a_n = \sqrt{a^2-a_t^2}$，最后 $\rho = v^2/a_n$，不要直接套公式。

### 动量

- **动量守恒不要求无外力**：只要合外力为零即可，或某方向合外力为零则该方向动量守恒。
- **内力不改变系统总动量**：但可以改变各质点的动量分配。
- **冲量方向由 $\Delta\vec{p}$ 决定**：不一定与初速度方向相同。

### 能量

- **做功与势能不能双重计算同一种力**：重力做功 $A_重 = -\Delta E_p = -(mgh_2 - mgh_1)$，等价于势能变化的负值，二者不可叠加。
- **摩擦力做功必须积分**：不同段摩擦力大小可能不同（如变质量链条），不能简单套 $f\cdot s$。
- **内力可改变总动能**：爆炸中化学能转化为动能，总动能增大，但总动量不变。
- **动能定理与参考系选择无关**：虽然功和动能的数值与参考系有关，但两者的差（即动能定理方程）不依赖于参考系选择。

### 角动量

- **力矩和角动量必须对同一参考点计算**：不同参考点的力矩和角动量是不同的。
- **合外力为零 $\nRightarrow$ 合外力矩为零**（反之亦然）：力为零时力矩一定为零，但力矩为零时力不一定为零（如有心力）。
- **角动量守恒定律只适用于惯性系**。

### 刚体

- **转动惯量依赖于转轴位置**：同一刚体对不同轴的 $J$ 不同，必须明确转轴。
- **平行轴定理只能从质心轴推到其他平行轴**：不能在两个非质心轴之间直接应用。
- **纯滚动时接触点速度为零**：$v_c = R\omega$，接触点速度 $v_{接触} = v_c - R\omega = 0$（相对地面）。
- **刚体做功公式**：外力对定轴转动刚体做的功为 $A = \int M_z\,d\varphi$，不是 $F\cdot s$。

### 流体力学

- **伯努利方程只适用于同一流线**：不同流线上的两点不能直接使用伯努利方程。
- **伯努利方程只适用于理想流体（不可压缩、无粘性）定常流动**：实际流体有粘性损耗，需要修正。
- **连续性方程描述质量守恒**：$v_1S_1 = v_2S_2$ 只在密度不变（不可压缩流体）时成立。

### 相对论

- **时间延缓中固有时最短**：$\Delta t_0$ 是同一参考系同一地点发生两事件的时间间隔，其他参考系测得的时间 $\Delta t = \gamma\Delta t_0 > \Delta t_0$。
- **固有长度最长**：$l_0$ 是物体静止参考系中的长度，运动参考系中测得 $l = l_0/\gamma < l_0$。
- **$E = mc^2$ 中 $m$ 是相对论质量**：$E_0 = m_0c^2$ 才是静止能量；动能 $E_k = E - E_0 = (\gamma-1)m_0c^2$。
- **速度变换用相对论公式**：不能简单地把速度相加减，必须用 $v_x' = \dfrac{v_x - u}{1 - v_xu/c^2}$。
- **同时的相对性**：在一个参考系中同时发生的两个异地事件，在另一个参考系中通常不是同时的。

## 附录：三大守恒定律对比

| | 动量守恒 | 能量守恒 | 角动量守恒 |
|--|---------|---------|----------|
| **条件** | 合外力为零 | 只有保守内力做功 | 合外力矩为零 |
| **守恒量** | $\vec{p} = \sum m_i\vec{v}_i$ | $E = E_k + E_p$ | $\vec{L} = \sum\vec{r}_i\times m_i\vec{v}_i$ |
| **定理形式** | $\vec{F} = d\vec{p}/dt$ | $A_{合} = \Delta E_k$ | $\vec{M} = d\vec{L}/dt$ |
| **积分形式** | $\vec{I} = \Delta\vec{p}$ | $A = \Delta E_k$（动能定理） | $\int\vec{M}\,dt = \Delta\vec{L}$ |
| **矢/标量** | 矢量（三个分量可分别守恒） | 标量 | 矢量（三个分量可分别守恒） |
| **适用范围** | 惯性系 | 惯性系 | 惯性系 |

> **深刻理解**：三大守恒定律是物理学中最基本的规律，在量子力学、相对论等更深层理论中仍然成立。它们分别对应时空的平移对称性（动量守恒）、时间平移对称性（能量守恒）和旋转对称性（角动量守恒）——这是诺特定理（Noether's theorem）的核心内容。
