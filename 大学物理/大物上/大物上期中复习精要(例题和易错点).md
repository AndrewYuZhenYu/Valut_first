# 大学物理（上）期中复习精要

> 本文是在《大学物理上期中考试试题研究》基础上提炼的复习笔记。原则：**公式—题型识别—易错点**，核心例题只给关键思路。

---

## 速查：核心公式一览

| 章节 | 核心关系 |
|------|---------|
| 运动学 | $\vec{v}=\dfrac{d\vec{r}}{dt}$，$\vec{a}=\dfrac{d\vec{v}}{dt}$，$a_t=\dfrac{dv}{dt}$，$a_n=\dfrac{v^2}{\rho}$ |
| 动量 | $\vec{F}=\dfrac{d\vec{p}}{dt}$，$\vec{I}=\int\vec{F}dt=\Delta\vec{p}$ |
| 能量 | $A=\int\vec{F}\cdot d\vec{r}=\Delta E_k$，$\vec{F}_{\text{保}}=-\nabla E_p$ |
| 角动量 | $\vec{L}=\vec{r}\times m\vec{v}$，$\vec{M}=\vec{r}\times\vec{F}=\dfrac{d\vec{L}}{dt}$ |
| 刚体 | $J=\sum m_ir_i^2$，$M=J\beta$，$L=J\omega$，$E_k=\dfrac{1}{2}J\omega^2$ |
| 相对论 | $\gamma=\dfrac{1}{\sqrt{1-u^2/c^2}}$，$\Delta t=\gamma\Delta t_0$，$l=l_0/\gamma$ |

## 一、质点运动学

### 1.1 基本公式

**直角坐标系**：$\vec{r}=x\vec{i}+y\vec{j}+z\vec{k}$，速度、加速度分量对应求导。

**自然坐标系**（曲线运动核心）：
$$\vec{a}=\underbrace{\dfrac{dv}{dt}\vec{e}_t}_{\text{切向:改变速率}}+\underbrace{\dfrac{v^2}{\rho}\vec{e}_n}_{\text{法向:改变方向}}$$

曲率半径反求：$\rho=\dfrac{v^2}{a_n}=\dfrac{v^2}{\sqrt{a^2-a_t^2}}$

**圆周运动**（角量与线量）：$v=R\omega$，$a_t=R\alpha$，$a_n=R\omega^2$

**相对运动**：$\vec{v}_{\text{绝}}=\vec{v}_{\text{相}}+\vec{v}_{\text{牵}}$（画矢量三角形）

### 1.2 题型识别

| 已知 | 方法 | 核心 |
|------|------|------|
| $\vec{r}(t)$ 求 $\vec{v},\vec{a}$ | 求导 | 先分量再合成 |
| $a(t)$ 求 $v(t)$ | $\int adt$ | 定积分带初值 |
| $a(v)$ 求 $v(t)$ | 分离变量 $dt=\dfrac{dv}{a(v)}$ | — |
| $a(v)$ 求 $v(x)$ | $a=v\dfrac{dv}{dx}$ | $dx=\dfrac{vdv}{a(v)}$ |
| $a(x)$ 求 $v(x)$ | $a\,dx=v\,dv$ | 经典招式 |

**关键变换**：$\dfrac{dv}{dt}=v\dfrac{dv}{dx}$（遇到 $a(x)$ 或 $a(v)$ 求位置关系必用）

### 1.3 易错点

⚠️ $\dfrac{dr}{dt}\neq|\vec{v}|$。前者是位矢模长变化率，后者是速率 $\dfrac{ds}{dt}$。只在沿位矢直线运动时相等。

⚠️ 微元等式 $|d\vec{r}|=ds$ 成立，但 $dr\neq ds$。

⚠️ 位矢⊥速度 ⟺ $\vec{r}\cdot\vec{v}=0$（求"位矢与速度垂直的时刻"用这个）

⚠️ 切向加速度 $a_t=\dfrac{dv}{dt}$ 是**速率**求导，不是速度矢量模求导（虽然一维结果相同）。

### 1.4 关键例题

**例**：$x=3t,y=12-3t^2$，求 $t=1$ 时 $a_t,a_n,\rho$。
- 思路：$\vec{v}=(3,-6t)$，$v=\sqrt{9+36t^2}$
- $a_t=\dfrac{dv}{dt}=\dfrac{36t}{\sqrt{9+36t^2}}\bigg|_{t=1}=\dfrac{12\sqrt5}{5}$
- $\vec{a}=(0,-6)$，$a=6$；$a_n=\sqrt{a^2-a_t^2}=\dfrac{6\sqrt5}{5}$
- $\rho=v^2/a_n=\dfrac{15\sqrt5}{2}$

**例**（雨天不被淋湿）：车速 $v_1$，雨滴偏前 $\theta$、速率 $v_2$。条件：$v_1\geq v_2\left(\dfrac{l\cos\theta}{h}+\sin\theta\right)$
- 思路：作出 $\vec{v}_{\text{雨车}}=\vec{v}_2-\vec{v}_1$ 矢量图，要求其偏角 $\geq\arctan(l/h)$。

## 二、动量守恒定律

### 2.1 基本公式

**动量定理**：$\vec{I}=\int_{t_1}^{t_2}\vec{F}dt=\Delta\vec{p}$（分量式独立使用）

**动量守恒**：合外力为零时 $\vec{p}=\sum m_i\vec{v}_i=$ 恒矢量

**放宽条件**：
- 内力 ≫ 外力时（碰撞、爆炸瞬间）近似守恒
- 某方向合外力为零 → 该方向动量守恒

**变质量系统方程**：
$$\vec{F}_{\text{外}}+\vec{u}\dfrac{dM}{dt}=M\dfrac{d\vec{v}}{dt}$$
其中 $\vec{u}$ 是加入/排出质量相对主体的速度。

**质心**：$\vec{r}_c=\dfrac{\sum m_i\vec{r}_i}{\sum m_i}$；连续分布 $\vec{r}_c=\dfrac{1}{m}\int\vec{r}\,dm$

**质心运动定理**：$\vec{F}_{\text{外}}=M\vec{a}_c$（无论内力多复杂，质心只看外力）

**非惯性系**：附加惯性力 $\vec{F}_0=-m\vec{a}_0$（平动非惯性系）或离心力 $mr\omega^2$（转动）

### 2.2 题型识别

| 场景特征 | 用什么 |
|----------|--------|
| 短时碰撞/爆炸、求末速度 | 动量守恒 |
| 求平均冲力 | 动量定理 $\bar{F}=\Delta p/\Delta t$ |
| 变力作用、给出 $F(t)$ | 冲量 $I=\int F\,dt$ |
| 变力 $F(v)$、$F(x)$ | 牛二 + 分离变量 |
| 主体质量变化（火箭、雨滴） | 变质量方程 |
| 非惯性系（如三棱柱上滑块） | 加惯性力或用相对加速度 |
| 求质心位置 | 微元积分 |

### 2.3 易错点

⚠️ 求冲力时若用 $I=\bar{F}\Delta t$，切记 $\Delta \vec{p}$ 是**矢量差**，反弹问题要分正负。

⚠️ 动量守恒在碰撞瞬间成立（哪怕外力存在），因为冲力 ≫ 外力。

⚠️ 动量守恒**只适用于惯性系**。非惯性系里要加惯性力的冲量项。

⚠️ 两质点动量守恒不代表机械能守恒（可能有内能耗散）。

⚠️ 变质量问题中 $\vec{u}$ 的方向：吸附时 $u=-v$（相对物体向后），喷射时 $u=$ 喷射速度。

### 2.4 关键例题

**例（甲推乙做功范围）**：$m_1v_1-m_2v_2=m_1v_{\text{甲}}+m_2v_{\text{乙}}$，对乙 $W=\dfrac{1}{2}m_2(v_{\text{乙}}^2-v_2^2)$。
- $v_{\text{甲}}=v_{\text{乙}}$ 时 $W$ 最小（临界不相撞）；
- $v_{\text{甲}}=-v_{\text{乙}}$ 时 $W$ 最大（相当于完全弹性）。

**例（圆锥摆冲量）**：半周内 $\vec{I}_G=-mg(\pi R/v)\vec{k}$；由 $\vec{I}_G+\vec{I}_T=\Delta\vec{p}=-2mv\vec{j}$ 得 $\vec{I}_T=-2mv\vec{j}+mg(\pi R/v)\vec{k}$。关键是**选好坐标系 + 时间 $t=\pi R/v$**。

**例（雨滴增长）**：$F=mg$，$u=0$ 所以 $v_r=-v$。由 $mg=m\dfrac{dv}{dt}+v\dfrac{dm}{dt}$ 即 $d(mv)=mg\,dt$。
- 由 $dm/dt\propto r^2$、$m\propto r^3$ 得 $r=kt$；
- 积分得 $v=\dfrac{g}{4}t$，$a=\dfrac{g}{4}$。
- **核心洞见**：雨滴吸收静止水汽要"分配"动量，故加速度只有 $g/4$。

**例（三棱柱 + 滑块）**：非惯性系方法最快。
- 以三棱柱为参系，对小物块：$mg\sin\theta+ma_M\cos\theta=ma_{\text{相}}$
- 对三棱柱（地面系）：$N'\sin\theta=Ma_M$
- 法向约束：$mg\cos\theta=N'+ma_M\sin\theta$
- 解得 $a_M=\dfrac{mg\sin\theta\cos\theta}{M+m\sin^2\theta}$

### 2.5 常用质心速记

| 形状 | 质心位置 |
|------|---------|
| 半圆薄板（半径 $R$） | $y_c=\dfrac{4R}{3\pi}$ |
| 半圆弧（线） | $y_c=\dfrac{2R}{\pi}$ |
| 半球壳 | $\dfrac{R}{2}$ |
| 半球体 | $\dfrac{3R}{8}$ |
| 圆锥体（距顶点） | $\dfrac{3h}{4}$ |

## 三、能量守恒定律

### 3.1 基本公式

**功**：$A=\int_a^b\vec{F}\cdot d\vec{r}$；恒力 $A=\vec{F}\cdot\Delta\vec{r}$；功率 $P=\vec{F}\cdot\vec{v}$

**动能定理**：$A_{\text{合}}=\Delta E_k$（质点）；$A_{\text{外}}+A_{\text{内}}=\Delta E_k$（质点系）

**保守力与势能**：
$$A_{\text{保}}=-\Delta E_p,\quad \vec{F}_{\text{保}}=-\nabla E_p$$

| 势能 | 公式 | 零点 |
|------|------|------|
| 重力 | $mgh$ | 任选，通常地面 |
| 弹性 | $\dfrac{1}{2}kx^2$ | 自然长度 $x=0$ |
| 引力 | $-\dfrac{GMm}{r}$ | $r=\infty$ |
| 电势 | $\dfrac{q_1q_2}{4\pi\varepsilon_0 r}$ | $r=\infty$ |

**功能原理**：$A_{\text{外}}+A_{\text{非保内}}=\Delta E$（机械能增量）

**机械能守恒**：$A_{\text{外}}=0$ 且 $A_{\text{非保内}}=0$ → $E=E_k+E_p=$ 常量

**一对力做功**：$dA_{\text{对}}=\vec{F}_{AB}\cdot d\vec{r}_{BA}$（**与参考系无关**）
- 推论：刚体内力做功为零；静摩擦一对力总功为零；滑动摩擦一对力总功 $=-f\cdot|\Delta\vec{r}_{\text{相}}|<0$（变热）

**柯尼希定理**：$E_k=\dfrac{1}{2}mv_c^2+E_k'$（质心平动 + 对质心的动能）

**恢复系数**：$e=\dfrac{u_{\text{碰后相对}}}{u_{\text{碰前相对}}}$；$e=1$ 弹性，$e=0$ 完全非弹性

### 3.2 题型识别

| 场景 | 工具 |
|------|------|
| 变力做功（给 $F(x)$ 或向心变化） | 积分 $\int\vec{F}\cdot d\vec{r}$ |
| 保守力做功 | 只看始末位置 $-\Delta E_p$ |
| 有摩擦、非保守力 | 功能原理，或动能定理把摩擦当外力 |
| 光滑系统 + 保守力 | 机械能守恒 |
| 碰撞 | 动量守恒 +（弹性则加能量守恒） |
| 弹簧 + 圆周等复合问题 | 能量守恒 + 牛二（在关键点如最低点列向心） |

### 3.3 易错点

⚠️ "合外力为零"≠"合外力做功为零"。外力做功不为零时机械能可能不守恒。

⚠️ 选择参考系影响动能和功，但动能定理本身与参考系无关。机械能守恒**与参考系选取有关**。

⚠️ 把地球纳入系统才能引入重力势能；否则重力视为外力。

⚠️ 求保守力用 $F=-dE_p/dx$，要从势能表达式直接求导。

⚠️ 柔软链条下滑、链条下垂问题：受力分段积分（见关键例题）。

### 3.4 关键例题

**例（引力势能+动能）**：飞船从 $r_2$ 降到 $r_1$，动能增量 $\Delta E_k=GMm\dfrac{r_2-r_1}{r_1r_2}$。
- 思路：$\Delta E_k=-\Delta E_p=GMm(1/r_1-1/r_2)$

**例（弹簧-圆环-重力综合）**：弹簧原长 $=R$，小环从 B 沿圆环滑到 C（夹角 60°）。
- 弹性：$A_F=-\dfrac{1}{2}k(2R-R)^2=-\dfrac{1}{2}kR^2$
- 重力：$A_P=mg(R+R\cos 60°)=\dfrac{3}{2}mgR$
- 动能定理：$A_F+A_P=\dfrac{1}{2}mv_C^2$ → $v_C=\sqrt{(3mgR-kR^2)/m}$
- C 点列牛二：$N-mg+k(2R-R)=\dfrac{mv_C^2}{R}$ → $N=4mg-2kR$

**例（链条下滑）**：长 $l$，摩擦因数 $\mu$，水平段脱离前受力平衡确定初始下垂长 $x_0=\mu l/(1+\mu)$。
- 重力功：$A_P=\int_{x_0}^l\dfrac{m}{l}xg\,dx=\dfrac{mg(l^2-x_0^2)}{2l}$
- 摩擦功：$A_f=-\int_{x_0}^l\mu\dfrac{m}{l}(l-x)g\,dx=-\dfrac{\mu mg(l-x_0)^2}{2l}$
- 动能定理：$v=\sqrt{gl/(1+\mu)}$

**例（动量 + 机械能 + 相对速度综合）**：光滑桌面上半圆槽 $M$，小物块 $m$ 从槽顶 a 滑到底 b。
- 水平动量守恒（槽+物块）：$mv_m=Mv_M$，积分得 $x_M=\dfrac{m}{M+m}R$
- 机械能守恒：$mgR=\dfrac{1}{2}mv_m^2+\dfrac{1}{2}Mv_M^2$
- 求物块在 b 点对槽的压力：以 $M$ 为非惯性系？**更简单的方法**：用相对速度 $v_{\text{相}}=v_m+v_M$，$v_{\text{相}}^2=\dfrac{2gR(M+m)}{M}$，然后在槽系中列向心力：$N-mg=mv_{\text{相}}^2/R$ → $N=\dfrac{mg(3M+2m)}{M}$

**辨析题要点**：
- "合外力为零" ≠ "机械能守恒"（反例：摩擦内能）
- "只有内力" ≠ "机械能守恒"（非保守内力）
- "合外力为零 + 只有保守内力" = 机械能守恒 ✓

## 四、角动量守恒定律

### 4.1 基本公式

**角动量**（对某点）：$\vec{L}=\vec{r}\times m\vec{v}$，大小 $L=rmv\sin\theta=mvd$（$d$ 为 $O$ 到速度线距离）

**对定轴**：$L_z=m(xv_y-yv_x)=mr^2\omega=J\omega$（对轴用转动惯量表达最省事）

**力矩**：$\vec{M}=\vec{r}\times\vec{F}$，大小 $M=r_\perp F$

**角动量定理**：$\vec{M}=\dfrac{d\vec{L}}{dt}$，积分 $\int\vec{M}dt=\Delta\vec{L}$

**角动量守恒**：合外力矩为零 → $\vec{L}=$ 恒矢量
- 有心力对力心角动量守恒
- 对某轴外力矩之和为零 → 对该轴角动量守恒（分量守恒）

**开普勒第二定律**：$\dfrac{dS}{dt}=\dfrac{L}{2m}=$ 常量（角动量守恒的几何表达）

### 4.2 题型识别

| 场景 | 方法 |
|------|------|
| 求对某点/某轴的角动量 | 定义 $\vec{r}\times m\vec{v}$ 或 $L=mvd$ |
| 有心力/绕中心转动半径变化 | 对中心角动量守恒 |
| 弹簧-绳约束运动变半径 | 动量守恒 +（分情况）角动量守恒 + 能量守恒 |
| 桌面小孔拉绳缩半径问题 | 角动量守恒（有心力，对小孔） + 动能定理求拉力功 |
| 求摩擦力矩（盘、棒） | 微元 $dM=\mu g r\,dm$ 积分 |

### 4.3 易错点

⚠️ 角动量必须指定**参考点**或**参考轴**。换点换轴结果可能不同。

⚠️ "合外力为零" ≠ "合外力矩为零"；反之亦然。

⚠️ 匀速直线运动的质点对非轨迹上任一点的角动量**守恒**（力矩为零）。

⚠️ 做变半径圆周运动时，若拉力沿径向（有心力），则对中心角动量守恒，但**动能不守恒**（拉力做功）。

⚠️ 计算 $L=mvd$ 时 $d$ 是 $O$ 到**速度线**的垂直距离，不是到质点的距离。

### 4.4 关键例题

**例（桌面小孔拉绳）**：绳另一端穿过小孔下拉，半径由 $r_0\to r$。
- 有心力（对小孔）：角动量守恒 → $v=v_0r_0/r$
- 拉力功（动能定理）：$W=\dfrac{1}{2}mv_0^2[(r_0/r)^2-1]$

**例（弹簧+子弹+碰撞综合）**：子弹射入木块→沿弹簧运动
- 碰撞瞬间：动量守恒 $mv_0=(m+M)v_1$
- 从 a 到 b：机械能守恒（弹簧拉长）
- 角动量守恒（对 O 点，弹簧力过 O）→ $(M+m)l_0v_1=(M+m)lv_2\sin\theta$

**例（两滑冰者手拉手）**：质心位置由 $m_Al_A=m_Bl_B$ 定，手拉手前后角动量守恒：
$$\omega=\dfrac{m_Av_Al_A+m_Bv_Bl_B}{m_Al_A^2+m_Bl_B^2}$$

**例（圆盘摩擦力矩）**：取半径 $r$、宽 $dr$ 圆环 $dm=\dfrac{2m}{R^2}r\,dr$
- $dM=\mu gr\,dm$，积分得 $M=\dfrac{2}{3}\mu mgR$

## 五、刚体力学

### 5.1 基本公式

**定轴转动基本对应**（质点 ↔ 刚体）：

| 质点 | 刚体定轴转动 |
|------|-------------|
| $m$ | $J=\sum m_ir_i^2=\int r^2\,dm$ |
| $\vec{p}=m\vec{v}$ | $L=J\omega$ |
| $\vec{F}=m\vec{a}$ | $M=J\beta$ |
| $E_k=\dfrac{1}{2}mv^2$ | $E_k=\dfrac{1}{2}J\omega^2$ |
| $A=\int\vec{F}\cdot d\vec{r}$ | $A=\int M\,d\varphi$ |
| 动能定理 | $A=\dfrac{1}{2}J\omega^2-\dfrac{1}{2}J\omega_0^2$ |

**平行轴定理**：$J_z=J_c+md^2$

**可叠加性**：$J=\sum J_i$（组合体）

**常用转动惯量速记**：

| 形状（质量 $m$） | 转轴 | $J$ |
|------------------|------|-----|
| 细棒（长 $l$） | 过中点⊥ | $\dfrac{1}{12}ml^2$ |
| 细棒 | 过端点⊥ | $\dfrac{1}{3}ml^2$ |
| 圆环（半径 $R$） | 中心轴 | $mR^2$ |
| 圆盘 | 中心轴 | $\dfrac{1}{2}mR^2$ |
| 圆盘 | 直径 | $\dfrac{1}{4}mR^2$ |
| 实心球 | 直径 | $\dfrac{2}{5}mR^2$ |
| 球壳 | 直径 | $\dfrac{2}{3}mR^2$ |

**平面平行运动**（如滚动）：$E_k=\dfrac{1}{2}mv_c^2+\dfrac{1}{2}J_c\omega^2$
- 纯滚动条件：$v_c=R\omega$
- 纯滚动圆盘总动能：$\dfrac{3}{4}mv_c^2$

### 5.2 题型识别

| 场景 | 方法 |
|------|------|
| 求 $J$（不规则形状） | 微元积分 / 叠加法 / 挖空用减法 |
| 求 $J$（不过质心轴） | 平行轴定理 |
| 已知外力矩求角加速度 | $M=J\beta$ |
| 碰撞（含棒、盘） | 角动量守恒（绝大多数情况） |
| 能量问题（转动 + 平动） | 机械能守恒 / 动能定理 |
| 滑轮 + 绳 + 物体 | 滑轮角动量定理 or 整体能量法 |
| 人-盘角动量问题 | 系统对轴角动量守恒（注意 $v_{\text{人对地}}$） |
| 滚动 + 摩擦 | 质心定理 + 绕质心轴转动定律 |

### 5.3 易错点

⚠️ **碰撞瞬间**重力对轴的冲量矩可忽略（极短时间），轴的支持力过轴心不产生力矩，故**对轴角动量守恒**；但**系统水平动量不守恒**（轴有水平反作用力）。

⚠️ 子弹嵌入棒后的总 $J$ 要**分别相加**：$J_{\text{棒}}+J_{\text{弹}}$。

⚠️ 转动惯量"挖空"：整体 $J$ 减去挖掉部分对**同一轴**的 $J$（用平行轴定理换算）。

⚠️ 滑轮不是质点！绳过滑轮时张力两边不等，除非滑轮无质量。

⚠️ 纯滚动不做功（接触点无相对位移），但滑动摩擦会。

⚠️ "人在转台上走"：设人对地速度 $v$，则 $v=u+r\omega$（$u$ 为人对台速度，$\omega$ 台角速度）。

### 5.4 关键例题

**例（带孔圆盘 $J$）**：挖两孔，用减法 + 平行轴定理
- 完整盘 $I_0=\dfrac{1}{2}\pi\sigma R^4$
- 每小盘对大盘中心：$I_{10}=\dfrac{1}{162}\pi\sigma R^4+m'(R/2)^2=\dfrac{11}{324}\pi\sigma R^4$
- 结果：$I=I_0-2I_{10}=\dfrac{35}{81}\pi\sigma R^4$

**例（子弹击中悬挂棒中点）**：
1. 角动量守恒：$mv_0(L/2)=\left(\dfrac{1}{3}M+\dfrac{1}{4}m\right)L^2\omega$ → $\omega=\dfrac{6mv_0}{(4M+3m)L}$
2. 求轴水平冲量：碰后 $P_2=(M+m)\omega(L/2)$，由 $I_x=P_2-mv_0=-\dfrac{Mmv_0}{4M+3m}$（向左）

**例（棒上套环脱出）**：光滑棒绕端 O 转，套环从 O 出发
- 机械能守恒：$\dfrac{1}{2}J\omega_0^2=\dfrac{1}{2}J\omega^2+\dfrac{1}{2}mv^2$
- 角动量守恒：$J\omega_0=J\omega+mvL\sin\theta$
- 几何：$v\sin\theta=\omega L$（环离开时的切向速度关系）
- 解得 $\omega=\dfrac{M}{M+3m}\omega_0$

**例（滑轮+爬绳人+重物）**：外力矩（对轴）$M=mgR-\dfrac{1}{2}mgR=\dfrac{1}{2}mgR$（只算外力产生的力矩，绳对滑轮张力相互抵消）
- 角动量 $L=\dfrac{m}{2}vR-m(u-v)R+I\omega$，$I=\dfrac{1}{8}mR^2$，$\omega=v/R$
- 得 $L=\dfrac{13}{8}mRv-mRu$
- 由 $M=dL/dt$ → $a=\dfrac{4}{13}g$

**例（圆柱斜面上滚）**：$\mu>\dfrac{1}{3}\tan\theta$ 时最终纯滚动
- 对质心轴：$\mu mg\cos\theta\cdot R=\dfrac{1}{2}mR^2\alpha$ → $\omega=\dfrac{2\mu g\cos\theta\cdot t}{R}$
- 平动：$v_c=v_0-(\mu\cos\theta+\sin\theta)gt$
- 纯滚条件 $v_c=R\omega$ 联立得 $t=\dfrac{v_0}{(3\mu\cos\theta+\sin\theta)g}$

## 六、流体力学（简介）

### 6.1 核心

**理想流体**：不可压缩 + 无粘性

**连续性方程**：$vS=$ 常量（细处流速快）

**伯努利方程**（一条流线上）：
$$p+\dfrac{1}{2}\rho v^2+\rho gh=\text{const}$$

三项对应：压强能 + 动能 + 势能（单位体积）

### 6.2 典型应用

- 同高度：流速大 → 压强小（机翼升力、喷雾器）
- 静止：$p_1+\rho gh_1=p_2+\rho gh_2$
- 水箱小孔出流：$v=\sqrt{2gh}$（托里拆利定律）

### 6.3 易错点

⚠️ 伯努利方程要求**同一条流线**。不同流管要小心。

⚠️ 粗细均匀管内流速处处相等（由连续性）。

⚠️ 虹吸管内最高点压强最小（可能低于大气压甚至小于饱和蒸气压 → 汽化断流）。

## 七、狭义相对论

### 7.1 基本公式

**基本假设**：① 相对性原理  ② 光速不变

**洛伦兹变换**（$S'$ 相对 $S$ 以 $u$ 沿 $x$ 正向）：
$$x'=\gamma(x-ut),\quad t'=\gamma\left(t-\dfrac{u}{c^2}x\right)$$
其中 $\gamma=\dfrac{1}{\sqrt{1-u^2/c^2}}\geq 1$

**速度变换**：
$$v_x'=\dfrac{v_x-u}{1-uv_x/c^2}$$

**时空效应**（要分清"原"的系）：

| 效应 | 公式 | 关键 |
|------|------|------|
| 时间延缓 | $\Delta t=\gamma\Delta t_0$ | 原时 $\Delta t_0$ 在**同地发生**的系最短 |
| 长度收缩 | $l=l_0/\gamma$ | 原长 $l_0$ 在**相对静止**系最长，**沿运动方向**收缩 |
| 同时的相对性 | $\Delta t'=\gamma(\Delta t-u\Delta x/c^2)$ | 异地同时事件在另一系非同时 |

**相对论动力学**：
$$m=\gamma m_0,\quad \vec{p}=\gamma m_0\vec{v},\quad E=mc^2=\gamma m_0c^2$$
$$E_k=(\gamma-1)m_0c^2,\quad E^2=p^2c^2+m_0^2c^4$$

### 7.2 题型识别

| 场景 | 方法 |
|------|------|
| 长度测量 | 分清原长在哪个系，运动方向上才收缩 |
| 时间间隔 | 分清原时（同地两事件）在哪个系 |
| 不同系两事件时空坐标 | 洛伦兹变换公式 |
| 速度合成 | 相对论速度变换（不要用伽利略） |
| 动能 / 总能 | $E_k=(\gamma-1)m_0c^2$，不要用 $\dfrac{1}{2}mv^2$ |
| 粒子衰变 | 动量 + 能量双守恒，配合 $E^2=p^2c^2+m_0^2c^4$ |

### 7.3 易错点

⚠️ "原时"（固有时）是同一地点两事件的时间间隔；"原长"是**相对静止**观察者测的长度。**"原"的系看到的最短时间、最长长度**。

⚠️ 垂直于运动方向的长度不收缩。

⚠️ 同时的相对性有方向性：在 $S'$ 中**沿运动方向前方**发生的事件在 $S$ 中**晚**发生（若 $S'$ 相对 $S$ 正向运动）。

⚠️ 动能不能用 $\dfrac{1}{2}mv^2$！必须用 $E_k=(\gamma-1)m_0c^2$，低速极限才还原经典。

⚠️ 若两事件在一个系**同地**发生，则另一系中它们的**空间距离** $=u\Delta t'$（同地在新系中当然不同地）。

### 7.4 关键例题

**例（飞船上发射子弹，地面观察时间）**：飞船相对地 0.6c，船上测子弹相对船 0.8c、飞行 60 m。
- 船上：$\Delta x'=60$，$\Delta t'=60/(0.8c)=2.5\times 10^{-7}$ s
- 地面：$\Delta t=\gamma(\Delta t'+u\Delta x'/c^2)=4.625\times 10^{-7}$ s

**例（μ 子寿命）**：$v=0.9c$，原时 $2\times 10^{-6}$ s
- 地面测寿命：$\Delta t=\gamma\Delta t_0=4.59\times 10^{-6}$ s
- 飞行距离：$h=v\Delta t=1.24\times 10^3$ m

**例（倾斜米尺的收缩）**：原长 $l_0$、与 $x$ 轴 30°，$u=0.8c$ 沿 $x$ 方向
- 平行分量 $l_0\cos\theta'$ 收缩为 $l_0\cos\theta'\sqrt{1-u^2/c^2}$；
- 垂直分量 $l_0\sin\theta'$ 不变；
- 新长度：$l=l_0\sqrt{1-\dfrac{u^2}{c^2}\cos^2\theta'}$；新方向角 $\tan\theta=\dfrac{\tan\theta'}{\sqrt{1-u^2/c^2}}$

**例（粒子衰变）**：静止 $M_0$ 衰变为 $m_{10},m_{20}$
- 动量守恒：$p_1=-p_2$
- 能量守恒：$E_1+E_2=M_0c^2$
- 结合 $E^2=p^2c^2+m_0^2c^4$ 解得：$E_1=\dfrac{(M_0^2+m_{10}^2-m_{20}^2)c^2}{2M_0}$

**例（同地两事件相对速度）**：$S$ 中同地两事件间隔 4s，$S'$ 中 5s
- 由 $\Delta t=\gamma\Delta t_0$：$\gamma=5/4$ → $u=3c/5$
- $S'$ 中空间距离：$\Delta x'=u\Delta t'=9\times 10^8$ m

## 附录：复习策略建议

### 按题型归类的考点热度（基于本资料）

**高频**：
- 变力运动（$a=a(x)$ 或 $a(v)$ → $v$ 关系）
- 碰撞 + 弹簧 / 圆周运动综合
- 刚体碰撞（子弹射棒）角动量守恒
- 相对论时间膨胀 / 长度收缩场景识别

**中频**：
- 变质量问题（火箭、雨滴、链条）
- 非惯性系（三棱柱滑块）
- 带孔刚体转动惯量
- 洛伦兹变换具体计算

**低频**（但易粗心丢分）：
- 伯努利方程
- 一对力做功与参考系无关的定性题
- 动量守恒与机械能守恒的辨析题

### 答题顺序建议

1. **先扫一遍**所有题，标出必做题（会做）和攻坚题（难）
2. **填空/选择**：15 分钟内速战速决，留痕检查
3. **计算题**：按"画受力图/物理图像 → 写守恒律或定理 → 代数求解"三步走
4. **辨析题**：看清"全部正确"还是"不正确"的选项

| 章节 | 必练题型 |

| 运动学 | 给 $a(x)$ 或 $a(v)$ 求 $v$ |
