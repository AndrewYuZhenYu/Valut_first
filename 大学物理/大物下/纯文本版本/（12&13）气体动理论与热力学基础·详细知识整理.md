# 第一部分 气体动理论（微观统计理论）

## 1. 平衡态与状态参量

### 1.1 热力学系统

热学的研究对象，由大量做热运动的分子构成的宏观物质体系。与系统相互作用的环境称为**外界**。系统与外界之间可进行能量交换和物质交换。

**系统的分类**（按交换情况）：
- 孤立系统：与外界既无能量交换，也无物质交换；
- 封闭系统：与外界有能量交换，无物质交换；
- 开放系统：与外界既有能量交换，也有物质交换。

### 1.2 平衡态

在与外界没有能量和物质交换的条件下，经过足够长时间后，系统宏观性质不随时间变化的状态。

**特征**：
- 系统内没有宏观粒子流动和能量流动；
- 系统达到平衡态之前的过程称为非平衡态；
- 平衡态是热动平衡：分子仍在运动，但宏观统计平均效果不变。

**注意**：平衡态是一种理想状态。实际中不存在完全不受外界影响、宏观性质绝对不变的系统，但许多问题中可近似当作平衡态处理。

### 1.3 稳恒态

宏观性质不随时间变化，但与外界存在能量或物质交换的状态。

**平衡态与稳恒态的区别**：

| | 平衡态 | 稳恒态 |
|---|---|---|
| 宏观性质 | 不随时间变化 | 不随时间变化 |
| 与外界交换 | 无能量、无物质交换 | 有能量或物质交换 |
| 举例 | 孤立容器中的气体 | 稳定传热中的金属棒 |

### 1.4 状态参量

平衡态下描述系统宏观状态的物理量，具有确定值。常见分类：
- 几何参量：如体积 $V$；
- 力学参量：如压强 $p$；
- 化学参量：如各成分的摩尔数 $\nu$。

### 1.5 准静态过程

状态变化过程进行得足够缓慢，可以认为系统经历的每一中间状态都无限接近于平衡态。

在状态参量构成的坐标空间中：
- 一个状态 ↔ 一个点；
- 一个准静态过程 ↔ 一条曲线。

**判断标准**：过程进行的时间远大于系统恢复平衡的弛豫时间。

**注意**：准静态过程是理想过程，实际过程只能近似看作准静态。无摩擦的准静态过程是可逆过程。

## 2. 温度与热力学第零定律

### 2.1 热力学第零定律

如果 $A$ 和 $B$ 分别与 $C$ 处于热平衡，则 $A$ 和 $B$ 也彼此处于热平衡。

**意义**：温度是表征系统热平衡状态的宏观物理量，处于热平衡的系统具有共同的温度。第零定律为温度概念提供了实验基础。

### 2.2 温标

温度的数值表示法。常见温标：

**经验温标**：以某种物质的某种随温度变化的特性确定。三要素：
1. 测温物质的测温属性；
2. 选定固定点；
3. 规定测温属性随温度的变化关系。

例如摄氏温标：$0^\circ\text{C}$ 为冰点（1 atm，纯冰和纯水混合物），$100^\circ\text{C}$ 为沸点（1 atm，纯水和水蒸气混合物），等分 100 格，线性。

**热力学温标**：与测温物质无关，用玻尔兹曼常量 $k$ 定义，单位开尔文（K）。

$$T/\text{K} = t/^\circ\text{C} + 273.15$$

**注意**：热力学温标是唯一不依赖测温物质的温标，是国际单位制中的基本温标。

## 3. 理想气体物态方程

### 3.1 实验定律

- 玻意耳定律：$p_0V_0 = pV$（等温）；
- 查理定律：$\frac{T}{p} = \frac{T_0}{p_0}$（等容）；
- 盖-吕萨克定律：$\frac{T}{V} = \frac{T_0}{V_0}$（等压）。

严格服从三个实验定律的气体称为**理想气体**。

**适用条件**：压强不太大（与大气压相比）、温度不太低（与室温相比）。

### 3.2 基本常量

- 阿伏伽德罗常量：$N_A = 6.022\times10^{23}\ \text{mol}^{-1}$；
- 摩尔气体常量：$R = 8.31\ \text{J}\cdot\text{mol}^{-1}\cdot\text{K}^{-1}$；
- 玻尔兹曼常量：$k = \frac{R}{N_A} = 1.38\times10^{-23}\ \text{J}\cdot\text{K}^{-1}$。

物质的量与分子数关系：

$$\nu = \frac{m}{M} = \frac{N}{N_A}$$

### 3.3 物态方程

$$pV = \nu RT = \frac{m}{M}RT$$

$$p = nkT,\qquad n = \frac{N}{V}$$

其中 $n$ 为分子数密度。

**推导思路**：从 $(p_0,V_0,T_0)$ 经等容到 $(p',V_0,T)$，再经等温到 $(p,V,T)$，消去 $p'$ 得 $\frac{pV}{T} = \frac{p_0V_0}{T_0}$。由阿伏伽德罗定律，标准条件下 $V_0 = \nu V_m$，得 $R = \frac{p_0V_m}{T_0}$。

**说明**：$pV = \nu RT$ 是理想气体的基本方程，$p = nkT$ 是其微观形式，两者在解题中常配合使用。

### 3.4 应用例题

**例**：容器内装有 $0.1\ \text{kg}$ 氧气，压强 $1.0\times10^6\ \text{Pa}$，温度 $47^\circ\text{C}$。漏气后压强降到原来的 $5/8$，温度降到 $27^\circ\text{C}$。求容器容积和漏气质量。

**解**：

(1) 由 $pV = \frac{m}{M}RT$：

$$V = \frac{mRT}{pM} = \frac{0.10\times8.31\times(273+47)}{1.0\times10^6\times0.032} = 8.31\times10^{-3}\ \text{m}^3$$

(2) 漏气后质量：

$$m' = \frac{Mp'V}{RT'} = \frac{0.032\times\frac{5}{8}\times10^6\times8.31\times10^{-3}}{8.31\times(273+27)} = 6.67\times10^{-2}\ \text{kg}$$

漏气质量：$\Delta m = m - m' = 0.0333\ \text{kg}$。

**关键**：容器容积不变，漏气前后分别用物态方程求质量。

## 4. 理想气体的微观模型与统计假设

### 4.1 微观模型

1. 分子的大小可以忽略（分子线度远小于分子间平均距离）；
2. 除碰撞瞬间外，分子间作用力可忽略；
3. 分子间及与器壁的碰撞视为完全弹性碰撞；
4. 分子服从经典运动规律。

### 4.2 平衡态统计假设

1. 分子空间分布均匀：$n = \frac{dN}{dV} = \frac{N}{V}$ 处处相等；
2. 频繁碰撞，沿各方向运动概率相同：

$$\overline{v}_x = \overline{v}_y = \overline{v}_z = 0$$

$$\overline{v}_x^2 = \overline{v}_y^2 = \overline{v}_z^2 = \frac{1}{3}\overline{v^2}$$

**注意**：这些是对大量分子的统计平均结果，对单个分子无意义。

## 5. 理想气体的压强与温度

### 5.1 压强公式的推导

**模型**：边长为 $l_x,l_y,l_z$ 的立方容器，分子数 $N$，分子质量 $m_0$。

**单个分子与右壁碰撞**：
- 碰撞前 $x$ 方向动量 $m_0v_{ix}$，碰撞后 $-m_0v_{ix}$；
- 对器壁的冲量：$I = 2m_0v_{ix}$。

**$dt$ 时间内能与 $dS$ 面相碰的分子数**：
$$v_{ix}dt\,dS\cdot\frac{\Delta N_i}{V}$$

**所有速度为 $v_i$ 的分子对 $dS$ 面的平均冲力**：
$$F_i = \frac{2m_0\cdot\Delta N_i v_{ix}^2 dS}{V}$$

**对所有 $v_{ix}>0$ 的分子求和**：
$$F = \sum_{v_i>0}F_i = \frac{1}{2}\sum_i F_i = m_0n\overline{v_x^2}dS$$

**压强**：
$$p = \frac{F}{dS} = nm_0\overline{v_x^2} = \frac{1}{3}nm_0\overline{v^2}$$

**引入平均平动动能** $\overline{\varepsilon}_k = \frac{1}{2}m_0\overline{v^2}$：

$$p = \frac{2}{3}n\overline{\varepsilon}_k$$

**微观本质**：压强是大量分子连续不断碰撞器壁形成的平均效果，是统计平均量。对个别分子谈压强毫无意义。

### 5.2 温度的微观解释

由 $p = nkT$ 与 $p = \frac{2}{3}n\overline{\varepsilon}_k$ 得：

$$\overline{\varepsilon}_k = \frac{3}{2}kT$$

**意义**：
- 理想气体分子平均平动动能只与温度有关；
- 温度是分子热运动剧烈程度的标志；
- 温度是大量分子热运动的集体表现，具有统计意义，对单个或少量分子无意义。

**注意**：$\overline{\varepsilon}_k$ 是分子做热运动的平均平动动能，不包括全体分子做整体定向运动的动能。

### 5.3 方均根速率

$$\sqrt{\overline{v^2}} = \sqrt{\frac{3kT}{m_0}} = \sqrt{\frac{3RT}{M}}$$

**应用**：可用于计算分子平均动能。

**例**：标准状态下空气密度 $\rho=1.29\ \text{kg/m}^3$，求方均根速率。

**解**：$\rho = nm_0$，

$$\sqrt{\overline{v^2}} = \sqrt{\frac{3kT}{m_0}} = \sqrt{\frac{3nkT}{nm_0}} = \sqrt{\frac{3p}{\rho}} = \sqrt{\frac{3\times1.01\times10^5}{1.29}} = 485\ \text{m/s}$$

### 5.4 道尔顿分压定律

混合气体压强等于各成分气体分压强之和：

$$p = p_1 + p_2 + \cdots$$

**证明**：$n = n_1 + n_2 + \cdots$，各成分温度相同，$\overline{\varepsilon}_{k1} = \overline{\varepsilon}_{k2} = \cdots$，

$$p = \frac{2}{3}n\overline{\varepsilon}_k = \frac{2}{3}n_1\overline{\varepsilon}_k + \frac{2}{3}n_2\overline{\varepsilon}_k + \cdots = p_1 + p_2 + \cdots$$

也可利用 $p = nkT$ 得出。

## 6. 能量均分定理与理想气体内能

### 6.1 自由度

确定物体空间位置所需的独立坐标数。

| 分子种类 | 平动 $t$ | 转动 $r$ | 总自由度 $i$ |
|---|---|---|---|
| 单原子（He） | 3 | 0 | 3 |
| 刚性双原子（O₂） | 3 | 2 | 5 |
| 刚性多原子（H₂O、NH₃） | 3 | 3 | 6 |

**刚性细杆**：质心 3 个平动自由度，轴方向 2 个转动自由度，共 5 个。

**刚体**：质心 3 个平动自由度，轴方向 2 个转动自由度，绕轴转角 1 个，共 6 个。

对于非刚性分子，还需考虑振动自由度 $s$：

$$i = t + r + s$$

常温下气体分子可看作刚性，$s = 0$，$i = t + r$。

### 6.2 能量均分定理

在温度为 $T$ 的平衡态下，气体分子每个自由度的平均动能等于 $\frac{1}{2}kT$。

**推广**：
- 分子的平均平动动能：$\frac{3}{2}kT$；
- 分子的平均总动能：$\frac{i}{2}kT$；
- 若考虑振动，每个振动自由度还贡献 $\frac{1}{2}kT$ 的平均振动势能。

**注意**：能量均分定理是统计规律，适用于大量分子。

### 6.3 刚性分子的平均总动能

$$\overline{\varepsilon}_k = \frac{i}{2}kT,\qquad i = 3,5,6$$

即单原子 $\frac{3}{2}kT$，双原子 $\frac{5}{2}kT$，多原子 $\frac{6}{2}kT$。

### 6.4 理想气体的内能

理想气体内能 = 所有分子各种形式动能 + 分子内原子间振动势能。

质量为 $m$ 的刚性理想气体：

$$U = \frac{m}{M}\cdot\frac{i}{2}RT = \frac{i}{2}\nu RT = \frac{i}{2}pV$$

**关键结论**：一定量理想气体的内能只和温度有关。

**常考关系**：

$$U = \frac{i}{2}\nu RT,\qquad i = 3,5,6$$

### 6.5 应用例题

**例**：容器内密闭有 $8\ \text{g}$ 氦气和 $64\ \text{g}$ 氧气组成的混合气体（刚性），温度 $300\ \text{K}$。求：
(1) 每个氦分子和氧分子的平均平动动能；
(2) 每个氦分子和氧分子的平均动能；
(3) 混合气体的内能。

**解**：

$i_{\text{He}} = 3$，$i_{\text{O}_2} = 5$。

(1) 两种气体分子的平均平动动能相等：

$$\overline{\varepsilon}_{\text{He}} = \overline{\varepsilon}_{\text{O}_2} = \frac{3}{2}kT = \frac{3}{2}\times1.38\times10^{-23}\times300 = 6.21\times10^{-21}\ \text{J}$$

(2) 平均动能：

$$\overline{\varepsilon}_{\text{He}} = \frac{3}{2}kT = 6.21\times10^{-21}\ \text{J}$$

$$\overline{\varepsilon}_{\text{O}_2} = \frac{5}{2}kT = 1.035\times10^{-20}\ \text{J}$$

(3) 内能：

$$U = U_{\text{He}} + U_{\text{O}_2} = \frac{3}{2}\frac{m_{\text{He}}}{M_{\text{He}}}RT + \frac{5}{2}\frac{m_{\text{O}_2}}{M_{\text{O}_2}}RT = 1.99\times10^4\ \text{J}$$

## 7. 麦克斯韦速率分布

### 7.1 速率分布函数

$$f(v) = \frac{dN}{N\,dv}$$

**物理意义**：在速率 $v$ 附近单位速率区间内的分子数占总分子数的比率。

**归一化条件**：

$$\int_0^\infty f(v)\,dv = 1$$

**说明**：$f(v)dv$ 表示速率在 $v\sim v+dv$ 区间的分子数占总分子数的比率。

### 7.2 麦克斯韦速率分布函数

1859 年，麦克斯韦导出理想气体在无外场平衡态下分子按速率的分布：

$$f(v) = 4\pi\left(\frac{m_0}{2\pi kT}\right)^{3/2}v^2 e^{-\frac{m_0v^2}{2kT}}$$

曲线特征：
- 曲线下总面积恒为 1；
- 绿色面积 $\int_{v_1}^{v_2}f(v)dv$ 表示速率在 $v_1\sim v_2$ 范围内的分子数占比；
- 存在一个峰值速率 $v_p$。

### 7.3 三种统计速率

**平均速率**：

$$\overline{v} = \int_0^\infty vf(v)\,dv = \sqrt{\frac{8kT}{\pi m_0}} = \sqrt{\frac{8RT}{\pi M}}$$

用于计算分子运动的平均距离。

**方均根速率**：

$$\sqrt{\overline{v^2}} = \sqrt{\int_0^\infty v^2f(v)\,dv} = \sqrt{\frac{3kT}{m_0}} = \sqrt{\frac{3RT}{M}}$$

用于计算分子平均动能。

**最概然速率**：

$$v_p = \sqrt{\frac{2kT}{m_0}} = \sqrt{\frac{2RT}{M}}$$

由 $\frac{df(v)}{dv} = 0$ 得到。

**三者大小关系**：

$$v_p < \overline{v} < \sqrt{\overline{v^2}}$$

具体比值为：

$$v_p : \overline{v} : \sqrt{\overline{v^2}} = \sqrt{2} : \sqrt{\frac{8}{\pi}} : \sqrt{3} \approx 1 : 1.13 : 1.22$$

### 7.4 分布曲线的影响因素

**温度影响**（同种气体）：
- 温度升高，速率大的分子数增多，曲线峰向高速区移动；
- 曲线下面积不变，峰值下降，曲线变平坦。

**分子质量影响**（同一温度）：
- 质量越小，$v_p$ 越大，曲线向高速区扩展，变宽变平坦。

### 7.5 任意区间的平均值

若求 $v_1\sim v_2$ 区间内分子的平均速率：

$$\overline{v}_{1-2} = \frac{\int_{v_1}^{v_2}vf(v)\,dv}{\int_{v_1}^{v_2}f(v)\,dv}$$

区间内分子数：

$$\Delta N = \int_{v_1}^{v_2}Nf(v)\,dv$$

### 7.6 应用例题

**例**：$f(v) = \begin{cases}kv^3, & 0\leq v<v_0\\0, & v_0<v<\infty\end{cases}$

求：
1. $k=?$
2. $\overline{v}=?$
3. 速率在 $0\sim v_0/3$ 之间的分子平均速率
4. 速率在 $0\sim v_0/3$ 之间的分子数
5. 若 $0\sim v_1$ 之间的粒子数占总粒子数的 $\frac{1}{16}$，则 $v_1=?$

**解**：

1. 由归一化条件：

$$\int_0^\infty f(v)\,dv = 1 \Rightarrow \int_0^{v_0}kv^3\,dv = 1 \Rightarrow k = \frac{4}{v_0^4}$$

2. 平均速率：

$$\overline{v} = \int_0^\infty vf(v)\,dv = \int_0^{v_0}v\cdot\frac{4}{v_0^4}v^3\,dv = \frac{4}{5}v_0$$

3. 区间平均速率：

$$\overline{v}_{0\sim v_0/3} = \frac{\int_0^{v_0/3}v\cdot kv^3\,dv}{\int_0^{v_0/3}kv^3\,dv} = \frac{4}{15}v_0$$

4. 区间分子数：

$$\Delta N = \int_0^{v_0/3}N\cdot\frac{4}{v_0^4}v^3\,dv = \frac{N}{81}$$

5. 由 $\frac{1}{16} = \int_0^{v_1}\frac{4}{v_0^4}v^3\,dv$，得 $v_1 = \frac{1}{2}v_0$。

## 8. 玻尔兹曼分布（选学）

### 8.1 重力场中分子数密度分布

**受力分析**：厚度 $dz$ 的气层，上下表面压力差与重力平衡：

$$dp = -m_0gndz$$

由 $p = nkT$，$\frac{dp}{p} = -\frac{m_0g}{kT}dz$，积分得：

$$n = n_0e^{-\frac{m_0gz}{kT}} = n_0e^{-\frac{Mgz}{RT}}$$

压强分布：

$$p = p_0e^{-\frac{m_0gz}{kT}} = p_0e^{-\frac{Mgz}{RT}}$$

### 8.2 推广到任意保守场

$$n_B(r) = n_0e^{-\frac{\varepsilon_p(r)}{kT}}$$

**意义**：分子处于势能越大的位置的概率越小。

## 9. 分子碰撞与输运现象

### 9.1 平均自由程与平均碰撞频率

**平均自由程** $\overline{\lambda}$：分子在连续两次碰撞之间通过的自由路程的平均值。

**平均碰撞频率** $\overline{Z}$：一个分子单位时间内与其他分子碰撞的平均次数。

**关系**：

$$\overline{\lambda} = \frac{\overline{v}}{\overline{Z}}$$

### 9.2 公式

$$\overline{Z} = \sqrt{2}\pi d^2\overline{v}n$$

$$\overline{\lambda} = \frac{1}{\sqrt{2}\pi d^2n} = \frac{kT}{\sqrt{2}\pi d^2p}$$

其中 $d$ 为分子直径。

**推导思路**：以分子有效直径 $d$ 为半径的圆柱体，单位时间内扫过的体积为 $\sqrt{2}\pi d^2\overline{v}$，乘以分子数密度 $n$ 即为碰撞频率。

**数量级**：标准状态下 $\lambda\sim10^{-7}\sim10^{-8}\ \text{m}$，$d\sim10^{-10}\ \text{m}$，$\lambda\gg d$；$Z\sim10^9/\text{s}$。

### 9.3 典型变化关系

**体积不变、温度升高**：
- $\overline{v}\propto\sqrt{T}$；
- $n$ 不变，$\overline{\lambda}$ 不变；
- $\overline{Z}\propto\overline{v}$，增大。

**恒压、温度升高**：
- $\overline{v}\propto\sqrt{T}$，增大；
- $n = \frac{p}{kT}$ 减小，$\overline{\lambda}\propto\frac{T}{p}$ 增大；
- $\overline{Z} = \sqrt{2}\pi d^2\overline{v}n$ 需综合判断，通常减小。

**应用例题**：
- 体积不变，温度由 $T_0$ 升到 $4T_0$：$\overline{v}$ 变为 $2\overline{v}_0$，$\overline{Z}$ 变为 $2\overline{Z}_0$，$\overline{\lambda}$ 不变；
- 恒压升温：平均碰撞频率减小，平均自由程增大。

# 第二部分 热力学基础（宏观理论）

## 10. 热力学第一定律

### 10.1 内能与第一定律

系统从外界吸热 $Q$，对外做功 $A$，内能从 $U_1$ 变为 $U_2$：

$$Q = \Delta U + A$$

**符号规定**：
- 系统吸热 $Q>0$；
- 系统对外做功 $A>0$；
- 系统内能增加 $\Delta U>0$。

**微分形式**：

$$dQ = dU + dA$$

**另一种表述**：第一类永动机不可能制成。

**第一类永动机**：不消耗能量而不断对外做功的机器。

**适用范围**：一切热力学系统的任意过程，但要求初、末态为平衡态。

### 10.2 特殊情况

| 条件 | 结论 | 物理意义 |
|---|---|---|
| $A=0$ | $Q=\Delta U$ | 吸热全部用于增加内能 |
| $Q=0$ | $\Delta U=-A$ | 绝热，外界做功全部转为内能 |
| $\Delta U=0$ | $Q=A$ | 吸热全部用于对外做功 |
| $Q=0$ 且 $A=0$ | $\Delta U=0$ | 绝热自由膨胀，内能不变 |

### 10.3 准静态过程的功

$$dA = p\,dV,\qquad A = \int_{V_1}^{V_2}p\,dV$$

**几何意义**：功等于 $p$-$V$ 图上过程曲线下的面积。

**关键结论**：功是过程量，不仅与初末态有关，还与路径有关。

**等温过程功**：

$$A = p_1V_1\ln\frac{V_2}{V_1} = \nu RT\ln\frac{V_2}{V_1}$$

等温膨胀 $A>0$，等温压缩 $A<0$。

### 10.4 热量与热容

**热容**：

$$C = \frac{dQ}{dT}$$

**比热容**：

$$c = \frac{C}{m}$$

**摩尔热容**：

$$C_m = \frac{C}{\nu}$$

**吸放热**：

$$Q = \int_{T_1}^{T_2}CdT = m\int_{T_1}^{T_2}cdT = \frac{m}{M}\int_{T_1}^{T_2}C_m dT$$

**关键结论**：热量与过程有关，热容也与过程有关。同一物质经历不同过程时 $C$ 值不同。

### 10.5 定容热容与定压热容

**定容热容**：

$$C_V = \left(\frac{dQ}{dT}\right)_V = \left(\frac{dU}{dT}\right)_V$$

因为 $dV=0$，$dQ=dU$。

**摩尔定容热容**（刚性理想气体）：

$$C_{V,m} = \frac{i}{2}R$$

**定压热容**：

$$C_p = \left(\frac{dQ}{dT}\right)_p$$

**摩尔定压热容**（刚性理想气体）：

$$C_{p,m} = \frac{i+2}{2}R$$

**推导**：$dQ_p = dU + pdV = d(U+pV) = d\left(\frac{i}{2}\nu RT + \nu RT\right) = \frac{i+2}{2}\nu RdT$。

**迈耶公式**：

$$C_{p,m} = C_{V,m} + R$$

**比热容比**：

$$\gamma = \frac{C_{p,m}}{C_{V,m}} = \frac{i+2}{i}$$

**常用数值**：

| 分子类型 | $i$ | $C_{V,m}$ | $C_{p,m}$ | $\gamma$ |
|---|---|---|---|---|
| 单原子 | 3 | $\frac{3}{2}R$ | $\frac{5}{2}R$ | $\frac{5}{3}$ |
| 双原子 | 5 | $\frac{5}{2}R$ | $\frac{7}{2}R$ | $\frac{7}{5}$ |
| 多原子 | 6 | $\frac{6}{2}R$ | $\frac{8}{2}R$ | $\frac{8}{6}$ |

**热量公式**：

$$Q_V = \Delta U = \nu C_{V,m}\Delta T$$

$$Q_p = \nu C_{p,m}\Delta T$$

## 11. 热一定律对理想气体准静态过程的应用

### 11.1 等容过程

- 特征：$V=$ 常量，$dV=0$；
- 过程方程：$\frac{p}{T}=$ 常量；
- 功：$A=0$；
- 热量：$Q=\Delta U=\nu C_{V,m}\Delta T$；
- 内能增量：$\Delta U=\nu C_{V,m}\Delta T$。

### 11.2 等压过程

- 特征：$p=$ 常量，$dp=0$；
- 过程方程：$\frac{V}{T}=$ 常量；
- 功：$A=p(V_2-V_1)=\nu R\Delta T$；
- 热量：$Q=\nu C_{p,m}\Delta T$；
- 内能增量：$\Delta U=\nu C_{V,m}\Delta T$。

**应用例题**：$1.25\ \text{kg}$ 氮气，标准大气压下缓慢加热升温 $1\ \text{K}$。

$$A_p = \frac{m}{M}R\Delta T = \frac{1.25}{0.028}\times8.31\times1 = 371\ \text{J}$$

$$\Delta U = \frac{m}{M}\frac{5R}{2}\Delta T = 929\ \text{J}$$

$$Q_p = \Delta U + A = 1300\ \text{J}$$

### 11.3 等温过程

- 特征：$T=$ 常量，$dT=0$；
- 过程方程：$pV=$ 常量；
- 内能增量：$\Delta U=0$；
- 功：$A=\nu RT\ln\frac{V_2}{V_1}=p_1V_1\ln\frac{V_2}{V_1}$；
- 热量：$Q=A$。

### 11.4 绝热过程

- 特征：$Q=0$，$dQ=0$；
- 过程方程：

$$pV^\gamma = \text{常量}$$

$$V^{\gamma-1}T = \text{常量}$$

$$p^{\gamma-1}T^{-\gamma} = \text{常量}$$

**推导**：由 $pdV + Vdp = \nu RdT$ 和 $pdV = -\nu C_{V,m}dT$，消去 $dT$ 得 $C_{V,m}Vdp + C_{p,m}pdV = 0$，积分得 $pV^\gamma = C$。

- 内能增量：$\Delta U=\nu C_{V,m}(T_2-T_1)$；
- 功：$A=-\Delta U$。

**功的另一种表达式**：

$$A = \frac{p_1V_1 - p_2V_2}{\gamma-1}$$

**绝热膨胀**：$V\uparrow$，$T\downarrow$，温度降低。

### 11.5 绝热线与等温线比较

等温线斜率：

$$\left(\frac{dp}{dV}\right)_T = -\frac{p}{V}$$

绝热线斜率：

$$\left(\frac{dp}{dV}\right)_Q = -\gamma\frac{p}{V}$$

因为 $\gamma>1$，所以绝热线比等温线更陡。

**物理意义**：绝热膨胀时温度降低，压强下降更快。

### 11.6 绝热自由膨胀

- 器壁绝热：$Q=0$；
- 向真空膨胀：$A=0$；
- 热一定律：$\Delta U=0$；
- 对理想气体：$T_1=T_2$，温度不变。

**注意**：这是非准静态绝热过程，初末态为平衡态，但不能在 $p$-$V$ 图上用一条曲线连接。

**与准静态绝热膨胀的区别**：

| | 准静态绝热膨胀 | 绝热自由膨胀 |
|---|---|---|
| 过程 | 准静态，有过程方程 | 非平衡过程，无过程方程 |
| 做功 | $A>0$ | $A=0$ |
| 温度 | 降低 | 不变 |

### 11.7 多方过程（选学）

过程方程：

$$pV^n = \text{常量}$$

| $n$ | 过程 |
|---|---|
| 0 | 等压 |
| 1 | 等温 |
| $\gamma$ | 绝热 |
| $\infty$ | 等容 |

功：

$$A = \frac{p_1V_1 - p_2V_2}{n-1}$$

多方过程热容：

$$C_{n,m} = C_{V,m}\frac{n-\gamma}{n-1}$$

### 11.8 各过程公式汇总

| 过程 | 过程方程 | 吸热 | 对外做功 | 内能增量 |
|---|---|---|---|---|
| 等容 | $\frac{p}{T}=C$ | $\nu C_{V,m}\Delta T$ | 0 | $\nu C_{V,m}\Delta T$ |
| 等压 | $\frac{V}{T}=C$ | $\nu C_{p,m}\Delta T$ | $p\Delta V$ 或 $\nu R\Delta T$ | $\nu C_{V,m}\Delta T$ |
| 等温 | $pV=C$ | $\nu RT\ln\frac{V_2}{V_1}$ | $\nu RT\ln\frac{V_2}{V_1}$ | 0 |
| 绝热 | $pV^\gamma=C$ | 0 | $-\nu C_{V,m}\Delta T$ | $\nu C_{V,m}\Delta T$ |
| 多方 | $pV^n=C$ | $A+\Delta U$ | $\frac{p_1V_1-p_2V_2}{n-1}$ | $\nu C_{V,m}\Delta T$ |

### 11.9 应用例题

**例**：$8\ \text{g}$ 氧气，体积 $0.41\times10^{-3}\ \text{m}^3$，温度 $300\ \text{K}$。准静态绝热膨胀到 $4.1\times10^{-3}\ \text{m}^3$，求做功。若等温膨胀到同样体积，做功多少？

**解**：

绝热膨胀：

$$T_2 = T_1\left(\frac{V_1}{V_2}\right)^{\gamma-1} = 300\left(\frac{1}{10}\right)^{0.4} = 119\ \text{K}$$

$$A_Q = -\nu C_{V,m}(T_2-T_1) = -\frac{8}{32}\times\frac{5\times8.31}{2}\times(119-300) = 941\ \text{J}$$

等温膨胀：

$$A_T = \nu RT_1\ln\frac{V_2}{V_1} = \frac{8}{32}\times8.31\times300\times\ln10 = 1.44\times10^3\ \text{J}$$

**结论**：$A_Q < A_T$，绝热膨胀做功小于等温膨胀。

## 12. 循环与效率

### 12.1 循环

系统经过一系列状态变化又回到原来的状态。

- 循环回到初态：$\Delta U=0$；
- 净热量等于净功：$Q=A$。

### 12.2 正循环与逆循环

**正循环**（顺时针）：$A>0$，$Q>0$，热机循环。

**逆循环**（逆时针）：$A<0$，$Q<0$，制冷循环。

**几何意义**：净功等于 $p$-$V$ 图上闭合曲线所包围的面积。

**注意**：正循环和逆循环都必须至少涉及两个温度不同的热源。

### 12.3 热机效率

$$\eta = \frac{A}{Q_{\text{吸}}} = \frac{Q_{\text{吸}}-|Q_{\text{放}}|}{Q_{\text{吸}}} = 1 - \frac{|Q_{\text{放}}|}{Q_{\text{吸}}}$$

$0<\eta<1$。

### 12.4 卡诺循环

由两个等温过程和两个绝热过程组成。

**卡诺正循环效率**：

$$\eta_c = 1 - \frac{T_{\text{低}}}{T_{\text{高}}}$$

**推导**：

$$Q_{\text{吸}} = \nu RT_{\text{高}}\ln\frac{V_2}{V_1}$$

$$|Q_{\text{放}}| = \nu RT_{\text{低}}\ln\frac{V_3}{V_4}$$

由绝热过程方程得 $\frac{V_2}{V_1} = \frac{V_3}{V_4}$，所以：

$$\eta_c = 1 - \frac{T_{\text{低}}}{T_{\text{高}}}$$

**关键结论**：卡诺循环效率只决定于两个热源的温度，与工作物质无关。

### 12.5 制冷机与制冷系数

**制冷机**：通过外界做功，从低温热源吸热，向高温热源放热。

$$|A| = |Q_{\text{放}}| - Q_{\text{吸}}$$

**制冷系数**：

$$w = \frac{Q_{\text{吸}}}{|A|} = \frac{Q_{\text{吸}}}{|Q_{\text{放}}|-Q_{\text{吸}}}$$

**卡诺制冷机**：

$$w_c = \frac{T_{\text{低}}}{T_{\text{高}}-T_{\text{低}}}$$

**注意**：
- 制冷系数可以大于 1；
- 高温热源一定时，低温热源温度越低，$w$ 越小，制冷越困难。

**数据**：$T_{\text{高}}=293\ \text{K}$ 时，

| $T_{\text{低}}$ | 273 | 223 | 100 | 51 |
|---|---|---|---|---|
| $w$ | 13.6 | 3.2 | 0.52 | 0.017 |

### 12.6 奥托循环

四冲程内燃机循环：绝热压缩 → 等容吸热 → 绝热膨胀 → 等容放热。

效率：

$$\eta = 1 - \left(\frac{V_2}{V_1}\right)^{\gamma-1}$$

其中 $\frac{V_1}{V_2}$ 为压缩比，实际汽油机效率约 25%。

### 12.7 循环效率计算例题

**例**：氢气作如图所示的循环，求效率。

**解**：

判断各过程热量正负：

$$Q_{ab} = \nu C_{p,m}(T_b-T_a) = \frac{i+2}{2}(p_bV_b-p_aV_a) = \frac{7}{2}(4-2) = 7\ \text{atm}\cdot\text{l} > 0$$

$$Q_{da} = \nu C_{V,m}(T_a-T_d) = \frac{i}{2}(p_aV_a-p_dV_d) = \frac{5}{2}\ \text{atm}\cdot\text{l} > 0$$

$$Q_{bc}<0,\qquad Q_{cd}<0$$

$$Q_{\text{吸}} = Q_{ab} + Q_{da} = \frac{19}{2}\ \text{atm}\cdot\text{l}$$

$$A_{\text{总}} = (p_a-p_d)(V_b-V_a) = 1\ \text{atm}\cdot\text{l}$$

$$\eta = \frac{A_{\text{总}}}{Q_{\text{吸}}} = \frac{1}{19/2} = 10.5\%$$

**关键**：先判断各过程吸放热，再计算总功和总吸热。

## 13. 热力学第二定律

### 13.1 热力学过程的方向性

- 热传导：热量可自动由高温传向低温，反之不可以；
- 功热转换：摩擦做功可产生热，热不能自动全部转化为功；
- 气体扩散、物体损坏等。

### 13.2 可逆过程与不可逆过程

**可逆过程**：存在另一过程，不仅能逆向重复原过程的每一个状态，而且同时使外界完全复原。

**不可逆过程**：找不到这样的过程。

**注意**：
- 不可逆过程不是系统不能回复原态，而是系统复原时必须施加额外外界影响，因而外界和系统不能同时复原；
- 自然界中一切与热现象有关的宏观实际过程都是不可逆过程；
- 无摩擦的准静态过程是可逆过程。

### 13.3 热力学第二定律的两种表述

**克劳修斯表述**：不可能把热量从低温物体传到高温物体而不引起其他变化。

**开尔文表述**：不可能从单一热源吸取热量，使之全部变为有用功，而不产生其他影响。

**等价性**：两种表述互为推证。若一种表述不成立，则另一种也不成立。

**证明思路**（反证法）：
- 假设开氏表述不成立，第二类永动机可实现，用它带动制冷机，总效果是热量从低温传到高温而不引起其他变化，违反克氏表述；
- 假设克氏表述不成立，热量可从低温传到高温而不引起其他变化，设计热机从高温吸热 $Q$，对外做功 $A$，向低温放热 $Q_2$，总效果是单热源热机，违反开氏表述。

**第二类永动机**：将吸收的热量全部转化为对外做功，效率为 100% 的热机，不可能造成。

### 13.4 卡诺定理

1. 工作在温度分别为 $T_1$、$T_2$ 的高低温热源之间的一切可逆热机效率相同，与工作物质无关：

$$\eta_r = \eta_c = 1 - \frac{T_2}{T_1}$$

2. 工作在两个给定热源之间的所有热机，其效率不可能大于可逆热机的效率：

$$\eta \leq \eta_c = 1 - \frac{T_2}{T_1}$$

**提高热机效率的途径**：
- 增大冷热源温度差；
- 尽量减少摩擦等耗散因素，接近可逆机。

### 13.5 克劳修斯不等式

$$\oint \frac{dQ}{T} \leq 0$$

等号对应于可逆循环。

**推导**：由卡诺定理，$1 - \frac{|Q_2|}{Q_1} \leq 1 - \frac{T_2}{T_1}$，得 $\frac{Q_1}{T_1} + \frac{Q_2}{T_2} \leq 0$，推广到任意循环得 $\oint\frac{dQ}{T}\leq0$。

## 14. 熵

### 14.1 克劳修斯熵

对任意可逆循环：

$$\oint \left(\frac{dQ}{T}\right)_{\text{可逆}} = 0$$

热温比的积分与路径无关，仅由状态 1、2 决定，是状态函数之差。

**克劳修斯熵公式**：

$$\Delta S = S_2 - S_1 = \int_1^2 \left(\frac{dQ}{T}\right)_{\text{可逆}}$$

$$dS = \left(\frac{dQ}{T}\right)_{\text{可逆}}$$

**注意**：
- 熵 $S$ 是态函数，只要初末为平衡态，熵变 $\Delta S$ 就确定，与具体过程无关；
- 熵的值是相对的，与参考点选择有关。

### 14.2 熵变的计算

**可逆过程**：直接计算

$$\Delta S = \int_A^B \left(\frac{dQ}{T}\right)_{\text{可逆}}$$

**不可逆过程**：设计一个连接同样初终两态的可逆过程，再利用上式。

**理想气体熵变公式**：

以 $(T,V)$ 为独立变量：

$$\Delta S = \nu C_{V,m}\ln\frac{T}{T_0} + \nu R\ln\frac{V}{V_0}$$

以 $(T,p)$ 为独立变量：

$$\Delta S = \nu C_{p,m}\ln\frac{T}{T_0} - \nu R\ln\frac{p}{p_0}$$

**绝热自由膨胀熵变**：

$$\Delta S = \nu R\ln\frac{V_2}{V_1} > 0$$

**应用例题**：刚性绝热容器有 $1\ \text{mol}$ 单原子理想气体，搅拌使压强由 $10^5\ \text{Pa}$ 升到 $1.4\times10^5\ \text{Pa}$，初温 $27^\circ\text{C}$，求熵变。

**解**：等体过程，

$$T_2 = \frac{p_2}{p_1}T_1 = \frac{1.4\times10^5}{1\times10^5}\times300 = 420\ \text{K}$$

$$\Delta S = \int\frac{dQ}{T} = \int\frac{\nu C_{V,m}dT}{T} = \frac{3}{2}R\ln\frac{T_2}{T_1} = 4.2\ \text{J/K}$$

### 14.3 温熵图

$$dQ = T\,dS$$

- 温熵图上曲线下的面积表示热量；
- 一次循环吸收的净热：$Q = \oint T\,dS$；
- 卡诺循环在温熵图上为矩形。

**卡诺循环温熵图**：

$$Q_1 = T_1(S_2-S_1),\qquad |Q_2| = T_2(S_2-S_1)$$

$$\eta_c = 1 - \frac{|Q_2|}{Q_1} = 1 - \frac{T_2}{T_1}$$

### 14.4 熵增加原理

对绝热过程：

$$dS_{\text{绝热}} \geq 0$$

**表述**：热力学系统经绝热过程熵永不减少；可逆绝热过程熵不变，不可逆绝热过程熵增加。

对孤立系统：

$$\Delta S_{\text{孤立系}} \geq 0$$

**表述**：孤立系统的熵永不减少。绝热系统或孤立系统由非平衡态向平衡态过渡时熵增加，最终平衡态是熵最大的状态。

### 14.5 玻尔兹曼熵

**热力学概率** $\Omega$：某一宏观态对应的微观态数目。

**玻尔兹曼关系**：

$$S = k\ln\Omega$$

**意义**：
- 熵是系统宏观状态无序程度的量度；
- $\Omega$ 越大，系统无序程度越高，熵越大；
- 一个宏观态 ↔ 一个 $\Omega$ 值 ↔ 一个 $S$ 值。

### 14.6 热力学第二定律的统计意义

在孤立系统内发生的一切实际过程，必然是由热力学概率小的宏观态向最概然状态过渡，向着熵增加的方向进行。

**自发方向**：

微观粒子热运动无序度小 → 大  
包含微观状态数少的态 → 多的态  
热力学概率小的态 → 大的态  
熵小的态 → 熵大的态

**注意**：一切自发过程都是从有序状态向无序状态的方向进行的。

## 15. 重要关系与易错点

### 15.1 微观与宏观的桥梁

| 微观量 | 宏观量 | 关系 |
|---|---|---|
| 平均平动动能 $\overline{\varepsilon}_k$ | 温度 $T$ | $\overline{\varepsilon}_k = \frac{3}{2}kT$ |
| 分子数密度 $n$、平均平动动能 | 压强 $p$ | $p = \frac{2}{3}n\overline{\varepsilon}_k$ |
| 分子自由度 $i$ | 内能 $U$ | $U = \frac{i}{2}\nu RT$ |
| 热力学概率 $\Omega$ | 熵 $S$ | $S = k\ln\Omega$ |

### 15.2 常见易错点

1. **温度与平均平动动能**：$\overline{\varepsilon}_k = \frac{3}{2}kT$ 只适用于平动，不包括转动和振动。
2. **内能只与温度有关**：仅对理想气体成立。
3. **功和热量是过程量**，内能和熵是态函数。
4. **绝热自由膨胀**：$Q=0$，$A=0$，$\Delta U=0$，温度不变，但这是非准静态过程，不能用绝热过程方程。
5. **卡诺循环效率**：$\eta_c = 1 - \frac{T_{\text{低}}}{T_{\text{高}}}$，温度必须用热力学温标。
6. **熵变计算**：不可逆过程不能直接积分 $\int\frac{dQ}{T}$，必须设计可逆路径。
7. **热力学第二定律**：两种表述等价，一切不可逆过程相互推证。
8. **平均自由程**：$\overline{\lambda} = \frac{1}{\sqrt{2}\pi d^2 n}$，与平均速率无关；恒压升温时 $\overline{\lambda}$ 增大，体积不变升温时 $\overline{\lambda}$ 不变。
9. **绝热线与等温线**：绝热线更陡，因为 $\gamma>1$。
10. **迈耶公式**：$C_{p,m} = C_{V,m} + R$ 仅对理想气体成立。

### 15.3 公式速查

**气体动理论**：

$$pV = \nu RT,\qquad p = nkT$$

$$p = \frac{1}{3}nm_0\overline{v^2} = \frac{2}{3}n\overline{\varepsilon}_k$$

$$\overline{\varepsilon}_k = \frac{3}{2}kT$$

$$\sqrt{\overline{v^2}} = \sqrt{\frac{3RT}{M}},\qquad \overline{v} = \sqrt{\frac{8RT}{\pi M}},\qquad v_p = \sqrt{\frac{2RT}{M}}$$

$$U = \frac{i}{2}\nu RT,\qquad i = 3,5,6$$

$$f(v) = 4\pi\left(\frac{m_0}{2\pi kT}\right)^{3/2}v^2e^{-\frac{m_0v^2}{2kT}}$$

$$\overline{Z} = \sqrt{2}\pi d^2\overline{v}n,\qquad \overline{\lambda} = \frac{1}{\sqrt{2}\pi d^2n}$$

**热力学基础**：

$$Q = \Delta U + A,\qquad dQ = dU + dA$$

$$A = \int_{V_1}^{V_2}p\,dV$$

$$C_{V,m} = \frac{i}{2}R,\qquad C_{p,m} = \frac{i+2}{2}R,\qquad \gamma = \frac{i+2}{i}$$

$$pV^\gamma = C,\qquad V^{\gamma-1}T = C,\qquad p^{\gamma-1}T^{-\gamma} = C$$

$$\eta = 1 - \frac{|Q_{\text{放}}|}{Q_{\text{吸}}},\qquad \eta_c = 1 - \frac{T_{\text{低}}}{T_{\text{高}}}$$

$$w = \frac{Q_{\text{吸}}}{|A|},\qquad w_c = \frac{T_{\text{低}}}{T_{\text{高}}-T_{\text{低}}}$$

$$\Delta S = \int_1^2\left(\frac{dQ}{T}\right)_{\text{可逆}},\qquad S = k\ln\Omega$$

$$\Delta S_{\text{孤立系}} \geq 0$$

## 16. 典型例题思路

### 16.1 热一定律应用

**例**：系统由 $a$ 沿 $abc$ 到 $c$ 吸热 $350\times10^5\ \text{J}$，求沿 $adc$ 到 $c$ 的吸热，以及沿 $ca$ 返回时的吸放热。

**思路**：
1. 功 = 曲线下面积，分别计算 $abc$ 和 $adc$ 的功；
2. 内能增量只和始末态有关：$\Delta U_{ac} = Q_{abc} - A_{abc}$；
3. 对 $adc$：$Q_{adc} = \Delta U_{ac} + A_{adc}$；
4. 对 $ca$：$\Delta U_{ca} = -\Delta U_{ac}$，$Q_{ca} = \Delta U_{ca} + A_{ca}$，由正负判断吸放热。

### 16.2 循环效率计算

**思路**：
1. 判断各过程热量正负；
2. 计算 $Q_{\text{吸}}$（所有 $Q>0$ 的过程之和）；
3. 计算净功 $A_{\text{总}}$（$p$-$V$ 图闭合曲线面积）；
4. $\eta = \frac{A_{\text{总}}}{Q_{\text{吸}}}$。

### 16.3 熵变计算

**例**：理想气体绝热自由膨胀 $V_1\to V_2$。

**思路**：
1. 自由膨胀 $Q=0$，$A=0$，$\Delta U=0$，$T$ 不变；
2. 设计可逆等温膨胀过程连接初末态；
3. $\Delta S = \int\frac{dQ}{T} = \int\frac{p\,dV}{T} = \nu R\ln\frac{V_2}{V_1} > 0$。

### 16.4 卡诺循环相关

**思路**：
1. 卡诺循环由两个等温、两个绝热过程组成；
2. 效率 $\eta_c = 1 - \frac{T_{\text{低}}}{T_{\text{高}}}$；
3. 制冷系数 $w_c = \frac{T_{\text{低}}}{T_{\text{高}}-T_{\text{低}}}$；
4. 注意温度单位用 K。

### 16.5 证明题

**例**：证明在 $p$-$V$ 图上一条等温线和一条绝热线不能相交两次。

**证**：反证法。设等温线和绝热线能相交两次，构成一个循环。图中循环可构成单热源热机，吸收热量全部用于对外做功而没产生其他影响，违反热力学第二定律的开氏表述。故假设不成立。

**例**：证明在 $p$-$V$ 图上两条绝热线不能相交。

**证**：反证法。假定绝热线 I、II 交于 A 点，作一条等温线 III 与两条绝热线组成循环。这个循环只有一个热源，把从热源吸收的热量全部变成了功，违反热力学第二定律。故不可能。
