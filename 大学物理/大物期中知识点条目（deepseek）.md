### **大学物理（上）期中考试核心知识点整理与拓展**

#### **第一章 质点运动学**

**（一）核心概念与公式精析**

1.  **质点**
    - **定义**：在某些情况下，可以忽略物体的**大小和形状**，将其视为一个只有质量而没有体积的几何点。
    - **核心思想**：这是一个**理想化模型**，用于简化问题。当物体的尺寸远小于其运动轨迹的尺度时，可视为质点。
    - **拓展**：能否视为质点取决于研究的问题。例如，研究地球公转时，地球可视为质点；研究地球自转时，则不能。

2.  **参考系与坐标系**
    - **参考系**：为描述物体运动而选作**参考标准**的物体或物体系。
    - **坐标系**：定量描述物体位置而固定在参考系上的数学框架，如直角坐标 $(x, y, z)$、自然坐标 $(s)$、极坐标 $(r, \theta)$。
    - **拓展**：运动描述的相对性。同一物体，不同参考系，运动描述不同。

3.  **位置矢量、位移、路程**
    - **位置矢量 ($\vec{r}$)**：由坐标原点指向质点所在位置的有向线段。
    - **位移 ($\Delta\vec{r}$)**：描述质点**位置变化**的矢量，$\Delta\vec{r} = \vec{r}_2 - \vec{r}_1$。只与初、末位置有关。
    - **路程 ($\Delta s$)**：质点实际运动轨迹的**长度**，是标量，$\Delta s \ge |\Delta\vec{r}|$。

4.  **速度与加速度**
    - **瞬时速度 ($\vec{v}$)**：位矢对时间的一阶导数，$\vec{v} = \frac{d\vec{r}}{dt}$。方向为轨迹切线方向。
    - **瞬时加速度 ($\vec{a}$)**：速度对时间的一阶导数，位矢的二阶导数，$\vec{a} = \frac{d\vec{v}}{dt} = \frac{d^2\vec{r}}{dt^2}$。

5.  **直角坐标系下的运动描述**
    - 运动方程：$\vec{r}(t) = x(t)\vec{i} + y(t)\vec{j} + z(t)\vec{k}$
    - 速度：$\vec{v} = v_x\vec{i} + v_y\vec{j} + v_z\vec{k} = \frac{dx}{dt}\vec{i} + \frac{dy}{dt}\vec{j} + \frac{dz}{dt}\vec{k}$
    - 加速度：$\vec{a} = a_x\vec{i} + a_y\vec{j} + a_z\vec{k} = \frac{dv_x}{dt}\vec{i} + \frac{dv_y}{dt}\vec{j} + \frac{dv_z}{dt}\vec{k}$

6.  **自然坐标系下的运动描述**
    - **核心思想**：将加速度分解到轨迹的切向和法向上。
    - **切向加速度 ($a_t$)**：改变速度的**大小**。$a_t = \frac{dv}{dt}$
    - **法向加速度 ($a_n$)**：改变速度的**方向**。$a_n = \frac{v^2}{\rho}$，其中 $\rho$ 为该点的曲率半径。
    - **总加速度**：$\vec{a} = \vec{a}_t + \vec{a}_n$，大小 $a = \sqrt{a_t^2 + a_n^2}$。

7.  **圆周运动的角量描述**
    - **角位置 ($\theta$)**、**角位移 ($\Delta\theta$)**
    - **角速度 ($\omega$)**：$\omega = \frac{d\theta}{dt}$ (rad/s)
    - **角加速度 ($\alpha$)**：$\alpha = \frac{d\omega}{dt} = \frac{d^2\theta}{dt^2}$ (rad/s²)
    - **线量与角量的关系**：$v = R\omega$， $a_t = R\alpha$， $a_n = R\omega^2 = \frac{v^2}{R}$。

8.  **相对运动**
    - **伽利略变换 (低速近似)**：绝对速度 = 相对速度 + 牵连速度 ($\vec{v}_{abs} = \vec{v}_{rel} + \vec{v}_{sys}$)。
    - **拓展**：加速度关系为 $\vec{a}_{abs} = \vec{a}_{rel} + \vec{a}_{sys}$。若牵连参考系为匀速直线运动 ($\vec{a}_{sys}=0$)，则绝对加速度等于相对加速度。

**（二）题型归纳与解题技巧**

- **题型一：已知运动方程，求速度和加速度** -> **方法：求导**。$r(t) \xrightarrow{\text{求导}} v(t) \xrightarrow{\text{求导}} a(t)$。
- **题型二：已知加速度和初始条件，求速度与运动方程** -> **方法：积分**。
    - 情况1：已知 $a(t)$，求 $v(t), x(t)$。 $v(t) = v_0 + \int_{t_0}^t a(t)dt$。
    - 情况2：已知 $a(x)$，求 $v(x)$。 利用 $a = \frac{dv}{dt} = \frac{dv}{dx}\frac{dx}{dt} = v\frac{dv}{dx}$，分离变量积分。
    - 情况3：已知 $a(v)$，求 $v(t)$ 或 $v(x)$。 利用 $a = \frac{dv}{dt}$ 或 $a = v\frac{dv}{dx}$，分离变量积分。
- **题型三：求切向、法向加速度和曲率半径** -> **方法：先求 $v$ 和 $a$ 的大小**。$a_t = \frac{dv}{dt}$，$a_n = \sqrt{a^2 - a_t^2}$，$\rho = \frac{v^2}{a_n}$。

#### **第二章 动量守恒定律**

**（一）核心概念与公式精析**

1.  **牛顿运动定律**
    - **第一定律 (惯性定律)**：定义了**惯性**和**惯性系**。孤立质点保持静止或匀速直线运动。
    - **第二定律 (核心定律)**：$\vec{F} = \frac{d\vec{p}}{dt} = m\vec{a}$ (仅在 $m$ 为常量时成立)。力是改变物体运动状态的原因。
    - **第三定律 (作用力与反作用力)**：$\vec{F}_{12} = -\vec{F}_{21}$。同时产生，同时消失，同性质，作用在不同物体上。

2.  **动量 ($\vec{p}$) 与冲量 ($\vec{I}$)**
    - **动量**：$\vec{p} = m\vec{v}$，是描述物体运动状态的**状态量**，矢量。
    - **冲量**：$\vec{I} = \int_{t_1}^{t_2} \vec{F} dt$，是力对时间的累积效应，**过程量**，矢量。

3.  **动量定理**
    - **质点**：合外力的冲量等于质点动量的增量。 $\vec{I} = \int_{t_1}^{t_2} \vec{F} dt = \vec{p}_2 - \vec{p}_1 = \Delta\vec{p}$。
    - **质点系**：系统总动量的增量等于系统所受**合外力**的冲量。**内力不会改变系统的总动量**。

4.  **动量守恒定律**
    - **条件**：系统所受的**合外力为零** ($\sum \vec{F}_{ext} = 0$)。
    - **结论**：系统的**总动量保持不变** ($\vec{p} = \sum \vec{p}_i = \text{恒矢量}$)。
    - **拓展**：
        - **近似守恒**：当内力 $\gg$ 外力时（如碰撞、爆炸），可近似认为动量守恒。
        - **分量守恒**：若合外力在某一方向（如 $x$ 方向）的分量为零，则该方向上的动量分量守恒。

5.  **质心与质心运动定理**
    - **质心位置**：$\vec{r}_c = \frac{\sum m_i \vec{r}_i}{\sum m_i}$，对于连续体，$\vec{r}_c = \frac{\int \vec{r} dm}{M}$。
    - **质心运动定理**：无论系统内部如何运动，系统**质心**的运动等同于一个质点的运动，该质点集中于系统的全部质量，并受到所有**外力**的作用。即 $\sum \vec{F}_{ext} = M\vec{a}_c$。

6.  **变质量系统**
    - **火箭方程**：$M\frac{d\vec{v}}{dt} = \sum \vec{F}_{ext} + \vec{u}_{rel}\frac{dM}{dt}$，其中 $\vec{u}_{rel}$ 为喷出物质相对主体的速度。

7.  **非惯性系与惯性力**
    - **核心思想**：为了让牛顿定律在非惯性系中也能形式不变地应用，需要引入假想的“力”——惯性力。
    - **平动加速系**：$\vec{F}_i = -m\vec{a}_{sys}$。
    - **匀速转动系**：
        - **惯性离心力**：$\vec{F}_c = m\omega^2\vec{r}$，方向背离圆心。
        - **科里奥利力**：$\vec{F}_{cor} = 2m\vec{v}_{rel} \times \vec{\omega}$，物体相对于转动系有速度时产生。

**（二）题型归纳与解题技巧**

- **动量守恒应用**：关键在于**明确系统**和**分析外力**。选取合适的系统使得外力为零或近似为零。动量是矢量，注意方向。
- **变质量问题**：应用火箭方程，注意 $\frac{dM}{dt}$ 的符号（通常为负，表示质量减小）和 $\vec{u}_{rel}$ 的方向。

#### **第三章 能量守恒定律**

**（一）核心概念与公式精析**

1.  **功 ($W$) 与功率 ($P$)**
    - **功**：力对空间的累积效应。$W = \int_a^b \vec{F} \cdot d\vec{r} = \int_a^b F\cos\theta ds$。功是**标量**，但有正负。
    - **一对力的功**：$dW_{pair} = \vec{F}_{12} \cdot d\vec{r}_{12}$。其大小与参考系的选择**无关**。
    - **功率**：$P = \frac{dW}{dt} = \vec{F} \cdot \vec{v}$。

2.  **动能 ($E_k$) 与动能定理**
    - **动能**：$E_k = \frac{1}{2}mv^2$。
    - **质点动能定理**：合外力对质点做的功等于质点动能的增量。$W_{total} = \Delta E_k$。
    - **质点系动能定理**：所有**外力**和**内力**做功的代数和等于系统总动能的增量。$W_{ext} + W_{int} = \Delta E_k$。

3.  **保守力与势能 ($E_p$)**
    - **保守力**：做功与路径无关，只与初、末位置有关的力（如重力、弹力、万有引力、静电力）。
    - **保守力的功**：$W_{cons} = -(E_{p2} - E_{p1}) = -\Delta E_p$。
    - **势能**：由相互作用的物体间相对位置决定的能量。属于**系统**共有。
    - **保守力与势能的关系**：$\vec{F} = -\nabla E_p = -(\frac{\partial E_p}{\partial x}\vec{i} + \frac{\partial E_p}{\partial y}\vec{j} + \frac{\partial E_p}{\partial z}\vec{k})$。力指向势能下降最快的方向。

4.  **功能原理与机械能守恒定律**
    - **功能原理**：$W_{ext} + W_{non-cons} = \Delta E = \Delta(E_k + E_p)$。外力和非保守内力做功之和等于系统机械能的增量。
    - **机械能守恒定律**：
        - **条件**：$W_{ext} = 0$ 且 $W_{non-cons} = 0$（只有保守内力做功）。
        - **结论**：系统的机械能 $E = E_k + E_p = \text{恒量}$。

5.  **碰撞**
    - **恢复系数**：$e = \frac{v_2 - v_1}{v_{10} - v_{20}}$ (碰后相对分离速度 / 碰前相对接近速度)。
    - **完全弹性碰撞** ($e=1$)：动量守恒，动能守恒。
    - **完全非弹性碰撞** ($e=0$)：动量守恒，碰后粘在一起，动能损失最大。
    - **非完全弹性碰撞** ($0<e<1$)：动量守恒，动能损失一部分。

**（二）题型归纳与解题技巧**

- **变力做功**：必须用积分 $W = \int F(x)dx$ 或 $W = \int \vec{F} \cdot d\vec{r}$ 求解。
- **机械能守恒应用**：关键在于**明确系统**和**判断守恒条件**。若条件满足，则只需考虑初、末状态的动能和势能，无需关心中间复杂的过程。

#### **第四章 角动量守恒定律**

**（一）核心概念与公式精析**

1.  **角动量 ($\vec{L}$)**
    - **定义**：$\vec{L} = \vec{r} \times \vec{p} = \vec{r} \times m\vec{v}$。矢量，方向由右手螺旋定则确定。
    - **对定轴的角动量**：$L_z = J_z\omega$，其中 $J_z$ 是转动惯量，$\omega$ 是角速度。

2.  **力矩 ($\vec{M}$)**
    - **定义**：$\vec{M} = \vec{r} \times \vec{F}$。矢量，是改变物体转动状态的原因。
    - **大小**：$M = rF\sin\theta = Fd$，其中 $d=r\sin\theta$ 为力臂。

3.  **角动量定理**
    - **微分形式**：$\vec{M}_{ext} = \frac{d\vec{L}}{dt}$。质点或质点系对某定点的角动量随时间的变化率等于系统所受对该点的**合外力矩**。
    - **积分形式**：$\int_{t_1}^{t_2} \vec{M}_{ext} dt = \vec{L}_2 - \vec{L}_1$。合外力矩的冲量矩等于角动量的增量。

4.  **角动量守恒定律**
    - **条件**：系统所受的对某定点的**合外力矩为零** ($\sum \vec{M}_{ext} = 0$)。
    - **结论**：系统对该定点的**总角动量保持不变** ($\vec{L} = \text{常矢量}$)。
    - **重要例子**：
        - **有心力场**：质点受有心力作用时，对力心的角动量守恒。这解释了开普勒第二定律（行星与太阳连线在相等时间内扫过相等面积）。
        - **生活中的例子**：滑冰运动员旋转时收回手臂（减小 $J$），转速 $\omega$ 增大；跳水运动员在空中抱膝（减小 $J$），可以翻腾更多圈。

**（二）题型归纳与解题技巧**

- **角动量计算**：务必明确**参考点**。$\vec{L} = \vec{r} \times m\vec{v}$，对于圆周运动，$L=mvr$。
- **守恒律应用**：与动量守恒类似，先**明确系统**和**参考点**，再**分析外力矩**。对于定轴转动，分析对转轴的合外力矩。

#### **第五章 刚体力学**

**（一）核心概念与公式精析**

1.  **刚体**：在力作用下，形状和大小都不发生变化的理想模型。其上任意两点间距离保持不变。

2.  **刚体定轴转动**
    - **转动惯量 ($J$)**：$J = \sum \Delta m_i r_i^2 = \int r^2 dm$。是刚体**转动惯性**的量度，与质量大小、质量分布和转轴位置有关。
    - **平行轴定理**：$J = J_c + md^2$。刚体对任意平行于过质心转轴的轴的转动惯量，等于对过质心轴的转动惯量加上 $md^2$。

3.  **刚体定轴转动定律**：$M_z = J_z\alpha$。合外力矩 = 转动惯量 × 角加速度。这是解决刚体转动问题的核心方程。

4.  **刚体转动的功与能**
    - **力矩的功**：$W = \int_{\theta_1}^{\theta_2} M_z d\theta$。
    - **转动动能**：$E_k = \frac{1}{2}J\omega^2$。
    - **重力势能**：$E_p = mgh_c$。一个刚体的重力势能等于其全部质量集中于**质心**时所具有的重力势能。
    - **动能定理**：$W_{ext} = \Delta E_k = \frac{1}{2}J\omega_2^2 - \frac{1}{2}J\omega_1^2$。

5.  **刚体平面平行运动**
    - **分解**：可视为**质心的平动** + **绕通过质心且垂直于运动平面的轴的转动**。
    - **动能**：$E_k = \frac{1}{2}mv_c^2 + \frac{1}{2}J_c\omega^2$ （柯尼希定理在刚体中的应用）。

6.  **进动 (回转运动)**
    - **现象**：高速自转的物体，其自转轴会绕着另一个轴缓慢旋转。
    - **原理**：$\vec{M} = \frac{d\vec{L}}{dt}$。重力矩 $\vec{M}$ 方向水平，始终垂直于角动量 $\vec{L}$（沿自转轴），因此只改变 $\vec{L}$ 的方向而不改变其大小，导致自转轴绕竖直轴进动。

**（二）题型归纳与解题技巧**

- **转动惯量计算**：掌握常见刚体（细杆、圆盘、圆环、球体）的转动惯量公式，并能灵活运用**平行轴定理**和**叠加原理**。
- **含刚体系统的守恒律**：
    - **机械能守恒**：若系统只有重力等保守力做功，则 $E = \frac{1}{2}mv_c^2 + \frac{1}{2}J_c\omega^2 + mgh_c = \text{恒量}$。
    - **角动量守恒**：若系统对定轴合外力矩为零，则 $\sum J_i\omega_i = \text{恒量}$。

#### **第六章 流体力学简介**

**（一）核心概念与公式精析**

1.  **理想流体**：**不可压缩**（密度 $\rho$ 为常数）且**无黏性**（内部无摩擦力）的流体模型。

2.  **连续性原理**
    - **物理意义**：质量守恒在流体力学中的体现。
    - **公式**：对于不可压缩流体作定常流动，$S_1v_1 = S_2v_2 = \text{常量}$。截面积小的地方，流速大。

3.  **伯努利方程**
    - **物理意义**：机械能守恒在理想流体作定常流动中的体现。
    - **公式**：$P + \frac{1}{2}\rho v^2 + \rho gh = \text{常量}$。
    - **各项含义**：$P$ 是压强能密度，$\frac{1}{2}\rho v^2$ 是动能密度，$\rho gh$ 是势能密度。沿同一条流线，三者之和保持不变。
    - **重要推论**：同一水平高度 ($h_1=h_2$)，流速大（窄处）的地方压强小。这是飞机机翼升力、喷雾器等的原理。

**（二）题型归纳与解题技巧**

- **典型应用**：取两个特征点（如液面和管口），应用伯努利方程和连续性方程联立求解。

#### **第七章 相对论**

**（一）核心概念与公式精析**

1.  **爱因斯坦的两个基本假设**
    - **相对性原理**：物理定律在所有惯性系中都相同。
    - **光速不变原理**：真空中的光速 $c$ 对所有惯性系中的观察者都相同，与光源运动无关。

2.  **洛伦兹变换**
    - **核心**：联系两个相对运动惯性系 ($S$ 和 $S'$) 的时空坐标变换。
    - **正变换** ($S \to S'$，$S'$ 相对 $S$ 以速度 $u$ 沿 $x$ 轴正方向运动)：
        - $x' = \gamma(x - ut)$
        - $y' = y$
        - $z' = z$
        - $t' = \gamma(t - \frac{u}{c^2}x)$
        其中 $\gamma = \frac{1}{\sqrt{1 - u^2/c^2}}$ 为洛伦兹因子。

3.  **相对论时空观**
    - **同时的相对性**：在一个惯性系中同时异地发生的两个事件，在另一个惯性系中**不同时**。
    - **时间延缓**：运动的时钟变慢。$\Delta t = \gamma \Delta t_0$。其中 $\Delta t_0$ 是**固有时**（同一地点发生两事件的时间间隔），是最短的。
    - **长度收缩**：运动的物体在运动方向上的长度变短。$L = \frac{L_0}{\gamma}$。其中 $L_0$ 是**固有长度**（物体静止时的长度），是最长的。

4.  **相对论动力学基础**
    - **质速关系**：$m = \gamma m_0$。速度越大，质量越大。
    - **动量**：$\vec{p} = m\vec{v} = \gamma m_0\vec{v}$。
    - **质能关系**：$E = mc^2 = \gamma m_0c^2$。
        - 静止能量：$E_0 = m_0c^2$
        - 动能：$E_k = E - E_0 = (\gamma - 1)m_0c^2$
    - **能量-动量关系**：$E^2 = p^2c^2 + m_0^2c^4$。

**（二）题型归纳与解题技巧**

- **固有时与固有长度**：解题的关键是**正确识别**哪个观察者测量的是固有时（发生在同一地点）和固有长度（相对其静止）。
- **区分事件坐标和长度**：计算长度必须**同时**测量两端的坐标。应用洛伦兹变换计算空间和时间间隔时，公式为 $\Delta x' = \gamma(\Delta x - u\Delta t)$ 和 $\Delta t' = \gamma(\Delta t - \frac{u}{c^2}\Delta x)$。
