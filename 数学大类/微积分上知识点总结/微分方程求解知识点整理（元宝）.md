### **微分方程 (Differential Equation, DE) 求解全知识梳理**

  

#### **第一部分：基本概念与预备知识**

  

1.  **定义**：含有未知函数及其导数的方程。

2.  **阶数**：方程中出现的未知函数的最高阶导数的阶数。

3.  **线性与非线性**：

    *   **线性微分方程**：未知函数及其各阶导数都是一次的，且系数仅依赖于自变量。一般形式为：

        $a_n(x)y^{(n)} + a_{n-1}(x)y^{(n-1)} + \dots + a_1(x)y' + a_0(x)y = f(x)$

    *   **非线性微分方程**：不满足上述线性条件的方程（如出现 $y^2$, $\sin y$, $(y')^2$ 等）。

4.  **解的类型**：

    *   **通解**：含有任意常数，且任意常数的个数与微分方程的阶数相同。它代表一族曲线。

    *   **特解**：通过给定初始条件（初值问题）或边界条件（边值问题），确定了通解中任意常数后得到的唯一解。它代表一条特定的曲线。

    *   **奇解**：有些微分方程的解不能通过给通解中的任意常数赋值得到，称为奇解。通常与包络线有关。

5.  **主要类型**：

    *   **可分离变量方程**

    *   **一阶线性微分方程**

    *   **齐次方程**

    *   **伯努利方程**

    *   **全微分方程**

    *   **高阶常系数线性微分方程**

    *   **欧拉方程**

  

---

  

#### **第二部分：一阶微分方程**

  

##### **1. 可分离变量方程**

*   **标准形式**：$\frac{dy}{dx} = f(x)g(y)$ 或 $M_1(x)N_1(y)dx + M_2(x)N_2(y)dy = 0$

*   **解法**：将变量分离到等式两边，然后两边积分。

    $\int \frac{1}{g(y)} dy = \int f(x) dx$

*   **注意**：若 $g(y)=0$ 有实根，则这些根也是方程的解（可能是奇解）。

*   **例**：$\frac{dy}{dx} = xy$ → $\frac{dy}{y} = x dx$ → $\ln|y| = \frac{x^2}{2} + C$

  

##### **2. 一阶线性微分方程**

*   **标准形式**：$y' + P(x)y = Q(x)$

*   **解法**：**常数变易法** 或直接使用 **公式法**。

    *   **通解公式**：

      $y = e^{-\int P(x)dx} \left( \int Q(x)e^{\int P(x)dx} dx + C \right)$

    *   **步骤**：

        1.  计算积分因子：$\mu(x) = e^{\int P(x)dx}$

        2.  将方程两边乘以 $\mu(x)$：$\mu(x)y' + \mu(x)P(x)y = \mu(x)Q(x)$，即 $[ \mu(x) y ]' = \mu(x)Q(x)$

        3.  两边积分：$\mu(x)y = \int \mu(x)Q(x) dx + C$

        4.  解出 $y$。

*   **例**：$y' + \frac{1}{x}y = x^2$ → $P(x)=\frac{1}{x}, Q(x)=x^2$ → 积分因子 $\mu(x)=e^{\int \frac{1}{x}dx}=x$ → $xy = \int x^3 dx = \frac{x^4}{4} + C$ → $y = \frac{x^3}{4} + \frac{C}{x}$

  

##### **3. 齐次方程**

*   **标准形式**：$\frac{dy}{dx} = f\left(\frac{y}{x}\right)$

*   **解法**：**变量代换法**。令 $u = \frac{y}{x}$，则 $y = ux$，$\frac{dy}{dx} = u + x\frac{du}{dx}$。

    *   代入原方程得：$u + x\frac{du}{dx} = f(u)$

    *   化为可分离变量方程：$x\frac{du}{dx} = f(u) - u$

    *   分离变量求解，最后将 $u = \frac{y}{x}$ 代回。

*   **例**：$\frac{dy}{dx} = \frac{y}{x} + \tan\frac{y}{x}$ → 令 $u=\frac{y}{x}$ → $u + x\frac{du}{dx} = u + \tan u$ → $x\frac{du}{dx} = \tan u$ → $\cot u du = \frac{dx}{x}$ → ...

  

##### **4. 伯努利方程**

*   **标准形式**：$y' + P(x)y = Q(x)y^n$ ($n \neq 0, 1$)

*   **解法**：**变量代换法**。当 $n=0$ 或 $n=1$ 时，方程为一阶线性或可分离变量。

    *   两边同时除以 $y^n$：$y^{-n}y' + P(x)y^{1-n} = Q(x)$

    *   令 $z = y^{1-n}$，则 $\frac{dz}{dx} = (1-n)y^{-n}\frac{dy}{dx}$。

    *   原方程化为关于 $z$ 的一阶线性方程：$\frac{1}{1-n}z' + P(x)z = Q(x)$，即 $z' + (1-n)P(x)z = (1-n)Q(x)$。

    *   按一阶线性方程的解法求解 $z$，再代回 $y=z^{\frac{1}{1-n}}$。

*   **例**：$y' - \frac{2}{x}y = x^2y^2$ ($n=2$) → 令 $z=y^{-1}$，$z'=-y^{-2}y'$ → $-z' - \frac{2}{x}z = x^2$ → $z' + \frac{2}{x}z = -x^2$ → ...

  

##### **5. 全微分方程**

*   **标准形式**：$P(x,y)dx + Q(x,y)dy = 0$，且满足 $\frac{\partial P}{\partial y} = \frac{\partial Q}{\partial x}$。

*   **解法**：

    1.  **判断**：验证 $\frac{\partial P}{\partial y} = \frac{\partial Q}{\partial x}$ 是否成立。

    2.  **求原函数 $u(x,y)$**：

        *   **方法一（偏积分）**：$u(x,y) = \int P(x,y) dx + \varphi(y)$，对 $y$ 求偏导并与 $Q$ 比较以确定 $\varphi(y)$。

        *   **方法二（曲线积分法）**：$u(x,y) = \int_{(x_0,y_0)}^{(x,y)} Pdx + Qdy$（常用折线路径）。

    3.  **写出通解**：$u(x,y) = C$。

*   **积分因子**：若方程不是全微分方程，有时可以找到一个函数 $\mu(x,y)$，使得 $\mu P dx + \mu Q dy = 0$ 成为全微分方程。寻找积分因子没有通用方法，常见情况：

    *   若 $\frac{1}{Q}(\frac{\partial P}{\partial y} - \frac{\partial Q}{\partial x})$ 仅为 $x$ 的函数，则积分因子 $\mu = \mu(x)$。

    *   若 $\frac{1}{P}(\frac{\partial Q}{\partial x} - \frac{\partial P}{\partial y})$ 仅为 $y$ 的函数，则积分因子 $\mu = \mu(y)$。

#### **第三部分：高阶微分方程**

  

##### **1. 可降阶的高阶微分方程**

  

这类方程的特点是右端不含未知函数 $y$ 或某些低阶导数。

  

*   **(1) $y^{(n)} = f(x)$ 型**

    *   **特点**：方程只含自变量 $x$ 和最高阶导数。

    *   **解法**：连续积分 $n$ 次即可。每次积分引入一个任意常数。

    *   **例**：$y''' = e^{2x} - \cos x$ → $y'' = \frac{1}{2}e^{2x} - \sin x + C_1$ → ...

  

*   **(2) $F(x, y', y'') = 0$ 型（不显含 $y$）**

    *   **特点**：方程中缺少未知函数 $y$。

    *   **解法**：令 $p = y'$，则 $y'' = p'$。原方程化为关于 $p$ 和 $x$ 的一阶方程 $F(x, p, p') = 0$。求出 $p = \phi(x, C_1)$，再由 $y' = \phi(x, C_1)$ 积分得通解。

    *   **例**：$(1+x^2)y'' = 2xy'$ → 令 $p=y'$，$p'=\frac{2xp}{1+x^2}$ → 可分离变量求解 $p$。

  

*   **(3) $F(y, y', y'') = 0$ 型（不显含 $x$）**

    *   **特点**：方程中缺少自变量 $x$。

    *   **解法**：令 $p = y'$，则 $y'' = \frac{dp}{dx} = \frac{dp}{dy} \cdot \frac{dy}{dx} = p\frac{dp}{dy}$。原方程化为关于 $p$ 和 $y$ 的一阶方程 $F(y, p, p\frac{dp}{dy}) = 0$。求出 $p = \phi(y, C_1)$，再由 $y' = \phi(y, C_1)$ 分离变量求解。

    *   **例**：$yy'' - (y')^2 = 0$ → 令 $p=y'$，$y''=p\frac{dp}{dy}$ → $yp\frac{dp}{dy} - p^2 = 0$ → $p(y\frac{dp}{dy} - p) = 0$ → ...

  

##### **2. 高阶线性微分方程理论（核心基础）**

  

考虑 $n$ 阶线性微分方程：

$y^{(n)} + a_{n-1}(x)y^{(n-1)} + \dots + a_1(x)y' + a_0(x)y = f(x)$

  

*   **存在唯一性定理**：在系数 $a_i(x)$ 和 $f(x)$ 连续的区间上，给定初始条件 $y(x_0)=y_0, y'(x_0)=y'_0, ..., y^{(n-1)}(x_0)=y_0^{(n-1)}$，方程存在唯一解。

*   **齐次方程解的结构**：

    *   **叠加原理**：若 $y_1, y_2, ..., y_k$ 是方程的解，则它们的线性组合 $C_1y_1 + C_2y_2 + ... + C_ky_k$ 也是解。

    *   **线性相关与无关**：若存在不全为零的常数 $k_i$ 使 $k_1y_1+...+k_ny_n \equiv 0$，则称这组解线性相关；否则线性无关。**朗斯基行列式 (Wronski Determinant)** $Wx = \begin{vmatrix} y_1 & \dots & y_n \\ y_1' & \dots & y_n' \\ \vdots & & \vdots \\ y_1^{(n-1)} & \dots & y_n^{(n-1)} \end{vmatrix} \neq 0$ 是线性无关的充分必要条件。

    *   **通解结构**：若 $y_1, y_2, ..., y_n$ 是 $n$ 阶齐次线性方程的 $n$ 个线性无关的特解，则其线性组合 $y = C_1y_1 + C_2y_2 + ... + C_ny_n$ 是该齐次方程的**通解**。

*   **非齐次方程解的结构**：

    *   **通解结构**：非齐次方程的通解 = 对应的齐次方程的通解 + 非齐次方程的一个特解。

      即 $y = Y + y^*$，其中 $Y$ 是齐次通解，$y^*$ 是非齐次特解。

    *   **叠加原理（用于 $f(x)$ 为和的形式）**：若 $y_1^*$ 是 $y^{(n)}+...+a_0y=f_1(x)$ 的特解，$y_2^*$ 是 $y^{(n)}+...+a_0y=f_2(x)$ 的特解，则 $y_1^* + y_2^*$ 是 $y^{(n)}+...+a_0y=f_1(x)+f_2(x)$ 的特解。

  

##### **3. 常系数线性微分方程**

  

当系数 $a_i(x)$ 为常数时，称为常系数线性微分方程。其解法系统化，是重点。

  

*   **(1) 常系数齐次线性微分方程**

    *   **标准形式**：$y^{(n)} + a_{n-1}y^{(n-1)} + \dots + a_1y' + a_0y = 0$

    *   **解法**：**特征方程法**。

        1.  写出特征方程：$r^n + a_{n-1}r^{n-1} + \dots + a_1r + a_0 = 0$

        2.  求出特征根 $r_1, r_2, ..., r_n$。

        3.  根据特征根的不同情况，写出通解：

            *   **单实根 $r$**：对应一项 $Ce^{rx}$

            *   **k重实根 $r$**：对应 $k$ 项 $e^{rx}(C_1 + C_2x + ... + C_kx^{k-1})$

            *   **一对单复根 $r = \alpha \pm i\beta$**：对应两项 $e^{\alpha x}(C_1\cos\beta x + C_2\sin\beta x)$

            *   **一对k重复根 $r = \alpha \pm i\beta$**：对应 $2k$ 项 $e^{\alpha x}[(C_1 + C_2x + ... + C_kx^{k-1})\cos\beta x + (D_1 + D_2x + ... + D_kx^{k-1})\sin\beta x]$

    *   **例**：$y'' - 3y' + 2y = 0$ → 特征方程 $r^2-3r+2=0$ → 根 $r_1=1, r_2=2$ → 通解 $y = C_1e^x + C_2e^{2x}$

  

*   **(2) 常系数非齐次线性微分方程**

    *   **标准形式**：$y^{(n)} + ... + a_0y = f(x)$

    *   **解法**：通解 = 齐次通解 $Y$ + 非齐次特解 $y^*$。关键在于求 $y^*$。

    *   **求特解 $y^*$ 的方法**：**待定系数法**（适用于 $f(x)$ 是多项式、指数函数、$Sine/Cosine$ 函数及其乘积形式）。

        *   **步骤**：

            1.  根据 $f(x)$ 的形式和特征根的情况，**设定特解 $y^*$ 的形式**（注意要与齐次解区分开，若设定的形式与齐次解重复，需乘以 $x^k$，$k$ 是重复的最小次数）。

            2.  将设定的 $y^*$ 代入原非齐次方程，确定其中的待定系数。

        *   **常见 $f(x)$ 形式及对应特解设定**：

            | $f(x)$ 形式 | 特解 $y^*$ 设定形式 (设 $P_m(x)$ 为 m 次多项式) | 说明 |

            | :--- | :--- | :--- |

            | $P_m(x)$ | $x^k Q_m(x)$ | $k$ 是 0 是否为特征根的重数 |

            | $P_m(x)e^{\lambda x}$ | $x^k Q_m(x)e^{\lambda x}$ | $k$ 是 $\lambda$ 作为特征根的重数 |

            | $e^{\alpha x}[P_l(x)\cos\beta x + P_n(x)\sin\beta x]$ | $x^k e^{\alpha x}[R_m^{(1)}(x)\cos\beta x + R_m^{(2)}(x)\sin\beta x]$ | $m=\max(l,n)$，$k$ 是 $\alpha \pm i\beta$ 作为特征根的重数 |

  

    *   **例 1**：$y'' - 3y' + 2y = x^2$ → $f(x)=x^2$，$0$ 不是特征根 ($k=0$) → 设 $y^* = Ax^2+Bx+C$ → 代入求系数。

    *   **例 2**：$y'' - 3y' + 2y = e^x$ → $f(x)=e^x$，$\lambda=1$ 是单特征根 ($k=1$) → 设 $y^* = Axe^x$ → 代入求系数。

    *   **例 3**：$y'' + y = x\cos 2x$ → $f(x)=x\cos 2x$，$\pm 2i$ 不是特征根 ($k=0$) → 设 $y^* = (Ax+B)\cos 2x + (Cx+D)\sin 2x$ → 代入求系数。

  

    *   **其他求特解方法**：**常数变易法**（适用于 $f(x)$ 形式复杂或无法使用待定系数法的情况）。思路是将齐次通解 $Y = C_1y_1 + ... + C_ny_n$ 中的任意常数 $C_i$ 变为待定函数 $v_i(x)$，即设 $y^* = v_1y_1 + ... + v_ny_n$，通过解方程组确定 $v_i'(x)$，再积分得到 $v_i(x)$。

  

##### **4. 欧拉方程 (Euler-Cauchy Equation)**

*   **标准形式**：$x^n y^{(n)} + a_{n-1}x^{n-1}y^{(n-1)} + \dots + a_1xy' + a_0y = f(x)$ ($x>0$)

*   **解法**：**变量代换法**。令 $x = e^t$（或 $t = \ln x$），可将欧拉方程化为以 $t$ 为自变量的常系数线性微分方程。

    *   利用算子变换：$xy' = \frac{dy}{dt}$, $x^2y'' = \frac{d^2y}{dt^2} - \frac{dy}{dt}$, $x^3y''' = \frac{d^3y}{dt^3} - 3\frac{d^2y}{dt^2} + 2\frac{dy}{dt}$，以此类推。

    *   代入原方程，得到一个关于 $y(t)$ 的常系数方程，用前述方法求解后，将 $t = \ln x$ 代回。

*   **例**：$x^2y'' + xy' - y = 0$ → 令 $x=e^t$ → $y''(t)-y'(t) + y'(t) - y = 0$ → $y''(t) - y(t) = 0$ → 特征根 $\pm 1$ → $y(t) = C_1e^t + C_2e^{-t}$ → $y(x) = C_1x + \frac{C_2}{x}$。

#### **第四部分：微分方程的应用与总结**

  

1.  **应用建模**：将实际问题（如几何、物理、生物、经济等）转化为微分方程模型。

    *   **几何**：已知切线斜率、曲率等。

    *   **物理**：牛顿第二定律 $F=ma$、电路中的基尔霍夫定律、热传导方程等。

    *   **生物/人口**：增长率模型（马尔萨斯模型、逻辑斯谛模型）。

    *   **方法**：分析微元变化关系，建立包含导数项的等式。

  

2.  **解题策略总结**：

    *   **识别类型**：拿到方程，首先判断其属于哪一类（阶数、线性/非线性、常系数/变系数、特殊形式）。

    *   **优先尝试简单方法**：对于一阶方程，先看能否分离变量，再看是否线性、齐次、伯努利等。

    *   **高阶方程**：先看是否能降阶。对于常系数线性方程，毫不犹豫地使用特征方程法和待定系数法。

    *   **活用理论**：深刻理解解的结构理论（叠加原理、齐次通解+特解），它是所有解法的基石。

    *   **多练习**：微分方程的技巧性较强，需要通过大量练习来熟悉各种题型和解法。

  

这份整理力求全面，涵盖了大学本科阶段微分方程课程的核心求解方法。掌握这些内容，足以应对绝大多数常规的微分方程求解问题。
