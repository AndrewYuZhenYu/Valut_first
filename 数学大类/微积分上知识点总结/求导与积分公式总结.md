# 微积分常用公式速查表

  

## 一、基本求导公式

  

### 1. 常数和基本幂函数

\[

\frac{d}{dx}(c) = 0

\]

\[

\frac{d}{dx}(x^n) = nx^{n-1} \quad (n \in \mathbb{R})

\]

  

### 2. 指数函数和对数函数

\[

\frac{d}{dx}(e^x) = e^x

\]

\[

\frac{d}{dx}(a^x) = a^x \ln a \quad (a>0, a\neq 1)

\]

\[

\frac{d}{dx}(\ln x) = \frac{1}{x}, \quad x>0

\]

\[

\frac{d}{dx}(\log_a x) = \frac{1}{x\ln a}

\]

  

### 3. 三角函数

\[

\frac{d}{dx}(\sin x) = \cos x

\]

\[

\frac{d}{dx}(\cos x) = -\sin x

\]

\[

\frac{d}{dx}(\tan x) = \sec^2 x

\]

\[

\frac{d}{dx}(\cot x) = -\csc^2 x

\]

\[

\frac{d}{dx}(\sec x) = \sec x \tan x

\]

\[

\frac{d}{dx}(\csc x) = -\csc x \cot x

\]

  

### 4. 反三角函数

\[

\frac{d}{dx}(\arcsin x) = \frac{1}{\sqrt{1-x^2}}, \ |x|<1

\]

\[

\frac{d}{dx}(\arccos x) = -\frac{1}{\sqrt{1-x^2}}

\]

\[

\frac{d}{dx}(\arctan x) = \frac{1}{1+x^2}

\]

\[

\frac{d}{dx}(\mathrm{arccot}\, x) = -\frac{1}{1+x^2}

\]

\[

\frac{d}{dx}(\mathrm{arcsec}\, x) = \frac{1}{|x|\sqrt{x^2-1}}, \ |x|>1

\]

\[

\frac{d}{dx}(\mathrm{arccsc}\, x) = -\frac{1}{|x|\sqrt{x^2-1}}

\]

  

### 5. 双曲函数

\[

\frac{d}{dx}(\sinh x) = \cosh x

\]

\[

\frac{d}{dx}(\cosh x) = \sinh x

\]

\[

\frac{d}{dx}(\tanh x) = \mathrm{sech}^2 x

\]

\[

\frac{d}{dx}(\coth x) = -\mathrm{csch}^2 x

\]

\[

\frac{d}{dx}(\mathrm{sech}\, x) = -\mathrm{sech}\, x \tanh x

\]

\[

\frac{d}{dx}(\mathrm{csch}\, x) = -\mathrm{csch}\, x \coth x

\]

## 二、求导法则

  

- **四则运算**

\[

(u\pm v)' = u' \pm v'

\]

\[

(uv)' = u'v + uv'

\]

\[

\left(\frac{u}{v}\right)' = \frac{u'v - uv'}{v^2}, \ v\neq 0

\]

  

- **链式法则**

\[

\frac{d}{dx}f(g(x)) = f'(g(x)) \cdot g'(x)

\]

  

- **反函数求导**

\[

(f^{-1})'(x) = \frac{1}{f'(f^{-1}(x))}

\]

  

- **隐函数求导**：对方程两边对 \(x\) 求导，解出 \(\frac{dy}{dx}\)。

  

- **参数方程求导**

\[

\frac{dy}{dx} = \frac{\frac{dy}{dt}}{\frac{dx}{dt}}

\]

\[

\frac{d^2y}{dx^2} = \frac{\frac{d}{dt}\left(\frac{dy}{dx}\right)}{\frac{dx}{dt}}

\]
