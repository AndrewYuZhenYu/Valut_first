## 一、 不定积分：

好的，我们进一步深化。不定积分不仅是公式的堆砌，更是一套严密的**数学变换逻辑**。为了达到极致的详细，我将从**理论深度、分类题型的专项突破、以及极易被忽视的“骚操作”技巧**三个维度进行全方位扩充。

---

### 一、 理论深度进阶：原函数存在定理与性质

#### 1. 原函数存在定理

并不是所有的函数都有不定积分。

- **连续必存在**：如果 $f(x)$ 在区间 $I$ 上连续，则 $f(x)$ 在该区间内一定存在原函数。
    
- **含有第一类间断点（跳跃、可去）**：在该区间内一定**没有**原函数。
    
- **含有无穷间断点**：也一定没有原函数。
    

> **结论**：原函数如果存在，它一定是**处处可导的连续函数**。

#### 2. 积分常数 $C$ 的物理意义

在物理学中，不定积分代表了某种“状态的累积”。$C$ 通常由**初始条件**决定。例如，已知速度 $v(t)$ 求位移 $s(t)$，$\int v(t)dt = s(t) + C$，这里的 $C$ 就是初始时刻的位移 $s(0)$。

### 二、 第一类换元法（凑微分）的“十六字诀”

凑微分的核心在于：**观察结构，内聚外放，整体代换，一气呵成**。

#### 常用凑微分对照表（实战高频）

为了提高解题速度，以下变换必须形成肌肉记忆：

|**被积表达式包含**|**凑微分目标**|**变换公式**|
|---|---|---|
|$\ln x$ 与 $\frac{1}{x}$|$d(\ln x)$|$\int \frac{\ln^n x}{x} dx = \int \ln^n x d(\ln x)$|
|$e^x$|$d(e^x)$|$\int e^{e^x} e^x dx = \int e^{e^x} d(e^x)$|
|$\sin x, \cos x$|$d(\sin x)$ 或 $d(\cos x)$|$\int \sin^n x \cos x dx = \int \sin^n x d(\sin x)$|
|$\arctan x$ 与 $\frac{1}{1+x^2}$|$d(\arctan x)$|$\int \frac{1}{(1+x^2)\arctan x} dx = \int \frac{1}{\arctan x} d(\arctan x)$|
|$\sqrt{x}$ 与 $\frac{1}{\sqrt{x}}$|$d(\sqrt{x})$|$\frac{1}{\sqrt{x}}dx = 2d(\sqrt{x})$|

### 三、 第二类换元法：针对“根号”的专项手术

当凑微分失效时，我们需要通过**变量置换**把复杂的根式“拔掉”。

#### 1. 三角代换的深度细节

我们在使用三角代换（如 $x = a\sin t$）时，必须注意参数 $t$ 的**取值范围**，以确保函数是一一对应的（通常取主值区间，如 $t \in [-\frac{\pi}{2}, \frac{\pi}{2}]$），这样在最后一步代回变量 $x$ 时，利用直角三角形辅助图才不会出错。

#### 2. 倒代换（Reciprocal Substitution）

适用场景：分母的幂次比分子高出 2 次或以上，或者被积函数含有 $\frac{1}{x\sqrt{ax^2+bx+c}}$。

方法：令 $x = \frac{1}{t}$，则 $dx = -\frac{1}{t^2}dt$。

神奇之处：它能把分母中高次的 $x$ 提到分子上，往往能化简复杂的根号。

---

### 四、 分部积分法：不仅仅是“反对幂三指”

#### 1. 常见类型与策略

- **升幂型**：$\int x^n \ln x dx$。选 $u = \ln x$，目的是通过微分让 $\ln x$ 消失。
    
- **降幂型**：$\int x^n e^x dx$。选 $u = x^n$，目的是通过多次微分让 $x^n$ 最终变成常数。
    
- **循环型（回生型）**：$\int e^x \sin x dx$。
    
    - 这类积分无论选谁做 $u$ 都会循环。
        
    - **技巧**：连续使用两次分部积分，会出现与原积分相同的项，然后通过解方程的方法把积分值解出来。
        

#### 2. 表格法（Tabular Integration）—— 考场提速神器

当你遇到 $\int P_n(x) \sin ax dx$ 或 $\int P_n(x) e^{ax} dx$（$P_n$ 为高次多项式）时，手动分部积分极易出错。

表格法步骤：

1. 左列写 $P(x)$，不断求导直到为 0。
    
2. 右列写三角/指数函数，不断求积分。
    
3. 对角线相乘，符号按 $+ - + -$ 交替排列。

### 五、 有理函数积分：拆解艺术

对于 $\int \frac{P(x)}{Q(x)} dx$，如果分母 $Q(x)$ 可以分解因式，我们使用**待定系数法**。

#### 分解规则表

|**分母因式情况**|**分解出的项**|
|---|---|
|单实根 $(x-a)$|$\frac{A}{x-a}$|
|重实根 $(x-a)^k$|$\frac{A_1}{x-a} + \frac{A_2}{(x-a)^2} + \dots + \frac{A_k}{(x-a)^k}$|
|二次不可约因式 $(x^2+px+q)$|$\frac{Ax+B}{x^2+px+q}$|

技巧：留数法（Cover-up Method）

在求简单分式的系数 $A$ 时，可以掩盖分母中对应的项，带入根值直接算出。这比解方程组快得多。

### 六、 两个特殊的“骨头”：欧拉代换与万能公式

#### 1. 欧拉代换 (Euler Substitutions)

处理 $\sqrt{ax^2+bx+c}$ 的终极武器（虽然计算量大，但它是万能的）：

- 若 $a > 0$，令 $\sqrt{ax^2+bx+c} = \pm\sqrt{a}x + t$
    
- 若 $c > 0$，令 $\sqrt{ax^2+bx+c} = xt \pm \sqrt{c}$
    

#### 2. 万能公式（Weierstrass Substitution）

令 $t = \tan \frac{x}{2}$，这是处理纯三角函数有理式（分母带 $\sin, \cos$ 加减常数）的底牌。

> **警示**：它是“万能”的，但往往也是“最繁”的。除非走投无路，否则先想凑微分或和差化积。

---

### 七、 总结：解题思维导图式流程

当你看到一个积分题，大脑应按以下路径检索：

1. **观察法**：是否是基本公式？是否能简单拆分？
    
2. **凑微分**：内部是否有某部分的导数在外面等着？（寻找 $g'(x)$）
    
3. **分部积分**：是否是两类不同性质函数的乘积？（反对幂三指）
    
4. **变量代换**：
    
    - 有根号？（根式代换或三角代换）
        
    - 分母复杂？（倒代换）
        
5. **有理化**：是否需要拆分分式？

### 八、 经典易错点与避坑指南

1. **分段函数的积分**：在连接点处，原函数必须**连续**。求出每一段的积分后，要通过调整 $C$ 的值使左右极限相等。
    
2. **符号陷阱**：$\int \frac{1}{x} dx = \ln |x| + C$，**必须加绝对值**！否则定义域会缩小，这在考试中是严重扣分点。
    
3. **根式化简**：$\sqrt{x^2} = |x|$。在不定积分中，如果题目没给区间，通常默认在使根式有意义的正值区间讨论，但严谨的题目需要考虑符号。

## 二、 定积分：高级技巧与进阶模型

### 1. 积分上限函数的导数 (Leibniz Rule)
这是考研的高频考点：
$$\frac{d}{dx} \int_{\psi(x)}^{\phi(x)} f(t,x) dt = f(\phi(x),x)\phi'(x) - f(\psi(x),x)\psi'(x) + \int_{\psi(x)}^{\phi(x)} \frac{\partial f}{\partial x} dt$$

### 2. 华里士公式 (Wallis / 点火公式)
$$\int_0^{\pi/2} \sin^n x dx = \int_0^{\pi/2} \cos^n x dx = \frac{(n-1)!!}{n!!} \cdot (\frac{\pi}{2} \text{ if } n \text{ is even})$$

### 3. 极限定律：定积分定义求和
当看到 $\lim_{n \to \infty} \sum_{i=1}^n \frac{1}{n} f(\frac{i}{n})$ 时，直接转化为 $\int_0^1 f(x) dx$。
* **变式**：若分母不是 $n$ 而是 $n^2, n^3$，则可能需要使用夹逼定理配合定积分。

### 4. 区间再现公式的威力
若 $f(x)$ 难以直接积分，尝试 $\int_a^b f(x) dx = \int_a^b f(a+b-x) dx$。
* **经典场景**：$\int_0^\pi \frac{x \sin x}{1+\cos^2 x} dx$。令 $x = \pi - t$，可以将分子上的 $x$ 消掉。

## 三、 反常积分：收敛性的判别算法 (Step-by-Step)

### 1. 无穷限反常积分 $\int_a^{+\infty} f(x)dx$
1.  **第一步**：观察 $x \to \infty$ 时 $f(x)$ 的数量级。
2.  **第二步**：若 $f(x) \sim \frac{1}{x^p}$：
    - $p > 1 \implies$ 收敛。
    - $p \le 1 \implies$ 发散。
3.  **注意**：若含有 $\ln x$，记住 $\ln x$ 跑得比任何 $x^\epsilon$ 都慢。

### 2. 瑕积分（无界函数）
1.  **第一步**：找出瑕点（使分母为 0 的点）。
2.  **第二步**：设瑕点为 $a$，观察 $x \to a^+$ 时 $f(x) \sim \frac{1}{(x-a)^p}$：
    - $p < 1 \implies$ 收敛。
    - $p \ge 1 \implies$ 发散。

## 四、 积分学的几何应用（建模方法）

### 1. 旋转体体积的“切法”
- **绕 $x$ 轴**：$V = \int \pi y^2 dx$。
- **绕 $y$ 轴**：
  - 方法A（圆环法）：$V = \int \pi x^2 dy$。
  - 方法B（柱壳法）：$V = 2\pi \int x y dx$ (推荐)。

### 2. 物理应用（微元法步骤）
1.  **选取变量**：一般选 $x$。
2.  **取微元**：$[x, x+dx]$。
3.  **写出微元表达式**：$dQ = f(x)dx$（如变力做功 $dW = F(x)dx$）。
4.  **求积**：$Q = \int_a^b f(x)dx$。

## 五、 易错陷阱 (The Red List)

- [ ] **常数项**：不定积分漏写 $+C$ 是最冤枉的扣分项。
- [ ] **绝对值**：$\int \frac{1}{x}dx = \ln|x| + C$，不要漏掉绝对值符号。
- [ ] **积分存在性**：在用牛顿-莱布尼茨公式前，必须确认函数在区间内**没有无穷断点**。
- [ ] **换元后的限**：定积分换元后，上、下限必须更新，或者最后换回原变量。
- [ ] **奇偶性前提**：必须是**对称区间**。不要在 $[0, 2\pi]$ 上对 $\sin x$ 说“奇函数积分为 0”。
