# 多元函数微分法及其应用 完整知识整理

## 一、多元函数的基本概念

### 1. 多元函数的定义
设 $D \subset \mathbb{R}^n$，若对 $D$ 中每个点 $P(x_1,\dots,x_n)$，按某种法则 $f$，有唯一实数 $u$ 与之对应，则称 $f$ 是 $D$ 上的 $n$ 元函数，记作  
$$u = f(P) = f(x_1,x_2,\dots,x_n).$$  
其中 $D$ 是定义域，$f(D)$ 是值域。

### 2. 平面点集的基本概念

- **邻域**：  
  $U(P_0, \delta) = \{ P \mid |P P_0| < \delta \}$  
  去心邻域：$\mathring{U}(P_0, \delta) = U(P_0, \delta) \setminus \{P_0\}$

- **内点、外点、边界点**：  
  对 $E \subset \mathbb{R}^n$：  
  - 内点：存在邻域 $U \subset E$  
  - 外点：存在邻域 $U \cap E = \varnothing$  
  - 边界点：任意邻域既有 $E$ 中点又有 $E^c$ 中点  
  - 聚点：任意去心邻域与 $E$ 相交  
  - 孤立点：$P \in E$ 但存在去心邻域与 $E$ 无交点  

- **开集、闭集、区域**：  
  - 开集：每个点都是内点  
  - 闭集：补集是开集  
  - 连通集：点集中任意两点可用全在 $E$ 中的折线连接  
  - 开区域：连通的开集  
  - 闭区域：开区域加边界  

### 3. 多元函数的极限

设 $f(P)$ 在 $D$ 上定义，$P_0$ 是 $D$ 的聚点。若 $\forall \varepsilon > 0, \exists \delta > 0$，使 $0 < |P P_0| < \delta$ 且 $P \in D$ 时，有 $|f(P) - A| < \varepsilon$，则称
$$\lim_{P \to P_0} f(P) = A.$$

> **注意**：要求沿**任何路径**趋近时极限相等。若沿不同路径得到不同极限值，则极限不存在。

**常用判断不存在的方法**：  
- 令 $y = kx$ 沿直线趋近，结果依赖 $k$  
- 令 $y = x^2$ 等特殊路径  

### 4. 多元函数的连续性

若  
$$\lim_{P \to P_0} f(P) = f(P_0)$$  
则称 $f$ 在 $P_0$ 连续。  
若在 $D$ 上每点连续，则称在 $D$ 上连续。

**性质**：  
- 连续函数的和、差、积、商（分母不为 0）仍连续  
- 复合函数连续  
- 闭区域上连续函数必有最大值、最小值，且一致连续

## 二、偏导数

### 1. 定义

对二元函数 $z = f(x,y)$：  
$$f_x(x_0,y_0) = \lim_{\Delta x \to 0} \frac{f(x_0+\Delta x, y_0) - f(x_0,y_0)}{\Delta x}$$  
$$f_y(x_0,y_0) = \lim_{\Delta y \to 0} \frac{f(x_0, y_0+\Delta y) - f(x_0,y_0)}{\Delta y}$$  
记作 $\frac{\partial z}{\partial x}$, $\frac{\partial z}{\partial y}$。

对 $n$ 元函数 $u = f(x_1,\dots,x_n)$：  
$$\frac{\partial f}{\partial x_i} = \lim_{h \to 0} \frac{f(x_1,\dots,x_i+h,\dots,x_n) - f(\dots)}{h}.$$

### 2. 高阶偏导数

$$\frac{\partial^2 f}{\partial x^2} = f_{xx}, \quad \frac{\partial^2 f}{\partial y^2} = f_{yy}$$  
$$\frac{\partial^2 f}{\partial x \partial y} = f_{xy} = \frac{\partial}{\partial y}\left( \frac{\partial f}{\partial x} \right)$$  
$$\frac{\partial^2 f}{\partial y \partial x} = f_{yx}$$

**定理（混合偏导与次序无关）**：  
若 $f_{xy}$ 和 $f_{yx}$ 在点 $P_0$ 处都连续，则 $f_{xy}(P_0) = f_{yx}(P_0)$。

## 三、全微分

### 1. 定义

对于 $z = f(x,y)$，若在 $(x_0,y_0)$ 的某邻域内  
$$\Delta z = f(x_0+\Delta x, y_0+\Delta y) - f(x_0,y_0) = A \Delta x + B \Delta y + o(\sqrt{(\Delta x)^2 + (\Delta y)^2})$$  
则称 $f$ 在 $(x_0,y_0)$ 可微，全微分为  
$$\mathrm{d}z = A \Delta x + B \Delta y = f_x(x_0,y_0) \mathrm{d}x + f_y(x_0,y_0) \mathrm{d}y.$$

**可微的必要条件**：可微 $\rightarrow$ 偏导存在，且 $A = f_x$，$B = f_y$。

**可微的充分条件**：若 $f_x, f_y$ 在 $(x_0,y_0)$ 邻域存在且在该点连续，则 $f$ 在该点可微。

### 2. 可微与连续、偏导的关系

- 可微 $\rightarrow$ 连续（因为 $\Delta z \to 0$）
- 可微 $\rightarrow$ 偏导存在
- 偏导存在 + 偏导连续 $\rightarrow$ 可微
- 偏导存在 不一定可微（反例：$f(x,y)=\frac{xy}{x^2+y^2}, f(0,0)=0$ 在 (0,0) 偏导存在，但不连续，故不可微）

## 四、多元复合函数求导法则（链式法则）

设 $z = f(u,v)$，$u = u(x,y)$，$v = v(x,y)$ 可微，则  
$$\frac{\partial z}{\partial x} = \frac{\partial z}{\partial u} \frac{\partial u}{\partial x} + \frac{\partial z}{\partial v} \frac{\partial v}{\partial x}$$  
$$\frac{\partial z}{\partial y} = \frac{\partial z}{\partial u} \frac{\partial u}{\partial y} + \frac{\partial z}{\partial v} \frac{\partial v}{\partial y}$$

推广到多个中间变量：  
$$\frac{\partial z}{\partial x_i} = \sum_{j=1}^m \frac{\partial z}{\partial u_j} \frac{\partial u_j}{\partial x_i}$$

## 五、隐函数求导

### 1. 一个方程情形

方程 $F(x,y) = 0$ 确定隐函数 $y = y(x)$：  
$$\frac{dy}{dx} = -\frac{F_x}{F_y} \quad (F_y \neq 0)$$

方程 $F(x,y,z) = 0$ 确定隐函数 $z = z(x,y)$：  
$$\frac{\partial z}{\partial x} = -\frac{F_x}{F_z}, \quad \frac{\partial z}{\partial y} = -\frac{F_y}{F_z}$$

### 2. 方程组情形

$$\begin{cases}
F(x,y,u,v) = 0 \\
G(x,y,u,v) = 0
\end{cases}$$  
确定 $u = u(x,y), v = v(x,y)$。  
对 $x$ 求偏导：  
$$F_x + F_u u_x + F_v v_x = 0$$  
$$G_x + G_u u_x + G_v v_x = 0$$  
解 $u_x, v_x$（雅可比行列式 $\frac{\partial(F,G)}{\partial(u,v)} \neq 0$）。

**雅可比行列式**：
$$\frac{\partial(F,G)}{\partial(u,v)} = \begin{vmatrix} F_u & F_v \\ G_u & G_v \end{vmatrix}$$

## 六、方向导数与梯度

### 1. 方向导数

设 $\vec{l} = (\cos\alpha, \cos\beta)$ 是方向余弦，则  
$$\frac{\partial f}{\partial l}\bigg|_{(x_0,y_0)} = \lim_{t \to 0^+} \frac{f(x_0 + t\cos\alpha, y_0 + t\cos\beta) - f(x_0,y_0)}{t}$$  
若 $f$ 可微，则  
$$\frac{\partial f}{\partial l} = f_x(x_0,y_0)\cos\alpha + f_y(x_0,y_0)\cos\beta$$

### 2. 梯度

$$\nabla f = \left( \frac{\partial f}{\partial x}, \frac{\partial f}{\partial y} \right)$$  
方向导数最大值：沿梯度方向，最大值为 $\| \nabla f \|$。

**梯度垂直于等值线（或等值面）**。

## 七、多元函数微分学的几何应用

### 1. 空间曲线的切线与法平面

曲线参数式 $\vec{r}(t) = (x(t), y(t), z(t))$，在 $t_0$ 处：  
切向量 $\vec{T} = (x'(t_0), y'(t_0), z'(t_0))$  
**切线方程**：  
$$\frac{x-x_0}{x'(t_0)} = \frac{y-y_0}{y'(t_0)} = \frac{z-z_0}{z'(t_0)}$$  
**法平面**：  
$$x'(t_0)(x-x_0) + y'(t_0)(y-y_0) + z'(t_0)(z-z_0) = 0$$

### 2. 空间曲面的切平面与法线

曲面 $F(x,y,z) = 0$，点 $P_0(x_0,y_0,z_0)$，法向量 $\vec{n} = (F_x, F_y, F_z)|_{P_0}$。  
**切平面**：  
$$F_x(P_0)(x-x_0) + F_y(P_0)(y-y_0) + F_z(P_0)(z-z_0) = 0$$  
**法线**：  
$$\frac{x-x_0}{F_x(P_0)} = \frac{y-y_0}{F_y(P_0)} = \frac{z-z_0}{F_z(P_0)}$$

曲面 $z = f(x,y)$ 即 $F(x,y,z) = f(x,y) - z = 0$：  
$$z - z_0 = f_x(x_0,y_0)(x-x_0) + f_y(x_0,y_0)(y-y_0)$$  
法向量 $(f_x, f_y, -1)$。

## 八、多元函数的极值

### 1. 无条件极值

**必要条件**：$f_x = 0, f_y = 0$（驻点）。

**充分条件（二元函数）**：  
令 $A = f_{xx}(x_0,y_0), B = f_{xy}(x_0,y_0), C = f_{yy}(x_0,y_0)$，  
$$\Delta = AC - B^2$$  
- $\Delta > 0$ 且 $A > 0$ $\rightarrow$ 极小值  
- $\Delta > 0$ 且 $A < 0$ $\rightarrow$ 极大值  
- $\Delta < 0$ $\rightarrow$ 不是极值（鞍点）  
- $\Delta = 0$ $\rightarrow$ 需进一步判断

### 2. 条件极值（拉格朗日乘数法）
---

###  1. 核心思想：切线与梯度

从几何上看，约束条件 $g(x, y) = 0$ 定义了平面上的一条曲线。我们在曲线上移动，寻找使 $f$ 取得最大或最小值的点。当极值发生时，$f$ 的等值线恰好与约束曲线 $g=0$ **相切**。

由于两个函数在某点相切，它们的**法向量（梯度）**必然共线。即：

$$\nabla f = \lambda \nabla g$$

其中 $\lambda$ 被称为 **Lagrange乘数**。

---

###  2. 二元函数（单个约束）

**问题描述：**

求 $z = f(x, y)$ 在约束 $g(x, y) = 0$ 下的极值。

**构造辅助函数（Lagrange函数）：**

$$L(x, y, \lambda) = f(x, y) + \lambda g(x, y)$$

**计算偏导并令其为零：**

我们需要解以下由三个方程组成的方程组：

$$\begin{cases} \dfrac{\partial L}{\partial x} = \dfrac{\partial f}{\partial x} + \lambda \dfrac{\partial g}{\partial x} = 0 \\ \dfrac{\partial L}{\partial y} = \dfrac{\partial f}{\partial y} + \lambda \dfrac{\partial g}{\partial y} = 0 \\ \dfrac{\partial L}{\partial \lambda} = g(x, y) = 0 \end{cases}$$

---

###  3. 多元函数（单个约束）

当变量推广到 $n$ 维时，逻辑是一致的。

**问题描述：**

目标函数：$u = f(x_1, x_2, \dots, x_n)$

约束条件：$g(x_1, x_2, \dots, x_n) = 0$

**构造方程组：**

$$\begin{cases} f_{x_1} + \lambda g_{x_1} = 0 \\ f_{x_2} + \lambda g_{x_2} = 0 \\ \vdots \\ f_{x_n} + \lambda g_{x_n} = 0 \\ g(x_1, x_2, \dots, x_n) = 0 \end{cases}$$

这总共有 $n+1$ 个方程，用以求解 $n+1$ 个未知数。

---

###  4. 多元函数（多个约束）

假设我们有多个约束条件：

**问题描述：**

目标函数：$f(x_1, x_2, \dots, x_n)$

约束条件：

1. $g_1(x_1, x_2, \dots, x_n) = 0$
    
2. $g_2(x_1, x_2, \dots, x_n) = 0$
    
3. $g_m(x_1, x_2, \dots, x_n) = 0$ （其中 $m < n$）
    

**构造辅助函数：**

我们需要为每一个约束引入一个乘数 $\lambda_i$：

$$L(x_1, \dots, x_n, \lambda_1, \dots, \lambda_m) = f + \sum_{i=1}^{m} \lambda_i g_i$$

**展开后的方程组：**

$$\begin{cases} \dfrac{\partial f}{\partial x_1} + \lambda_1 \dfrac{\partial g_1}{\partial x_1} + \lambda_2 \dfrac{\partial g_2}{\partial x_1} + \dots + \lambda_m \dfrac{\partial g_m}{\partial x_1} = 0 \\ \dfrac{\partial f}{\partial x_2} + \lambda_1 \dfrac{\partial g_1}{\partial x_2} + \lambda_2 \dfrac{\partial g_2}{\partial x_2} + \dots + \lambda_m \dfrac{\partial g_m}{\partial x_2} = 0 \\ \vdots \\ \dfrac{\partial f}{\partial x_n} + \lambda_1 \dfrac{\partial g_1}{\partial x_n} + \lambda_2 \dfrac{\partial g_2}{\partial x_n} + \dots + \lambda_m \dfrac{\partial g_m}{\partial x_n} = 0 \\ g_1(x_1, \dots, x_n) = 0 \\ g_2(x_1, \dots, x_n) = 0 \\ \vdots \\ g_m(x_1, \dots, x_n) = 0 \end{cases}$$

---

### 5. 总结与注意事项

- **必要而非充分条件：** 解出方程组得到的点只是**候选点**。
    
- **$\lambda$ 的符号：** 在构造时使用加号或减号均可，不影响最终解。
    
- **物理意义：** 在经济学中，$\lambda$ 常被称为“影子价格”，代表约束条件变动对目标值的影响。

求 $f(x,y)$ 在条件 $\varphi(x,y) = 0$ 下的极值：  
构造  
$$L(x,y,\lambda) = f(x,y) + \lambda \varphi(x,y)$$  
解  
$$\begin{cases}
\frac{\partial L}{\partial x} = f_x + \lambda \varphi_x = 0 \\
\frac{\partial L}{\partial y} = f_y + \lambda \varphi_y = 0 \\
\varphi(x,y) = 0
\end{cases}$$

**多个条件**：$\varphi_1 = 0, \dots, \varphi_k = 0$，构造  
$$L = f + \lambda_1 \varphi_1 + \dots + \lambda_k \varphi_k$$  
对每个变量（包括 $x_i$）求偏导 = 0，加上约束方程求解。

## 九、常用题型与方法总结

1. **求极限并判断是否存在**  
   - 极坐标 $x = r\cos\theta, y = r\sin\theta$  
   - 选择特殊路径（直线 $y=kx$，抛物线 $y=x^2$）

2. **求偏导与全微分**  
   - 按定义求  
   - 利用链式法则、隐函数求导

3. **判断可微性**  
   - 先看是否连续，再看偏导存在，再看 $\Delta z - f_x \Delta x - f_y \Delta y = o(\rho)$

4. **方向导数与梯度**  
   - 求方向导数直接用梯度点乘方向余弦  
   - 求最大变化率与方向

5. **几何应用**  
   - 曲线切线与法平面  
   - 曲面切平面与法线

6. **极值与最值**  
   - 无条件极值：找驻点，用 $AC-B^2$ 判定  
   - 条件极值：拉格朗日乘数法  
   - 闭区域最值：比较内部驻点与边界上的条件极值

7. **隐函数组求导**  
   - 联立方程，用雅可比行列式解  
   - 全微分法（两边同时微分，解出 $du, dv$）
