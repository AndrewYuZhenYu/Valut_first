## 课程背景与问题引入

### 要解决的核心问题

已知二维随机变量 $(X,Y)$ 的联合分布（联合分布列或联合密度），求它们的函数 $Z = g(X,Y)$ 的分布。

### 典型应用场景（系统寿命问题）

设两个元件的寿命分别为 $X, Y$，它们**相互独立同分布**。求系统寿命 $Z$ 的分布：

| 系统类型 | 示意 | $Z$ 的表达式 |
|---------|------|--------------|
| **串联系统** | 元件首尾相接，任何一个坏就整体坏 | $Z = \min(X, Y)$ |
| **并联系统** | 元件并行，全部坏才整体坏 | $Z = \max(X, Y)$ |
| **备用系统** | 主元件坏后备用元件启动 | $Z = X + Y$ |

本节就是要把这类问题系统化地解决。

### 本节四个专题

1. **一般情形**（分布函数法，万能方法）
2. **和的分布**（含重要的可加性结论）
3. **商的分布**
4. **极值的分布**（最大值、最小值）

## 一、一般情形 —— 分布函数法

这是求 $Z = g(X,Y)$ 分布的**通用方法**，不论 $g$ 是什么函数都能用。

### 解题步骤（四步法）

**第一步**：写出 $Z$ 的分布函数的定义
$$F_Z(z) = P(Z \le z) = P(g(X,Y) \le z)$$

**第二步**：把事件 $\{g(X,Y) \le z\}$ 转化为 $(X,Y)$ 平面上的区域
$$D_z = \{(x,y) : g(x,y) \le z\}$$

**第三步**：用联合密度求概率（连续型）
$$F_Z(z) = \iint_{D_z} f(x, y)\, dx\, dy$$

若为离散型：
$$F_Z(z) = \sum_{(x_i, y_j) \in D_z} p_{ij}$$

**第四步**：对 $z$ 求导得到密度
$$f_Z(z) = \frac{d}{dz} F_Z(z)$$

### 关键技巧

- **画图**！几乎所有题都要画出区域 $D_z$
- **分段讨论**：区域 $D_z$ 随 $z$ 变化的形状不同，要分段讨论 $z$ 的范围
- **注意联合密度的非零区域**和 $D_z$ 的交集才是真正的积分区域

## 二、和的分布 $Z = X+Y$

### 1. 离散型 —— 卷积求和

若 $X, Y$ 独立，$P(X = x_i) = p_i$，$P(Y = y_j) = q_j$，则
$$P(Z = z_k) = \sum_i P(X = x_i)\, P(Y = z_k - x_i)$$

### 2. 连续型 —— 卷积公式 ⭐

设 $(X, Y)$ 联合密度为 $f(x, y)$，$Z = X + Y$，则

$$\boxed{\ f_Z(z) = \int_{-\infty}^{+\infty} f(x,\ z-x)\, dx = \int_{-\infty}^{+\infty} f(z-y,\ y)\, dy \ }$$

**推导思路**：

$$F_Z(z) = P(X + Y \le z) = \iint_{x+y \le z} f(x,y)\, dx\, dy$$

积分区域是直线 $x+y = z$ 左下方的半平面。先对 $y$ 积分（$y$ 从 $-\infty$ 到 $z-x$），再对 $x$ 积分：

$$F_Z(z) = \int_{-\infty}^{+\infty} \left[ \int_{-\infty}^{z-x} f(x, y)\, dy \right] dx$$

对 $z$ 求导（求导穿过积分号，内层上限 $z-x$ 对 $z$ 求导为 1）：

$$f_Z(z) = \int_{-\infty}^{+\infty} f(x,\ z-x)\, dx$$

### 3. 独立情形下的卷积公式

若 $X, Y$ **独立**，则 $f(x, y) = f_X(x)\, f_Y(y)$，卷积公式化为：

$$\boxed{\ f_Z(z) = \int_{-\infty}^{+\infty} f_X(x)\, f_Y(z - x)\, dx = (f_X * f_Y)(z) \ }$$

### 4. 三个重要可加性结论 ⭐⭐⭐（必背）

#### (1) 正态分布的可加性

若 $X \sim N(\mu_1, \sigma_1^2)$，$Y \sim N(\mu_2, \sigma_2^2)$，**且 $X, Y$ 独立**，则

$$X + Y \sim N(\mu_1 + \mu_2,\ \sigma_1^2 + \sigma_2^2)$$

**一般线性组合**：对任意常数 $a, b, c$，

$$aX + bY + c \sim N(a\mu_1 + b\mu_2 + c,\ a^2 \sigma_1^2 + b^2 \sigma_2^2)$$

**推广到 $n$ 个独立正态**：$X_i \sim N(\mu_i, \sigma_i^2)$ 相互独立，则

$$\sum_{i=1}^n c_i X_i \sim N\left(\sum_{i=1}^n c_i \mu_i,\ \sum_{i=1}^n c_i^2 \sigma_i^2\right)$$

> **考研高频考点**，几乎每年都考。

#### (2) 泊松分布的可加性

若 $X \sim P(\lambda_1)$，$Y \sim P(\lambda_2)$ 独立，则

$$X + Y \sim P(\lambda_1 + \lambda_2)$$

#### (3) Gamma 分布的可加性

若 $X \sim \Gamma(\alpha_1, \beta)$，$Y \sim \Gamma(\alpha_2, \beta)$ 独立（**要求同尺度参数 $\beta$**），则

$$X + Y \sim \Gamma(\alpha_1 + \alpha_2,\ \beta)$$

**推论**（由此可推出）：

- $n$ 个独立同分布 $\text{Exp}(\lambda)$ 的和：$X_1 + \dots + X_n \sim \Gamma(n, \lambda)$（爱尔朗分布）
- $n$ 个独立 $N(0,1)$ 的平方和：$X_1^2 + \dots + X_n^2 \sim \chi^2(n)$

### 5. 卷积积分的实战技巧

计算 $\int f_X(x) f_Y(z - x)\, dx$ 时：

1. 由 $f_X(x) \ne 0$ 得 $x$ 的范围，记为区间 $A$
2. 由 $f_Y(z - x) \ne 0$ 得 $z - x$ 在某区间，解出 $x$ 的范围，记为区间 $B(z)$（含 $z$）
3. **实际积分区间 = $A \cap B(z)$**
4. 按 $z$ 的取值分段讨论（$A \cap B(z)$ 随 $z$ 变化）

#### 经典例题模板：均匀分布之和

设 $X, Y \sim U(0, 1)$ 独立，求 $Z = X + Y$ 的密度。

- $f_X(x) = 1\ (0 \le x \le 1)$，$f_Y(y) = 1\ (0 \le y \le 1)$
- 卷积积分要求 $0 \le x \le 1$ 且 $0 \le z - x \le 1$，即 $\max(0, z-1) \le x \le \min(1, z)$
- 分段：
  - 当 $0 \le z \le 1$：$f_Z(z) = \int_0^z 1\, dx = z$
  - 当 $1 < z \le 2$：$f_Z(z) = \int_{z-1}^1 1\, dx = 2 - z$
  - 其他：$f_Z(z) = 0$

得到三角形分布（辛普森分布）。

## 三、商的分布 $Z = Y/X$

### 一般公式

设 $(X, Y)$ 联合密度为 $f(x, y)$，$Z = Y/X$，则

$$\boxed{\ f_Z(z) = \int_{-\infty}^{+\infty} |x|\, f(x,\ xz)\, dx \ }$$

### 推导思路

$F_Z(z) = P(Y/X \le z)$。需要**分 $X > 0$ 和 $X < 0$ 两种情形**：

- 当 $x > 0$：$\{Y/X \le z\} \Leftrightarrow \{Y \le xz\}$
- 当 $x < 0$：$\{Y/X \le z\} \Leftrightarrow \{Y \ge xz\}$（**不等号反向**）

$$F_Z(z) = \int_0^{+\infty} \int_{-\infty}^{xz} f(x,y)\, dy\, dx + \int_{-\infty}^0 \int_{xz}^{+\infty} f(x,y)\, dy\, dx$$

对 $z$ 求导后合并两项，产生 $|x|$ 因子。

### 相关公式

- **乘积分布** $Z = XY$：$\displaystyle f_Z(z) = \int_{-\infty}^{+\infty} \frac{1}{|x|}\, f\!\left(x,\ \frac{z}{x}\right) dx$

## 四、极值的分布

设 $X_1, X_2, \dots, X_n$ **相互独立**，分布函数分别为 $F_{X_i}(x)$，密度分别为 $f_{X_i}(x)$。

### 1. 最大值 $M = \max(X_1, X_2, \dots, X_n)$

**核心思路**：最大值 $\le z$ **等价于**每一个 $X_i$ 都 $\le z$。

$$F_M(z) = P(M \le z) = P(X_1 \le z,\ X_2 \le z,\ \dots,\ X_n \le z)$$

由独立性：

$$\boxed{\ F_M(z) = \prod_{i=1}^n F_{X_i}(z) \ }$$

密度：$\displaystyle f_M(z) = \sum_{i=1}^n f_{X_i}(z) \prod_{j \ne i} F_{X_j}(z)$

### 2. 最小值 $N = \min(X_1, X_2, \dots, X_n)$

**核心思路**：最小值 $> z$ **等价于**每一个 $X_i$ 都 $> z$。用**补事件**处理。

$$F_N(z) = 1 - P(N > z) = 1 - P(X_1 > z,\ \dots,\ X_n > z)$$

由独立性：

$$\boxed{\ F_N(z) = 1 - \prod_{i=1}^n \left[1 - F_{X_i}(z)\right] \ }$$

密度：$\displaystyle f_N(z) = \sum_{i=1}^n f_{X_i}(z) \prod_{j \ne i} [1 - F_{X_j}(z)]$

### 3. 独立同分布特殊情形

若 $X_1, \dots, X_n$ 独立**同分布**，共同分布函数 $F(x)$，密度 $f(x)$：

| 统计量 | 分布函数 | 密度 |
|--------|----------|------|
| $\max$ | $F_{\max}(z) = [F(z)]^n$ | $f_{\max}(z) = n[F(z)]^{n-1} f(z)$ |
| $\min$ | $F_{\min}(z) = 1 - [1-F(z)]^n$ | $f_{\min}(z) = n[1-F(z)]^{n-1} f(z)$ |

### 4. 重要结论 —— 指数分布的最小值

若 $X_i \sim \text{Exp}(\lambda_i)$ **相互独立**（参数可以不同），则

$$\boxed{\ \min(X_1, X_2, \dots, X_n) \sim \text{Exp}\!\left(\sum_{i=1}^n \lambda_i\right) \ }$$

这直接回答了串联系统的寿命问题：n 个独立指数寿命元件串联，系统寿命仍是指数分布，参数是各元件参数之和（失效率相加）。

**证明**：$P(\min > z) = \prod P(X_i > z) = \prod e^{-\lambda_i z} = e^{-(\sum \lambda_i) z}$，正好是参数为 $\sum \lambda_i$ 的指数分布的生存函数。

> 注意：最大值**不**有类似漂亮结论（指数分布最大值不再是指数分布）。

## 解题套路速查表

| 题型 | 首选方法 | 公式/技巧 |
|------|----------|-----------|
| 离散 $(X,Y)$，求 $Z = g(X,Y)$ | 枚举取值，合并相同 $z$ 值的概率 | $P(Z=z) = \sum_{g(x_i,y_j)=z} p_{ij}$ |
| 连续 + 连续，求 $Z = X+Y$ | 卷积公式 | $f_Z(z) = \int f_X(x) f_Y(z-x)\, dx$ |
| 一般函数 $Z = g(X,Y)$ | 分布函数法（画区域 $D_z$） | $F_Z(z) = \iint_{D_z} f\, dx\, dy$ |
| $\max$ 或 $\min$ | 直接套公式 | $F_{\max} = \prod F_i$，$F_{\min} = 1 - \prod(1-F_i)$ |
| 正态、泊松、Gamma 的和 | 直接用可加性 | 不需要做积分 |
| 指数分布的最小值 | 直接用结论 | $\min \sim \text{Exp}(\sum \lambda_i)$ |

## 常见易错点

1. **卷积积分忘记取两密度非零区域的交集**
   - 积分限应由 $f_X(x) \ne 0$ **和** $f_Y(z-x) \ne 0$ 共同决定

2. **分段讨论 $z$ 时边界搞错**
   - 画出 $(x, y)$ 平面区域图，随 $z$ 变化观察区域形状

3. **$\max$ 和 $\min$ 公式混淆**
   - 记忆口诀：max 正着乘（都 $\le z$），min 反着乘（都 $>z$ 再取补）

4. **忽略"独立"前提**
   - 极值公式、卷积公式、可加性结论都**要求独立**
   - 不独立时必须用一般的分布函数法

5. **正态可加性误用**
   - 只有**独立**正态之和才是正态
   - 不独立的正态之和一般不再是正态（联合正态除外）

6. **Gamma 可加性的尺度参数**
   - 必须**同一个 $\beta$** 才能直接相加

7. **求导时忽略分段边界**
   - 分布函数在分段点要检查连续性，密度在分段点可能不连续

## 第三章整体小结

本章是概率论的核心章节，要求掌握：

1. **二维随机变量的分布函数**：定义、性质、与一维的关系
2. **边缘分布 vs 联合分布**：
   - 由联合分布能求边缘分布
   - 由边缘分布**一般不能**唯一确定联合分布
3. **条件分布**：了解定义和求法
4. **两个重要分布**（要熟练掌握）：
   - 二维均匀分布
   - 二维正态分布
5. **独立性**：判定条件 $f(x,y) = f_X(x) f_Y(y)$（几乎处处成立）
6. **函数的分布**（本节）：
   - 和的分布（卷积公式 + 三个可加性）
   - 极值的分布（max、min 公式）
   - 一般函数的分布（分布函数法）
