# 常用级数整理

我整理了一份**更全面的常用级数表**，包括基础、函数展开和特殊用途级数，并把 Taylor 级数包含进来。

---

## 一、基础数列型级数

| 类型   | 一般形式 | 收敛条件/特点 | 应用 |
| ------ | -------- | -------------- | ---- |
| 等差级数 | $$a + (a+d) + \dots + [a+(n-1)d]$$ | 有限项求和公式简单，∞项发散 | 初中/高中的求和问题 |
| 等比级数 | $$a + aq + aq^2 + \dots$$ | 有限项公式：$$S_n = a\frac{1-q^n}{1-q}$$；无限项收敛：$$|q|<1$$ | 金融、物理衰减、几何问题 |
| 调和级数 | $$1 + \frac{1}{2} + \frac{1}{3} + \dots$$ | 发散 | 数学分析经典例子 |
| p级数 | $$\sum_{n=1}^\infty \frac{1}{n^p}$$ | 收敛 $$p>1$$；发散 $$p\le 1$$ | 收敛性判断、积分比较法 |

---

## 二、函数展开类级数

| 类型 | 一般形式 | 收敛条件/特点 | 应用 |
| ---- | -------- | -------------- | ---- |
| 幂级数 | $$\sum_{n=0}^\infty a_n (x-c)^n$$ | 收敛半径 $$R$$ 内收敛 $$|x-c|<R$$ | 表示函数、近似计算 |
| Taylor 级数 | $$\sum_{n=0}^{\infty} \frac{f^{(n)}(c)}{n!} (x-c)^n$$ | 收敛半径内近似原函数 | 函数展开、近似计算、微积分 |
| Maclaurin 级数 | Taylor 级数特例，$$c=0$$ | 同上 | 常用基础函数展开 |
| 傅里叶级数 | $$\frac{a_0}{2} + \sum_{n=1}^\infty [a_n \cos nx + b_n \sin nx]$$ | 周期函数可展开，收敛到函数值或间断点中点 | 信号处理、物理振动、波动方程 |

---

## 三、特殊或高级级数

| 类型 | 一般形式 | 收敛条件/特点 | 应用 |
| ---- | -------- | -------------- | ---- |
| 指数级数 | $$e^x = \sum_{n=0}^\infty \frac{x^n}{n!}$$ | 收敛于全体实数 | 数学、物理指数函数展开 |
| 对数级数 | $$\ln(1+x) = \sum_{n=1}^\infty (-1)^{n+1} \frac{x^n}{n}$$ | $\vert x\vert<1$ | 函数近似、积分计算 |
| 正弦级数 | $$\sin x = \sum_{n=0}^\infty (-1)^n \frac{x^{2n+1}}{(2n+1)!}$$ | 全体实数收敛 | 数值计算、振动问题 |
| 余弦级数 | $$\cos x = \sum_{n=0}^\infty (-1)^n \frac{x^{2n}}{(2n)!}$$ | 全体实数收敛 | 同上 |
| 双调和级数 | $$\sum_{n=1}^\infty \frac{1}{n^p (\log n)^q}$$ | 收敛条件更复杂，p>1 或 p=1 且 q>1 | 高级收敛性分析 |
| Leibniz 交错级数 | $$1 - \frac{1}{3} + \frac{1}{5} - \frac{1}{7} + \dots$$ | 交错项绝对值递减 → 收敛 | π 的近似计算 |

---

## 四、总结分类思路

1. **数列型**：等差、等比、调和、p级数  
2. **函数展开型**：幂级数、Taylor/Maclaurin、傅里叶  
3. **特殊级数**：指数、对数、三角函数、交错、双调和  
4. **应用/性质**：  
   * 收敛性（有限/无限、收敛半径）  
   * 表示函数、数值近似、信号处理、积分估算
   * $$f(x; \lambda) = \begin{cases} \lambda e^{-\lambda x} & x \ge 0 \ 0 & x < 0 \end{cases}$$
