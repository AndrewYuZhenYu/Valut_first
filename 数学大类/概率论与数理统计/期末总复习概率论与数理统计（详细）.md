## 第一章 概率与随机事件

### 一、预备知识：排列组合

#### 1. 加法原理
完成一件事有 $n$ 类方法，只要选择任何一类中的一种方法，这件事就可以完成。

总方法数 = $m_1 + m_2 + \dots + m_n$

**关键词**：“要么…要么…”、“分类”

#### 2. 乘法原理
完成一件事有 $n$ 个步骤，必须依次完成所有步骤，这件事才算完成。

总方法数 = $m_1 \times m_2 \times \dots \times m_n$

**关键词**：“先…后…”、“分步”

#### 3. 排列
从 $n$ 个**不同**元素中，每次取出 $m$ 个元素，按照一定的顺序排成一列。

- **有放回排列**：每次抽取一个，看后放回，共抽取 $m$ 次，共有 $n^m$ 种排列。
- **无放回排列**：每次抽取一个，看后不放回，共抽取 $m$ 次（$m \le n$），共有 $A_n^m = n \times (n-1) \times \dots \times (n-m+1) = \frac{n!}{(n-m)!}$ 种排列。

#### 4. 组合
从 $n$ 个**不同**元素中，每次取出 $m$ 个元素，**不考虑其先后顺序**作为一组。

$C_n^m = \frac{n \times (n-1) \times \dots \times (n-m+1)}{m!} = \frac{n!}{m!(n-m)!}$

**性质**：$C_n^m = C_n^{n-m}$

---

### 二、随机试验

满足以下三个条件的试验称为随机试验，记作 $E$：

1. **可重复性**：可以在相同的条件下重复进行。
2. **结果明确性**：每次试验的可能结果不止一个，且事先可以明确试验的所有可能结果。
3. **结果不确定性**：进行一次试验前，不能确定哪一个结果会出现。

---

### 三、样本空间与事件

- **样本空间 $\Omega$**：随机试验 $E$ 的一切可能结果组成的集合。
- **样本点 $\omega$**：样本空间中的元素，即试验的每个结果。
- **随机事件**：样本空间 $\Omega$ 的某一子集，用 $A, B, C, \dots$ 表示。
- **必然事件 $\Omega$**：每次试验中必然发生的事件。
- **不可能事件 $\emptyset$**：每次试验中都不可能发生的事件。

---

### 四、事件的关系和运算

#### 1. 事件之间的关系
- **包含** $A \subset B$：$A$ 发生必然导致 $B$ 发生。
- **相等** $A = B$：$A \subset B$ 且 $B \subset A$。
- **互不相容（互斥）** $AB = \emptyset$：$A$ 与 $B$ 不能同时发生。
- **对立事件** $\bar{A}$：$A$ 不发生，满足 $A \cup \bar{A} = \Omega$，$A\bar{A} = \emptyset$。

#### 2. 事件的运算
- **并（和）** $A \cup B$：$A$ 与 $B$ 至少有一个发生。
- **交（积）** $A \cap B$ 或 $AB$：$A$ 与 $B$ 同时发生。
- **差** $A - B = A\bar{B}$：$A$ 发生而 $B$ 不发生。

#### 3. 运算法则（重点）
- **交换律**：$A\cup B = B\cup A$，$A\cap B = B\cap A$
- **结合律**：$A\cup (B\cup C) = (A\cup B)\cup C$，$A\cap (B\cap C) = (A\cap B)\cap C$
- **分配律**：
  - $A\cup (B\cap C) = (A\cup B)\cap (A\cup C)$
  - $A\cap (B\cup C) = (A\cap B)\cup (A\cap C)$
- **德摩根律（对偶律）**（最重要）：
  - $\overline{A\cup B} = \bar{A}\cap \bar{B}$（并集的对立 = 对立的交集）
  - $\overline{A\cap B} = \bar{A}\cup \bar{B}$（交集的对立 = 对立的并集）
  - **口诀**：“长线变短线，符号变，开口方向反转”
- **吸收律**：若 $A\subset B$，则 $AB = A$，$A\cup B = B$

---

### 五、概率的定义与性质

#### 1. 公理化定义
$P$ 满足：
- **非负性**：$0 \le P(A) \le 1$
- **正规性**：$P(\Omega) = 1$
- **可列可加性**：若 $A_1, A_2, \dots$ 两两互不相容，则 $P(\bigcup_{n=1}^{\infty} A_n) = \sum_{n=1}^{\infty} P(A_n)$

#### 2. 重要性质（必须熟练掌握）

$P(\emptyset) = 0$，$P(\Omega) = 1$

**有限可加性**：若 $A_1, \dots, A_n$ 两两互不相容，则 $P(\bigcup_{i=1}^n A_i) = \sum_{i=1}^n P(A_i)$

**单调性**：若 $A \subset B$，则 $P(B-A) = P(B) - P(A)$，$P(A) \le P(B)$

**求逆公式**：$P(\bar{A}) = 1 - P(A)$

> **技巧**：多个事件取反时结合德摩根律
> - $P(\bar{A}\bar{B}) = P(\overline{A \cup B}) = 1 - P(A \cup B)$
> - $P(\bar{A} \cup \bar{B}) = P(\overline{AB}) = 1 - P(AB)$

**减法公式**：$P(A - B) = P(A\bar{B}) = P(A) - P(AB)$

**加法公式**（核心）：
- 两个事件：$P(A \cup B) = P(A) + P(B) - P(AB)$
- 三个事件：$P(A \cup B \cup C) = P(A)+P(B)+P(C) - P(AB)-P(BC)-P(AC) + P(ABC)$

**次可加性**：$P(\bigcup_{n \ge 1} A_n) \le \sum_{n \ge 1} P(A_n)$

---

### 六、等可能概型

#### 1. 古典概型
**特征**：有限个结果，等可能。

**公式**：$P(A) = \frac{A\text{包含的基本事件数}}{\Omega\text{中基本事件总数}} = \frac{k}{n}$

**常用结论**：$N$ 件产品有 $M$ 件次品，任取 $n$ 件，恰有 $k$ 件次品的概率为 $\frac{C_M^k C_{N-M}^{n-k}}{C_N^n}$

#### 2. 几何概型
**特征**：无限个结果（构成几何区域），等可能。

**公式**：$P(A) = \frac{S(A)}{S(\Omega)}$（$S$ 为长度、面积或体积）

**适用情况**：区间内取点、时间段内随机到达、区域内均匀投点

---

### 七、条件概率与独立性（核心）

#### 1. 条件概率
$P(A|B) = \frac{P(AB)}{P(B)}$（$P(B) > 0$）

**计算方法**：
- 公式法：$P(B|A) = \frac{P(AB)}{P(A)}$
- 缩减样本空间法：直接在新的样本空间中计算

**乘法公式**：
- $P(AB) = P(A)P(B|A) = P(B)P(A|B)$
- 推广：$P(A_1A_2\dots A_n) = P(A_n|A_1\dots A_{n-1})P(A_{n-1}|A_1\dots A_{n-2})\dots P(A_2|A_1)P(A_1)$

#### 2. 事件的独立性
**定义**：$A, B$ 独立 $\iff$ $P(AB) = P(A)P(B)$

**性质**：
- 若 $A, B$ 独立且 $P(B) > 0$，则 $P(A|B) = P(A)$
- $A$ 与 $B$ 独立 $\iff$ $A$ 与 $\bar{B}$ 独立 $\iff$ $\bar{A}$ 与 $\bar{B}$ 独立

**三个事件的相互独立性**：需同时满足
- $P(AB) = P(A)P(B)$
- $P(AC) = P(A)P(C)$
- $P(BC) = P(B)P(C)$
- $P(ABC) = P(A)P(B)P(C)$

> **注意**：两两独立 $\nRightarrow$ 相互独立

#### 3. 全概率公式与贝叶斯公式（最高频考点）

**完备事件组**：$\{A_i\}$ 满足
- 两两互不相容
- $\bigcup_{i=1}^n A_i = \Omega$
- $P(A_i) > 0$

**全概率公式（由因求果）**：
$P(B) = \sum_{i=1}^n P(A_i)P(B|A_i)$

**贝叶斯公式（执果寻因）**：
$P(A_i|B) = \frac{P(A_i)P(B|A_i)}{\sum_{j=1}^n P(A_j)P(B|A_j)}$

#### 4. 伯努利模型
**$n$ 重伯努利试验**中，事件 $A$ 恰好发生 $k$ 次的概率：

$P_n(k) = C_n^k p^k (1-p)^{n-k}, \quad k = 0,1,2,\dots,n$

---

### 八、题型总结

#### 1. 摸球问题
- 无放回 + 考虑顺序：$A_n^m$
- 无放回 + 不考虑顺序：$C_n^m$
- 有放回 + 考虑顺序：$n^m$

**核心结论**：无放回抽取中，第 $i$ 次抽到白球的概率 = $\frac{\text{白球数}}{\text{总数}}$，与次序无关。

#### 2. 古典概率问题
**全错排公式**：
$D_n = n! \left(1 - \frac{1}{1!} + \frac{1}{2!} - \frac{1}{3!} + \dots + (-1)^n \frac{1}{n!}\right)$

#### 3. 伯努利试验
- $n$ 次中成功 $k$ 次：$C_n^k p^k (1-p)^{n-k}$
- 第 $n$ 次时刚好成功 $k$ 次（最后一次必成功）：$C_{n-1}^{k-1} p^k (1-p)^{n-k}$

#### 4. 全概率与贝叶斯公式应用步骤
1. 确定完备事件组（原因）
2. 计算各原因的概率 $P(A_i)$
3. 计算各原因下结果发生的概率 $P(B|A_i)$
4. 全概率公式求 $P(B)$
5. 贝叶斯公式求 $P(A_i|B)$

## 第二章 随机变量及其分布

### 一、随机变量及其分布函数

#### 1. 随机变量
定义在样本空间 $\Omega$ 上的单值实函数 $X = X(\omega)$。

#### 2. 分布函数
$F(x) = P\{X \le x\}$

**性质**：
1. 单调不减：$x_1 < x_2 \Rightarrow F(x_1) \le F(x_2)$
2. $0 \le F(x) \le 1$，$F(-\infty)=0$，$F(+\infty)=1$
3. 右连续：$F(x+0) = F(x)$
4. $P\{x_1 < X \le x_2\} = F(x_2) - F(x_1)$
5. $P\{X = x\} = F(x) - F(x-0)$

**常用计算公式**：
- $P(X < a) = F(a-0)$
- $P(a \le X \le b) = F(b) - F(a-0)$
- $P(a < X < b) = F(b-0) - F(a)$
- $P(a \le X < b) = F(b-0) - F(a-0)$
- $P(a < X \le b) = F(b) - F(a)$
- $P(X = a) = F(a) - F(a-0)$

---

### 二、离散型随机变量

#### 1. 分布律
$P\{X = x_i\} = p_i$，满足 $\sum p_i = 1$，$p_i \ge 0$

#### 2. 分布函数
$F(x) = \sum_{x_i \le x} p_i$（阶梯函数，在 $x_i$ 处跳跃，跳跃度为 $p_i$）

#### 3. 常见分布

| 分布 | 记法 | 分布律 | 参数 |
|-----|------|--------|------|
| 两点分布 | $B(1, p)$ | $P(X=k)=p^k(1-p)^{1-k}, k=0,1$ | $0<p<1$ |
| 二项分布 | $B(n, p)$ | $P(X=k)=C_n^k p^k (1-p)^{n-k}$ | $n\ge1, 0<p<1$ |
| 泊松分布 | $P(\lambda)$ | $P(X=k)=\frac{\lambda^k}{k!}e^{-\lambda}$ | $\lambda>0$ |
| 几何分布 | $G(p)$ | $P(X=k)=p(1-p)^{k-1}$ | $0<p<1$ |
| 超几何分布 | $H(N,M,n)$ | $P(X=k)=\frac{C_M^k C_{N-M}^{n-k}}{C_N^n}$ | $N,M,n$ 自然数 |

**泊松定理**：若 $\lim_{n\to\infty} np_n = \lambda$，则 $C_n^k p_n^k (1-p_n)^{n-k} \to \frac{\lambda^k e^{-\lambda}}{k!}$

---

### 三、连续型随机变量

#### 1. 概率密度函数
$f(x) \ge 0$，$\int_{-\infty}^{+\infty} f(x) dx = 1$，$F'(x) = f(x)$（在连续点）

#### 2. 常见分布

**均匀分布** $U(a, b)$：
$f(x) = \begin{cases} \frac{1}{b-a}, & a < x < b \\ 0, & \text{其他} \end{cases}$
$F(x) = \begin{cases} 0, & x < a \\ \frac{x-a}{b-a}, & a \le x < b \\ 1, & x \ge b \end{cases}$

**指数分布** $E(\lambda)$：
$f(x) = \begin{cases} \lambda e^{-\lambda x}, & x > 0 \\ 0, & x \le 0 \end{cases}$
$F(x) = \begin{cases} 1 - e^{-\lambda x}, & x > 0 \\ 0, & x \le 0 \end{cases}$

**正态分布** $N(\mu, \sigma^2)$：
$f(x) = \frac{1}{\sqrt{2\pi}\sigma} e^{-\frac{(x-\mu)^2}{2\sigma^2}}$

**标准正态分布** $\Phi(x)$：
$\Phi(x) = \int_{-\infty}^x \frac{1}{\sqrt{2\pi}} e^{-\frac{t^2}{2}} dt$

**正态分布性质**：
- $\Phi(-x) = 1 - \Phi(x)$
- $P(X \le a) = \Phi(\frac{a-\mu}{\sigma})$
- $P(X \ge a) = 1 - \Phi(\frac{a-\mu}{\sigma})$
- $P(a \le X \le b) = \Phi(\frac{b-\mu}{\sigma}) - \Phi(\frac{a-\mu}{\sigma})$
- $P(|X-\mu| \le a) = 2\Phi(\frac{a}{\sigma}) - 1$

## 第三章 多维随机变量及其分布

### 一、预备知识：二重积分

**直角坐标**：
- 先 $y$ 后 $x$：$\iint_D f(x,y) d\sigma = \int_a^b dx \int_{y_1(x)}^{y_2(x)} f(x,y) dy$
- 先 $x$ 后 $y$：$\iint_D f(x,y) d\sigma = \int_c^d dy \int_{x_1(y)}^{x_2(y)} f(x,y) dx$

**极坐标**：
- 变换：$x = \rho \cos\theta$，$y = \rho \sin\theta$，$d\sigma = \rho d\rho d\theta$
- $\iint_D f(x,y) d\sigma = \int_\alpha^\beta d\theta \int_{\rho_1(\theta)}^{\rho_2(\theta)} f(\rho\cos\theta, \rho\sin\theta) \rho d\rho$

**适用极坐标的情况**：
- 被积函数：$f(\sqrt{x^2+y^2})$，$f(x^2+y^2)$，$f(\frac{x}{y})$，$f(\frac{y}{x})$
- 积分区域：圆形、环形、扇形

---

### 二、二维随机变量及其联合分布函数

#### 1. 联合分布函数
$F(x, y) = P\{X \le x, Y \le y\}$

#### 2. 性质
- $0 \le F(x, y) \le 1$
- $F(-\infty, y) = F(x, -\infty) = F(-\infty, -\infty) = 0$，$F(+\infty, +\infty) = 1$
- 关于每个变量单调不减、右连续
- $P\{x_1 < X \le x_2, y_1 < Y \le y_2\} = F(x_2, y_2) - F(x_2, y_1) - F(x_1, y_2) + F(x_1, y_1)$

---

### 三、二维离散型随机变量

**联合分布律**：$P\{X = x_i, Y = y_j\} = p_{ij}$，$\sum_i \sum_j p_{ij} = 1$

**边缘分布律**：
- $p_{i\cdot} = \sum_j p_{ij}$（$X$ 的边缘）
- $p_{\cdot j} = \sum_i p_{ij}$（$Y$ 的边缘）

---

### 四、二维连续型随机变量

**联合概率密度**：$f(x, y) \ge 0$，$\iint f(x, y) dx dy = 1$，$F(x, y) = \int_{-\infty}^x \int_{-\infty}^y f(u, v) du dv$

**边缘概率密度**：
- $f_X(x) = \int_{-\infty}^{+\infty} f(x, y) dy$
- $f_Y(y) = \int_{-\infty}^{+\infty} f(x, y) dx$

---

### 五、常见的二维连续随机分布

#### 1. 二维均匀分布
$f(x, y) = \begin{cases} \frac{1}{A}, & (x, y) \in G \\ 0, & \text{其他} \end{cases}$，其中 $A = S_G$

$P\{(X, Y) \in D\} = \frac{S_D}{S_G}$

#### 2. 二维正态分布
$(X, Y) \sim N(\mu_1, \mu_2; \sigma_1^2, \sigma_2^2; \rho)$

**重要性质**：
- $X \sim N(\mu_1, \sigma_1^2)$，$Y \sim N(\mu_2, \sigma_2^2)$
- $X$ 与 $Y$ 独立 $\iff$ $\rho = 0$
- $aX + bY \sim N(a\mu_1 + b\mu_2, a^2\sigma_1^2 + 2ab\sigma_1\sigma_2\rho + b^2\sigma_2^2)$

---

### 六、条件分布

**离散型**：
$P(Y=y_j|X=x_i) = \frac{p_{ij}}{p_{i\cdot}}$（$p_{i\cdot} > 0$）
$P(X=x_i|Y=y_j) = \frac{p_{ij}}{p_{\cdot j}}$（$p_{\cdot j} > 0$）

**连续型**：
$f_{Y|X}(y|x) = \frac{f(x, y)}{f_X(x)}$（$f_X(x) > 0$）
$f_{X|Y}(x|y) = \frac{f(x, y)}{f_Y(y)}$（$f_Y(y) > 0$）

---

### 七、相互独立的随机变量

**充要条件**：$F(x, y) = F_X(x) F_Y(y)$

**离散型**：$p_{ij} = p_{i\cdot} \cdot p_{\cdot j}$（对所有 $i, j$）

**连续型**：$f(x, y) = f_X(x) f_Y(y)$

**推论**：若 $X$ 与 $Y$ 独立，则条件分布等于边缘分布。

---

### 八、多维随机变量函数的分布

#### 1. 离散型
列出 $Z = \phi(X, Y)$ 的所有可能取值，合并相同值的概率。

#### 2. 连续型（分布函数法）
1. $F_Z(z) = P\{Z \le z\} = \iint_{\phi(X,Y) \le z} f(x, y) dx dy$
2. $f_Z(z) = F_Z'(z)$

#### 3. 卷积公式

**$Z = X + Y$**：
$f_Z(z) = \int_{-\infty}^{+\infty} f(x, z-x) dx$
若 $X, Y$ 独立：$f_Z(z) = \int_{-\infty}^{+\infty} f_X(x) f_Y(z-x) dx$

**$Z = X - Y$**：
$f_Z(z) = \int_{-\infty}^{+\infty} f(x, x-z) dx = \int_{-\infty}^{+\infty} f(y+z, y) dy$

**$Z = XY$**：
$f_Z(z) = \int_{-\infty}^{+\infty} \frac{1}{|x|} f(x, \frac{z}{x}) dx$

**$Z = \frac{X}{Y}$**：
$f_Z(z) = \int_{-\infty}^{+\infty} |y| f(yz, y) dy$

#### 4. 最大、最小值分布

**最大值**：
$F_{\max}(z) = F(z, z)$
若 $X, Y$ 独立：$F_{\max}(z) = F_X(z) F_Y(z)$

**最小值**：
$F_{\min}(z) = 1 - P\{X > z, Y > z\}$
若 $X, Y$ 独立：$F_{\min}(z) = 1 - [1 - F_X(z)][1 - F_Y(z)]$

## 第四章 随机变量的数字特征

### 一、数学期望

#### 1. 定义
**离散型**：$E(X) = \sum_i x_i p_i$（绝对收敛）

**连续型**：$E(X) = \int_{-\infty}^{+\infty} x f(x) dx$（绝对收敛）

#### 2. 随机变量函数的期望
**一维**：
$E[g(X)] = \begin{cases} \sum_i g(x_i) p_i, & \text{离散} \\ \int_{-\infty}^{+\infty} g(x) f(x) dx, & \text{连续} \end{cases}$

**二维**：
$E[g(X,Y)] = \begin{cases} \sum_i \sum_j g(x_i, y_j) p_{ij}, & \text{离散} \\ \iint g(x, y) f(x, y) dx dy, & \text{连续} \end{cases}$

#### 3. 性质
- $E(C) = C$
- $E(aX + b) = aE(X) + b$
- $E(X \pm Y) = E(X) \pm E(Y)$
- 若 $X, Y$ 独立，则 $E(XY) = E(X)E(Y)$

---

### 二、方差

#### 1. 定义
$D(X) = E\{[X - E(X)]^2\} = E(X^2) - [E(X)]^2$

**标准差**：$\sigma(X) = \sqrt{D(X)}$

#### 2. 性质
- $D(C) = 0$
- $D(aX + b) = a^2 D(X)$
- $D(X \pm Y) = D(X) + D(Y) \pm 2\text{Cov}(X, Y)$
- 若 $X, Y$ 独立，则 $D(X \pm Y) = D(X) + D(Y)$

---

### 三、协方差

#### 1. 定义
$\text{Cov}(X, Y) = E\{[X - E(X)][Y - E(Y)]\} = E(XY) - E(X)E(Y)$

#### 2. 性质
- $\text{Cov}(X, Y) = \text{Cov}(Y, X)$
- $\text{Cov}(aX, bY) = ab\text{Cov}(X, Y)$
- $\text{Cov}(aX + b, Y) = a\text{Cov}(X, Y)$
- $\text{Cov}(X_1 + X_2, Y) = \text{Cov}(X_1, Y) + \text{Cov}(X_2, Y)$
- $\text{Cov}(X, C) = 0$
- 若 $X, Y$ 独立，则 $\text{Cov}(X, Y) = 0$

---

### 四、相关系数

#### 1. 定义
$\rho_{XY} = \frac{\text{Cov}(X, Y)}{\sqrt{D(X)}\sqrt{D(Y)}}$，$|\rho_{XY}| \le 1$

#### 2. 含义
- $\rho_{XY} = 1$：正相关，$P\{Y = aX + b\} = 1$（$a > 0$）
- $\rho_{XY} = -1$：负相关，$P\{Y = aX + b\} = 1$（$a < 0$）
- $\rho_{XY} = 0$：不相关，$E(XY) = E(X)E(Y)$

#### 3. 独立性与相关性的关系
- 独立 $\Rightarrow$ 不相关（反之不成立）
- **例外**：二维正态分布中，不相关 $\iff$ 独立

---

### 五、矩

- **$k$ 阶原点矩**：$E(X^k)$
- **$k$ 阶中心矩**：$E\{[X - E(X)]^k\}$
- **$k+l$ 阶混合矩**：$E(X^k Y^l)$
- **$k+l$ 阶混合中心矩**：$E\{[X - E(X)]^k [Y - E(Y)]^l\}$

## 第五章 大数定律和中心极限定理

### 一、依概率收敛

$X_n \xrightarrow{P} X$：对任意 $\epsilon > 0$，$\lim_{n \to \infty} P\{|X_n - X| < \epsilon\} = 1$

---

### 二、大数定律
---

三个大数定律通常指：**切比雪夫大数定律**、**辛钦大数定律**、**伯努利大数定律**。它们共同说明：在大量重复试验中，样本均值依概率收敛于期望值。下面整理核心内容。

---

#### 1. 伯努利大数定律（频率的稳定性）
- **内容**：设 $n_A$ 是 $n$ 次独立伯努利试验中事件 $A$ 发生的次数，$p = P(A)$，则对任意 $\varepsilon > 0$，
  $\lim_{n \to \infty} P\left( \left| \frac{n_A}{n} - p \right| \ge \varepsilon \right) = 0.$
- **条件**：独立同分布，两点分布（试验结果仅为 $A$ 或非 $A$）。
- **意义**：首次严格证明频率依概率收敛于概率，是数理统计推断的基石。

#### 2. 切比雪夫大数定律
- **内容**：设 $X_1, X_2, \dots$ 是**相互独立**的随机变量序列，具有有限期望 $\mu_i$ 和方差 $\sigma_i^2$，且方差有公共上界 $\sigma_i^2 \le C$（$C$ 为常数）。则对任意 $\varepsilon > 0$，
  $\lim_{n \to \infty} P\left( \left| \frac{1}{n}\sum_{i=1}^n X_i - \frac{1}{n}\sum_{i=1}^n \mu_i \right| \ge \varepsilon \right) = 0.$
- **条件**：独立，方差存在且一致有界。
- **意义**：不要求同分布，只要求方差一致有界。可推广到不独立（若协方差有界且平均协方差趋于 $0$，条件可放宽）。

#### 3. 辛钦大数定律
- **内容**：设 $X_1, X_2, \dots$ 是**独立同分布**的随机变量，且期望 $E[X_i] = \mu$ 存在（有限），则对任意 $\varepsilon > 0$，
  $\lim_{n \to \infty} P\left( \left| \frac{1}{n}\sum_{i=1}^n X_i - \mu \right| \ge \varepsilon \right) = 0.$
- **条件**：独立同分布，期望存在（不要求方差存在）。
- **意义**：比切比雪夫适用更广（方差可无穷），是应用最广泛的大数定律（如蒙特卡洛方法的理论基础）。

---

#### 对比总结表

| 定律 | 独立性要求 | 同分布要求 | 矩条件 | 收敛对象 |
|------|------------|------------|--------|------------|
| 伯努利 | 独立 | 同（两点分布） | 期望存在（$p$） | 频率 $\to$ 概率 |
| 切比雪夫 | 独立（可放宽） | 不同分布允许 | 方差存在且一致有界 | 样本均值 $\to$ 期望均值 |
| 辛钦 | 独立 | 同分布 | 期望存在（有限） | 样本均值 $\to$ 公共期望 |

---

#### 核心关系
- **伯努利** 是 **辛钦** 在二值随机变量时的特例。
- **辛钦** 的条件比 **切比雪夫** 更弱（不需方差），但要求同分布。
- 三者都得出 **依概率收敛**（弱大数定律），而非几乎必然收敛（强大数定律）。

### 三、中心极限定理

#### 1. 列维-林德伯格定理（独立同分布）
**条件**：$\{X_n\}$ 独立同分布，$E(X_n) = \mu$，$D(X_n) = \sigma^2$

**结论**：$\frac{\sum_{i=1}^n X_i - n\mu}{\sqrt{n}\sigma} \xrightarrow{\text{近似}} N(0, 1)$

即当 $n$ 很大时，$\sum_{i=1}^n X_i \approx N(n\mu, n\sigma^2)$

#### 2. 棣莫弗-拉普拉斯定理（二项分布）
**条件**：$n_A \sim B(n, p)$

**结论**：$\frac{n_A - np}{\sqrt{np(1-p)}} \xrightarrow{\text{近似}} N(0, 1)$

即当 $n$ 很大时，$n_A \approx N(np, np(1-p))$

## 第六章 参数估计

### 一、样本与统计量

#### 1. 基本概念
- **总体**：研究对象的某项数量指标的全体
- **样本**：$n$ 个相互独立且与总体 $X$ 同分布的 $X_1, X_2, \dots, X_n$
- **统计量**：样本的不含未知参数的函数

#### 2. 样本的数字特征
- **样本均值**：$\bar{X} = \frac{1}{n} \sum_{i=1}^n X_i$
- **样本方差**：$S^2 = \frac{1}{n-1} \sum_{i=1}^n (X_i - \bar{X})^2$
- **样本标准差**：$S = \sqrt{S^2}$
- **$k$ 阶原点矩**：$A_k = \frac{1}{n} \sum_{i=1}^n X_i^k$
- **$k$ 阶中心矩**：$B_k = \frac{1}{n} \sum_{i=1}^n (X_i - \bar{X})^k$

#### 3. 重要性质
- $E(\bar{X}) = \mu$
- $D(\bar{X}) = \frac{\sigma^2}{n}$
- $E(S^2) = \sigma^2$

---

### 二、点估计

#### 1. 矩估计法
**原理**：令样本矩等于总体矩

**步骤**：
1. 求 $E(X)$，判断含有几个未知参数
2. 若 1 个参数，令 $\bar{X} = E(X)$ 求解
3. 若 2 个参数，联立 $\begin{cases} \bar{X} = E(X) \\ \frac{1}{n}\sum (X_i - \bar{X})^2 = D(X) \end{cases}$ 求解

#### 2. 最大似然估计法
**原理**：选择使样本出现概率最大的参数值

**步骤**：
1. 写出似然函数 $L(\theta) = \prod_{i=1}^n f(x_i; \theta)$（连续型）或 $L(\theta) = \prod_{i=1}^n p(x_i; \theta)$（离散型）
2. 取对数 $\ln L(\theta)$
3. 求导，令导数为 0，解出 $\hat{\theta}$
4. （多参数）解似然方程组 $\begin{cases} \frac{\partial \ln L}{\partial \theta_1} = 0 \\ \frac{\partial \ln L}{\partial \theta_2} = 0 \end{cases}$

---

### 三、估计量的评选标准

- **无偏性**：$E(\hat{\theta}) = \theta$（例如 $S^2$ 是 $\sigma^2$ 的无偏估计）
- **有效性**：无偏估计中方差越小越有效
- **一致性**：$\hat{\theta} \xrightarrow{P} \theta$

---

### 四、正态总体统计量的分布

#### 1. $\chi^2$ 分布
若 $X_i \sim N(0, 1)$ 独立，则 $\chi^2 = \sum_{i=1}^n X_i^2 \sim \chi^2(n)$

**性质**：$E(\chi^2) = n$，$D(\chi^2) = 2n$，可加性

#### 2. $t$ 分布
若 $X \sim N(0, 1)$，$Y \sim \chi^2(n)$ 独立，则 $T = \frac{X}{\sqrt{Y/n}} \sim t(n)$

**性质**：概率密度为偶函数；$n$ 充分大时 $t(n) \approx N(0, 1)$

#### 3. $F$ 分布
若 $U \sim \chi^2(n_1)$，$V \sim \chi^2(n_2)$ 独立，则 $F = \frac{U/n_1}{V/n_2} \sim F(n_1, n_2)$

#### 4. 一个正态总体的抽样分布（核心）
设 $X_1, \dots, X_n$ 来自 $N(\mu, \sigma^2)$，则：
- $\bar{X} \sim N(\mu, \frac{\sigma^2}{n})$，$\frac{\bar{X} - \mu}{\sigma/\sqrt{n}} \sim N(0, 1)$
- $\frac{(n-1)S^2}{\sigma^2} \sim \chi^2(n-1)$
- $\frac{\bar{X} - \mu}{S/\sqrt{n}} \sim t(n-1)$
- $\bar{X}$ 与 $S^2$ 相互独立

---

### 五、置信区间（一个正态总体）

| 待估参数 | 其他参数 | $1-\alpha$ 置信区间 |
|---------|---------|-------------------|
| $\mu$ | $\sigma^2$ 已知 | $\left(\bar{X} - z_{\alpha/2} \frac{\sigma}{\sqrt{n}}, \bar{X} + z_{\alpha/2} \frac{\sigma}{\sqrt{n}}\right)$ |
| $\mu$ | $\sigma^2$ 未知 | $\left(\bar{X} - t_{\alpha/2}(n-1) \frac{S}{\sqrt{n}}, \bar{X} + t_{\alpha/2}(n-1) \frac{S}{\sqrt{n}}\right)$ |
| $\sigma^2$ | $\mu$ 未知 | $\left(\frac{(n-1)S^2}{\chi^2_{\alpha/2}(n-1)}, \frac{(n-1)S^2}{\chi^2_{1-\alpha/2}(n-1)}\right)$ |

---

## 第七章 假设检验

### 一、基本概念

#### 1. 假设检验的步骤
1. **提出假设**：$H_0$（原假设）和 $H_1$（备择假设）
2. **选择检验统计量**：当 $H_0$ 为真时，统计量的分布已知
3. **确定拒绝域**：给定显著性水平 $\alpha$，查表得临界值
4. **做出决策**：统计量值在拒绝域内则拒绝 $H_0$，否则不拒绝

#### 2. 两类错误
- **第一类错误（弃真）**：$H_0$ 正确但拒绝，概率为 $\alpha$
- **第二类错误（存伪）**：$H_0$ 错误但接受，概率为 $\beta$

---

### 二、一个正态总体参数的假设检验（双侧检验）

| 检验参数 | 情形 | $H_0$ | $H_1$ | 检验统计量 | 拒绝域 |
|---------|-----|-------|-------|-----------|--------|
| $\mu$ | $\sigma^2$ 已知 | $\mu = \mu_0$ | $\mu \ne \mu_0$ | $U = \frac{\bar{X} - \mu_0}{\sigma/\sqrt{n}}$ | $|U| \ge z_{\alpha/2}$ |
| $\mu$ | $\sigma^2$ 未知 | $\mu = \mu_0$ | $\mu \ne \mu_0$ | $T = \frac{\bar{X} - \mu_0}{S/\sqrt{n}}$ | $|T| \ge t_{\alpha/2}(n-1)$ |
| $\sigma^2$ | $\mu$ 未知 | $\sigma^2 = \sigma_0^2$ | $\sigma^2 \ne \sigma_0^2$ | $\chi^2 = \frac{(n-1)S^2}{\sigma_0^2}$ | $\chi^2 \le \chi^2_{1-\alpha/2}(n-1)$ 或 $\chi^2 \ge \chi^2_{\alpha/2}(n-1)$ |

| **连续** | 标准正态分布 | $X \sim N(0, 1)$ | 无 | $f(x) = \dfrac{1}{\sqrt{2\pi}} e^{-\frac{x^2}{2}}$ | $0$ | $1$ |

| **连续** | $t$ 分布 | $X \sim t(n)$ | $n \in \mathbb{N}^*$（自由度） | $f(x) = \dfrac{\Gamma\!\left(\frac{n+1}{2}\right)}{\sqrt{n\pi}\,\Gamma\!\left(\frac{n}{2}\right)} \left(1 + \dfrac{x^2}{n}\right)^{-\frac{n+1}{2}}$ | $0$（$n>1$） | $\dfrac{n}{n-2}$（$n>2$） |

## 补充：重要函数与关系

- **泊松分布可加性**：若 $X \sim P(\lambda_1)$，$Y \sim P(\lambda_2)$ 且独立，则 $X+Y \sim P(\lambda_1 + \lambda_2)$。
- **正态分布可加性**：若 $X \sim N(\mu_1, \sigma_1^2)$，$Y \sim N(\mu_2, \sigma_2^2)$ 且独立，则 $X+Y \sim N(\mu_1+\mu_2, \sigma_1^2+\sigma_2^2)$。
- **二项分布 → 泊松分布**：当 $n \to \infty$ 且 $np = \lambda$（常数）时，二项分布趋近于泊松分布。
- **二项分布 → 正态分布**：当 $n$ 较大时（通常 $np>5$ 且 $n(1-p)>5$），二项分布可用 $N(np, np(1-p))$ 近似（需连续性校正）。
- **正态家族关系链**：标准正态平方和 → 卡方分布；正态变量与卡方变量的组合 → $t$ 分布；两个卡方变量的比值 → $F$ 分布。

### 二、常见题型解题步骤

#### 1. 全概率与贝叶斯公式题
1. 确定完备事件组（原因事件）
2. 写出 $P(A_i)$ 和 $P(B\|A_i)$
3. 全概率公式求 $P(B)$
4. 贝叶斯公式求 $P(A_i\|B)$

#### 2. 分布函数与密度函数互求
- 已知 $f(x)$ 求 $F(x)$：$F(x) = \int_{-\infty}^x f(t) dt$
- 已知 $F(x)$ 求 $f(x)$：$f(x) = F'(x)$（在连续点）

#### 3. 随机变量函数分布（连续型）
1. 求 $F_Z(z) = P\{g(X,Y) \le z\} = \iint_{g(x,y) \le z} f(x,y) dx dy$
2. $f_Z(z) = F_Z'(z)$

#### 4. 矩估计步骤
1. 计算总体矩 $E(X)$（或 $D(X)$）
2. 令样本矩等于总体矩
3. 解出参数估计量

#### 5. 最大似然估计步骤
1. 写出似然函数 $L(\theta) = \prod f(x_i; \theta)$
2. 取对数 $\ln L(\theta)$
3. 求导并令导数为 0
4. 解出 $\hat{\theta}$

#### 6. 假设检验步骤
1. 提出 $H_0$ 和 $H_1$
2. 构造检验统计量
3. 给定 $\alpha$，确定拒绝域
4. 计算统计量值，判断是否拒绝 $H_0$

### 三、易错点提醒

1. **条件概率与交事件的区别**：$P(A\|B) = P(AB)/P(B)$，不是 $P(AB)$
2. **独立性判断**：$P(AB) = P(A)P(B)$，不是 $P(A\|B) = P(A)$（当 $P(B)=0$ 时不适用）
3. **方差公式**：$D(X) = E(X^2) - [E(X)]^2$，不要记错符号
4. **样本方差**：分母是 $n-1$（无偏估计），不是 $n$
5. **中心极限定理**：是近似分布，不是精确分布
6. **德摩根律**：长线变短线，$\cup$ 与 $\cap$ 互换
7. **全概率公式**：完备事件组必须两两互斥且并集为全集
8. **贝叶斯公式**：分母就是全概率公式的结果
9. **二维正态分布独立性**：$\rho = 0 \iff$ 独立（其他分布不成立）
10. **最大似然估计**：似然函数是乘积形式，通常取对数求导
