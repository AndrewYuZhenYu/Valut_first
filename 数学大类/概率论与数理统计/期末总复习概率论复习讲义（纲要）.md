### **第一部分：概率论基础 (第一章)**

#### **一、预备知识：排列组合**

1.  **加法原理**：完成一件事有 \(n\) 类方法，总方法数为 \(m_1 + m_2 + \dots + m_n\)。
2.  **乘法原理**：完成一件事有 \(n\) 个步骤，总方法数为 \(m_1 \times m_2 \times \dots \times m_n\)。
3.  **排列**：从 \(n\) 个不同元素中，有放回地取 \(m\) 个：\(n^m\) 种。无放回地取 \(m\) 个：\(A_n^m = \frac{n!}{(n-m)!}\) 种。
4.  **组合**：从 \(n\) 个不同元素中取 \(m\) 个（不考虑顺序）：\(C_n^m = \frac{n!}{m!(n-m)!}\) 种。

#### **二、随机事件与概率**

1.  **基本概念**
    *   **随机试验 \(E\)**：可重复、结果明确、结果不确定。
    *   **样本空间 \(\Omega\)**：所有可能结果的集合。
    *   **事件**：样本空间的子集。**必然事件 \(\Omega\)**，**不可能事件 \(\emptyset\)**。

2.  **事件的关系与运算 (重点)**
    *   **包含**、**相等**、**互不相容(互斥)**、**对立**。
    *   **德摩根律 (对偶律)**：\(\overline{A \cup B} = \bar{A} \cap \bar{B}\)，\(\overline{A \cap B} = \bar{A} \cup \bar{B}\)。 (长线变短线，符号变，开口方向反转)
    *   **分配律**、**结合律**、**交换律**。

3.  **概率的公理化定义与性质 (重点公式)**
    *   **性质**：
        *   \(P(\emptyset) = 0\)，\(P(\Omega) = 1\)。
        *   **求逆公式**：\(P(\bar{A}) = 1 - P(A)\)。
        *   **减法公式**：\(P(A - B) = P(A\bar{B}) = P(A) - P(AB)\)。
        *   **加法公式**：
            *   两个事件：\(P(A \cup B) = P(A) + P(B) - P(AB)\)。
            *   三个事件：\(P(A \cup B \cup C) = P(A)+P(B)+P(C)-P(AB)-P(BC)-P(AC)+P(ABC)\)。
        *   **次可加性**：\(P(\bigcup_{n} A_n) \le \sum_{n} P(A_n)\)。

4.  **等可能概型 (古典概型)**
    *   特征：有限个结果，等可能。
    *   公式：\(P(A) = \frac{A\text{包含的样本点数}}{\Omega\text{的样本总数}}\)。
    *   **超几何分布公式**：\(N\)件产品有\(M\)件次品，任取\(n\)件，恰有\(k\)件次品的概率为 \( \frac{C_M^k C_{N-M}^{n-k}}{C_N^n}\)。

5.  **几何概型**
    *   特征：无限个结果（构成几何区域），等可能。
    *   公式：\(P(A) = \frac{S(A)}{S(\Omega)}\)（\(S\) 为长度、面积或体积）。

#### **三、条件概率与独立性 (核心)**

1.  **条件概率**
    *   定义：\(P(B|A) = \frac{P(AB)}{P(A)}, (P(A)>0)\)。
    *   **乘法公式**：\(P(AB) = P(A)P(B|A) = P(B)P(A|B)\)。
    *   推广：\(P(A_1A_2\dots A_n) = P(A_1)P(A_2|A_1)\dots P(A_n|A_1\dots A_{n-1})\)。

2.  **事件的独立性**
    *   **定义**：\(A, B\) 独立 \(\iff\) \(P(AB) = P(A)P(B)\)。
    *   **性质**：若 \(A, B\) 独立，则 \(A\) 与 \(\bar{B}\)，\(\bar{A}\) 与 \(B\)，\(\bar{A}\) 与 \(\bar{B}\) 也独立。
    *   **三个事件相互独立**：需要满足 \(P(AB)=P(A)P(B), P(AC)=P(A)P(C), P(BC)=P(B)P(C)\)，且 \(P(ABC)=P(A)P(B)P(C)\)。**两两独立不一定相互独立。**

3.  **全概率公式与贝叶斯公式 (核心)**
    *   **完备事件组**：\(A_1, \dots, A_n\) 两两互斥，且 \(\bigcup_{i=1}^n A_i = \Omega\)。
    *   **全概率公式**：\(P(B) = \sum_{i=1}^n P(A_i)P(B|A_i)\)（用于由因求果）。
    *   **贝叶斯公式**：\(P(A_i|B) = \frac{P(A_i)P(B|A_i)}{\sum_{j=1}^n P(A_j)P(B|A_j)}\)（用于执果寻因，先验概率更新为后验概率）。

4.  **伯努利模型**
    *   \(n\)重伯努利试验中，事件 \(A\) 恰好发生 \(k\) 次的概率为：\(C_n^k p^k (1-p)^{n-k}, \quad k=0,1,\dots,n\)。

### **第二部分：随机变量及其分布 (第二、三章)**

#### **一、一维随机变量**

1.  **分布函数 \(F(x)\)**
    *   定义：\(F(x) = P\{X \le x\}\)。
    *   性质：单调不减、\(0\le F(x)\le 1\)、右连续、\(F(-\infty)=0, F(+\infty)=1\)。
    *   重要计算：
        *   \(P(a < X \le b) = F(b) - F(a)\)
        *   \(P(X = a) = F(a) - F(a-0)\)

2.  **离散型随机变量**
    *   分布律：\(P(X=x_i)=p_i\)，满足 \(\sum p_i = 1\)。
    *   **常见分布**：
        *   **(0-1)分布** \(B(1, p)\)：\(P(X=k)=p^k(1-p)^{1-k}, k=0,1\)。
        *   **二项分布** \(B(n, p)\)：\(P(X=k)=C_n^k p^k (1-p)^{n-k}\)。
        *   **泊松分布** \(P(\lambda)\)：\(P(X=k)=\frac{\lambda^k}{k!}e^{-\lambda}, k=0,1,2,\dots\)。
        *   **几何分布** \(G(p)\)：\(P(X=k)=p(1-p)^{k-1}, k=1,2,\dots\)。

3.  **连续型随机变量**
    *   概率密度函数 \(f(x)\)：满足 \(f(x)\ge 0, \int_{-\infty}^{+\infty}f(x)dx=1\)，且 \(F'(x)=f(x)\)（在连续点）。
    *   **常见分布**：
        *   **均匀分布** \(U(a,b)\)：\(f(x)=\frac{1}{b-a}, a<x<b\)；\(F(x)=\frac{x-a}{b-a}, a\le x<b\)。
        *   **指数分布** \(E(\lambda)\)：\(f(x)=\lambda e^{-\lambda x}, x>0\)；\(F(x)=1-e^{-\lambda x}, x>0\)。
        *   **正态分布** \(N(\mu, \sigma^2)\)：\(f(x)=\frac{1}{\sqrt{2\pi}\sigma}e^{-\frac{(x-\mu)^2}{2\sigma^2}}\)。
            *   **标准化**：若 \(X \sim N(\mu, \sigma^2)\)，则 \(\frac{X-\mu}{\sigma} \sim N(0,1)\)。
            *   \(\Phi(x)\) 是标准正态分布函数，有 \(\Phi(-x)=1-\Phi(x)\)。
            *   概率计算：\(P(X \le a) = \Phi(\frac{a-\mu}{\sigma})\)，\(P(a<X\le b)=\Phi(\frac{b-\mu}{\sigma})-\Phi(\frac{a-\mu}{\sigma})\)。

#### **二、多维随机变量 (以二维为例)**

1.  **联合分布与边缘分布**
    *   **联合分布函数**：\(F(x,y)=P\{X\le x, Y\le y\}\)。
    *   **离散型**：联合分布律 \(p_{ij}=P(X=x_i, Y=y_j)\)。**边缘分布律**：\(p_{i\cdot}=\sum_j p_{ij}\)，\(p_{\cdot j}=\sum_i p_{ij}\)。
    *   **连续型**：联合概率密度 \(f(x,y)\)，满足 \(\iint f(x,y)dxdy=1\)。**边缘概率密度**：\(f_X(x)=\int_{-\infty}^{+\infty} f(x,y)dy\)，\(f_Y(y)=\int_{-\infty}^{+\infty} f(x,y)dx\)。

2.  **条件分布**
    *   **离散型**：\(P(X=x_i|Y=y_j)=\frac{p_{ij}}{p_{\cdot j}}\)。
    *   **连续型**：\(f_{X|Y}(x|y)=\frac{f(x,y)}{f_Y(y)}\)，\(f_{Y|X}(y|x)=\frac{f(x,y)}{f_X(x)}\)。

3.  **独立性**
    *   \(X\) 与 \(Y\) 独立 \(\iff\) \(F(x,y)=F_X(x)F_Y(y)\)。
    *   **离散型**：\(p_{ij}=p_{i\cdot} \cdot p_{\cdot j}\)（对所有 \(i,j\)）。
    *   **连续型**：\(f(x,y)=f_X(x)f_Y(y)\)。

4.  **二维常见分布**
    *   **二维均匀分布**：\((X,Y)\) 在区域 \(G\) 上均匀分布，\(f(x,y)=\frac{1}{S_G}, (x,y)\in G\)。
    *   **二维正态分布** \(N(\mu_1,\mu_2;\sigma_1^2,\sigma_2^2;\rho)\)。
        *   **重要性质**：边缘分布 \(X\sim N(\mu_1, \sigma_1^2)\)，\(Y\sim N(\mu_2, \sigma_2^2)\)。
        *   **独立性与相关性**：\(X\) 与 \(Y\) 独立 \(\iff\) \(\rho=0\)。

5.  **随机变量函数的分布**
    *   **离散型**：列出 \(Z=g(X,Y)\) 的所有可能值，合并相同值的概率。
    *   **连续型**：使用**卷积公式** (以 \(Z=X+Y\) 为例)
        *   \(f_Z(z) = \int_{-\infty}^{+\infty} f(x, z-x) dx\)。
        *   若 \(X, Y\) 独立：\(f_Z(z) = \int_{-\infty}^{+\infty} f_X(x) f_Y(z-x) dx\)。
    *   **最大、最小值分布**：
        *   \(F_{\max}(z) = F_X(z)F_Y(z)\) （\(X, Y\) 独立）。
        *   \(F_{\min}(z) = 1 - [1-F_X(z)][1-F_Y(z)]\) （\(X, Y\) 独立）。

### **第三部分：随机变量的数字特征 (第四章)**

#### **一、数学期望 \(E(X)\)**

1.  **定义**：
    *   离散型：\(E(X)=\sum_i x_i p_i\) (需绝对收敛)。
    *   连续型：\(E(X)=\int_{-\infty}^{+\infty} x f(x) dx\) (需绝对收敛)。
2.  **函数期望**：
    *   \(E[g(X)] = \sum_i g(x_i)p_i\) 或 \(\int_{-\infty}^{+\infty} g(x)f(x)dx\)。
    *   \(E[g(X,Y)] = \sum_i\sum_j g(x_i,y_j)p_{ij}\) 或 \(\iint g(x,y)f(x,y)dxdy\)。
3.  **性质**：
    *   \(E(C)=C\)，\(E(aX+b)=aE(X)+b\)。
    *   \(E(X\pm Y)=E(X)\pm E(Y)\)。
    *   **若 \(X, Y\) 独立**，则 \(E(XY)=E(X)E(Y)\)。

#### **二、方差 \(D(X)\)**

1.  **定义**：\(D(X)=E\{[X-E(X)]^2\} = E(X^2) - [E(X)]^2\)。
2.  **性质**：
    *   \(D(C)=0\)，\(D(aX+b)=a^2D(X)\)。
    *   \(D(X\pm Y)=D(X)+D(Y) \pm 2\text{Cov}(X,Y)\)。
    *   **若 \(X, Y\) 独立**，则 \(D(X\pm Y)=D(X)+D(Y)\)。

#### **三、协方差 \(\text{Cov}(X,Y)\) 与相关系数 \(\rho_{XY}\)**

1.  **协方差**：
    *   定义：\(\text{Cov}(X,Y)=E\{[X-E(X)][Y-E(Y)]\} = E(XY)-E(X)E(Y)\)。
    *   性质：\(\text{Cov}(aX+b, cY+d)=ac\text{Cov}(X,Y)\)。
2.  **相关系数**：
    *   定义：\(\rho_{XY} = \frac{\text{Cov}(X,Y)}{\sqrt{D(X)}\sqrt{D(Y)}}\)，且 \(|\rho_{XY}| \le 1\)。
3.  **独立性与相关性**：
    *   **独立 \(\Rightarrow\) 不相关** (\(\rho=0\))。**反之不成立**。
    *   **例外**：对于**二维正态分布**，不相关 \(\iff\) 独立 (\(\rho=0\))。

### **第四部分：大数定律与中心极限定理 (第五章)**

#### **一、大数定律**

*   **切比雪夫大数定律**：要求方差存在且一致有界。
*   **伯努利大数定律**：频率 \(n_A/n\) 依概率收敛于概率 \(p\)。
*   **辛钦大数定律**：独立同分布，期望 \(\mu\) 存在，则样本均值 \(\bar{X}\) 依概率收敛于 \(\mu\)。

#### **二、中心极限定理 (核心)**

1.  **列维-林德伯格定理 (独立同分布)**：无论总体服从什么分布，只要 \(E(X)=\mu, D(X)=\sigma^2\) 存在，则当 \(n\) 很大时，\(\sum_{i=1}^n X_i\) 近似服从 \(N(n\mu, n\sigma^2)\)。即：
    \[
    \frac{\sum_{i=1}^n X_i - n\mu}{\sqrt{n}\sigma} \xrightarrow{\text{近似}} N(0, 1)
    \]

2.  **棣莫弗-拉普拉斯定理 (二项分布)**：若 \(X \sim B(n, p)\)，当 \(n\) 很大时，\(X\) 近似服从 \(N(np, np(1-p))\)。即：
    \[
    \frac{X - np}{\sqrt{np(1-p)}} \xrightarrow{\text{近似}} N(0, 1)
    \]
    *   用于解决“次数”问题，如“求参加家长会人数超过450的概率”。

### **第五部分：数理统计基础 (第六章)**

#### **一、基本概念**

*   **总体、样本、统计量**。
*   **样本均值**：\(\bar{X} = \frac{1}{n}\sum_{i=1}^n X_i\)。
*   **样本方差**：\(S^2 = \frac{1}{n-1}\sum_{i=1}^n (X_i - \bar{X})^2\)。
*   **重要性质**：\(E(\bar{X}) = \mu\)，\(D(\bar{X}) = \sigma^2/n\)，\(E(S^2) = \sigma^2\)。

#### **二、三大抽样分布**

1.  **\(\chi^2\) 分布**：设 \(X_i \sim N(0,1)\)，则 \(\sum_{i=1}^n X_i^2 \sim \chi^2(n)\)。性质：\(E(\chi^2)=n\)，\(D(\chi^2)=2n\)，可加性。
2.  **\(t\) 分布**：\(T = \frac{X}{\sqrt{Y/n}}\)，其中 \(X\sim N(0,1), Y\sim \chi^2(n)\)，则 \(T\sim t(n)\)。
3.  **\(F\) 分布**：\(F = \frac{U/n_1}{V/n_2}\)，其中 \(U\sim \chi^2(n_1), V\sim \chi^2(n_2)\)，则 \(F\sim F(n_1, n_2)\)。

#### **三、正态总体的抽样分布 (核心)**

设 \(X_1, \dots, X_n\) 来自总体 \(N(\mu, \sigma^2)\)，\(\bar{X}\) 和 \(S^2\) 分别为样本均值和方差。
1.  \(\bar{X} \sim N(\mu, \frac{\sigma^2}{n})\)，\(\frac{\bar{X}-\mu}{\sigma/\sqrt{n}} \sim N(0,1)\)。
2.  \(\frac{(n-1)S^2}{\sigma^2} \sim \chi^2(n-1)\)。
3.  \(\frac{\bar{X}-\mu}{S/\sqrt{n}} \sim t(n-1)\)。

#### **四、参数估计**

1.  **点估计方法**：
    *   **矩估计**：令样本矩等于总体矩，解方程。常用：\(\bar{X}=E(X)\)，\(\frac{1}{n}\sum (X_i-\bar{X})^2 = D(X)\)。
    *   **最大似然估计**：写出似然函数 \(L(\theta)=\prod f(x_i;\theta)\)，取对数，求导，令导数为0，解出 \(\hat{\theta}\)。
2.  **估计量的评选标准**：
    *   **无偏性**：\(E(\hat{\theta}) = \theta\)。例如 \(S^2\) 是 \(\sigma^2\) 的无偏估计。
    *   **有效性**：方差越小越有效。
    *   **一致性**：\(\hat{\theta} \xrightarrow{P} \theta\)。

#### **五、置信区间 (一个正态总体)**

*   **\(\mu\) 的置信区间**：\(\sigma^2\) 已知：\(\bar{X} \pm z_{\alpha/2} \frac{\sigma}{\sqrt{n}}\)；\(\sigma^2\) 未知：\(\bar{X} \pm t_{\alpha/2}(n-1) \frac{S}{\sqrt{n}}\)。
*   **\(\sigma^2\) 的置信区间**：\(\mu\) 未知：\(\left( \frac{(n-1)S^2}{\chi^2_{\alpha/2}(n-1)}, \frac{(n-1)S^2}{\chi^2_{1-\alpha/2}(n-1)} \right)\)。

### **第六部分：假设检验 (第七章)**

#### **一、基本步骤**

1.  **提出假设**：原假设 \(H_0\) 和备择假设 \(H_1\)。
2.  **选择检验统计量**：当 \(H_0\) 为真时，统计量的分布是已知的。
3.  **确定拒绝域**：给定显著性水平 \(\alpha\)，查表得到临界值，确定拒绝域 \(W\)。
4.  **做出决策**：根据样本计算统计量的值，若落在拒绝域内，则拒绝 \(H_0\)；否则，不拒绝 \(H_0\)。

#### **二、一个正态总体参数的假设检验 (双侧检验)**

*   **检验 \(\mu\)**：
    *   \(\sigma^2\) 已知：检验统计量 \(U = \frac{\bar{X}-\mu_0}{\sigma/\sqrt{n}} \sim N(0,1)\)，拒绝域 \(|U| \ge z_{\alpha/2}\)。
    *   \(\sigma^2\) 未知：检验统计量 \(T = \frac{\bar{X}-\mu_0}{S/\sqrt{n}} \sim t(n-1)\)，拒绝域 \(|T| \ge t_{\alpha/2}(n-1)\)。
*   **检验 \(\sigma^2\)**：
    *   \(\mu\) 已知：检验统计量 \(\chi^2 = \frac{\sum_{i=1}^n (X_i-\mu)^2}{\sigma_0^2} \sim \chi^2(n)\)。
    *   \(\mu\) 未知：检验统计量 \(\chi^2 = \frac{(n-1)S^2}{\sigma_0^2} \sim \chi^2(n-1)\)。
