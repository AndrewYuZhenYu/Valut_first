## 一、本章导览

栈和队列是**限定插入和删除只能在表的"端点"进行**的线性表。它们与普通线性表的区别在于操作位置的限制：

| 结构 | 插入位置 | 删除位置 | 特性 | 别称 |
|------|----------|----------|------|------|
| 线性表 | 任意位置 `Insert(L, i, x)`，`1≤i≤n+1` | 任意位置 `Delete(L, i)`，`1≤i≤n` | 自由 | — |
| 栈 | 仅表尾 `Insert(S, n+1, x)` | 仅表尾 `Delete(S, n)` | 后进先出 | LIFO 表 |
| 队列 | 仅表尾 `Insert(Q, n+1, x)` | 仅表头 `Delete(Q, 1)` | 先进先出 | FIFO 表 |

## 二、栈（Stack）

### 2.1 栈的定义

> **栈**是限定仅在**表尾**进行插入或删除操作的线性表。

- 允许插入和删除的一端（表尾）称为**栈顶（top）**；
- 另一端（表头）称为**栈底（bottom）**；
- 表中没有元素时称为**空栈**。

设栈 $S=(a_1, a_2, \dots, a_n)$，则：

- 进栈次序：$a_1, a_2, \dots, a_{n-1}, a_n$；
- 退栈次序：$a_n, a_{n-1}, \dots, a_2, a_1$。

栈按照**后进先出（LIFO, Last In First Out）**原则处理数据元素，因此栈也称为"后进先出"表。

### 2.2 栈的抽象数据类型（ADT）

```
ADT Stack {
    数据对象：D = { ai | ai ∈ ElemSet, i = 1,2,...,n, n≥0 }
    数据关系：R1 = { <ai-1, ai> | ai-1, ai ∈ D, i = 2,...,n }
              约定 an 端为栈顶，a1 端为栈底。
    基本操作：...
} ADT Stack
```

**基本操作一览：**

| 操作 | 含义 |
|------|------|
| `InitStack(&S)` | 初始化，构造空栈 S |
| `DestroyStack(&S)` | 销毁栈（前提：S 已存在） |
| `ClearStack(&S)` | 将 S 清为空栈 |
| `StackEmpty(S)` | 判空，空返回 1，否则返回 0 |
| `StackLength(S)` | 求长度，返回元素个数 |
| `GetTop(S, &e)` | 取栈顶元素（S 非空） |
| `Push(&S, e)` | 入栈，e 成为新栈顶 |
| `Pop(&S, &e)` | 出栈，删除栈顶并用 e 返回其值（S 非空） |
| `StackTravers(S, visit())` | 从栈底到栈顶依次调用 `visit()`，一旦失败则操作失败 |

> 记忆要点：带 `&S` 的（Init/Destroy/Clear/Push/Pop）会**修改栈本身**；带 `&e` 的（GetTop/Pop）会**回传元素值**。

### 2.3 出栈序列问题

**例**：三个元素的进栈顺序为 1、2、3（以 `s` 表示进栈、`x` 表示出栈），可能的出栈序列有 5 种：

| 出栈序列 | 操作序列 |
|----------|----------|
| 1, 2, 3 | s x s x s x |
| 1, 3, 2 | s x s s x x |
| 2, 1, 3 | s s x x s x |
| 2, 3, 1 | s s x s x x |
| 3, 2, 1 | s s s x x x |

> **不可能出现 3, 1, 2**：因为 3 先出栈意味着 1、2 都在栈中，且 2 在 1 之上，出栈必然是 2 先于 1。

### 2.4 栈的存储实现

栈有两种存储方法：**顺序存储结构**和**链式存储结构**。

#### 2.4.1 顺序栈（方法一：定长数组）

利用一组地址连续的存储单元依次存放从栈底到栈顶的数据元素，数组上界 `MAXSIZE` 表示栈的最大容量，附设栈顶指针 `Top` 指示栈顶元素在数组中的位置。栈底位置固定，栈顶位置随进栈/出栈而变化。

- `Top = -1`：空栈；
- 栈满时再入栈产生"**上溢**"；空栈时再出栈产生"**下溢**"。

```cpp
// 顺序栈（方法一）：栈顶指针指向栈顶元素本身
#include <stdio.h>

#define MAXSIZE 100
#define OK   1
#define ERROR 0

struct SqStack {
    int Stack[MAXSIZE];
    int Top;              // 栈顶指针，指向栈顶元素
};

// 初始化：构造一个空栈
int InitStack(SqStack &S) {
    S.Top = -1;
    return OK;
}

// 判空
int StackEmpty(SqStack S) {
    return S.Top < 0;
}

// 入栈
int Push(SqStack &S, int x) {
    if (S.Top >= MAXSIZE - 1) return ERROR;   // 栈满，上溢
    S.Stack[++S.Top] = x;
    return OK;
}

// 出栈
int Pop(SqStack &S, int &e) {
    if (S.Top < 0) return ERROR;              // 栈空，下溢
    e = S.Stack[S.Top--];
    return OK;
}

// 取栈顶元素
int GetTop(SqStack S, int &e) {
    if (S.Top < 0) return ERROR;
    e = S.Stack[S.Top];
    return OK;
}

int main() {
    SqStack S;
    InitStack(S);
    for (int i = 1; i <= 5; i++) Push(S, i * 10);

    int e;
    GetTop(S, e);
    printf("栈顶元素: %d\n", e);

    printf("出栈序列: ");
    while (Pop(S, e)) printf("%d ", e);
    printf("\n");
    return 0;
}
```

#### 2.4.2 顺序栈（方法二：动态数组）

栈顶指针指向**栈顶元素的下一个位置**，栈底用指针 `Base` 表示，容量不足时可动态增长（`realloc`）。

```cpp
// 顺序栈（方法二）：栈顶指针指向栈顶元素的下一个位置，可动态扩容
#include <stdio.h>
#include <stdlib.h>

#define STACK_INIT_SIZE 100   // 初始容量
#define STACKINCREMENT  10    // 每次增长量
#define OK   1
#define ERROR 0

struct SqStack {
    int *Base;        // 栈底指针
    int *Top;         // 栈顶指针，指向栈顶元素的下一个位置
    int  Stacksize;   // 当前已分配的存储容量
};

// 构造空栈
int InitStack(SqStack &S) {
    S.Base = (int *)malloc(STACK_INIT_SIZE * sizeof(int));
    if (!S.Base) return ERROR;
    S.Top = S.Base;
    S.Stacksize = STACK_INIT_SIZE;
    return OK;
}

// 判空
int StackEmpty(SqStack S) {
    return S.Top == S.Base;
}

// 求长度
int StackLength(SqStack S) {
    return (int)(S.Top - S.Base);
}

// 取栈顶元素
int GetTop(SqStack S, int &e) {
    if (S.Top == S.Base) return ERROR;   // 栈空
    e = *(S.Top - 1);
    return OK;
}

// 入栈
int Push(SqStack &S, int e) {
    if (S.Top - S.Base >= S.Stacksize) {          // 栈满，追加存储空间
        S.Base = (int *)realloc(S.Base,
                    (S.Stacksize + STACKINCREMENT) * sizeof(int));
        if (!S.Base) return ERROR;
        S.Top = S.Base + S.Stacksize;
        S.Stacksize += STACKINCREMENT;
    }
    *S.Top++ = e;         // 先赋值，后 top 加 1
    return OK;
}

// 出栈
int Pop(SqStack &S, int &e) {
    if (S.Top == S.Base) return ERROR;   // 栈空
    e = *--S.Top;         // 先 top 减 1，后取值
    return OK;
}

int main() {
    SqStack S;
    InitStack(S);

    for (int i = 1; i <= 150; i++) Push(S, i);   // 超过初始容量，触发扩容
    printf("入栈后长度: %d（容量 %d）\n", StackLength(S), S.Stacksize);

    int e;
    GetTop(S, e);
    printf("栈顶元素: %d\n", e);
    return 0;
}
```

**顺序栈判空、判满条件（方法二）：**

- 栈空：`S.Top == S.Base`；
- 栈满：`S.Top - S.Base >= S.Stacksize`。

> 注意：非空栈中的栈顶指针始终在**栈顶元素的下一个位置**上。

#### 2.4.3 链栈

当最大需要容量事先不能估计时，采用链式存储结构更有效。链栈的操作**只能在栈顶处进行**。

```cpp
// 链栈：仅在栈顶（链表头部）进行插入和删除
#include <stdio.h>
#include <stdlib.h>

#define OK   1
#define ERROR 0

struct snode {
    int data;
    struct snode *next;
};

// 进栈
int push(struct snode *&top, int x) {
    struct snode *t = (struct snode *)malloc(sizeof(struct snode));
    if (t == NULL) return ERROR;   // 内存无可用空间，栈上溢
    t->data = x;
    t->next = top;
    top = t;
    return OK;
}

// 出栈
int pop(struct snode *&top, int &e) {
    if (top == NULL) return ERROR; // 栈空，下溢
    struct snode *p = top;
    top = top->next;
    e = p->data;
    free(p);
    return OK;
}

// 判空
int stackEmpty(struct snode *top) {
    return top == NULL;
}

int main() {
    struct snode *top = NULL;      // 空链栈
    for (int i = 1; i <= 5; i++) push(top, i);

    printf("链栈是否为空: %d\n", stackEmpty(top));

    int e;
    printf("出栈序列: ");
    while (pop(top, e)) printf("%d ", e);
    printf("\n");
    return 0;
}
```

> **链栈的特点**：不会产生单个栈满而其余栈空的情形，只有系统空间全部用完（`malloc` 无法实现）时才会发生上溢，因此多个链栈共享空间是自然的。对元素多变的栈来说，链式存储结构更适宜；初始化、判空也易实现。

## 三、栈的应用举例

### 3.1 数制转换

**原理**：$N = (N\ \text{div}\ d) \times d + N\ \text{mod}\ d$。除基取余，余数**逆序**即为结果，恰好符合栈的 LIFO 特性。

**例**：$(1348)_{10} = (2504)_8$

| N | N div 8 | N mod 8 |
|---|---------|---------|
| 1348 | 168 | 4 |
| 168 | 21 | 0 |
| 21 | 2 | 5 |
| 2 | 0 | 2 |

计算顺序（余数）为 4→0→5→2，输出顺序（逆序）为 **2504**。

```cpp
// 数制转换：将十进制数 N 转换为 d 进制并输出
#include <stdio.h>

#define MAXSIZE 100
#define OK   1
#define ERROR 0

int Stack[MAXSIZE];
int Top = -1;

int Push(int x) {
    if (Top >= MAXSIZE - 1) return ERROR;
    Stack[++Top] = x;
    return OK;
}

int Pop(int &e) {
    if (Top < 0) return ERROR;
    e = Stack[Top--];
    return OK;
}

int StackEmpty() {
    return Top < 0;
}

// 将十进制 N 转换为 d 进制并输出（2≤d≤10）
void conversion(int N, int d) {
    Top = -1;
    while (N != 0) {          // N 不等于 0 时循环
        Push(N % d);
        N = N / d;
    }
    int e;
    while (!StackEmpty()) {
        Pop(e);
        printf("%d", e);
    }
}

int main() {
    int N = 1348, d = 8;
    printf("(%d)10 = (", N);
    conversion(N, d);
    printf(")%d\n", d);
    return 0;
}
```

### 3.2 括号匹配的检验

检验括号是否匹配可用"**期待的急迫程度**"来描述：

- `( [ ] ( ) )`、`[ ( [ ] [ ] ) ]` 为正确格式；
- `[ ( ] )`、`( [ ( ) )`、`( ( ) ] )` 为不正确格式。

**可能出现的不匹配情况：**

1. 到来的右括号**并非所"期待"的**（"不速之客"）；
2. 直到结束，也没有到来所"期待"的括号（左括号有余）。

**算法设计思想：**

1. 凡出现**左括号**，则**进栈**；
2. 凡出现**右括号**，则先检查栈是否空——若栈空则表明该右括号多余；否则与栈顶元素比较，若相匹配则左括号出栈，否则表明不匹配；
3. 表达式检验结束时，若**栈空**则匹配正确，否则表明"左括号"有余。

```cpp
// 括号匹配检验：支持 () 、[] 、{} 三种括号任意嵌套
#include <stdio.h>

#define MAXSIZE 100

char Stack[MAXSIZE];
int  Top = -1;

void Push(char c) { Stack[++Top] = c; }
char Pop()        { return Stack[Top--]; }
char GetTop()     { return Stack[Top]; }
int  StackEmpty() { return Top < 0; }

// 判断左右括号是否匹配
int Match(char left, char right) {
    return (left == '(' && right == ')') ||
           (left == '[' && right == ']') ||
           (left == '{' && right == '}');
}

// 检验表达式 exp（以 '\0' 结束）中的括号是否匹配
// 返回 1 表示匹配正确，0 表示错误
int matching(char *exp) {
    Top = -1;
    int i = 0;
    int state = 1;                        // 1 表示到目前为止匹配
    while (exp[i] != '\0' && state) {
        char c = exp[i];
        switch (c) {
            case '(':
            case '[':
            case '{':
                Push(c);                  // 左括号一律进栈
                break;
            case ')':
            case ']':
            case '}':
                if (!StackEmpty() && Match(GetTop(), c))
                    Pop();                // 相匹配，左括号出栈
                else
                    state = 0;            // 不匹配
                break;
            default:
                break;                    // 其他字符忽略
        }
        i++;
    }
    if (StackEmpty() && state) return 1;  // 栈空且无错误 → 匹配正确
    else return 0;
}

int main() {
    char t1[] = "([ ]( ))";
    char t2[] = "[([ ][ ])]";
    char t3[] = "[( ])";
    char t4[] = "([( ))";
    printf("%-14s -> %s\n", t1, matching(t1) ? "匹配正确" : "匹配错误");
    printf("%-14s -> %s\n", t2, matching(t2) ? "匹配正确" : "匹配错误");
    printf("%-14s -> %s\n", t3, matching(t3) ? "匹配正确" : "匹配错误");
    printf("%-14s -> %s\n", t4, matching(t4) ? "匹配正确" : "匹配错误");
    return 0;
}
```

### 3.3 行编辑程序问题

用户终端输入时难免出错，若"每接收一个字符即存入数据区"则不便更正。合理做法：设立**输入缓冲区**，接收一行字符后逐行存入数据区，并约定：

- `#` 为**退格符**（前一个字符无效）；
- `@` 为**退行符**（整行作废）。

**缓冲区可用栈实现**，每接收一个字符后判别：

- 既非退格符也非退行符 → **压入栈顶**；
- 是退格符 → 从栈顶**删去一个字符**；
- 是退行符 → 字符栈**清为空栈**。

**例**：输入 `whli##ilr#e(s#*s)` 与 `outcha@putchar(*s=#++);`，实际有效为 `while(*s)` 与 `putchar(*s++);`。

```cpp
// 行编辑程序：用栈作输入缓冲区，处理退格符 '#' 与退行符 '@'
#include <stdio.h>

#define MAXSIZE 100

char Stack[MAXSIZE];
int  Top = -1;

void Push(char c)  { Stack[++Top] = c; }
char Pop()         { return Stack[Top--]; }
void ClearStack()  { Top = -1; }
int  StackEmpty()  { return Top < 0; }

// 处理一行字符（以 '\0' 结束），输出有效内容
void LineEdit(char *line) {
    Top = -1;
    int i = 0;
    while (line[i] != '\0') {
        char ch = line[i];
        if (ch == '#') {                  // 退格符
            if (!StackEmpty()) Pop();
        } else if (ch == '@') {           // 退行符
            ClearStack();
        } else {
            Push(ch);                     // 普通字符进栈
        }
        i++;
    }
    // 从栈底到栈顶输出（即缓冲区的有效内容）
    for (int k = 0; k <= Top; k++) printf("%c", Stack[k]);
    printf("\n");
}

int main() {
    LineEdit("whli##ilr#e(s#*s)");
    LineEdit("outcha@putchar(*s=#++);");
    return 0;
}
```

### 3.4 迷宫求解

通常用"**穷举求解**"：从入口出发，沿某一方向探索，能通则前进，不能通则沿原路退回换方向。求迷宫路径的基本思想：

- 若当前位置"**可通**"，则纳入路径，继续前进；
- 若当前位置"**不可通**"，则后退，换方向继续探索；
- 若四周"**均无通路**"，则将当前位置从路径中删除（回溯）。

算法从当前位置的**东向**开始按**顺时针**方向（东→南→西→北）探测，用栈保存"当前已走过但尚未走通的路径"。

```cpp
// 迷宫求解：用栈实现"穷举 + 回溯"，从入口 (1,1) 走到出口 (M,N)
#include <stdio.h>

#define MAXSIZE 100
#define M 8
#define N 8

int maze[M + 2][N + 2];       // 1 表示墙，0 表示可通（外围加一圈墙）
int visited[M + 2][N + 2];    // 是否已经走过

struct Pos {
    int x, y;   // 坐标
    int dir;    // 已探测到的方向：-1 表示尚未开始
};

struct Pos Stack[MAXSIZE];
int Top = -1;

// 方向：0 东、1 南、2 西、3 北（顺时针）
int dx[4] = {0, 1, 0, -1};
int dy[4] = {1, 0, -1, 0};

void Push(struct Pos p) { Stack[++Top] = p; }
struct Pos Pop()        { return Stack[Top--]; }

int main() {
    // 初始化迷宫：全部清 0，再在外围加一圈墙
    for (int i = 0; i <= M + 1; i++)
        for (int j = 0; j <= N + 1; j++)
            maze[i][j] = 0;
    for (int i = 0; i <= M + 1; i++) { maze[i][0] = 1; maze[i][N + 1] = 1; }
    for (int j = 0; j <= N + 1; j++) { maze[0][j] = 1; maze[M + 1][j] = 1; }

    // 设置内部墙（"立柱"式布局，保证从入口到出口连通）
    maze[2][2] = 1; maze[2][4] = 1; maze[2][6] = 1;
    maze[4][2] = 1; maze[4][4] = 1; maze[4][6] = 1;
    maze[6][2] = 1; maze[6][4] = 1; maze[6][6] = 1;

    int sx = 1, sy = 1;           // 入口
    int ex = M, ey = N;           // 出口

    struct Pos start = {sx, sy, -1};
    Push(start);
    visited[sx][sy] = 1;

    while (Top >= 0) {
        struct Pos cur = Stack[Top];
        if (cur.x == ex && cur.y == ey) {          // 到达出口
            printf("找到一条路径:\n");
            for (int i = 0; i <= Top; i++)
                printf("(%d,%d) ", Stack[i].x, Stack[i].y);
            printf("\n路径长度: %d\n", Top + 1);
            return 0;
        }
        int found = 0;
        for (int d = cur.dir + 1; d < 4; d++) {    // 换下一个方向探索
            int nx = cur.x + dx[d];
            int ny = cur.y + dy[d];
            if (maze[nx][ny] == 0 && !visited[nx][ny]) {
                Stack[Top].dir = d;                // 记录栈顶已试过的方向
                visited[nx][ny] = 1;               // 标记走通
                struct Pos np = {nx, ny, -1};
                Push(np);
                found = 1;
                break;
            }
        }
        if (!found) Top--;                         // 四周均不通，退栈（回溯）
    }
    printf("迷宫没有通路\n");
    return 0;
}
```

### 3.5 表达式求值（算符优先法）

表达式求值是编译的基本问题。"算符优先法"根据运算优先关系规定实现对表达式的编译或解释执行。

**算术四则运算规则：** ① 先括号内后括号外；② 先乘除后加减；③ 同级运算从左到右。

**表达式的组成：**

- **操作数（operand）**：常数、变量或常量标识符；
- **运算符（operator）**：算术、关系、逻辑运算符等；
- **界限符（delimiter）**：`(`、`)`、表达式结束符等。

**算符间的优先关系**：把运算符和界限符统称为**算符**，任意两个相继出现的算符 $\theta_1$、$\theta_2$ 之间的优先关系至多为以下三种之一：

- $\theta_1 < \theta_2$：$\theta_1$ 优先权**低于** $\theta_2$；
- $\theta_1 = \theta_2$：优先权**等于**；
- $\theta_1 > \theta_2$：$\theta_1$ 优先权**高于** $\theta_2$。

**算符优先关系表**（行 $\theta_1$，列 $\theta_2$）：

| $\theta_1\backslash\theta_2$ | + | - | * | / | ( | ) | # |
|---|---|---|---|---|---|---|---|
| + | > | > | < | < | < | > | > |
| - | > | > | < | < | < | > | > |
| * | > | > | > | > | < | > | > |
| / | > | > | > | > | < | > | > |
| ( | < | < | < | < | < | = | (空) |
| ) | > | > | > | > | (空) | > | > |
| # | < | < | < | < | < | (空) | = |

**算法基本思想**（使用两个工作栈）：

- **OPTR 栈**：寄存运算符；
- **OPND 栈**：寄存操作数或运算结果。

1. 置操作数栈为空，表达式起始符 `#` 为运算符栈栈底元素；
2. 依次读入每个字符：若是操作数则进 OPND 栈；若是运算符则与 OPTR 栈顶比较优先数后作相应操作，直至整个表达式求值完毕（OPTR 栈顶和当前读入字符均为 `#`）。

```cpp
// 表达式求值（算符优先法）：支持 + - * / ( ) 及多位整数，表达式以 '#' 结束
#include <stdio.h>

#define MAXSIZE 100

int  OPND[MAXSIZE];   // 操作数栈（int）
int  opndTop = -1;
char OPTR[MAXSIZE];   // 运算符栈（char）
int  optrTop = -1;

void pushOpnd(int x)   { OPND[++opndTop] = x; }
int  popOpnd()         { return OPND[opndTop--]; }
void pushOptr(char c)  { OPTR[++optrTop] = c; }
char popOptr()         { return OPTR[optrTop--]; }
char getTopOptr()      { return OPTR[optrTop]; }

// 判断 c 是否为算符
int In(char c) {
    return c == '+' || c == '-' || c == '*' || c == '/'
        || c == '(' || c == ')' || c == '#';
}

// 返回栈顶算符 t1 与当前算符 t2 的优先关系：'<' '=' '>'
char Precede(char t1, char t2) {
    if (t1 == '+' || t1 == '-') {
        if (t2 == '+' || t2 == '-' || t2 == ')' || t2 == '#') return '>';
        return '<';
    }
    if (t1 == '*' || t1 == '/') {
        if (t2 == '(') return '<';
        return '>';
    }
    if (t1 == '(') {
        if (t2 == ')') return '=';
        return '<';
    }
    if (t1 == ')') {
        if (t2 == '(') return '<';
        return '>';
    }
    if (t1 == '#') {                     // 栈底 '#'
        if (t2 == '#') return '=';
        return '<';
    }
    return '>';
}

// 二元运算
int Operate(int a, char theta, int b) {
    switch (theta) {
        case '+': return a + b;
        case '-': return a - b;
        case '*': return a * b;
        case '/': return a / b;
    }
    return 0;
}

// 求值：exp 为以 '#' 结束的表达式
int EvaluateExpression(char *exp) {
    opndTop = -1;
    optrTop = -1;
    pushOptr('#');                       // 运算符栈栈底放 '#'
    int i = 0;
    char c = exp[i];

    while (c != '#' || getTopOptr() != '#') {
        if (!In(c)) {                    // 读入的是操作数
            int num = 0;                 // 支持多位整数
            while (!In(exp[i])) {
                num = num * 10 + (exp[i] - '0');
                i++;
            }
            pushOpnd(num);
            c = exp[i];
        } else {
            switch (Precede(getTopOptr(), c)) {
                case '<':                // 栈顶优先权低，算符进栈
                    pushOptr(c); i++; c = exp[i];
                    break;
                case '=':                // 脱括号，接收下一字符
                    popOptr(); i++; c = exp[i];
                    break;
                case '>': {              // 退栈双操作数并运算，c 不变
                    char theta = popOptr();
                    int b = popOpnd();
                    int a = popOpnd();
                    pushOpnd(Operate(a, theta, b));
                    break;
                }
            }
        }
    }
    return popOpnd();
}

int main() {
    char exp[] = "4+2*3-10/5#";
    printf("%s = %d\n", exp, EvaluateExpression(exp));
    char exp2[] = "2*(3+4)-6/2#";
    printf("%s = %d\n", exp2, EvaluateExpression(exp2));
    return 0;
}
```

#### 表达式的三种表示法

设 $Exp = S_1 + OP + S_2$：

| 表示法 | 形式 | 示例（`a×b + (c-d/e)×f`） |
|--------|------|------|
| 前缀式 | $OP + S_1 + S_2$ | `+ × a b × - c / d e f` |
| 中缀式 | $S_1 + OP + S_2$ | `a×b + c-d/e×f` |
| 后缀式 | $S_1 + S_2 + OP$ | `a b × c d e / - f × +` |

**结论：** ① 操作数之间的相对次序不变；② 运算符的相对次序不同；③ 中缀式丢失了括号信息，致使运算次序不确定。

**运算规则：**

- **前缀式**：连续出现的两个操作数和在它们之前且紧靠它们的运算符构成一个最小表达式；
- **后缀式**：每个运算符和在它之前出现且紧靠它的两个操作数构成一个最小表达式；运算符在表达式中出现的顺序恰为表达式的运算顺序。

#### 后缀式的求值

先找运算符，再找操作数。规则：

1. 设立操作数栈 S，表达式结束符为 `#`；
2. 读入一个字符，若是操作数则压入栈；
3. 若是运算符 `optr`，弹出两个数：`x2 = pop(S); x1 = pop(S); push(S, x1 optr x2);`
4. 重复 2、3 直至读到结束符，栈顶即为表达式的值。

```cpp
// 后缀式求值：操作数以整数形式、用空格分隔（如 "4 2 3 * + 10 5 / -"）
#include <stdio.h>

#define MAXSIZE 100

int S[MAXSIZE];
int Top = -1;

void push(int x) { S[++Top] = x; }
int  pop()       { return S[Top--]; }

int isDigit(char c) { return c >= '0' && c <= '9'; }

int main() {
    char str[] = "4 2 3 * + 10 5 / -";   // 对应中缀式 4+2*3-10/5
    int i = 0;
    while (str[i] != '\0') {
        if (str[i] == ' ') { i++; continue; }
        if (isDigit(str[i])) {           // 读入一个整数操作数
            int num = 0;
            while (isDigit(str[i])) {
                num = num * 10 + (str[i] - '0');
                i++;
            }
            push(num);
        } else {                         // 读入运算符
            int x2 = pop();
            int x1 = pop();
            switch (str[i]) {
                case '+': push(x1 + x2); break;
                case '-': push(x1 - x2); break;
                case '*': push(x1 * x2); break;
                case '/': push(x1 / x2); break;
            }
            i++;
        }
    }
    printf("后缀式结果: %d\n", pop());
    return 0;
}
```

#### 中缀式转后缀式

每个运算符的运算次序由它之后的运算符决定；后缀式中优先数高的运算符领先于优先数低的运算符。转换规律：

1. 设立运算符栈，预设栈底为 `#`，表达式结束符为 `#`；
2. 当前字符是操作数 → 直接发送给后缀式；
3. 当前运算符优先数**高于**栈顶运算符 → 进栈；
4. 否则退出栈顶运算符发送给后缀式；
5. `(` 对它前后的运算符起隔离作用，`)` 可视为自相应左括号开始的表达式的结束符。

```cpp
// 中缀式转后缀式：表达式以 '#' 结束，结果直接输出（仅含 + - * / ( )）
#include <stdio.h>

#define MAXSIZE 100

char S[MAXSIZE];
int  Top = -1;

void push(char c) { S[++Top] = c; }
char pop()        { return S[Top--]; }
char getTop()     { return S[Top]; }

int In(char c) {
    return c == '+' || c == '-' || c == '*' || c == '/'
        || c == '(' || c == ')' || c == '#';
}

char Precede(char t1, char t2) {
    if (t1 == '+' || t1 == '-') {
        if (t2 == '+' || t2 == '-' || t2 == ')' || t2 == '#') return '>';
        return '<';
    }
    if (t1 == '*' || t1 == '/') {
        if (t2 == '(') return '<';
        return '>';
    }
    if (t1 == '(') {
        if (t2 == ')') return '=';
        return '<';
    }
    if (t1 == '#') return '<';
    return '>';                  // t1 == ')' 的情况
}

void Transform(char *exp) {
    Top = -1;
    push('#');
    int i = 0;
    char ch = exp[i];
    while (ch != '#' || getTop() != '#') {
        if (!In(ch)) {                     // 操作数直接发送到后缀式
            printf("%c", ch);
            i++;
            ch = exp[i];
        } else {
            switch (Precede(getTop(), ch)) {
                case '<': push(ch); i++; ch = exp[i]; break;   // 进栈
                case '=': pop();    i++; ch = exp[i]; break;   // 脱括号
                case '>': printf("%c", pop()); break;          // 退栈并输出
            }
        }
    }
    printf("\n");
}

int main() {
    char exp[] = "4+2*3-10/5#";
    printf("中缀式: %s\n", exp);
    printf("后缀式: ");
    Transform(exp);
    return 0;
}
```

### 3.6 实现递归

函数调用时，系统栈负责信息传递与控制转移：

**调用子函数前需完成三项任务：** ① 将实在参数、返回地址等信息传递给被调用函数并保存；② 为被调用函数的局部变量分配存储区；③ 将控制转移到被调用函数入口。

**从被调用函数返回前需完成三项任务：** ① 保存被调函数的计算结果；② 释放被调函数的数据区；③ 依照保存的返回地址将控制转移到调用函数。

多个函数嵌套调用的规则是"**后调用先返回**"，内存管理实行"**栈式管理**"。

> **关键理解**：系统将整个程序运行所需的数据空间安排在一个栈内。每调用一个函数，就在栈顶分配一个存储区；每退出一个函数，就释放其存储区。因此**当前运行的函数的数据区必在栈顶**。

**递归函数的运行层次**：递归函数运行类似于多个函数的嵌套调用，只是调用者与被调用者是同一个函数。主函数是**第 0 层**，从主函数调用递归函数进入**第 1 层**。每进入一层递归，产生一个新的**工作记录**（含上一层的返回地址、实在参数、局部量）压入栈顶；每退出一层，从栈顶弹出一个工作记录。

#### 例：n 阶 Hanoi 塔问题

将塔座 X 上 n 个圆盘（小到大编号 1,2,…,n）移到塔座 Z，仍按同样顺序叠排。规则：① 每次只移动一个圆盘；② 圆盘可插在任一塔座；③ 任何时刻不能把较大圆盘压在较小圆盘上。

**递归思路：** $n=1$ 时直接从 X→Z；$n>1$ 时，以 Y 为辅助塔，先把 X 上 $n-1$ 个盘 X→Y，再把第 n 个盘 X→Z，最后把 Y 上 $n-1$ 个盘 Y→Z。

```cpp
// n 阶 Hanoi 塔问题
#include <stdio.h>

int count = 0;   // 移动次数

// 将编号为 n 的圆盘从 x 移到 z
void move(char x, int n, char z) {
    printf("第 %d 步: 将 %d 号盘从 %c 移到 %c\n", ++count, n, x, z);
}

// 将塔座 x 上编号 1~n 的圆盘搬到塔座 z，y 作辅助塔
void hanoi(int n, char x, char y, char z) {
    if (n == 1) {
        move(x, 1, z);
    } else {
        hanoi(n - 1, x, z, y);   // 将 x 上 1~n-1 盘移到 y，z 作辅助
        move(x, n, z);           // 将编号 n 的盘从 x 移到 z
        hanoi(n - 1, y, x, z);   // 将 y 上 1~n-1 盘移到 z，x 作辅助
    }
}

int main() {
    int n = 3;
    hanoi(n, 'X', 'Y', 'Z');
    printf("共移动 %d 次\n", count);
    return 0;
}
```

### 3.7 N 皇后问题求解

设 n 皇后问题的解为 $(x_1, x_2, \dots, x_n)$，约束条件：任意两个 $x_i$、$x_j$ 不能位于**同行、同列及同对角线**。

**表示方法**：每行、每列及对角线上只能有一个棋子，因此只需记录每列中棋子所在的行号，用一维数组 `a[j]`（第 j 列皇后所在行号）即可。

**回溯求解过程**：解的初始值为空；先添加 $x_1=1$，再添加满足条件的 $x_2=3$；若对所有 $x_3$ 都找不到满足约束的部分解 $(x_1,x_2,x_3)$，则**回溯**到部分解 $(x_1)$，重新添加 $x_2=4$，依次类推。

```cpp
// N 皇后问题（回溯法）：a[j] 表示第 j 列皇后所在的行号
#include <stdio.h>

#define N 8

int a[N + 1];     // a[j] 存放第 j 列皇后放置的行号（1-based）
int m = 0;        // 解的个数

// 检查在第 j 列、第 i 行放皇后是否与前面各列冲突
int ok(int i, int j) {
    int j1, i1, ok1;
    j1 = j; i1 = i; ok1 = 1;
    while ((j1 > 1) && ok1) {                       // 检查是否同行
        j1--;
        ok1 = (a[j1] != i);
    }
    j1 = j; i1 = i;
    while ((j1 > 1) && (i1 > 1) && ok1) {           // 检查一条对角线
        j1--; i1--;
        ok1 = (a[j1] != i1);
    }
    j1 = j; i1 = i;
    while ((j1 > 1) && (i1 < N) && ok1) {           // 检查另一条对角线
        j1--; i1++;
        ok1 = (a[j1] != i1);
    }
    return ok1;
}

// 从第 j 列开始逐个试探
void queen(int j) {
    if (j > N) {                                    // 得到一个完整解
        m++;
        printf("第 %d 个解: ", m);
        for (int i = 1; i <= N; i++) printf("%d ", a[i]);
        printf("\n");
    } else {
        for (int i = 1; i <= N; i++) {
            if (ok(i, j)) {                         // (i,j) 可放棋子
                a[j] = i;
                queen(j + 1);                       // 递归放置下一列
            }
        }
    }
}

int main() {
    queen(1);
    printf("共 %d 个解\n", m);
    return 0;
}
```

## 四、队列（Queue）

### 4.1 队列的定义

> **队列**是只允许在表的一端进行插入、在另一端删除元素的线性表。

- 允许插入的一端称为**队尾（rear）**；
- 允许删除的一端称为**队头（front）**。

设队列 $Q=(a_1, a_2, \dots, a_n)$，则 $a_1$ 是队头元素，$a_n$ 是队尾元素。元素按 $a_1, a_2, \dots, a_n$ 顺序进入，也按此顺序退出。队列中没有元素时称为**空队列**。队列是"**先进先出（FIFO, First In First Out）**"的线性表。

### 4.2 队列的抽象数据类型（ADT）

```
ADT Queue {
    数据对象：D = { ai | ai ∈ ElemSet, i = 1,2,...,n, n≥0 }
    数据关系：R1 = { <ai-1, ai> | ai-1, ai ∈ D, i = 2,...,n }
              约定 a1 端为队列头，an 端为队列尾。
    基本操作：...
} ADT Queue
```

**基本操作一览：**

| 操作 | 含义 |
|------|------|
| `InitQueue(&Q)` | 构造空队列 Q |
| `DestroyQueue(&Q)` | 销毁队列（Q 已存在） |
| `QueueEmpty(Q)` | 判空，空返回 1，否则返回 0 |
| `QueueLength(Q)` | 返回元素个数 |
| `GetHead(Q, &e)` | 用 e 返回队头元素（Q 非空） |
| `ClearQueue(&Q)` | 将 Q 清为空队列 |
| `EnQueue(&Q, e)` | 插入 e 为新的队尾元素 |
| `DeQueue(&Q, &e)` | 删除队头元素并用 e 返回其值（Q 非空） |
| `QueueTravers(Q, visit())` | 从队头到队尾依次调用 `visit()` |

### 4.3 队列的存储实现

队列的存储有**链队列（链式映象）**和**循环队列（顺序映象）**两种。

#### 4.3.1 顺序队列（一般的队列）

采用一维数组存储队列元素，数组上界表示最大容量；另设两个指针 `front`、`rear` 分别指示队头、队尾元素位置。

**约定：**

- 空队列时 `front = rear = 0`；
- 非空队列时，`front` 指向队头元素当前位置，`rear` 指示队尾元素的**下一个**位置。

```cpp
// 顺序队列（一般队列）：front 指向队头元素，rear 指向队尾元素的下一个位置
#include <stdio.h>

#define MAXQSIZE 10

struct SeQueue {
    int queue[MAXQSIZE];
    int front, rear;
};

// 初始化
void InitQueue(SeQueue &Q) {
    Q.front = 0;
    Q.rear = 0;
}

// 入队：返回 1 成功，0 失败（队满）
int EnQueue(SeQueue &Q, int x) {
    if (Q.rear == MAXQSIZE) return 0;   // 队列已满
    Q.queue[Q.rear] = x;
    Q.rear++;
    return 1;
}

// 出队：返回 1 成功，0 失败（队空）
int DeQueue(SeQueue &Q, int &e) {
    if (Q.front == Q.rear) return 0;    // 队列空
    e = Q.queue[Q.front];
    Q.front++;
    return 1;
}

int main() {
    SeQueue Q;
    InitQueue(Q);
    for (int i = 1; i <= 5; i++) EnQueue(Q, i * 10);

    int e;
    printf("出队序列: ");
    while (DeQueue(Q, e)) printf("%d ", e);
    printf("\n");
    return 0;
}
```

**假溢出问题**：当 `front ≠ 0` 且 `rear == MAXQSIZE` 时，虽然数组前部有空位，但队列被看作满而不能入队——这称为"**假溢出**"。

**判断队列空**（非循环队列）：

- 当 `q.front = q.rear ≠ 0` 时，**不能**断定队列为空（可能前面已有元素出队）；
- 当 `q.rear = 0` 时，**能**断定队列为空；
- 当 `q.front = 0` 时，**能**断定队列为空。

**解决假溢出的两种办法：**

1. 将整个队列左移，使第一个元素重新位于 `queue[0]`，置 `front = 0`——但会引起大量元素移动，增加运行时间；
2. **循环队列**：设想 `queue[0]` 接在 `queue[MAXQSIZE-1]` 之后，使数组成为首尾相接的环。

#### 4.3.2 循环队列

用**取模运算**实现指针的循环移动。循环队列中 `front == rear` 既可能是队空也可能是队满，需区分：

- **方法一（设置标志 flag）**：flag 初始为 `delete`；每次插入后置 `entry`，每次删除后置 `delete`。当 `front == rear` 时，若 flag 为 `entry` 则队满，否则队空。缺点：维护 flag 减慢了插入/删除速度。
- **方法二（少用一个元素空间）**：以"队尾指针加 1 等于队头指针"表示队列满：$(rear + 1) \% MAXQSIZE = front$。这样队尾指针所指位置始终空着，容量 `MAXQSIZE` 只能表示长度不超过 `MAXQSIZE-1` 的队列，但可免设标志；此时 `rear == front` 仍用于判断队列空。

```cpp
// 循环队列（采用"少用一个元素空间"法判满）
#include <stdio.h>

#define MAXQSIZE 10
#define OK   1
#define ERROR 0

struct SeQueue {
    int queue[MAXQSIZE];
    int front, rear;
};

void InitQueue(SeQueue &Q) {
    Q.front = 0;
    Q.rear = 0;
}

// 入队
int EnQueue(SeQueue &Q, int x) {
    if ((Q.rear + 1) % MAXQSIZE == Q.front) return ERROR;   // 队列满
    Q.queue[Q.rear] = x;
    Q.rear = (Q.rear + 1) % MAXQSIZE;                       // 队尾指针循环加 1
    return OK;
}

// 出队
int DeQueue(SeQueue &Q, int &e) {
    if (Q.front == Q.rear) return ERROR;                    // 队列空
    e = Q.queue[Q.front];
    Q.front = (Q.front + 1) % MAXQSIZE;                     // 队头指针循环加 1
    return OK;
}

int main() {
    SeQueue Q;
    InitQueue(Q);

    // 容量 MAXQSIZE=10，实际最多存 9 个：验证"循环"与"队满"
    for (int i = 1; i <= 12; i++) {
        if (EnQueue(Q, i)) printf("入队 %d\n", i);
        else               printf("队列满，%d 入队失败\n", i);
    }

    int e;
    printf("出队序列: ");
    while (DeQueue(Q, e)) printf("%d ", e);
    printf("\n");
    return 0;
}
```

#### 4.3.3 链队列

对于数据元素变动较大的数据结构，链式存储更有利。用链表表示的队列简称**链队列**，需两个指针分别指示队头和队尾。为操作方便，添加一个**头结点**，令头指针指向头结点。空链队列的判定条件为**头指针与尾指针均指向头结点**。

链队列的操作是单链表插入和删除的特殊情况，只是还需修改尾指针和头指针。

```cpp
// 链队列：带一个头结点，front 指向头结点，rear 指向队尾结点
#include <stdio.h>
#include <stdlib.h>

#define OK   1
#define ERROR 0

struct qnode {
    int data;
    struct qnode *next;
};

struct LinkQueue {
    struct qnode *front;   // 队头指针（指向头结点）
    struct qnode *rear;    // 队尾指针
};

// 初始化：产生头结点，头、尾指针均指向它
int InitQueue(LinkQueue &Q) {
    Q.front = (struct qnode *)malloc(sizeof(struct qnode));
    if (!Q.front) return ERROR;
    Q.front->next = NULL;
    Q.rear = Q.front;
    return OK;
}

// 判空
int QueueEmpty(LinkQueue Q) {
    return Q.front == Q.rear;
}

// 入队
int EnQueue(LinkQueue &Q, int x) {
    struct qnode *p = (struct qnode *)malloc(sizeof(struct qnode));
    if (!p) return ERROR;
    p->data = x;
    p->next = NULL;
    Q.rear->next = p;
    Q.rear = p;
    return OK;
}

// 出队
int DeQueue(LinkQueue &Q, int &e) {
    if (Q.front == Q.rear) return ERROR;       // 队空
    struct qnode *p = Q.front->next;           // p 指向队头元素
    Q.front->next = p->next;                   // 修改头结点指针域
    e = p->data;
    if (Q.rear == p) Q.rear = Q.front;         // 仅有一个元素，需改队尾指针
    free(p);
    return OK;
}

int main() {
    LinkQueue Q;
    InitQueue(Q);
    for (int i = 1; i <= 5; i++) EnQueue(Q, i * 10);

    int e;
    printf("出队序列: ");
    while (DeQueue(Q, e)) printf("%d ", e);
    printf("\n");
    return 0;
}
```

> **关键细节**：当链队列长度大于 1 时，出队只需修改头结点的 `next` 域，队尾指针不变；当长度**等于 1** 时，出队后成为空队列，除修改 `next` 域外还需修改队尾指针（因为此时队尾指针也指向被删结点）。

## 五、本章小结

- 栈和队列都是**运算受限的线性表**：栈的插入和删除均在栈顶进行，是"后进先出"（LIFO）的线性表；队列插入在队尾、删除在队头，是"先进先出"（FIFO）的线性表。
- 依存储表示不同：栈有**顺序栈**和**链栈**，队列有**顺序队列**和**链队列**，实际中使用的队列是**循环队列**。
- 应重点领会栈和队列的"**上溢**"（空间满仍写入）和"**下溢**"（空间空仍读出）概念及判别条件，正确使用栈空/队列空来控制返回。

**本章学习要点：**

1. 掌握栈和队列类型的特点，并能在相应应用问题中正确选用；
2. 熟练掌握栈的两种实现方法，特别注意**栈满和栈空的条件**及其描述方法；
3. 熟练掌握循环队列和链队列的基本操作实现算法，特别注意**队满和队空的描述方法**；
4. 了解栈和队列的应用，理解递归算法执行过程中栈状态的变化过程。

## 六、核心知识速查表

### 栈与队列对比

| 维度 | 栈 | 队列 |
|------|-----|------|
| 插入端 | 栈顶（表尾） | 队尾 |
| 删除端 | 栈顶（表尾） | 队头（表头） |
| 特性 | 后进先出 LIFO | 先进先出 FIFO |
| 顺序实现判空 | `Top == Base`（或 `Top == -1`） | `front == rear` |
| 顺序实现判满 | `Top - Base >= Stacksize`（或 `Top >= MAXSIZE-1`） | `(rear+1)%MAXQSIZE == front` |
| 链式实现 | 链栈（仅栈顶操作） | 链队列（带头结点，front/rear 双指针） |

### 常见易错点

- 顺序栈顶指针指向栈顶元素（方法一）与指向栈顶下一位置（方法二）的判空/判满条件不同，勿混淆；
- 循环队列必须区分 `front == rear` 是队空还是队满（flag 法或空一元素法）；
- 链队列出队时，若只剩一个元素，出队后需同时修改 `rear` 指针；
- 出栈序列问题：进栈次序为 1,2,3 时不可能得到 3,1,2；
- 中缀式丢失括号信息，导致运算次序不确定，故求值/转换需借助栈。

### 3.10 将下列递归过程改写为非递归过程

原递归过程（读入若干个数，直到读到 0，再回溯累加并逐个输出）：

```c
void test(int &sum) {
    int x;
    scanf(x);
    if (x == 0) {
        sum = 0;
    } else {
        test(sum);
        sum = sum + x;
    }
    printf(sum);
}
```

**参考解**（用栈保存读入的非零数，模拟递归回溯过程；输入 `1 2 3 0` 输出 `0 3 5 6`）：

```cpp
// 3.10 递归改非递归：用栈模拟递归的工作记录
#include <stdio.h>

#define MAXSIZE 100

int main() {
    int S[MAXSIZE];       // 保存读入的非零数
    int Top = -1;
    int x, sum = 0;

    while (scanf("%d", &x) == 1 && x != 0)   // 读入直到 0
        S[++Top] = x;

    printf("%d ", sum);                      // 对应最内层（x==0 那层）的输出
    while (Top >= 0) {                       // 回溯：依次累加并输出
        sum += S[Top--];
        printf("%d ", sum);
    }
    printf("\n");
    return 0;
}
```

### 3.19 括号配对判别算法

假设算术表达式中可包含 `()`、`[]`、`{}` 三种括号，且可按任意次序嵌套。编写判别给定表达式中括号是否正确配对出现的算法（表达式已存入数据元素为字符的顺序表中）。

**参考解**：

```cpp
// 3.19 三种括号配对判别
#include <stdio.h>

#define MAXSIZE 100

char S[MAXSIZE];
int  Top = -1;

void Push(char c) { S[++Top] = c; }
char Pop()        { return S[Top--]; }
char GetTop()     { return S[Top]; }
int  StackEmpty() { return Top < 0; }

int Match(char left, char right) {
    return (left == '(' && right == ')') ||
           (left == '[' && right == ']') ||
           (left == '{' && right == '}');
}

int main() {
    char exp[] = "{[( )]}";      // 可自行修改为待检验的表达式
    int i = 0, ok = 1;
    while (exp[i] != '\0' && ok) {
        char c = exp[i];
        if (c == '(' || c == '[' || c == '{') {
            Push(c);
        } else if (c == ')' || c == ']' || c == '}') {
            if (StackEmpty() || !Match(GetTop(), c)) ok = 0;
            else Pop();
        }
        i++;
    }
    if (ok && StackEmpty()) printf("括号配对正确\n");
    else                    printf("括号配对错误\n");
    return 0;
}
```

### 上机题 5：k 阶斐波那契序列

试利用**循环队列**求 k 阶斐波那契序列前 $n+1$ 项（$f_0, f_1, \dots, f_n$），要求满足 $f_n \le max$ 而 $f_{n+1} > max$。注意循环队列容量仅为 $k$，算法结束时队列中应留下最后 $k$ 项 $f_{n-k+1}, \dots, f_n$。

**定义**：$f_0=f_1=\dots=f_{k-2}=0$，$f_{k-1}=1$，$f_n = f_{n-1}+f_{n-2}+\dots+f_{n-k}$（$n=k,k+1,\dots$）。

**优化推导**：由 $f_i = f_{i-1}+f_{i-2}+\dots+f_{i-k}$ 与 $f_{i+1} = f_i + f_{i-1} + \dots + f_{i-k+1}$ 两式相减得

$$f_{i+1} = 2 f_i - f_{i-k}$$

据此可把队列容量优化为 $k+1$。

**参考解**（循环队列容量为 k，输出满足 $f_n \le max < f_{n+1}$ 的前若干项）：

```cpp
// 上机题 5：用循环队列求 k 阶斐波那契序列
#include <stdio.h>

#define KMAX 100

int main() {
    int k = 3, max = 100000;
    int cq[KMAX];      // 循环队列，容量为 k
    int f[10000];      // 存放生成的序列
    int i, j, n, rear;

    for (i = 0; i <= k - 2; i++) { f[i] = 0; cq[i] = 0; }   // 前 k-1 项为 0
    cq[k - 1] = 1;                                          // 第 k 项为 1
    f[k - 1] = 1;
    rear = k - 1;                                           // 队尾指针
    n = k;

    while (1) {
        int sum = 0;
        for (j = 0; j < k; j++) sum += cq[j];   // 前 k 项之和
        if (sum > max) break;                   // 下一项已超过 max，停止
        rear = (rear + 1) % k;                  // 循环入队
        cq[rear] = sum;
        f[n] = sum;
        n++;
    }

    printf("k=%d 阶斐波那契序列(共 %d 项): ", k, n);
    for (i = 0; i < n; i++) printf("%d ", f[i]);
    printf("\n");

    printf("循环队列中剩余(最后 k 项): ");
    for (i = 0; i < k; i++) printf("%d ", cq[(rear + 1 + i) % k]);
    printf("\n");
    return 0;
}
```
