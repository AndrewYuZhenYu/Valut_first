## 一、iPadOS系统级快捷键

### 基础导航与控制

| 功能 | 快捷键 | 说明 |
|------|--------|------|
| **返回主屏幕** | ⌘ + H | 快速回到主屏幕 |
| **App切换器** | ⌘ + Tab | 按住⌘连续按Tab切换 |
| **Spotlight搜索** | ⌘ + 空格 | 全局搜索 |
| **显示/隐藏程序坞** | ⌘ + ⌥ + D | 快速呼出Dock |
| **截图** | ⌘ + Shift + 3 | 标准截图 |
| **截图并编辑** | ⌘ + Shift + 4 | 截图后直接进入编辑 |
| **锁定屏幕** | Ctrl + ⌘ + Q | 立即锁屏 |
| **强制退出应用** | 在切换器中选中 + ⌘ + Q | 需开启全键盘控制 |

## 十、故障排除

| 问题 | 解决方法 |
|------|----------|
| **快捷键无效** | 检查是否开启全键盘控制（设置→辅助功能→键盘） |
| **地球仪键不工作** | 确认使用的是兼容键盘，重启iPad |
| **按键延迟** | 清理键盘连接，重启设备 |
| **特殊字符无法输入** | 检查键盘语言设置，尝试长按相关键 |
| **外接键盘不识别** | 重新配对蓝牙键盘，检查电量 |

- 不同App可能有专属快捷键，建议查阅App内帮助文档
