从Windows切换到Mac，最核心的变化在于：**键盘上的`Command`键（⌘）替代了`Ctrl`键，成为了绝大多数快捷键的“主角”**。

这份手册整理了最全面、详细的macOS快捷键，并特别标注了与Windows的差异点，希望能帮你顺利过渡。

### 💡 核心差异速览：从Win到Mac的关键转变

在开始记忆快捷键之前，先记住以下几条黄金法则，能让你事半功倍：

| 操作场景 | Windows 习惯 | macOS 对应操作 | 特别说明 |
| :--- | :--- | :--- | :--- |
| **复制/粘贴/剪切** | `Ctrl` + `C` / `V` / `X` | **`Command`** + `C` / `V` / `X` | **肌肉记忆核心**：最频繁的改动。 |
| **切换应用** | `Alt` + `Tab` | `Command` + `Tab` | 功能类似，但macOS是**切换应用**，而非应用内的单个窗口。 |
| **删除文件/文字** | `Delete` 键向后删除 | 两种删除方式：<br>• `Delete` = 向前删除（Windows的退格键）<br>• `Fn` + `Delete` = 向后删除（Windows的Delete键） | 这是初期最容易混淆的点之一。 |
| **退出应用** | `Alt` + `F4` | `Command` + `Q` | 在macOS中，**关闭窗口 (`Command` + `W`) 不等于退出应用**。点击红点是关窗，应用仍在后台。 |
| **锁定屏幕** | `Win` + `L` | `Control` + `Command` + `Q` | 休息或离开时，记得用这个组合键保护隐私。 |
| **打开文件/程序** | 选中后按 `Enter` 打开 | 选中后按 `Command` + `O` 打开 | 在Finder（访达）中，**`Enter` 键的作用是重命名文件**，这是新用户最容易“踩坑”的地方。 |

**一句话总结**：当你想执行复制、粘贴等编辑操作时，下意识地把左手小指从`Ctrl`键移到相邻的`Command`键上。

### 📝 通用编辑与系统快捷键

这是日常使用频率最高的快捷键类别，适用于绝大部分应用（文本编辑、浏览器、设计软件等）。

| 功能              | macOS 快捷键                    | Windows 对照                | 备注与操作提示                   |
| :-------------- | :--------------------------- | :------------------------ | :------------------------ |
| **撤销**          | `Command` + `Z`              | `Ctrl` + `Z`              | 撤销上一步操作。                  |
| **重做**          | `Shift` + `Command` + `Z`    | `Ctrl` + `Y`              | 恢复被撤销的操作。                 |
| **剪切**          | `Command` + `X`              | `Ctrl` + `X`              | 剪切文本或文件。                  |
| **复制**          | `Command` + `C`              | `Ctrl` + `C`              | 复制文本或文件。                  |
| **粘贴**          | `Command` + `V`              | `Ctrl` + `V`              | 粘贴。                       |
| **全选**          | `Command` + `A`              | `Ctrl` + `A`              | 选中当前页面或文档的所有内容。           |
| **保存**          | `Command` + `S`              | `Ctrl` + `S`              | 保存当前文档。                   |
| **查找**          | `Command` + `F`              | `Ctrl` + `F`              | 在当前页面或文档中搜索。              |
| **打开新窗口**       | `Command` + `N`              | `Ctrl` + `N`              | 在多数应用中新建文稿或窗口。            |
| **打开新标签页**      | `Command` + `T`              | `Ctrl` + `T`              | 在浏览器或Finder中新建标签页。        |
| **关闭当前标签/窗口**   | `Command` + `W`              | `Ctrl` + `W`              | 关闭当前活动的标签页或窗口，但**不退出应用**。 |
| **退出当前应用**      | `Command` + `Q`              | `Alt` + `F4`              | **完全关闭应用程序**。             |
| **隐藏当前应用**      | `Command` + `H`              | 无直接对应                     | 快速隐藏最前方应用的所有窗口，让桌面变干净。    |
| **打开应用偏好设置**    | `Command` + `,` (逗号)         | `Ctrl` + `,`              | 快速进入当前应用的设置界面。            |
| **打开Emoji表情面板** | `Control` + `Command` + `空格` | `Win` + `句号(.)`           | 在聊天或编辑时快速插入表情符号。          |
| **强制退出应用**      | `Option` + `Command` + `Esc` | `Ctrl` + `Alt` + `Delete` | 当程序无响应时，打开强制退出窗口。         |

### 🖥️ 系统与屏幕管理

这些快捷键能帮你高效地管理窗口、显示器，并执行系统级操作。

| 功能 | macOS 快捷键 | Windows 对照 | 备注与操作提示 |
| :--- | :--- | :--- | :--- |
| **显示/隐藏Dock栏** | `Option` + `Command` + `D` | 无直接对应 | 快速获得全屏空间。 |
| **打开Spotlight搜索** | `Command` + `空格` | `Win` + `S` | 强大的全局搜索，可搜文件、计算器、查单词、启动App。 |
| **切换应用** | `Command` + `Tab` | `Alt` + `Tab` | 在已开启的**应用程序**之间切换（注意：是切换应用，不是切换窗口）。 |
| **切换同应用的窗口** | `Command` + `～` (反引号) | `Alt` + `Tab` | 例如，在多个Finder窗口或多个Chrome窗口间切换，非常实用。 |
| **截取全屏** | `Shift` + `Command` + `3` | `PrtSc` | 截图保存到桌面。 |
| **截取区域** | `Shift` + `Command` + `4` | `Win` + `Shift` + `S` | 光标变为十字，拖拽选择区域截图。 |
| **截取窗口** | 先按 `Shift` + `Command` + `4`，**再按空格** | 无直接对应 | 相机图标出现后，点击任意窗口即可精准截图，带阴影效果。 |
| **打开截图工具栏** | `Shift` + `Command` + `5` | 部分系统支持 | 调出功能更全的截图和录屏控制面板，可设置定时、保存位置等。 |
| **进入/退出全屏** | `Control` + `Command` + `F` | `F11` | 让当前应用全屏显示，在顶部菜单栏可以快速退出。 |
| **锁屏** | `Control` + `Command` + `Q` | `Win` + `L` | 立即锁定屏幕，需要密码才能唤醒。 |
| **将Mac关机** | `Control` + `Option` + `Command` + `电源键` | 通过开始菜单 | 立即退出所有应用并关机，系统会提示是否保存未存储的文件。 |

### 📁 Finder (访达) 与文件管理

Finder就是Windows里的“资源管理器”，这些快捷键能让你成为文件管理大师。

| 功能 | macOS 快捷键 | Windows 对照 | 备注与操作提示 |
| :--- | :--- | :--- | :--- |
| **打开新Finder窗口** | `Command` + `N` | `Win` + `E` | 打开一个新的文件管理窗口。 |
| **复制文件** | `Command` + `C` / `Command` + `V` | `Ctrl` + `C` / `Ctrl` + `V` | 标准的复制粘贴。 |
| **移动文件** | `Command` + `C` → `Option` + `Command` + `V` | `Ctrl` + `X` → `Ctrl` + `V` | **注意**：macOS的“剪切”文件是这个组合，而非`Command`+`X`。 |
| **复制/备份文件** | 选中文件，按 `Command` + `D` | `Ctrl` + `C` 再 `Ctrl` + `V` | 立即在原地生成一个名为“文件名称 copy”的副本。 |
| **新建文件夹** | `Shift` + `Command` + `N` | `Ctrl` + `Shift` + `N` | 在当前目录下创建一个新文件夹。 |
| **查看文件简介** | `Command` + `I` | `Alt` + `Enter` | 查看文件或文件夹的详细信息、大小、权限等。 |
| **快速查看** | 选中文件，按 `空格键` | 需要安装第三方软件（如QuickLook） | **神级功能**：无需打开程序，直接按空格预览图片、视频、文档内容，再按空格关闭。 |
| **删除文件/移至废纸篓** | `Command` + `Delete` | `Delete` | 将选中的文件移至废纸篓。 |
| **清空废纸篓** | `Shift` + `Command` + `Delete` | 右键清空回收站 | 永久删除废纸篓中的所有文件。 |
| **打开当前文件的上级文件夹** | `Command` + `向上箭头` | `Backspace` / `Alt` + `向上` | 返回上一级目录。 |
| **进入所选文件夹** | `Command` + `向下箭头` | `Enter` | 相当于“打开”操作。 |
| **打开个人文件夹** | `Shift` + `Command` + `H` | `C:`\Users\用户名 | 快速跳转到你的用户目录（通常是/Users/你的名字/）。 |
| **打开桌面文件夹** | `Shift` + `Command` + `D` | 快速访问桌面 | 无论你身在何处，一键打开桌面文件夹。 |
| **打开“实用工具”文件夹** | `Shift` + `Command` + `U` | 控制面板 | 快速找到“终端”、“磁盘工具”、“活动监视器”等系统工具。 |
| **显示/隐藏隐藏文件** | `Shift` + `Command` + `.` (句号) | 需要在文件夹选项中设置 | **重要技巧**：一键显示被隐藏的文件夹（如`~/.ssh`， `~/.bash_profile`）。 |
| **前往指定文件夹** | `Shift` + `Command` + `G` | 在地址栏直接输入 | 打开“前往文件夹”窗口，输入路径（如`/Library/`）直接跳转。 |

### 🔧 键盘修饰键映射 (对于Windows键盘)

如果你在Mac上使用标准的Windows键盘（如大部分机械键盘），键位会有些不同，但完全可用。你可以在 **系统设置 > 键盘 > 键盘快捷键 > 修饰键** 中重新映射，但默认的对应关系如下：

- **`Win`键 → `Command` (⌘) 键**
- **`Alt`键 → `Option` (⌥) 键**

**这意味着**：当你看到快捷键是`Command`+`C`时，就按下键盘上的`Win`键和`C`键；当你看到`Option`+`Command`+`D`时，就按下`Alt`+`Win`+`D`。右上角的`Delete`键功能不变。
