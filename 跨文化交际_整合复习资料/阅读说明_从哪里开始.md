# 跨文化交际｜教材三章 × 四份课件融合复习包

这份资料按**教材 Chapter 1 / Chapter 3 / Chapter 6** 为主线，融合四份课件（PPT Chapter 2 Culture、Chapter 3 Communication、Chapter 4 Cultural Value Orientations、Chapter 5 Hofstede）。**优先遵从教材定义与原有专业名词**；把课件补充、课件不同措辞、考场辨析归纳分开。所有新增场景题都以“模拟题”标记，不冒充原书真题。

## 建议阅读顺序

1. `00_教材思维导图与四份课件_覆盖核对表.md`——先确认每一章 Chapter Outline 分支都有对应知识点，并了解 PPT 超纲补充。
2. `01_教材第1章_文化与交际_融合复习.md`——文化本质、五项教材特点、文化身份、九要素和交际类型；补 PPT 七项特征、Hanvey 四层次等。
3. `03_教材第3章_跨文化交际障碍_融合复习.md`——情感/态度/翻译障碍，四个容易混淆的态度概念、五种翻译不对等。
4. `06_教材第6章_文化模式_融合复习.md`——文化模式四组件、Hall、KS 五类十五项、Hofstede 教材四维及 PPT 六维。
5. `04_相似概念与考试陷阱_精确辨析.md`——重点看 Ethnocentrism / Stereotyping / Prejudice / Racism 等相似概念。
6. `05_四十道概念辨析情境题_题答分离.md`——题目与答案分开安排，建议做完后看解析。

## 与上次版式相比的变化

- 仍保留原书术语及大纲，但补充 PPT 额外定义、分类、案例和易混点。
- 书本定义、课件原句与自编的判断提示相互区分；读者不会把复习归纳误认为原文。
- 教材三章的原始思维导图逐项核对；PPT 另有考点也独立入档。
- 多套不完全一致的清单分别保留，不按“看上去类似”自行合并，例如：文化特点（教材 5，PPT 7）、交际要素（教材 9，PPT 另列 Response）、人性分类（措辞差异）、Hofstede（教材 4，PPT 6）。
- 所有 Markdown 使用 UTF-8，可导入 Obsidian。`> [!note]`、`> [!warning]` 等为 Obsidian Callout。
