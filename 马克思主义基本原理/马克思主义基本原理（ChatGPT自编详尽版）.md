整体保留教材“导论＋七章”的结构，在此基础上细化基本概念、理论原理、逻辑关系、方法论、计算公式、实际案例和易混淆知识点。不仅用于期末考试复习，也作为系统理解马克思主义理论的基础知识体系。

以下关于社会制度、历史发展趋势等内容，按照大陆高校教材中的马克思主义理论立场进行阐释；这些理论判断不意味着所有其他哲学、经济学和社会科学流派均持相同观点。

## 导论　马克思主义概述

### 0.1 马克思主义的含义

马克思主义由马克思、恩格斯创立，并在后续社会实践中不断发展的理论体系，主要研究自然、社会和人类思维的一般规律，以及资本主义、社会主义和共产主义的发展规律。

#### 0.1.1 狭义与广义的马克思主义

| 分类 | 含义 |
|---|---|
| 狭义马克思主义 | 马克思、恩格斯创立的基本理论、基本观点和基本学说 |
| 广义马克思主义 | 马克思、恩格斯创立的理论及其在后续历史实践中的发展成果 |

#### 0.1.2 马克思主义的三个理论来源

| 理论来源 | 代表人物 | 主要继承和批判发展的内容 |
|---|---|---|
| 德国古典哲学 | 黑格尔、费尔巴哈 | 辩证法、唯物主义 |
| 英国古典政治经济学 | 亚当·斯密、大卫·李嘉图 | 劳动价值理论 |
| 英法空想社会主义 | 圣西门、傅立叶、欧文 | 对资本主义的批判、未来社会的构想 |

### 0.2 马克思主义产生的历史条件

| 条件 | 具体内容 |
|---|---|
| 经济社会条件 | 工业革命、资本主义生产方式发展及其矛盾显现 |
| 阶级基础 | 无产阶级作为独立政治力量登上历史舞台 |
| 思想理论条件 | 近代哲学、政治经济学、社会主义思想的发展 |
| 自然科学基础 | 细胞学说、能量守恒和转化定律、生物进化论等科学成果 |

1848年，《共产党宣言》发表，通常被视为马克思主义诞生的重要标志。

### 0.3 马克思主义的发展历程

![[Assets/Marxism_20261125_Fundamentals_16c09463808a4ddc_assets/images/marx_history_ba62e1ce-f8d7-4d61-95af-a3349a372b23.png]]

*图：马克思主义的发展历程*

- **1848年：马克思主义创立**——《共产党宣言》发表。
- **1867年：《资本论》第一卷出版**——系统研究资本主义生产方式及其经济规律。
- **19世纪末至20世纪初：列宁主义形成**——结合帝国主义时代与俄国革命实践发展马克思主义。
- **20世纪以来：马克思主义中国化时代化**——马克思主义基本原理与中国具体实际相结合。
- **当代：马克思主义理论的继续发展**——结合新的社会实践、科技发展与时代问题展开理论创新。

大陆高校教学中，马克思主义中国化时代化的理论成果主要包括毛泽东思想和中国特色社会主义理论体系，习近平新时代中国特色社会主义思想是当代中国马克思主义、二十一世纪马克思主义。

### 0.4 马克思主义的基本特征

| 特征 | 含义 |
|---|---|
| 科学性 | 强调以客观实际为依据，研究事物发展规律 |
| 人民性 | 将人民群众的利益和人的解放作为价值立场 |
| 实践性 | 来源于实践、服务于实践，并接受实践检验 |
| 发展性 | 随着历史条件与社会实践的发展不断丰富 |

马克思主义的鲜明理论特征可以概括为科学性与革命性的统一。

实践观点是马克思主义的基本观点，在其理论体系中具有基础性地位。

### 0.5 马克思主义的当代价值

主要体现在提供认识社会的理论工具、分析经济与社会矛盾的方法、指导社会实践以及研究人的全面发展等方面。

学习马克思主义，应当重视理论联系实际，避免把理论理解为脱离条件、机械套用的固定结论。

## 第一章　世界的物质性及发展规律

本章是整个马克思主义哲学的基础，主要包括辩证唯物论和唯物辩证法两大部分。

![[Assets/Marxism_20261125_Fundamentals_16c09463808a4ddc_assets/images/marx_ch1_e300356d-6ad6-4652-89c8-f20b9940e4b6.png]]

*图：第一章知识结构*

### 1.1 哲学的基本问题

哲学的基本问题是**思维与存在的关系问题**，也可以表述为意识与物质的关系问题。

这一问题由恩格斯作出经典概括。

#### 1.1.1 哲学基本问题的两个方面

| 方面 | 研究问题 | 划分标准 |
|---|---|---|
| 第一方面 | 物质和意识何者具有第一性 | 唯物主义与唯心主义 |
| 第二方面 | 思维能否正确认识存在 | 可知论与不可知论 |

第一方面是划分哲学基本派别的根本标准。

![[Assets/Marxism_20261125_Fundamentals_16c09463808a4ddc_assets/images/marx_philosophy_56a54f48-c7d6-4a49-85cf-491b041647a1.png]]

*图：哲学基本问题的两个方面及派别划分*

### 1.2 唯物主义与唯心主义

#### 1.2.1 唯物主义的三种历史形态

| 形态 | 主要观点 | 特点及局限 |
|---|---|---|
| 古代朴素唯物主义 | 用水、火、气、原子等解释世界本原 | 坚持物质第一性，但具有直观性和猜测性 |
| 近代形而上学唯物主义 | 借助近代自然科学解释世界 | 往往具有机械性、形而上学性和历史观上的不彻底性 |
| 辩证唯物主义和历史唯物主义 | 世界具有物质性，并处于联系和发展中 | 将唯物主义、辩证法及社会历史观统一起来 |

#### 1.2.2 唯心主义的两种基本形式

| 类型 | 基本观点 | 典型思想或代表 |
|---|---|---|
| 主观唯心主义 | 将人的主观精神作为世界的本原 | 贝克莱的部分哲学思想 |
| 客观唯心主义 | 将独立于个人意识的客观精神作为世界本原 | 黑格尔的绝对理念 |

> [!warning] 注意
> 重视精神、文化、思考和意识的作用，并不等于唯心主义。关键在于是否把精神视为世界的第一本原。

#### 1.2.3 辩证法与形而上学

| 比较维度 | 辩证法 | 形而上学思维方式 |
|---|---|---|
| 看待事物 | 联系的 | 孤立的 |
| 看待变化 | 发展的 | 静止的 |
| 看待矛盾 | 承认事物内部矛盾 | 否认或忽视内部矛盾 |
| 分析方式 | 全面、动态、具体 | 片面、静态、僵化 |

这里的“形而上学”特指教材中与辩证法相对立的思维方式，不完全等同于现代哲学学科意义上的形而上学。

### 1.3 物质及其存在方式

#### 1.3.1 物质的哲学定义

物质是指不依赖于人的意识而存在、能够被人的意识所反映的客观实在。

**客观实在性是物质的唯一特性。**

需要区分哲学上的物质概念与自然科学中的具体物质形态。

| 概念 | 含义 | 示例 |
|---|---|---|
| 哲学物质概念 | 对一切客观实在共同属性的抽象概括 | 客观实在性 |
| 具体物质形态 | 客观实在的具体存在形式 | 原子、分子、电磁场等 |

哲学中的物质概念并不会因为某一种具体物质结构理论被推翻而失效。

#### 1.3.2 物质与运动

运动是物质的根本属性和存在方式。

二者关系：

- 物质是运动的承担者。
- 运动是物质的存在方式。
- 不存在完全脱离运动的物质。
- 不存在脱离物质承担者的运动。

#### 1.3.3 绝对运动与相对静止

| 概念 | 含义 |
|---|---|
| 绝对运动 | 物质始终处于变化过程中 |
| 相对静止 | 在一定条件和范围内，事物的空间位置或根本性质保持相对稳定 |

![[Assets/Marxism_20261125_Fundamentals_16c09463808a4ddc_assets/images/marx_train_3dc938c2-47ce-46b2-a1fe-318284cb5bf6.png]]

*图：运动与静止是绝对性和相对性的统一，不能把相对静止理解为物质运动的彻底停止。*

#### 1.3.4 时间与空间

时间和空间是运动着的物质的基本存在形式。

| 概念 | 基本特点 |
|---|---|
| 时间 | 表现为物质运动的持续性和顺序性，具有一维性 |
| 空间 | 表现为物质存在的广延性和位置关系，通常讨论三维性 |

时间和空间具有客观性，不能脱离物质运动而独立存在。

### 1.4 意识的本质与作用

#### 1.4.1 意识的起源

意识是自然界长期演化和社会历史发展的产物。

从马克思主义哲学的角度，劳动和语言对于人类意识的产生与发展具有重要作用。

#### 1.4.2 意识的本质

意识是人脑的机能和对客观世界的主观反映。

意识的内容具有客观来源，而反映形式具有主观性，因此不同主体面对相同的客观对象，可能形成不同的认识。

意识并不是对客观世界的机械复制，而具有选择、加工、抽象和创造等特点。

#### 1.4.3 意识的能动作用

| 表现 | 含义 |
|---|---|
| 目的性和计划性 | 人可以预先设定目标并制定方案 |
| 创造性 | 人能够形成尚未在现实中实现的构想 |
| 指导实践 | 意识通过实践活动影响客观世界 |
| 调控作用 | 意识能够调节人的行为和部分生理活动 |

### 1.5 物质与意识的辩证关系

这是第一章的核心原理之一。

![[Assets/Marxism_20261125_Fundamentals_16c09463808a4ddc_assets/images/marx_matter_9ab91a61-0863-4dc6-9ad5-2a75efbda20f.png]]

*图：物质决定意识，意识通过实践产生能动反作用*

> [!important] 原理与方法论
> **原理：**物质决定意识，意识对物质具有能动的反作用。正确的认识可以指导实践取得积极效果，错误的认识则可能使实践受到阻碍。
>
> **方法论：**一切从实际出发，实事求是，同时重视意识和理论的指导作用。

> [!warning] 典型错误
> 认为只要主观愿望足够强烈，就可以直接改变客观现实。

### 1.6 客观规律与主观能动性

规律是事物运动发展中具有本质性、必然性和相对稳定性的联系。

规律具有客观性，人不能凭主观意愿创造、消灭或任意改变客观规律，但能够认识、利用规律，并通过改变条件影响事物发展的具体过程。

| 概念 | 核心含义 |
|---|---|
| 客观规律性 | 事物的发展具有不以人的意志为转移的规律 |
| 主观能动性 | 人主动认识世界和改造世界的能力与活动 |

二者的辩证关系：

1. 尊重客观规律是正确发挥主观能动性的前提。
2. 发挥主观能动性是认识和利用客观规律的必要条件。
3. 实践是二者实现统一的基础。

> [!example] 例子
> 工程师无法取消重力规律，却可以利用空气动力学、材料科学等知识设计飞机。

### 1.7 世界的物质统一性

马克思主义认为，世界的统一性在于其物质性。

自然界具有物质性，人类社会建立在物质生产实践基础之上，意识也是物质世界长期发展过程中形成的现象。

这一原理要求人们从客观实际出发，而不是从脱离现实的观念出发。

### 1.8 唯物辩证法的总体结构

![[Assets/Marxism_20261125_Fundamentals_16c09463808a4ddc_assets/images/marx_dialectic_e838a342-158b-4720-b29c-560b1f26ea59.png]]

*图：唯物辩证法的两大总特征、三大规律及五对范畴*

两大总特征：联系、发展。三大基本规律：对立统一规律、量变质变规律、否定之否定规律。五对基本范畴：内容与形式、本质与现象、原因与结果、必然与偶然、现实与可能。

**对立统一规律是唯物辩证法的实质和核心。**

### 1.9 事物的普遍联系

联系是事物内部各要素之间以及不同事物之间的相互影响、相互制约和相互作用。

#### 1.9.1 联系的基本特点

| 特点 | 含义 |
|---|---|
| 客观性 | 联系并非由主观意愿任意决定 |
| 普遍性 | 事物普遍存在于相互联系的系统之中 |
| 多样性 | 联系有直接、间接、内部、外部等不同形式 |
| 条件性 | 具体联系的存在与变化依赖一定条件 |

**方法论：**用联系的观点看问题，重视整体与部分、系统与要素以及事物所处的具体条件。

联系具有普遍性，并不意味着任意两个事物之间都存在直接联系。

### 1.10 事物的变化与发展

发展是一种具有前进性质的变化，表现为新事物的产生和旧事物的灭亡。

| 概念 | 含义 |
|---|---|
| 运动 | 一切变化和过程 |
| 变化 | 事物状态发生改变 |
| 发展 | 具有前进、上升性质的变化 |

并非一切变化都是发展。

新事物与旧事物的区分，也不能简单依据出现时间，而应考察其是否适应客观规律、是否具有发展前途。

### 1.11 对立统一规律

对立统一规律揭示事物发展的源泉和动力，是唯物辩证法最核心的规律。

#### 1.11.1 矛盾的含义

矛盾是反映事物内部或事物之间对立统一关系的哲学范畴。

矛盾的两种基本属性是同一性和斗争性。

| 属性 | 含义 | 特征 |
|---|---|---|
| 同一性 | 矛盾双方相互依存、相互贯通，并在一定条件下相互转化 | 相对的、有条件的 |
| 斗争性 | 矛盾双方相互排斥、相互区别的性质和趋势 | 绝对的 |

![[Assets/Marxism_20261125_Fundamentals_16c09463808a4ddc_assets/images/marx_contradiction_364a7032-274b-4bf4-bcb1-122696854a2e.png]]

*图：同一性与斗争性共同推动事物发展*

哲学中的斗争性并不单指暴力冲突，还可以表现为竞争、差异、制约和相互排斥。

#### 1.11.2 内因与外因

内因是事物内部的矛盾，外因是事物发展所处的外部条件及外部矛盾。

**基本原理：**内因是事物变化发展的根据，外因是事物变化发展的条件，外因通过内因起作用。

例如，相同的外部学习环境对不同学生产生的效果可能不同，因为每个人的知识基础、学习习惯和理解能力存在差异。

#### 1.11.3 矛盾的普遍性与特殊性

| 概念 | 含义 |
|---|---|
| 矛盾普遍性 | 矛盾存在于一切事物及其发展过程之中 |
| 矛盾特殊性 | 不同事物、不同阶段及不同矛盾具有各自的特点 |

矛盾的普遍性与特殊性是共性与个性、一般与个别的关系。

普遍性寓于特殊性之中，并通过特殊性表现出来；二者在一定条件下可以相互转化。

**方法论：**坚持具体问题具体分析，把一般原理与具体实际结合起来。

#### 1.11.4 主要矛盾与次要矛盾

一个复杂事物中往往存在多种矛盾。

- 主要矛盾在一定阶段居于支配地位，对事物发展起决定性作用。
- 次要矛盾处于从属地位，但也会影响事物的发展。

主要矛盾和次要矛盾在一定条件下可以相互转化。

#### 1.11.5 矛盾的主要方面与次要方面

同一个矛盾内部，其双方的地位和作用也可能不平衡。

- 主要方面居于支配地位，事物的性质主要由主要矛盾的主要方面决定。
- 次要方面处于被支配地位，但同样对事物产生影响。

![[Assets/Marxism_20261125_Fundamentals_16c09463808a4ddc_assets/images/marx_major_5867a42d-ba69-4cc0-b722-7f15d54c9ba6.png]]

*图：主要矛盾是多个矛盾之间的比较；矛盾的主要方面是同一个矛盾内部双方的比较。图中比例仅用于示意，不代表实际测量。*

#### 1.11.6 两点论与重点论

| 理论 | 方法论要求 |
|---|---|
| 两点论 | 既看到主要矛盾，也看到次要矛盾；既看到矛盾主要方面，也看到次要方面 |
| 重点论 | 抓住主要矛盾和矛盾的主要方面 |

两点论与重点论应当统一，既不能平均用力，也不能只看一个方面。

### 1.12 量变质变规律

量变质变规律揭示事物发展的基本形式和状态。

#### 1.12.1 质、量、度

| 概念 | 含义 |
|---|---|
| 质 | 使事物成为自身并区别于其他事物的内在规定性 |
| 量 | 事物的数量、规模、程度、速度等规定性 |
| 度 | 事物保持其质的数量界限 |

#### 1.12.2 量变与质变的关系

量变是在一定范围内的数量变化；质变是事物根本性质的变化。

- 量变是质变的必要准备。
- 质变是量变发展到一定阶段的必然结果。
- 质变为新的量变开辟道路。
- 量变和质变相互渗透。

![[Assets/Marxism_20261125_Fundamentals_16c09463808a4ddc_assets/images/marx_heat_6c60cee8-92e3-4eda-90ec-c741c8bd7e57.png]]

*图：标准大气压下纯水的理想化加热曲线：用温度变化与物态变化说明量变和质变的区别。相变期间仍需吸收热量。*

**方法论：**重视量的积累，把握适度原则，并在条件成熟时促进事物发生质的变化。

### 1.13 否定之否定规律

否定之否定规律主要揭示事物发展的方向和道路。

#### 1.13.1 辩证否定观

辩证的否定是事物内部矛盾运动引起的自我否定、自我发展。

辩证否定具有两个重要特点：它既是事物发展的环节，又是事物联系的环节。

辩证否定的实质是**扬弃**，即既克服旧事物的消极因素，又保留和发展其中合理的因素。

| 辩证否定观 | 形而上学否定观 |
|---|---|
| 强调事物的自我否定 | 将否定完全归结为外部作用 |
| 既克服又保留 | 全盘肯定或全盘否定 |
| 体现发展和联系 | 割裂新旧事物的关系 |

#### 1.13.2 否定之否定的过程

![[Assets/Marxism_20261125_Fundamentals_16c09463808a4ddc_assets/images/marx_spiral_39f13ae7-73f2-47b9-aa79-8a3fdda2232a.png]]

*图：螺旋式上升是理论示意，不表示所有事物均按照固定的三阶段模式发展。*

**方法论：**坚持发展的观点，正确对待事物发展的曲折性，避免全盘否定或简单复古。

### 1.14 三大规律的比较

| 基本规律 | 揭示的问题 | 核心概念 |
|---|---|---|
| 对立统一规律 | 为什么发展 | 矛盾、同一性、斗争性 |
| 量变质变规律 | 以什么状态和形式发展 | 质、量、度、量变、质变 |
| 否定之否定规律 | 发展的方向和道路是什么 | 扬弃、前进性、曲折性 |

### 1.15 唯物辩证法的五对基本范畴

| 范畴 | 基本含义 | 方法论 |
|---|---|---|
| 内容与形式 | 内容是构成事物的要素总和，形式是内容的组织和表现方式 | 根据内容选择形式，重视形式对内容的反作用 |
| 本质与现象 | 本质是事物内在的根本规定，现象是本质的外在表现 | 透过现象认识本质 |
| 原因与结果 | 原因是引起一定现象的现象，结果是被引起的现象 | 分析因果关系，防止倒果为因 |
| 必然与偶然 | 必然是合乎规律的发展趋势，偶然是不确定的具体表现 | 把握必然趋势，重视偶然因素 |
| 现实与可能 | 现实是已经实现的存在，可能是客观条件中包含的发展趋势 | 立足现实，创造条件促使可能转化为现实 |

#### 1.15.1 本质、真象与假象

真象从正面表现事物本质，假象则以歪曲的方式表现本质。

假象仍然是一种客观现象，而错觉是主体产生的错误认识，二者不能混为一谈。

#### 1.15.2 原因与结果的复杂性

因果关系可能表现为一因一果、一因多果、多因一果、多因多果，也可能形成相互作用的因果链条。

具有时间先后关系的两个事件，不一定具有因果关系。

#### 1.15.3 可能性与不可能性

可能性必须具有一定的客观依据。仅仅能够在头脑中设想某件事，并不意味着它具有现实可能性。

### 1.16 唯物辩证法的思维方法

| 思维方法 | 主要内容 |
|---|---|
| 归纳与演绎 | 从个别到一般、从一般到个别 |
| 分析与综合 | 分解研究对象，再将各部分统一起来认识 |
| 抽象与具体 | 提取本质规定，再形成对事物的完整认识 |
| 逻辑与历史相统一 | 理论逻辑与客观历史过程相结合 |
| 系统思维 | 从整体、结构和要素关系分析问题 |
| 战略思维 | 从全局、长远和发展趋势考虑问题 |
| 底线思维 | 认识风险边界，做好应对准备 |
| 创新思维 | 突破不合适的既有观念和方法 |

## 第二章　实践与认识及其发展规律

本章主要研究人怎样认识世界、认识怎样产生和发展、如何判断认识是否正确，以及认识活动与人的价值追求之间的关系。

![[Assets/Marxism_20261125_Fundamentals_16c09463808a4ddc_assets/images/marx_ch2_cc696eaa-626d-43c7-8924-dbd2895ecaf9.png]]

*图：实践观、认识论、真理观与价值观*

### 2.1 实践的本质

实践是人类能动地改造世界的社会性的物质活动。

实践不同于单纯的思维活动，它要求主体通过一定手段与客观对象发生现实作用。

#### 2.1.1 实践的三个基本特征

| 特征 | 含义 |
|---|---|
| 客观实在性 | 实践的对象、手段和过程具有客观物质性 |
| 自觉能动性 | 实践是有目的、有意识的活动 |
| 社会历史性 | 实践受到具体社会关系和历史条件的制约 |

#### 2.1.2 实践的基本结构

![[Assets/Marxism_20261125_Fundamentals_16c09463808a4ddc_assets/images/marx_practice_3131344f-3862-4e2b-9d4d-7897696d5eaa.png]]

*图：主体借助中介对客体产生现实作用*

#### 2.1.3 实践的基本形式

| 形式 | 含义 | 示例 |
|---|---|---|
| 物质生产实践 | 生产物质生活资料的活动，是最基本的实践形式 | 工农业生产、工程建设 |
| 社会政治实践 | 调整和处理社会关系的活动 | 社会治理、制度改革 |
| 科学文化实践 | 科学探索和文化创造等活动 | 科学实验、技术研发 |

随着信息技术发展，虚拟实践等新形式也受到关注，但它们仍然具有现实物质条件和社会基础。

### 2.2 实践与认识的辩证关系

#### 2.2.1 实践对认识的决定作用

| 基本作用 | 具体解释 |
|---|---|
| 实践是认识的来源 | 认识最终来源于人类对客观世界的实践活动 |
| 实践是认识发展的动力 | 实践提出新问题，并提供新的认识条件 |
| 实践是认识的目的 | 认识最终服务于现实实践 |
| 实践是检验认识真理性的唯一标准 | 通过实践考察主观认识是否符合客观实际 |

> [!note] 注意
> 人的知识可以通过直接经验和间接经验获得，但间接经验归根到底也来源于社会实践。例如，学生可以通过教材间接获得物理知识，不必亲自重复所有科学实验。

#### 2.2.2 认识对实践的反作用

认识能够指导实践。

符合客观实际的认识有助于提高实践的有效性；错误认识则可能导致决策失误和实践失败。

### 2.3 认识的本质

马克思主义认识论认为，认识是主体在实践基础上对客体的能动反映。

#### 2.3.1 不同认识论的比较

| 认识论 | 基本观点 |
|---|---|
| 唯心主义认识论 | 从精神或意识出发解释认识及其来源 |
| 旧唯物主义认识论 | 承认认识是对客观世界的反映，但往往忽视实践和主体能动性 |
| 辩证唯物主义认识论 | 强调认识以实践为基础，并具有能动性和创造性 |

认识包含反映与创造的统一。

创造性不意味着人可以脱离客观对象任意构造真理。

### 2.4 认识过程中的两次飞跃

![[Assets/Marxism_20261125_Fundamentals_16c09463808a4ddc_assets/images/marx_jumps_27d00a44-2a7a-4bb1-8da9-9c0f12ba50e0.png]]

*图：从感性认识到理性认识，再到新的实践*

#### 2.4.1 感性认识

感性认识是人通过感觉器官直接接触客观对象所形成的认识，主要反映事物的现象、外部联系和具体特征。

| 形式 | 含义 |
|---|---|
| 感觉 | 对事物个别属性的反映 |
| 知觉 | 对事物整体形象的反映 |
| 表象 | 客观对象离开直接感知后，在头脑中保留或再现的形象 |

#### 2.4.2 理性认识

理性认识是对事物本质、内部联系和规律的抽象认识。

| 形式 | 含义 |
|---|---|
| 概念 | 对事物本质属性的抽象概括 |
| 判断 | 对事物及其关系作出的肯定或否定 |
| 推理 | 根据已有判断得出新的判断 |

#### 2.4.3 第一次飞跃：从感性认识到理性认识

实现第一次飞跃，需要掌握丰富而真实的感性材料，并运用科学思维方法对材料进行加工。

典型方法包括去粗取精、去伪存真、由此及彼、由表及里。

#### 2.4.4 第二次飞跃：从理性认识到实践

将形成的理论、方案和认识用于现实活动，通过实践检验并发展认识。

第二次飞跃具有特别重要的意义，因为认识的目的在于实践，认识的真理性也需要由实践检验。

### 2.5 认识运动的基本规律

认识运动不是一次性完成的，而是不断反复、不断深化的过程。

$$
\text{实践}\rightarrow\text{认识}\rightarrow\text{再实践}\rightarrow\text{再认识}\rightarrow\cdots
$$

#### 2.5.1 认识的反复性

由于客观事物复杂多变、主体认识能力有限，以及社会历史条件的制约，正确认识往往需要经过多次实践和认识的反复。

#### 2.5.2 认识的无限性

客观世界不断发展，人类的认识活动也不断深入，不存在一劳永逸地完成全部认识的状态。

#### 2.5.3 认识的上升性

认识运动不是简单重复，而是在实践基础上不断深化和发展的过程。

#### 综合案例：软件开发

| 认识阶段 | 实际表现 |
|---|---|
| 实践 | 收集软件运行日志、用户反馈 |
| 感性认识 | 发现卡顿、闪退、界面异常 |
| 理性认识 | 分析代码，推断问题产生的原因 |
| 再实践 | 修改代码并进行测试 |
| 再认识 | 根据测试结果修正原有判断 |

该过程体现了实践与认识不断循环发展的基本规律。

### 2.6 真理及其基本属性

真理是对客观事物及其规律的正确认识。

与真理相对的是谬误，即对客观事物及其规律的错误认识。

#### 2.6.1 真理的客观性

真理所反映的内容不以个人主观意愿为转移，检验真理的标准也是客观的社会实践。

真理的表现形式可以是主观的，但其正确性具有客观依据。

#### 2.6.2 真理的绝对性与相对性

| 属性 | 含义 |
|---|---|
| 绝对性 | 真理具有不依赖于主观意愿的客观内容，人类原则上能够认识客观世界 |
| 相对性 | 具体真理受到认识条件、范围和深度的限制 |

![[Assets/Marxism_20261125_Fundamentals_16c09463808a4ddc_assets/images/marx_truth_48dfd347-9617-454d-b410-0fc515d3cc71.png]]

*图：具体认识有限，认识过程不断深化*

真理的绝对性和相对性是同一真理的两个方面，而不是两类相互独立的真理。

#### 2.6.3 真理与谬误的关系

真理和谬误具有明确区别，但在一定条件下可以发生转化。

例如，牛顿力学在适用范围内具有可靠性，但如果无条件地将其推广到所有高速、微观或强引力情形，就可能得出不准确的结论。

这体现了真理的具体性和条件性。

### 2.7 实践是检验真理的唯一标准

#### 2.7.1 为什么必须以实践为标准

主观认识是否符合客观实际，不能仅仅依靠主观感觉、逻辑自洽、权威判断或者多数人的意见来最终确定。

实践能够把主观认识转化为现实活动，并根据客观结果考察认识的正确性。

#### 2.7.2 实践标准的确定性与不确定性

| 属性 | 含义 |
|---|---|
| 确定性、绝对性 | 实践是检验认识真理性的最终标准 |
| 不确定性、相对性 | 具体实践受到历史条件限制，可能无法一次完成检验 |

逻辑证明在科学认识中具有重要作用，但理论的经验内容是否符合客观实际，仍需要实践支持。

### 2.8 价值及其基本特性

哲学意义上的价值，是客体对于主体需要所具有的意义。

例如，水对人的生存具有价值，软件对使用者解决问题具有价值。

#### 2.8.1 价值的基本特性

| 特性 | 含义 |
|---|---|
| 客观性 | 价值受到客体属性与主体实际需要的制约 |
| 主体性 | 价值是相对于一定主体而言的 |
| 社会历史性 | 价值关系随社会和历史条件变化 |
| 多维性 | 同一客体可以具有经济、文化、社会等不同方面的价值 |

#### 2.8.2 价值评价与价值观

价值评价是主体依据一定标准，对客体满足主体需要的程度作出的评价。

价值观是关于价值及价值评价的总体观点，它影响人的目标选择、行为方式和社会实践。

### 2.9 真理与价值的辩证统一

| 比较 | 真理 | 价值 |
|---|---|---|
| 核心问题 | 认识是否符合客观实际 | 对主体有什么意义 |
| 基本尺度 | 客观规律 | 主体需要及其合理性 |
| 主要作用 | 指导人正确认识世界 | 指导人选择实践目标 |

实践活动需要同时考虑真理尺度和价值尺度。

例如，一项技术是否可行属于事实和规律层面的问题；这项技术是否值得开发、是否有益于社会，则涉及价值判断。

### 2.10 认识世界与改造世界

认识世界是改造世界的重要前提，改造世界是认识世界的根本目的。

马克思主义认识论的实践要求包括：一切从实际出发、实事求是、理论联系实际、坚持守正创新，以及推动理论创新与实践创新相互促进。

## 第三章　人类社会及其发展规律

本章是历史唯物主义的主要内容。核心问题是：人类社会为何产生、社会结构如何形成、社会历史发展的动力是什么，以及谁是历史的创造者。

### 3.1 两种根本对立的历史观

| 历史观 | 基本观点 |
|---|---|
| 历史唯物主义（唯物史观） | 社会存在决定社会意识，物质生产活动构成社会发展的基础 |
| 历史唯心主义（唯心史观） | 将精神、思想等视为社会历史发展的根本决定因素 |

社会历史观的基本问题是社会存在与社会意识的关系问题，它是哲学基本问题在社会历史领域的具体表现。

### 3.2 社会存在与社会意识

#### 3.2.1 社会存在

社会存在是社会生活的物质方面，主要包括：

| 构成 | 含义 |
|---|---|
| 自然地理环境 | 社会生活所处的自然条件 |
| 人口因素 | 人口数量、结构和分布等 |
| 物质资料生产方式 | 人们生产物质生活资料的方式 |

物质资料生产方式是社会存在和发展的基础，是社会发展的决定性力量。

自然环境和人口因素是社会发展的重要条件，但不能将社会历史发展简单归结为地理环境或人口数量。

#### 3.2.2 社会意识

社会意识是社会生活的精神方面，是社会存在在精神领域中的反映。

![[Assets/Marxism_20261125_Fundamentals_16c09463808a4ddc_assets/images/marx_consciousness_3760dde8-f766-4958-ab1c-b1f6b3e9b68e.png]]

*图：从社会意识的层次进行划分*

社会意识还可以划分为个体意识与群体意识、意识形态与非意识形态等。

意识形态通常包括政治法律思想、道德、宗教、哲学等具有社会立场和利益关系的思想形式；自然科学等通常不直接属于意识形态。

#### 3.2.3 社会存在与社会意识的辩证关系

社会存在决定社会意识，社会意识反映社会存在，并对社会存在具有能动的反作用。

社会意识具有相对独立性，主要表现为：

| 表现 | 解释 |
|---|---|
| 不完全同步性 | 社会意识的发展与社会存在的变化并不总是同步 |
| 历史继承性 | 社会意识会继承以往的思想文化成果 |
| 相互影响性 | 不同社会意识形式之间相互影响 |
| 能动反作用 | 社会意识能够通过社会实践促进或阻碍社会发展 |

### 3.3 社会的基本结构

![[Assets/Marxism_20261125_Fundamentals_16c09463808a4ddc_assets/images/marx_social_structure_19a93685-d7b5-420a-b621-efafabeb4977.png]]

*图：社会基本结构及其决定与反作用关系*

### 3.4 生产力与生产关系

#### 3.4.1 生产力

生产力是人类在物质生产实践中改造自然、获取物质生活资料的现实能力。

生产力的三个基本要素：

| 要素 | 含义 | 例子 |
|---|---|---|
| 劳动者 | 具有劳动能力的人 | 工人、技术人员 |
| 劳动资料 | 人们进行生产所使用的手段 | 机器、工具、设备 |
| 劳动对象 | 劳动所作用的对象 | 原材料、矿产、待加工产品 |

其中，劳动者是生产力中最活跃的因素，生产工具是衡量生产力发展水平的重要客观标志。

科学技术能够通过劳动者素质、生产设备和生产组织等途径转化为现实生产力。

#### 3.4.2 生产关系

生产关系是人们在物质生产过程中形成的、不以个人意志为转移的经济关系。

| 构成 | 地位 |
|---|---|
| 生产资料所有制关系 | 生产关系的基础，具有决定性意义 |
| 人们在生产中的地位和相互关系 | 体现生产过程中的组织与社会关系 |
| 产品分配关系 | 体现生产成果如何分配 |

#### 3.4.3 生产力与生产关系的辩证关系

生产力决定生产关系的性质及其发展变化，生产关系则对生产力具有反作用。

当生产关系适应生产力发展要求时，可以促进生产力发展；当生产关系不适应生产力发展要求时，则可能阻碍生产力发展。

> [!important] 基本规律
> 生产关系一定要适合生产力状况。

#### 3.4.4 生产方式

生产方式是生产力与生产关系的统一。

不能把生产方式仅仅理解为技术手段，也不能仅仅理解为所有制关系。

### 3.5 经济基础与上层建筑

#### 3.5.1 经济基础

经济基础是由社会一定发展阶段的生产力所决定的生产关系的总和。

经济基础不是生产力，也不是社会财富或经济发展水平本身。

#### 3.5.2 上层建筑

上层建筑是在一定经济基础上形成的思想观念及相应的制度、组织和设施。

| 类型 | 内容 |
|---|---|
| 政治上层建筑 | 国家政权、政治法律制度及有关组织设施 |
| 观念上层建筑 | 政治法律思想、道德、宗教、哲学等社会意识形态 |

#### 3.5.3 经济基础与上层建筑的辩证关系

经济基础决定上层建筑的性质及其发展变化，上层建筑对经济基础具有反作用。

判断上层建筑对社会发展的作用，不能只看它是否维护现有经济基础，还需要考察该经济基础是否适应生产力的发展要求。

> [!important] 基本规律
> 上层建筑一定要适合经济基础状况。

### 3.6 人类社会的两对基本矛盾

| 基本矛盾 | 对应规律 |
|---|---|
| 生产力与生产关系的矛盾 | 生产关系一定要适合生产力状况 |
| 经济基础与上层建筑的矛盾 | 上层建筑一定要适合经济基础状况 |

社会基本矛盾贯穿社会发展过程，是马克思主义历史唯物主义所强调的社会发展的根本动力。

### 3.7 社会形态及其更替

社会形态是一定生产力发展水平基础上的经济基础与上层建筑的统一体。

马克思主义经典社会形态理论通常将人类社会的发展概括为以下形态：

![[Assets/Marxism_20261125_Fundamentals_16c09463808a4ddc_assets/images/marx_formations_d2e075cc-229c-462b-8c5d-521a8ecf4f44.png]]

*图：经典五种社会形态的理论概括，并非所有国家和民族都必须依次经历完全相同的历史阶段。*

社会形态更替具有客观规律性，同时存在历史道路的多样性以及人们在客观条件下进行选择的空间。

### 3.8 社会历史发展的动力

| 动力因素 | 理论地位 |
|---|---|
| 社会基本矛盾 | 社会发展的根本动力 |
| 阶级斗争 | 阶级社会发展的直接动力 |
| 社会革命 | 实现社会形态重大变革的重要方式 |
| 社会改革 | 调整社会关系、促进社会发展的重要动力 |
| 科学技术 | 推动社会经济发展的强大杠杆 |
| 文化 | 提供思想指引、精神动力和社会凝聚力量 |

#### 3.8.1 阶级与阶级斗争

阶级是由一定社会生产关系形成的、在经济地位和生产资料占有关系等方面存在差别的社会集团。

马克思主义使用阶级分析方法研究不同社会群体的经济地位、利益关系及其社会政治影响。

#### 3.8.2 社会革命与社会改革

| 比较 | 社会革命 | 社会改革 |
|---|---|---|
| 主要对象 | 社会制度和基本社会关系的根本变革 | 现有制度中具体体制和关系的调整 |
| 变化性质 | 根本性变化 | 调整性、完善性变化，也可能具有重大深远影响 |
| 主要作用 | 推动社会形态更替等重大历史变化 | 解决社会发展中的矛盾，促进制度适应发展需要 |

#### 3.8.3 科学技术的社会作用

科学技术可以提高生产效率、改变产业结构、推动社会交往和生活方式变化，同时也可能伴随失业风险、伦理冲突、环境问题和技术垄断等现象。

因此，应当结合社会制度、应用目的和具体实践条件分析科学技术的影响，避免技术决定论。

### 3.9 人民群众是历史的创造者

唯物史观认为，人民群众是社会历史的主体，是推动历史发展的决定性力量。

人民群众的历史作用主要表现为：

| 作用 | 内容 |
|---|---|
| 创造物质财富 | 通过生产实践提供社会生存和发展的物质基础 |
| 创造精神财富 | 通过社会实践和文化活动推动精神文明发展 |
| 推动社会变革 | 参与社会制度、社会关系的变革 |

#### 3.9.1 人民群众与个人的关系

承认人民群众的决定性作用，并不否认杰出人物在历史中的重要作用。

杰出人物可以影响历史事件的进程、形式和具体结果，但其活动受到客观历史条件和社会发展规律的制约。

#### 3.9.2 群众观点与群众路线

| 概念 | 基本内容 |
|---|---|
| 群众观点 | 相信群众、依靠群众、服务群众，尊重群众的历史主体地位 |
| 群众路线 | 一切为了群众，一切依靠群众，从群众中来，到群众中去 |

### 3.10 人的本质与人的发展

马克思主义从社会实践和社会关系出发理解人的本质，强调现实的人不是脱离社会关系的孤立个体。

人的发展既与生产力发展有关，也与社会关系、教育条件、文化生活和个人实践有关。

人的自由全面发展是马克思主义社会发展理论中的重要价值目标。

### 3.11 人类交往、世界历史与文明多样性

生产力发展和社会分工促进不同地区之间的经济、政治、文化交往，使相对孤立的历史逐步发展为具有普遍联系的世界历史。

文明的发展既具有共同性，也受到不同民族、地区的历史条件影响，因而呈现多样性。

这一部分与后续经济全球化、世界市场等内容存在直接联系。

## 第四章　资本主义的本质及规律

本章是马克思主义政治经济学的核心，也是全课程中概念关系和计算题最多的一章。

主要研究商品、货币、价值、资本、剩余价值、利润、工资、资本积累及经济危机等问题。

![[Assets/Marxism_20261125_Fundamentals_16c09463808a4ddc_assets/images/marx_ch4_a6633063-f4fe-4eaf-a5d6-5bf5bb8406c4.png]]

*图：资本主义政治经济学的知识主线*

> [!note] 概念范围
> 本章中的价值、劳动、资本和利润等概念，主要采用马克思主义政治经济学的理论定义，与现代微观经济学、金融学及会计学中的同名概念不一定完全相同。

### 4.1 商品经济的产生

#### 4.1.1 自然经济与商品经济

| 经济形式 | 生产目的 | 主要特点 |
|---|---|---|
| 自然经济 | 满足生产者自身需要 | 自给自足，交换不占主导地位 |
| 商品经济 | 通过交换满足社会需要 | 社会分工、市场交换 |

商品经济产生的两个基本条件是社会分工，以及生产资料和劳动产品属于不同所有者。

商品经济并非资本主义社会所独有，也可以存在于其他社会制度中。

### 4.2 商品的二因素

商品是用于交换、能够满足某种需要的劳动产品。

商品具有使用价值和价值两个因素。

| 因素 | 含义 | 属性 |
|---|---|---|
| 使用价值 | 商品满足人的某种需要的属性 | 自然属性 |
| 价值 | 凝结在商品中的无差别的一般人类劳动 | 社会属性 |

#### 4.2.1 使用价值与价值的关系

使用价值是价值的物质承担者。

没有使用价值的劳动产品不能成为正常商品，但具有使用价值的物品不一定具有马克思主义劳动价值论意义上的价值。

例如，未经劳动加工且可自由获取的自然空气具有使用价值，但通常不是商品。

#### 4.2.2 价值与交换价值

价值是商品交换价值的基础，交换价值是价值的表现形式。

交换价值表现为一种使用价值与另一种使用价值相交换的数量比例。

价格则是商品价值的货币表现。

### 4.3 生产商品的劳动二重性

生产商品的同一劳动具有具体劳动和抽象劳动两个方面。

![[Assets/Marxism_20261125_Fundamentals_16c09463808a4ddc_assets/images/marx_labor_2f8fc6a5-bed5-4fc1-9ed5-beb263ab3a07.png]]

*图：具体劳动形成使用价值，抽象劳动形成价值*

| 比较 | 具体劳动 | 抽象劳动 |
|---|---|---|
| 关注对象 | 劳动的具体形式和用途 | 劳动力的一般耗费 |
| 作用 | 创造使用价值 | 形成商品价值 |
| 属性 | 体现人与自然的关系 | 体现商品生产者之间的社会关系 |
| 例子 | 缝纫、编程、木工 | 撇开具体形式的一般人类劳动 |

劳动二重性不是两次劳动，也不是两种相互独立的劳动，而是生产商品的同一劳动过程的两个方面。

马克思将劳动二重性理论视为理解政治经济学的重要枢纽。

### 4.4 商品价值量的决定

#### 4.4.1 社会必要劳动时间

商品价值量由生产该商品的社会必要劳动时间决定，而非由某个生产者实际耗费的个别劳动时间决定。

社会必要劳动时间是在社会正常生产条件、平均劳动熟练程度和平均劳动强度下，生产某种使用价值所需要的劳动时间。

#### 4.4.2 劳动生产率

劳动生产率表示劳动者在一定时间内生产使用价值的效率。

$$
\text{劳动生产率}=\frac{\text{产品数量}}{\text{劳动时间}}
$$

在其他条件不变、劳动强度相同的情况下，社会劳动生产率提高，单位商品所需社会必要劳动时间减少，单位商品价值量下降。

$$
\text{单位商品价值量}\propto\frac{1}{\text{社会劳动生产率}}
$$

![[Assets/Marxism_20261125_Fundamentals_16c09463808a4ddc_assets/images/marx_productivity_babf5030-2cae-4086-ab12-04bdd1320a3b.png]]

*图：假设初始单位商品价值量为100，其他条件保持不变。*

#### 4.4.3 个别劳动生产率与社会劳动生产率

| 变化 | 单位商品社会价值量 | 相同时间内的产量 | 价值总量 |
|---|---|---|---|
| 社会劳动生产率提高 | 下降 | 增加 | 在劳动时间、强度等不变时，新创造的价值总量保持不变（见说明） |
| 个别劳动生产率提高 | 不变 | 增加 | 按既定社会价值计算的商品价值总额增加 |

个别企业提高劳动生产率，可以形成个别价值低于社会价值的竞争优势，但能否实现相应收益仍取决于商品销售等条件。

> [!note] 口径说明
> 原文将社会劳动生产率提高后的“价值总量”直接表述为保持不变。本表明确为相同劳动时间和强度下新创造的价值总量；包括生产资料转移价值的商品价值总额还需考虑生产资料消耗的变化。

#### 4.4.4 简单劳动与复杂劳动

简单劳动是普通劳动者一般能够进行的劳动；复杂劳动是需要专门训练、知识或技能的劳动。

在马克思劳动价值论中，复杂劳动被看作倍加的简单劳动，其折算通过社会过程形成，并不是由劳动者自行决定。

### 4.5 货币的产生及职能

#### 4.5.1 价值形式的发展

货币产生于商品交换和价值形式的长期发展。

![[Assets/Marxism_20261125_Fundamentals_16c09463808a4ddc_assets/images/marx_money_c202658d-a02d-436e-82f9-f1e578415d19.png]]

*图：简单价值形式、扩大价值形式、一般价值形式、货币形式*

在马克思主义经典货币理论中，货币是从商品交换过程中分离出来、固定充当一般等价物的特殊商品。

现代信用货币、法定货币和电子支付体系，则需要结合现代货币制度进一步认识，不能简单理解为所有现代货币都必须具有金属商品价值。

#### 4.5.2 货币的五项经典职能

| 职能 | 含义 | 例子 |
|---|---|---|
| 价值尺度 | 衡量和表现商品价值 | 商品标价100元 |
| 流通手段 | 作为商品交换的媒介 | 付款后取得商品 |
| 贮藏手段 | 退出流通并保存财富 | 贮藏金银货币 |
| 支付手段 | 清偿债务或履行延期支付义务 | 支付工资、偿还贷款 |
| 世界货币 | 在国际经济交往中发挥货币作用 | 跨境支付与结算 |

价值尺度与流通手段是货币的两个基本职能。

#### 4.5.3 货币流通规律

在简化的商品流通模型中：

$$
M=\frac{\sum PQ}{V}
$$

| 符号 | 含义 |
|---|---|
| $M$ | 流通所需要的货币量 |
| $P$ | 商品价格 |
| $Q$ | 商品流通数量 |
| $V$ | 同一货币单位的平均流通速度 |

考虑赊销、延期支付和相互抵销的支付义务时，需要对分子进行相应调整。

### 4.6 价值规律

价值规律是商品经济的基本规律。

其基本内容是商品价值量由社会必要劳动时间决定，商品交换以价值量为基础实行等价交换。

#### 4.6.1 价值规律的表现形式

商品价格受到供求关系等因素影响，围绕价值发生波动。

![[Assets/Marxism_20261125_Fundamentals_16c09463808a4ddc_assets/images/marx_price_71b9dd41-2fda-4292-b7b9-b080467a5642.png]]

*图：价值规律的简化示意。在资本主义竞争条件下，还需要进一步考虑生产价格、平均利润和垄断价格等因素。*

价格围绕价值波动并不意味着每一次交换都按照商品价值进行，也不意味着价值规律失去作用。

#### 4.6.2 价值规律的作用

| 作用 | 表现 |
|---|---|
| 调节资源配置 | 通过价格和盈利变化影响资源流向 |
| 刺激生产力发展 | 推动企业改进技术、提高劳动生产率 |
| 促进生产者分化 | 不同生产者因成本和竞争条件不同而产生分化 |

价值规律的自发作用也可能伴随资源浪费、收入分化、生产波动和市场失衡。

### 4.7 私有制商品经济的基本矛盾

以私有制为基础的商品经济，其基本矛盾是私人劳动与社会劳动之间的矛盾。

私人劳动意味着生产者独立组织生产；社会劳动意味着该劳动需要通过社会交换获得承认，并成为社会总劳动的一部分。

![[Assets/Marxism_20261125_Fundamentals_16c09463808a4ddc_assets/images/marx_private_08afcb99-0c4a-43ad-b3f0-736011113b00.png]]

*图：若商品无法出售或只能低价出售，私人劳动不能充分实现其社会价值。*

### 4.8 马克思劳动价值论

劳动价值论主要研究商品价值的来源、价值量的决定以及商品生产者之间的社会关系。

核心内容包括商品二因素、劳动二重性、社会必要劳动时间、货币和价值规律。

需要特别区分：

| 问题 | 劳动价值论的解释 |
|---|---|
| 商品价值从何而来 | 抽象劳动 |
| 商品价值量由什么决定 | 社会必要劳动时间 |
| 机器是否能够转移已有价值 | 能够 |
| 机器本身是否创造新的价值 | 按马克思经典劳动价值论，不创造新的价值 |
| 自然资源是否具有使用价值 | 可以具有 |
| 所有价格是否都等于劳动价值 | 不等于 |

### 4.9 资本主义生产关系的产生

资本主义生产关系建立的重要条件包括资本的积累、生产资料的集中，以及具有自由身份但缺少生产资料的劳动者形成。

#### 4.9.1 资本原始积累

资本原始积累是生产者与生产资料分离、货币财富集中并形成资本主义生产条件的历史过程。

马克思对这一过程的研究强调圈地、殖民活动及其他强制性财富转移方式在部分资本主义国家历史上的作用。

原始积累不同于资本主义生产制度形成以后通过剩余价值资本化进行的资本积累。

### 4.10 货币转化为资本

#### 4.10.1 商品流通与资本流通

普通商品流通：

$$
W-G-W
$$

即出售商品获得货币，再用货币购买其他商品，最终目的是获得使用价值。

资本流通的总公式：

$$
G-W-G'
$$

其中：

$$
G'=G+\Delta G
$$

资本流通的直接目的在于价值增殖。

![[Assets/Marxism_20261125_Fundamentals_16c09463808a4ddc_assets/images/marx_circulation_52c89994-d8df-490d-abac-11cdbaa3432b.png]]

*图：普通商品流通与资本流通的目的不同*

#### 4.10.2 劳动力成为商品

劳动力是人的劳动能力，劳动则是劳动力在生产过程中的实际使用。

劳动力成为商品需要两个基本条件：

1. 劳动者具有自由身份，能够支配并出售自己的劳动力。
2. 劳动者缺少独立进行生产所需的生产资料和相应生活条件，需要通过出售劳动力维持生活。

#### 4.10.3 劳动力商品的特殊性

劳动力商品同样具有价值和使用价值。

其价值主要由维持劳动者自身生存、家庭劳动力再生产以及教育训练所需要的生活资料价值构成，还包含历史和道德因素。

其特殊使用价值在于能够创造新的价值，而且可以创造超过劳动力自身价值的价值。

因此，在马克思的理论中，劳动力成为商品是货币转化为资本的关键。

### 4.11 剩余价值的生产

剩余价值是雇佣劳动者创造的、超过其劳动力价值并由资本所有者占有的价值。

#### 4.11.1 必要劳动与剩余劳动

| 劳动形式 | 含义 |
|---|---|
| 必要劳动 | 再生产劳动力自身价值的劳动 |
| 剩余劳动 | 超过必要劳动的、创造剩余价值的劳动 |

假设一个工作日为8小时，其中4小时创造相当于劳动力价值的价值，另外4小时创造剩余价值。

![[Assets/Marxism_20261125_Fundamentals_16c09463808a4ddc_assets/images/marx_workday_b1138200-9f49-4cb4-9bad-9d661246471d.png]]

*图：8小时工作日的必要劳动与剩余劳动*

这是一种理论分解，并不意味着劳动者在实际生产中必须先完成4小时必要劳动，再开始4小时剩余劳动。

### 4.12 不变资本与可变资本

资本按照在剩余价值生产过程中所起的不同作用，可以划分为不变资本和可变资本。

| 类型 | 符号 | 含义 |
|---|---|---|
| 不变资本 | $c$ | 用于购买生产资料的资本 |
| 可变资本 | $v$ | 用于购买劳动力的资本 |
| 剩余价值 | $m$ | 劳动者创造的超过劳动力价值的新增价值 |

商品价值构成：

$$
W=c+v+m
$$

这里的 $c$ 指转移到当期商品中的生产资料价值。

劳动者创造的新价值为：

$$
W_{\text{新}}=v+m
$$

![[Assets/Marxism_20261125_Fundamentals_16c09463808a4ddc_assets/images/marx_value_6570fbaf-f8bf-4806-b2d5-552fdc84f9f2.png]]

*图：商品价值构成示例：生产资料转移价值800，劳动力价值200，剩余价值200；总价值1200，新创造的价值为400。*

### 4.13 剩余价值率

剩余价值率反映剩余价值与可变资本之间的比例。在马克思主义政治经济学中，用于衡量资本对雇佣劳动的剥削程度。

$$
m'=\frac{m}{v}\times100\%
$$

也可以表示为：

$$
m'=\frac{\text{剩余劳动时间}}{\text{必要劳动时间}}\times100\%
$$

> [!example] 计算示例
> 假设必要劳动时间为3小时，剩余劳动时间为5小时，则：
>
> $$
> m'=\frac{5}{3}\times100\%\approx166.67\%
> $$

### 4.14 绝对剩余价值与相对剩余价值

#### 4.14.1 绝对剩余价值

在必要劳动时间不变的条件下，通过延长工作日增加剩余劳动时间，从而增加剩余价值。

#### 4.14.2 相对剩余价值

在工作日长度不变的条件下，通过提高社会劳动生产率，降低劳动力再生产所需要的生活资料价值，从而缩短必要劳动时间、延长剩余劳动时间。

![[Assets/Marxism_20261125_Fundamentals_16c09463808a4ddc_assets/images/marx_surplus_88ecb5ea-9e95-4279-8ac4-e8922c44a7f2.png]]

*图：三种工作日的比较：初始状态、绝对剩余价值、相对剩余价值。*

| 比较 | 绝对剩余价值 | 相对剩余价值 |
|---|---|---|
| 工作日长度 | 延长 | 不变 |
| 必要劳动时间 | 不变 | 缩短 |
| 剩余劳动时间 | 增加 | 增加 |
| 实现方式 | 延长工作日 | 提高相关部门的社会劳动生产率 |

#### 4.14.3 超额剩余价值

个别企业通过技术创新或管理改进，使商品的个别价值低于社会价值，在按社会价值出售时获得额外的剩余价值。

个别企业追求超额剩余价值，会推动社会劳动生产率普遍提高，并在一定条件下促进相对剩余价值的生产。

### 4.16 资本积累

资本积累是将剩余价值的一部分转化为追加资本的过程，即剩余价值的资本化。

#### 4.16.1 简单再生产与扩大再生产

| 类型 | 含义 |
|---|---|
| 简单再生产 | 剩余价值全部用于个人消费，生产规模保持不变 |
| 扩大再生产 | 剩余价值的一部分转化为追加资本，使生产规模扩大 |

![[Assets/Marxism_20261125_Fundamentals_16c09463808a4ddc_assets/images/marx_accumulation_39a5a3db-be87-4894-83d4-dbd120841240.png]]

*图：剩余价值用于个人消费或追加资本*

#### 4.16.2 影响资本积累规模的因素

| 因素 | 影响 |
|---|---|
| 剩余价值率 | 其他条件不变时，影响剩余价值的数量 |
| 劳动生产率 | 影响生产效率和追加资本的实际购买能力 |
| 所用资本与所费资本的差额 | 影响生产资料长期发挥作用的程度 |
| 预付资本规模 | 影响可以组织的生产规模 |
| 剩余价值的积累比例 | 决定多少剩余价值被用于扩大再生产 |

#### 4.16.3 资本积聚与资本集中

| 概念 | 含义 | 示例 |
|---|---|---|
| 资本积聚 | 个别资本通过自身积累不断扩大 | 企业将利润用于扩建 |
| 资本集中 | 已有资本通过兼并、联合等方式重新组合 | 企业并购 |

资本积聚通常伴随社会资本总额增加；单纯的资本集中不必然增加社会资本总额，却能够迅速扩大个别资本规模。

#### 4.16.4 资本有机构成

资本构成可以从技术和价值两个方面研究。

资本技术构成是生产资料与劳动力在物质数量上的比例；资本价值构成是不变资本与可变资本在价值上的比例。

由技术构成决定并反映其变化的资本价值构成，称为资本有机构成。

$$
\text{资本有机构成}=c:v
$$

需要注意，并非任何 $c:v$ 的变化都一定意味着资本技术构成发生变化。

#### 4.16.5 相对过剩人口

在马克思资本积累理论中，随着资本有机构成提高，资本对劳动力的需求可能相对于资本总量减少，由此形成相对于资本增殖需要而言的过剩劳动力。

相对过剩人口不是指人口相对于自然资源绝对过多，而是指相对于资本使用劳动力的需要而言的过剩。

### 4.17 资本的循环与周转

#### 4.17.1 产业资本循环

产业资本的循环一般经历购买、生产、销售三个阶段。

$$
G-W\left\{\begin{matrix} A\\ Pm\end{matrix}\right.\cdots P\cdots W'-G'
$$

其中 $A$ 表示劳动力，$Pm$ 表示生产资料，$P$ 表示生产过程。

![[Assets/Marxism_20261125_Fundamentals_16c09463808a4ddc_assets/images/marx_cycle_b0c25f20-dab4-499b-8dd4-0e2d57554663.png]]

*图：产业资本循环的三种职能形式相互衔接*

#### 4.17.2 资本周转时间

$$
t=t_{\text{生产}}+t_{\text{流通}}
$$

资本周转次数：

$$
n=\frac{T}{t}
$$

其中 $T$ 是选定的时间周期，通常为一年，$t$ 是一次资本周转所需要的时间。

假设资本每3个月完成一次周转，则一年周转4次。

#### 4.17.3 年剩余价值量与年剩余价值率

在每次周转条件相同的简化情况下（$n$ 为可变资本年周转次数）：

$$
M=mn=m'vn
$$

$$
M'=\frac{M}{v}=m'n
$$

计算时，百分数形式的剩余价值率应先转换为小数。

#### 4.17.4 固定资本与流动资本

| 类型 | 特点 | 示例 |
|---|---|---|
| 固定资本 | 价值在多个生产周期中逐步转移 | 机器、厂房 |
| 流动资本 | 价值在一个生产周期中全部转移或再生产 | 原材料、购买劳动力的资本 |

固定资本与流动资本依据资本价值的周转方式划分；不变资本与可变资本依据其在剩余价值生产中的作用划分。

![[Assets/Marxism_20261125_Fundamentals_16c09463808a4ddc_assets/images/marx_fixed_a9f2e2be-3a40-4bdb-a167-fd9ea2bb08b3.png]]

*图：同一生产资本的两种不同分类标准*

### 4.18 资本主义工资

马克思主义政治经济学认为，资本主义工资在本质上是劳动力价值或价格的转化形式，而不是劳动本身的价值。

工资的主要形式包括计时工资和计件工资。

名义工资是劳动者获得的货币工资，实际工资是该货币工资所能够购买的实际商品与服务数量。

名义工资上涨，并不必然意味着实际工资上涨，因为实际购买力还受到物价水平等因素影响。

### 4.19 剩余价值转化为利润

#### 4.19.1 成本价格

在马克思的经典理论中，商品的资本主义成本价格为生产商品所耗费的不变资本与可变资本之和：

$$
k=c+v
$$

商品价值：

$$
W=k+m
$$

当剩余价值表现为全部预付资本的产物时，剩余价值便表现为利润。

#### 4.19.2 利润率

$$
p'=\frac{m}{C}\times100\%
$$

其中 $C$ 表示全部预付资本。

在预付资本全部于本期耗费的简化条件下：

$$
p'=\frac{m}{c+v}\times100\%
$$

| 比较 | 剩余价值率 | 利润率 |
|---|---|---|
| 分子 | 剩余价值 | 剩余价值或利润 |
| 分母 | 可变资本 | 全部预付资本 |
| 主要反映 | 剩余劳动与必要劳动关系 | 资本增殖程度 |

#### 4.19.3 平均利润与生产价格

资本在不同部门之间流动和竞争，使不同部门的利润率具有平均化趋势。

$$
\overline{p'}=\frac{\sum m_i}{\sum C_i}
$$

$$
\text{平均利润}=\text{预付资本}\times\text{平均利润率}
$$

$$
\text{生产价格}=\text{成本价格}+\text{平均利润}
$$

假设三个部门各预付100单位资本，资本全部在本期转移，剩余价值率均为100%。

| 部门 | 不变资本 | 可变资本 | 剩余价值 | 商品价值 |
|---|---:|---:|---:|---:|
| A | 90 | 10 | 10 | 110 |
| B | 80 | 20 | 20 | 120 |
| C | 70 | 30 | 30 | 130 |
| 合计 | 240 | 60 | 60 | 360 |

平均利润率：

$$
\overline{p'}=\frac{60}{300}=20\%
$$

每个部门的平均利润为20，生产价格均为120。

![[Assets/Marxism_20261125_Fundamentals_16c09463808a4ddc_assets/images/marx_average_69887bc1-5dcb-41a0-b581-8c957e7cfa9d.png]]

*图：部门A、B、C的商品价值与生产价格对比*

在这一马克思主义理论模型中，社会总生产价格等于社会总价值，平均利润总额等于剩余价值总额。

#### 4.19.4 剩余价值的分配形式

| 形式 | 基本含义 |
|---|---|
| 产业利润 | 产业资本取得的利润 |
| 商业利润 | 商业资本通过参与剩余价值分配取得的利润 |
| 利息 | 借贷资本所获得的收入 |
| 企业主收入 | 职能资本所有者在支付利息后获得的利润部分 |
| 资本主义地租 | 土地所有者凭土地所有权获得的相关收入 |

### 4.20 社会总资本的再生产

马克思将社会生产划分为两大部类。

| 部类 | 生产对象 |
|---|---|
| 第一部类 I | 生产资料 |
| 第二部类 II | 消费资料 |

在简单再生产模型中，两大部类之间实现交换的基本条件为：

$$
I(v+m)=IIc
$$

即第一部类劳动者和资本所有者用于消费的新增价值，需要与第二部类用于补偿生产资料的价值实现相应交换。

这一理论强调社会生产不仅需要价值补偿，还需要实物补偿及不同生产部门之间保持适当比例。

### 4.21 资本主义社会的基本矛盾

马克思主义认为，资本主义的基本矛盾是**生产社会化与生产资料资本主义私人占有之间的矛盾**。

| 矛盾表现 | 内容 |
|---|---|
| 企业内部与社会生产之间 | 企业内部可以有组织、有计划，而社会生产整体受到市场竞争等因素影响 |
| 生产能力与有效需求之间 | 生产能力扩张可能与具有支付能力的社会需求发生冲突 |
| 阶级关系方面 | 资本所有者与雇佣劳动者之间存在利益关系和矛盾 |

### 4.22 资本主义经济危机

马克思主义经济危机理论强调，资本主义经济危机的实质是相对生产过剩。

这里的过剩不是社会绝对不需要相关产品，而是相对于具有支付能力的需求而言出现过剩。

例如，市场上可能存在大量未售出的住房，同时仍有部分人因购买能力不足而无法获得住房。

#### 4.22.1 经济危机的周期性

![[Assets/Marxism_20261125_Fundamentals_16c09463808a4ddc_assets/images/marx_crisis_059d2921-c1be-405d-a63b-0603bea493c9.png]]

*图：经济周期的经典四阶段示意。实际经济周期的持续时间、幅度及成因并不固定。*

经济危机的周期性运动通常被概括为危机、萧条、复苏和繁荣四个阶段。

固定资本的大规模更新被视为资本主义经济危机周期性的一项物质基础，但并非现实经济周期的唯一决定因素。

### 4.23 资本主义上层建筑

资本主义上层建筑包括相应的政治制度、法律制度和意识形态。

按照大陆高校马克思主义政治经济学教学，分析资本主义政治制度时，需要同时认识其在近代历史中反对封建特权、建立现代法治和政治制度等方面的进步作用，以及其受到资本主义经济基础和社会利益关系制约的一面。

这一分析还涉及国家职能、代议制度、选举制度、政党制度、自由平等观念和资本对政治活动的影响等问题。

## 第五章　资本主义的发展及其趋势

本章研究资本主义从自由竞争阶段发展到垄断阶段的过程，以及国家干预、金融资本、经济全球化与当代资本主义的新变化。

### 5.1 自由竞争资本主义与垄断资本主义

| 比较 | 自由竞争资本主义 | 垄断资本主义 |
|---|---|---|
| 企业结构 | 大量相互竞争的企业 | 大型企业及垄断组织影响增强 |
| 资本集中程度 | 相对较低 | 较高 |
| 市场竞争 | 自由竞争占主要地位 | 垄断条件下的竞争 |
| 资本组织 | 个别产业资本较为突出 | 金融资本、垄断组织影响突出 |

垄断是生产和资本集中发展到一定程度后形成的经济现象。

![[Assets/Marxism_20261125_Fundamentals_16c09463808a4ddc_assets/images/marx_monopoly_d11251fb-0cb6-40b6-b282-015193f6f880.png]]

*图：生产集中和资本集中可能推动市场力量集中，并不意味着所有市场最终都形成单一企业垄断。*

### 5.2 垄断组织及其形式

| 组织形式 | 特点 |
|---|---|
| 卡特尔 | 企业通过协议协调价格、产量或销售市场 |
| 辛迪加 | 企业统一组织采购或销售，生产方面保持一定独立性 |
| 托拉斯 | 多个企业合并，形成较为统一的经营组织 |
| 康采恩 | 通过金融控制、股权关系等形成大型企业集团 |

这些是经典政治经济学中的垄断组织形式。在现代经济中，还可以考察企业集团、跨国公司、平台企业及不同市场结构。

### 5.3 垄断与竞争的关系

垄断产生于竞争，但并不能完全消除竞争。

竞争可以存在于垄断企业之间、垄断企业与非垄断企业之间以及不同国家的资本集团之间。

垄断条件下的竞争往往涉及技术、资本规模、供应链、市场控制力等多个方面。

### 5.4 垄断利润与垄断价格

垄断利润是垄断资本凭借其市场地位取得的超过一般平均利润的高额利润。

垄断价格一般可概括为：

$$
\text{垄断价格}=\text{成本价格}+\text{垄断利润}
$$

经典理论区分垄断高价和垄断低价。垄断企业可能通过较高的销售价格或较低的采购价格，在社会价值分配中取得有利地位。

按照马克思主义劳动价值论，垄断价格并没有改变价值创造的根本来源，而是影响价值和剩余价值的实现与分配。

### 5.5 金融资本与金融寡头

金融资本在经典垄断资本主义理论中，指工业垄断资本与银行垄断资本融合形成的资本形态。

金融寡头是控制大量金融资本，并对经济生活与政治生活产生重大影响的少数资本集团。

其控制方式主要包括：

| 方式 | 含义 |
|---|---|
| 参与制 | 通过股权控制、控股公司等方式影响其他企业 |
| 资本关系网络 | 通过融资、投资和信用关系形成控制能力 |
| 政治影响 | 通过人员联系及其他制度性渠道影响公共政策 |

这里的金融资本具有特定的马克思主义政治经济学含义，不等同于日常金融学中所有可用于投资的资金。

### 5.6 国家垄断资本主义

国家垄断资本主义是国家政权和私人垄断资本相结合的资本主义形态。

主要表现形式包括国家直接经营某些企业、国家与私人资本共同参与经营、国家通过财政金融政策等方式进行经济调节，以及政府采购、产业支持等活动。

国家干预经济可以缓解一定时期的经济矛盾、促进基础设施和公共服务发展，但按照该理论，其并不必然改变资本主义生产关系的基本性质。

### 5.7 列宁关于帝国主义的理论

列宁在研究20世纪初资本主义发展时，概括出帝国主义的五个基本经济特征：

| 特征 | 内容 |
|---|---|
| 垄断组织的形成 | 生产和资本集中达到较高程度 |
| 金融资本形成 | 银行资本与工业资本融合 |
| 资本输出 | 资本输出具有突出的经济意义 |
| 国际垄断同盟 | 不同垄断资本集团参与世界市场的划分 |
| 世界领土划分 | 当时主要资本主义列强已基本完成对世界领土的瓜分 |

这一理论形成于特定历史时期，应用于当代国际经济和政治问题时，需要结合历史背景与现实变化具体分析。

### 5.8 商品输出与资本输出

| 比较 | 商品输出 | 资本输出 |
|---|---|---|
| 输出对象 | 商品和服务 | 资本 |
| 主要目的 | 实现商品价值 | 获取投资收益或其他资本收益 |
| 典型形式 | 国际贸易 | 对外投资、跨国融资 |

资本输出可以采取借贷资本输出和生产资本输出等形式。

### 5.9 经济全球化

经济全球化是不同国家和地区的经济活动日益相互联系、相互依赖的过程。

#### 5.9.1 经济全球化的主要表现

![[Assets/Marxism_20261125_Fundamentals_16c09463808a4ddc_assets/images/marx_globalization_b5509d12-c908-469e-8db7-ad9fddf9901b.png]]

*图：生产、贸易、金融与科技全球化*

#### 5.9.2 经济全球化的推动因素

科技进步、交通通信条件改善、跨国公司发展、国际分工深化、贸易投资自由化以及国际金融市场的发展，均是经济全球化的重要推动因素。

#### 5.9.3 经济全球化的双重影响

| 积极影响 | 风险与挑战 |
|---|---|
| 促进资源跨境配置 | 收益和风险分布不均衡 |
| 推动国际贸易发展 | 部分产业和就业受到冲击 |
| 促进技术交流 | 可能形成技术依赖 |
| 扩大投资和市场机会 | 金融风险跨境传播 |
| 深化国际分工 | 全球产业链可能面临中断风险 |

经济全球化不等于政治一体化，也不意味着各国的发展水平自动趋于一致。

### 5.10 当代资本主义的新变化

第二次世界大战以后，资本主义社会在生产力、所有制结构、劳动关系、分配制度和经济调节机制等方面发生了重要变化。

| 领域 | 主要表现 |
|---|---|
| 生产力 | 自动化、信息化、数字化和人工智能发展 |
| 所有制结构 | 股份公司、机构投资者和多样化资本组织发展 |
| 劳动关系 | 服务业增长、新型就业及劳动组织变化 |
| 收入分配 | 税收调节、社会福利和社会保障制度发展 |
| 国家调节 | 财政政策、货币政策、产业政策等广泛应用 |
| 产业结构 | 知识经济、平台经济和高技术产业发展 |
| 金融结构 | 金融市场扩大、资产管理和金融工具发展 |

按照教材的分析，产生这些变化的原因包括科学技术革命、生产力发展、劳动者争取权益的实践、社会制度之间的相互影响，以及资本主义自身的调节机制。

教材强调这些变化能够调整资本主义的具体运行方式，但并不因此认为资本主义的基本经济制度已经发生根本改变。

### 5.11 资本主义的历史地位

马克思主义历史理论肯定资本主义在打破封建生产关系、发展社会生产力、推动科学技术进步、建立世界市场等方面的历史作用，同时批判其生产资料私人占有、剩余价值生产、经济危机以及社会利益冲突等问题。

### 5.12 资本主义的发展趋势

大陆高校教材依据历史唯物主义与资本主义基本矛盾理论，提出资本主义被社会主义所代替的历史趋势，并强调这一历史过程具有长期性、复杂性和曲折性。

这一结论属于马克思主义的社会历史理论判断，不是关于某个资本主义国家在具体年份必然发生制度更替的可精确预测。

## 第六章　社会主义的发展及其规律

本章主要研究社会主义思想的历史演进、科学社会主义的形成、社会主义制度的实践及发展道路。

### 6.1 社会主义思想的发展历程

![[Assets/Marxism_20261125_Fundamentals_16c09463808a4ddc_assets/images/marx_socialism_history_07f77ede-0a83-4000-84f8-721b6edfb7fd.png]]

*图：社会主义思想与实践的发展历程*

- **16世纪：早期空想社会主义**——1516年，托马斯·莫尔发表《乌托邦》。
- **18世纪：空想社会主义进一步发展**——出现更多关于财产关系、社会平等和理想制度的理论构想。
- **19世纪初：批判的空想社会主义**——圣西门、傅立叶、欧文成为主要代表。
- **1848年：科学社会主义形成**——《共产党宣言》发表。
- **1871年：巴黎公社**——无产阶级建立自身政权的重要历史尝试。
- **1917年：俄国十月革命**——社会主义从理论走向国家制度层面的实践。
- **第二次世界大战以后**——社会主义实践由一国发展到多国。
- **20世纪末以来**——社会主义实践经历重大曲折，不同国家继续探索各自的发展道路。

### 6.2 空想社会主义

空想社会主义是科学社会主义形成之前，对资本主义进行批判并提出理想社会构想的社会主义思想。

#### 6.2.1 主要代表人物

| 人物 | 主要思想或实践 |
|---|---|
| 托马斯·莫尔 | 《乌托邦》，构想与现实私有制社会不同的理想制度 |
| 圣西门 | 重视工业发展与有组织的社会生产 |
| 傅立叶 | 构想以协作和集体生活为基础的社会组织 |
| 罗伯特·欧文 | 改善工人生活条件，并开展合作社和社会实验 |

#### 6.2.2 空想社会主义的历史贡献与局限性

| 历史贡献 | 理论局限 |
|---|---|
| 揭露资本主义社会中的不平等和社会问题 | 未能系统揭示资本主义社会发展的客观规律 |
| 提出新的社会组织构想 | 未能充分认识实现社会变革的现实力量 |
| 关注劳动者权益及社会公平 | 对理想社会的实现方式具有较强的主观构想性质 |

### 6.3 科学社会主义的形成

马克思主义理论认为，唯物史观和剩余价值学说的创立，使社会主义从空想发展为科学。

| 理论基础 | 作用 |
|---|---|
| 唯物史观 | 从社会物质生产及基本矛盾出发解释社会发展 |
| 剩余价值学说 | 分析资本主义生产方式中的价值增殖和阶级关系 |

![[Assets/Marxism_20261125_Fundamentals_16c09463808a4ddc_assets/images/marx_scientific_c30f0e9e-a164-4a1f-a84a-0f10a9ead608.png]]

*图：唯物史观与剩余价值学说构成科学社会主义的理论基础*

#### 6.3.1 空想社会主义与科学社会主义的区别

| 比较 | 空想社会主义 | 科学社会主义 |
|---|---|---|
| 理论基础 | 道德批判及理想社会构想 | 唯物史观和剩余价值学说 |
| 社会发展分析 | 注重对现存社会弊端的批判 | 强调社会生产关系和历史规律 |
| 实践力量 | 往往寄希望于社会各阶层接受理想方案 | 强调无产阶级和人民群众的历史作用 |
| 实现方式 | 理想制度设计、示范实验等 | 社会实践与生产关系的历史变革 |

### 6.4 科学社会主义的基本原则

按照大陆高校的教学体系，科学社会主义基本原则可以从以下维度进行掌握。

| 维度 | 主要理论内容 |
|---|---|
| 历史发展 | 依据社会基本矛盾研究社会形态演进 |
| 政治主体 | 强调人民群众的主体地位和马克思主义政党的领导作用 |
| 经济制度 | 强调生产资料社会占有和社会主义经济制度建设 |
| 生产目的 | 解放和发展生产力，满足人民不断增长的物质文化需要 |
| 分配制度 | 社会主义阶段实行按劳分配等与具体发展条件相适应的制度 |
| 社会治理 | 发展社会主义民主，保障人民权益 |
| 精神文化 | 推动社会主义文化和精神文明建设 |
| 最终目标 | 推动人的自由全面发展，实现共产主义理想 |

科学社会主义的基本原则与各国社会主义建设中的具体制度形式需要加以区分。基本原则并不意味着所有国家必须采用完全相同的经济体制、政策安排和发展道路。

### 6.5 社会主义从理论到实践

#### 6.5.1 巴黎公社

1871年巴黎公社是无产阶级建立自身政权的重要尝试，对马克思主义国家学说和社会变革理论产生了重要影响。

#### 6.5.2 十月革命

1917年俄国十月革命使社会主义由理论构想进入国家制度实践阶段。

#### 6.5.3 苏联社会主义实践

苏联在工业化、基础设施、教育和科学技术等方面取得过重要成果，其制度运行也出现经济管理体制僵化、激励不足、官僚主义等问题。

1991年苏联解体是世界社会主义发展历程中的重大曲折。

大陆高校教材通常强调，应当区分社会主义基本原则与特定社会主义建设模式，不能把某一具体制度模式的失败直接等同于全部社会主义理论和实践的失败。

### 6.6 社会主义发展道路的多样性

社会主义发展道路具有多样性，其原因主要包括不同国家的生产力水平、历史文化传统、社会制度基础、国际环境和现实发展任务存在差异。

因此，需要把科学社会主义的一般原则与具体国家的实际条件结合起来。

这一思想与第一章的矛盾普遍性和特殊性原理、第二章的实践与认识原理相互联系。

### 6.7 社会主义建设的长期性

社会主义建设不是一次性完成的，其长期性主要与以下因素有关：

| 因素 | 含义 |
|---|---|
| 生产力发展 | 物质技术基础的形成需要长期积累 |
| 社会制度建设 | 经济、政治及社会制度需要不断完善 |
| 人的发展 | 教育、文化、公共服务和人的能力发展需要长期过程 |
| 理论与实践 | 社会主义建设规律需要在实践中不断探索 |
| 国际环境 | 国际竞争、经济联系和外部环境不断变化 |

### 6.8 社会主义社会的基本矛盾

社会主义社会仍然存在生产力与生产关系、经济基础与上层建筑之间的矛盾。

社会主义制度的建立不意味着社会矛盾完全消失。

按照大陆高校教材的理论，社会主义社会的基本矛盾可以通过社会主义制度的自我完善和发展得到调整和解决，改革是推动社会主义社会发展的重要方式。

### 6.9 中国特色社会主义

中国特色社会主义是在中国具体历史条件和社会实践中探索形成的社会主义发展道路。

#### 6.9.1 中国特色社会主义的基本构成

| 构成 | 含义 |
|---|---|
| 中国特色社会主义道路 | 社会主义现代化建设的实践道路 |
| 中国特色社会主义理论体系 | 马克思主义中国化时代化的重要理论成果 |
| 中国特色社会主义制度 | 中国社会主义建设形成的制度体系 |
| 中国特色社会主义文化 | 社会主义文化建设及其相关思想文化成果 |

#### 6.9.2 社会主义初级阶段

大陆高校教材将社会主义初级阶段理解为中国在生产力水平及社会发展条件等方面所处的特定历史阶段。

其理论强调中国已经进入社会主义社会，但社会主义制度的完善、生产力发展和现代化建设仍需经过较长历史过程。

#### 6.9.3 社会主义基本经济制度

中国社会主义基本经济制度包括：

| 方面 | 主要内容 |
|---|---|
| 所有制 | 公有制为主体、多种所有制经济共同发展 |
| 分配制度 | 按劳分配为主体、多种分配方式并存 |
| 经济体制 | 社会主义市场经济体制 |

#### 6.9.4 计划与市场的关系

计划和市场都是调节经济活动、配置资源的手段，并不能单独作为划分社会主义与资本主义的根本标准。

| 概念 | 研究对象 |
|---|---|
| 社会主义与资本主义 | 社会基本制度及其生产关系 |
| 计划与市场 | 资源配置方式和经济运行机制 |
| 公有制与私有制 | 生产资料所有制关系 |

社会主义市场经济理论强调发挥市场在资源配置中的决定性作用，更好发挥政府作用。

因此，商品经济、市场交易、金融活动和资本使用并非只能存在于资本主义社会。

#### 6.9.5 社会主义共同富裕

共同富裕强调发展成果的合理共享，既涉及生产力发展和财富创造，也涉及收入分配、公共服务、社会保障与发展机会。

共同富裕不等于同步富裕、同等富裕或平均主义。

## 第七章　共产主义崇高理想及其最终实现

本章研究马克思主义对未来社会的理论构想、共产主义的基本特征以及社会主义与共产主义的历史联系。

### 7.1 马克思主义预见未来社会的方法

马克思主义关于未来社会的研究，主要强调从现实社会的发展条件和矛盾运动出发，依据社会发展规律进行分析。

它不同于直接设计一套脱离历史条件、适用于所有社会的详细制度蓝图。

其方法主要包括研究现实社会的经济关系和发展趋势、分析未来社会形成所需要的客观条件，以及在社会实践中不断检验和发展相关理论认识。

### 7.2 共产主义社会的基本特征

![[Assets/Marxism_20261125_Fundamentals_16c09463808a4ddc_assets/images/marx_communism_5615f944-3658-4d55-bf8f-0fa2867de62b.png]]

*图：共产主义社会的物质条件、社会关系与人的发展*

#### 7.2.1 物质财富极大丰富

在共产主义理论构想中，社会生产力高度发展，物质财富能够充分满足社会成员合理的物质文化需要，并具备实行按需分配的条件。

#### 7.2.2 社会关系高度和谐

共产主义社会的理论构想包括消除阶级对立和剥削关系，逐步消除旧式社会分工所造成的人的片面发展，推动社会关系发生根本变化。

#### 7.2.3 人的自由全面发展

人的自由全面发展是共产主义社会的重要价值目标。

它不仅指物质生活改善，还包括个人能力、教育文化水平、社会交往、创造性和自主发展空间的提升。

### 7.3 社会主义与共产主义的关系

在马克思主义经典理论中，共产主义社会可以区分为第一阶段与高级阶段。后来通常将第一阶段称为社会主义社会。

| 比较 | 社会主义阶段 | 共产主义高级阶段 |
|---|---|---|
| 生产力 | 不断发展，受具体历史条件制约 | 高度发展 |
| 分配原则 | 按劳分配等 | 各尽所能，按需分配 |
| 社会关系 | 仍需解决现实社会矛盾 | 阶级对立消除，社会关系发生深刻变化 |
| 国家的地位 | 国家仍然发挥重要作用 | 按经典理论，作为阶级统治工具的国家逐渐消亡 |
| 人的发展 | 不断创造全面发展的条件 | 人的自由全面发展得到充分实现 |

按需分配不是不受资源约束的无限消费，而是以生产力高度发展和相应社会条件成熟为前提的理论构想。

### 7.4 共产主义实现的历史条件

| 条件 | 主要内容 |
|---|---|
| 物质条件 | 生产力高度发展 |
| 经济条件 | 生产关系与生产方式发生相应变化 |
| 社会条件 | 社会关系和社会组织方式的发展 |
| 文化条件 | 教育、文化和精神生活水平提高 |
| 人的条件 | 社会成员能力、素质和自由发展程度提高 |

### 7.5 实现共产主义的长期性

马克思主义认为，共产主义的实现是一个长期的历史过程，不能脱离现实社会发展条件而人为设定具体时间表。

大陆高校教材将共产主义作为远大理想，将中国特色社会主义现代化建设等现实任务与长期社会发展目标联系起来。

### 7.6 共产主义远大理想与中国特色社会主义共同理想

| 理想 | 理论地位 |
|---|---|
| 共产主义远大理想 | 马克思主义的最终社会理想 |
| 中国特色社会主义共同理想 | 中国社会主义建设现阶段的共同奋斗目标 |

二者属于长远目标与现实发展任务之间的关系。

## 第十部分　政治经济学公式汇总

### 10.1 商品与货币

| 名称 | 公式 |
|---|---|
| 劳动生产率 | $a=\dfrac{Q}{t}$ |
| 单位商品价值量与社会劳动生产率关系 | $w\propto\dfrac{1}{a}$ |
| 简化货币流通量 | $M=\dfrac{\sum PQ}{V}$ |
| 资本流通总公式 | $G-W-G'$ |
| 货币增殖量 | $\Delta G=G'-G$ |

### 10.2 资本与剩余价值

| 名称 | 公式 |
|---|---|
| 商品价值 | $W=c+v+m$ |
| 新创造的价值 | $W_{\text{新}}=v+m$ |
| 成本价格 | $k=c+v$ |
| 剩余价值率 | $m'=\dfrac{m}{v}\times100\%$ |
| 剩余价值量 | $m=m'v$ |
| 劳动时间表示的剩余价值率 | $m'=\dfrac{t_{\text{剩余}}}{t_{\text{必要}}}\times100\%$ |
| 资本有机构成 | $c:v$ |

### 10.3 资本周转与利润

| 名称 | 公式 |
|---|---|
| 资本周转时间 | $t=t_{\text{生产}}+t_{\text{流通}}$ |
| 资本周转次数 | $n=\dfrac{T}{t}$ |
| 年剩余价值量 | $M=m'vn$ |
| 年剩余价值率 | $M'=m'n$ |
| 利润率 | $p'=\dfrac{m}{C}\times100\%$ |
| 平均利润率 | $\overline{p'}=\dfrac{\sum m_i}{\sum C_i}\times100\%$ |
| 平均利润 | $\overline p=C\overline{p'}$ |
| 生产价格 | $k+\overline p$ |

其中，$C$ 表示全部预付资本。涉及固定资本折旧时，预付资本与当期耗费资本应当区别计算。计算乘积时，百分数形式的比率按小数代入。

## 第十二部分　运用马克思主义分析实际问题

马克思主义基本原理不应只停留于概念辨析。比较重要的是理解不同理论能够用于分析什么问题，以及它们的适用条件和局限。

### 12.1 人工智能与社会发展

| 分析角度 | 可以研究的问题 |
|---|---|
| 物质与意识 | 人工智能系统与人类意识之间的区别 |
| 生产力 | 人工智能如何改变生产效率和劳动工具 |
| 生产关系 | 技术进步如何影响就业、劳动组织及收益分配 |
| 社会基本矛盾 | 原有制度与新技术发展之间的适应问题 |
| 真理与价值 | 技术可行性与技术应用伦理之间的关系 |
| 矛盾分析法 | 人工智能的经济收益、就业影响和潜在风险 |

### 12.2 企业经营与市场竞争

| 分析角度 | 可以研究的问题 |
|---|---|
| 劳动生产率 | 企业为什么重视技术创新和降低成本 |
| 个别价值与社会价值 | 企业如何形成竞争优势 |
| 价值规律 | 供求变化如何影响价格与资源流动 |
| 资本积累 | 企业为什么将部分收益用于扩大生产 |
| 资本集中 | 企业兼并收购如何改变市场结构 |
| 垄断理论 | 大型企业如何形成市场控制力 |

### 12.3 金融市场与经济波动

| 分析角度 | 可以研究的问题 |
|---|---|
| 货币理论 | 货币流通、支付和经济交换 |
| 借贷资本 | 利息、融资活动与资本收益 |
| 金融资本 | 金融机构与产业资本之间的关系 |
| 资本输出 | 跨境投资和国际资本流动 |
| 经济全球化 | 国际金融市场的相互联系 |
| 经济危机理论 | 生产、需求、债务与经济波动之间的关系 |

> [!note] 适用范围
> 马克思主义政治经济学能够提供关于金融活动、生产关系和经济利益结构的分析视角，但它并不直接提供股票估值、技术分析、资产定价或者投资交易策略。研究这些具体问题，还需要现代经济学、金融学、统计学等知识。

## 第十四部分　总体学习规划

从知识的重要性、抽象程度、应用价值以及概念之间的依赖关系综合考虑，可以将马克思主义基本原理分为三个学习阶段。

|---|---:|---|---|
